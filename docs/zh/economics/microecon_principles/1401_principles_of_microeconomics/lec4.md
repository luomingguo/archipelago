# Lec 4 需求曲线与收入/替代效应

> MIT 14.01 Principles of Microeconomics · Lecture 4 · Jonathan Gruber

## TL;DR

- 价格变动对需求的影响可严格解耦为纯相对价格变动的替代效应，以及购买力变动的收入效应。
- 正常品与普通劣等品的总效应均为负，确保需求曲线严格向下倾斜；吉芬商品则呈现正斜率特例。
- 斯勒茨基补偿与希克斯补偿从不同数学定义下分离效用恒定与购买力恒定，奠定了需求弹性理论。

> MIT 14.01 · Principles of Microeconomics · 主讲 Jonathan Gruber

## 推导需求曲线

- **需求曲线（demand curve）**表示价格与需求量之间的关系。我们通常通过消费者选择理论（consumer choice theory）来推导需求曲线：在保持收入不变的前提下，改变价格。

## 弹性

- **需求价格弹性（price elasticity of demand）**定义为：

$$
\epsilon = \frac{\delta Q/Q}{\delta P/P}
$$

  例如，如果价格每上涨 1%，需求量下降 2%，则 $\epsilon = -2$。
- **完全无弹性需求（perfectly inelastic demand）**：无论价格如何变化，需求量都不变，$\epsilon = 0$。当某商品没有可行的替代品时，其需求很可能是完全无弹性的。
- **完全弹性需求（perfectly elastic demand）**：价格只要发生任何变动，需求量就会降为零，$\epsilon = -\infty$。当存在完美替代品时，其需求很可能是完全弹性的。
- 弹性决定了消费者对价格变化的反应方式，进而影响厂商收入：
  - 若弹性在 0 到 −1 之间，厂商可以通过提价来增加收入（因为消费者仍会购买相当数量的商品）；
  - 若 $\epsilon < -1$，提价则会导致厂商收入下降。
- 要准确估计弹性，需要观察**供给曲线的移动**（例如对供给方征税会使供给曲线向上移动，导致均衡价格上升、均衡数量下降，由此可以计算出需求的价格弹性）。

## 需求曲线的移动

- 要**描出（trace out）**一条需求曲线，需要在保持收入不变的情况下改变价格；要**移动（shift）**一条需求曲线，需要在保持价格不变的情况下改变收入。
- **恩格尔曲线（"Engel Curve"）**展示了收入与消费量之间的直接关系。
- **需求收入弹性（income elasticity of demand）**衡量收入变化时消费量如何变化：

$$
\gamma = \frac{\delta Q/Q}{\delta Y/Y}
$$

  - 大多数商品是**正常品（normal goods）**：收入弹性为正，即收入上升时，其消费量也会增加。
  - **劣等品（inferior goods）**的收入弹性为负，即收入上升时其消费量反而下降。
  - **必需品（necessities）**是 $\gamma < 1$ 的商品：随着收入上升，你花在必需品上的收入占比会变小。
  - **奢侈品（luxuries）**是 $\gamma > 1$ 的商品：随着收入上升，你花在奢侈品上的收入占比会变大。

## 收入效应与替代效应

- 价格上涨会产生两种效应：**收入效应（income effect）**和**替代效应（substitution effect）**。
- **替代效应**是指在效用（utility）保持不变的前提下，某商品价格变化所引起的需求量变化。
  - 当某商品相对变贵时，替代效应体现为你在多大程度上转向购买其他商品。
- **收入效应**是指在价格保持不变的前提下，由收入变化所引起的某商品需求量变化。
  - 价格上涨实际上相当于降低了消费者的实际收入，这会对需求产生一种独立的效应。
- 对正常品而言，收入效应与替代效应方向一致——二者都会随收入上升而使需求量下降；但对劣等品而言，收入效应与替代效应方向相反。因此，替代效应恒为负，而收入效应可正可负。
- 由此，价格上涨对某商品消费量的总效应，对正常品而言可以是负的，对劣等品而言也可能是正的（当收入效应大于替代效应时）。

| 价格变化 | 替代效应 | 收入效应 | 总效应 |
|---|---|---|---|
| 正常品涨价 | ≤ 0 | ≤ 0 | ≤ 0 |
| 正常品降价 | ≥ 0 | ≥ 0 | ≥ 0 |
| 劣等品涨价 | ≤ 0 | ≥ 0 | 不确定 |
| 劣等品降价 | ≥ 0 | ≤ 0 | 不确定 |

- **吉芬商品（Giffen good）**是自身价格弹性为正的商品——即价格上涨反而使需求量增加的极端劣等品。

::: insight 价格信号的双重变形
当一件商品涨价时，它在两个完全不同的维度撕裂消费者的行为：其一是它相对其他替代品变得更昂贵（纯粹相对价格扭曲），其二是它暗中剥夺了消费者的实质财富（隐性实际收入缩水）。斯勒茨基分解的伟大之处，在于为实证经济学家提供了一把精密手术刀，能够将这两种混杂的力量剥离得一清二楚。
:::

## 复习要点

**概念理解**

- 能解释"沿需求曲线移动"与"需求曲线整体移动"的区别。
- 能解释需求/供给弹性对均衡变化意味着什么。
- 能解释价格变化后观察到的数量变化，对收入效应和替代效应分别意味着什么。

**图形与数学理解**

- 给定需求的代数表达式，能计算曲线上任意一点的需求价格弹性。
- 能画出预算约束线，并说明当某商品价格变化或消费者收入变化时，该线如何移动或旋转。
- 给定效用函数、其中一种商品的价格和收入水平，能用数学方法推导出需求曲线。
- 给定效用函数和两种商品的价格，能用数学方法推导出恩格尔曲线。
- 能在展示消费者最优组合的图形中，画出并计算价格变化的效应；能将该效应在图形上分解为收入效应和替代效应。

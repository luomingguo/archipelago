# Lec 7 完全竞争 I

> MIT 14.01 Principles of Microeconomics · Lecture 7 · Jonathan Gruber

## TL;DR

- 完全竞争市场中企业作为价格接受者面临水平需求曲线，利润最大化条件简化为价格等于边际成本。
- 短期内只要市场价格高于平均可变成本最低点（$P > AVC_{min}$），企业即使亏损固定成本也应维持生产。
- 沉没成本属于历史已发生的不可逆支出，在任何理性的边际经营决策中均应严格忽略。

> MIT 14.01 · Principles of Microeconomics · 主讲 Jonathan Gruber

## 完全竞争（Perfect Competition）

- 市场中的企业在产品市场和要素市场两侧都是价格接受者（price takers）。
- 完全竞争的成立条件：
  - 企业销售同质产品（firms sell identical products）；
  - 消费者了解市场上所有企业的定价（consumers know prices charged by all firms in market）；
  - 消费者在不同购买机会之间搜寻的交易成本（transaction costs）非常低。

## 短期利润最大化（Short Run Profit Maximization）

在短期（short run），假设没有企业进入或退出市场。

- 企业选择产量 $q$ 以最大化利润：

$$\max \pi(q) = R(q) - C(q)$$

其中 $R(q)$ 是企业销售产量 $q$ 所获得的总收益（total revenue），$C(q)$ 是总成本（total cost）。

- 对利润函数求一阶导数并令其为零：

$$\frac{\partial \pi(q)}{\partial q} = \frac{\partial R(q)}{\partial q} - \frac{\partial C(q)}{\partial q} = 0$$

$$\frac{\partial R(q)}{\partial q} = \frac{\partial C(q)}{\partial q}$$

$$MR = MC$$

即边际收益（marginal revenue, $MR$）等于边际成本（marginal cost, $MC$）时，企业实现利润最大化。

- 在完全竞争市场中，边际收益 $MR$ 等于市场价格 $p$。因此企业生产至 $MR = MC = p$ 为止。
- 短期内，完全竞争企业面对一条完全弹性（perfectly elastic）的需求曲线，即 $MR = p$。因此对完全竞争企业而言，$P = MC$。
- 停产决策（shutdown decisions）：只要价格能覆盖企业的可变成本（variable costs），企业短期内就会继续生产。只有当 $P < \min AVC$（平均可变成本的最小值）时，企业才会选择停产。

## 短期与长期供给（Short Run and Long Run Supply）

- 企业的短期供给曲线（short-run supply）是其 $MC$ 曲线中位于 $\min AVC$（平均可变成本最小值）以上的部分。
- 企业的长期供给曲线（long-run supply）是其 $MC$ 曲线中位于 $ATC$（平均总成本，average total cost）以上的部分。
- 市场供给（market supply）是所有企业各自供给曲线的水平加总（horizontal sum）。
- 短期均衡（short run equilibrium）发生在市场需求曲线与市场供给曲线的交点，该交点决定均衡价格；随后每家企业按 $MC = p$ 决定各自的产量。

::: insight 沉没成本与边际理性的决裂
完全竞争企业的停产原则是全人类最难克服的心理难关：如果今天关门，厂房租金照样要付；因此只要卖出的每一块钱能填补原材料和工人工资（$P > AVC$），哪怕账面严重亏损，继续开工依然是理性的最优解！承认已经沉没的固定成本不是资产而是过眼云烟，是经济学生涯第一堂残酷而清醒的成人礼。
:::

## 复习要点

**概念理解（Conceptual Understanding）**

- 解释/掌握企业在（1）短期和（2）长期分别在什么条件下会停产。
- 解释企业在长期会在什么情况下进入或退出市场。
- 理解为什么完全竞争市场中企业短期内会按 $MR = MC = p$ 生产。

**图形与数学理解（Graphical and Math Understanding）**

- 给定生产函数和成本函数，会计算 $MR$ 和 $MC$。
- 在完全竞争市场中，给定企业的短期成本曲线，能求出该企业的短期供给曲线。
- 在完全竞争市场中，能用图形展示随着企业数量增加，市场总供给如何变化。
- 在完全竞争市场的短期情形下，给定企业的成本曲线、市场需求以及企业数量，能求出均衡价格、每家企业的产量以及市场总产量。

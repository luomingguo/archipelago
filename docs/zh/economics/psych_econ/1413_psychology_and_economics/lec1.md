# Lec 1 行为经济学导论与标准模型的局限（Introduction and Overview I）

> MIT 14.13 · Psychology and Economics · 主讲 Frank Schilbach

## TL;DR

- 心理学与经济学（行为经济学）通过引入心理学洞见改进经济模型，使其更贴近现实并增强预测力。
- 检视“完全理性、完全自利、完全自控”三大新古典假说的现实反例与系统性偏差。
- 确立优秀模型的评价标准：简约性、可操作性、可推广性与可证伪性；新模型应嵌套完全理性特例。
- 确立研究路线：识别行为反常现象 → 提出心理假设 → 建立数学模型 → 检验市场与福利含义。

## "心理与经济学"研究什么

- 一个工作定义：心理与经济学是研究心理因素与经济因素对行为的共同影响的学术领域（Rabin, 2002）。更宽泛的版本还会纳入医学、社会学、人类学等学科的证据。
- 与常见说法"行为经济学（Behavioral Economics）"基本同义。
- 核心目标不是描述心理现象本身，而是**用这些洞见改进经济模型**，使其更真实、预测更准。

## 标准模型假设的"理性经济人"是谁

标准经济学模型（Rabin, 2002 总结）通常假设决策者：

- 拥有良定义（well-defined）且稳定的偏好；
- 是贝叶斯信息处理者，能够最优地处理信息；
- 追求期望效用最大化；
- 采用指数贴现（exponential discounting）来权衡当前与未来的福祉；
- 是（狭义上）自利的，即只关心自己（或家庭）的效用；
- 只在意最终结果，不在意达成结果的过程或变化路径；
- 对信念或信息本身没有"偏好"（即不因为知道或不知道某事本身而获得或损失效用）。

::: pitfall 这些假设的现实反例
课堂讨论提示我们可以从日常生活中找到大量反例：健身房门口的电梯挤满了想健身却懒得走楼梯的人，新年计划（如"减肥"）在年初集中出现随后迅速消退（Google Trends 数据可见"calories"和"weight watchers"搜索量的锯齿状季节性），电视剧《豪斯医生》中人物对信息本身抱有强烈的好奇或恐惧（对信念的偏好），器官捐献默认选项（opt-in vs. opt-out）在不同国家造成的捐献率天差地别（丹麦 4.25% vs. 奥地利 99.98%，Johnson and Goldstein, 2003），GlowCaps 智能药瓶靠灯光和声音提醒吃药来提高依从性，以及 GiveDirectly 这样的慈善机构证明人们确实关心陌生人的福祉。这些现象都难以被"完全理性、完全自利、完全自控"的标准假设直接解释。
:::

## Homo Economicus 的三个"过度"

大多数心理与经济学的研究者认为，古典的理性经济人假设走向了三个极端：

- **过度理性（too rational）**：人们会犯错，而且这些错误往往是系统性、可预测的，而非随机噪声。
- **过度自利（too selfish）**：人们并不只关心自己（或家庭）的利益，慈善捐赠约占美国 GDP 的 2%（2015 年约 3733 亿美元）就是证据之一。
- **过度自控（too willful）**：良好的意图不总能转化为后续的实际行动，减肥计划、储蓄目标、戒烟意愿等常常"知行不一"。

::: pitfall 几乎没有经济学家真的相信标准假设完全成立
关键问题不是"标准假设是否精确为真"（几乎肯定不是），而是：这些偏差是否重要？哪些偏差是重要的？只有能显著改变预测或政策含义的偏差，才值得引入模型。
:::

## 什么样的经济模型算"好"

- 模型（model）是对世界的简化表征。多数模型基于"近似为真、精确为假"的假设——就像把地球建模为平面、球面、椭球体或质点，都不会还原每一处地表起伏，但依然是有用的近似。
- Gabaix and Laibson (2008) 提出评价一个模型的七条标准：

::: definition 好模型的七个属性（Gabaix and Laibson, 2008）
1. 简约性（parsimony）：模型是否足够简单？
2. 可操作性（tractability）：模型是否便于分析和求解？
3. 概念启发性（conceptual insightfulness）：模型是否揭示了某个重要的思想？
4. 可推广性（generalizability）：模型能否应用于多种不同情境？
5. 可证伪性（falsifiability）：模型是否给出可检验的预测？
6. 经验一致性（empirical consistency）：模型是否与已知事实相符？
7. 预测精度（predictive precision）：模型的预测是否足够精确？
:::

- 标准模型的假设（完全理性、完全自利、完全自控）在简约性上得分很高：假设越简单，模型往往越易于分析。让模型在心理学意义上更真实，通常意味着更复杂、更难分析。
- 因此关键问题不是"标准假设是否对大多数人成立"（答案是否定的），而是：（1）能否用可操作的方式让某些假设更真实；（2）这样做能否更好地解释重要的现实现象。

## 好的行为经济学家仍然是好的经济学家

::: pitfall 行为经济学不是要推翻主流经济学
行为经济学的目标不是**取代**标准经济理论，而是**基于心理学等学科的证据去增强（augment）它**。主流经济学的关键原则依然成立：决策者总体上是高度精明的，市场和激励在塑造行为中起核心作用，市场在大多数时候能有效配置资源。
:::

- 关键方法论原则也保持不变：
  - 继续使用观察数据和实验数据；
  - 数学模型仍是表达知识、推导含义的有效工具；
  - 新模型应当能够"嵌套"完全理性这一特例（即让心理参数取某个极限值时退化为标准模型），从而保持与既有理论的连续性。
- 一个提醒行为经济学局限性的例子：Ito et al. (2018) 在日本冬季用电实验中比较"道德劝说"（moral suasion）和"经济激励"（economic incentive，即价格）对节能的效果，发现价格手段在几乎所有周期中的效果都显著强于单纯的说服（用电减少的对数点数明显更高）。这提醒我们：很多时候，价格仍然是影响选择最重要的因素，不能因为强调心理因素而忽视了传统的激励机制。

## 本课程分析每个主题的方法论

1. 从直观、经验或实验证据出发，观察人们在某些情境下的真实行为。
2. 思考可能是什么在驱动这种行为，或人们是如何看待该情境的。
3. 把假设精确化，识别备择假设，并思考如何用数据区分不同假设。
4. 探讨这些假设能解释什么、对市场、福利和其他后果有何含义。

## 案例研究：课堂是否应允许使用电子设备

这是贯穿全课程方法论的一个具体演练：

- **经济学考量**：笔记本电脑对部分学生是有用的记笔记工具，但也可能被用于与课堂无关的活动。
- **心理学考量**：
  - 对附近同学产生负外部性（分心），因为人的注意力有限；
  - 人们往往高估自己"多任务并行"的能力（过度自信，overconfidence）；
  - 网络上充斥着分散注意力和诱惑的内容，会削弱人们"专心听课"的初衷（诱惑与present bias 相关）；
  - 人们通常不喜欢强硬的家长主义（hard paternalism），即被强制剥夺选择权。

::: example 政策选项的比较
针对课堂电子设备问题，可能的政策包括：完全自由放任（laissez-faire）、教育性干预、对使用笔记本征税并再分配、全面禁止（医疗需要除外）、以"无笔记本区"为默认并允许选择进入"笔记本区"（opt-in）、以"笔记本区"为默认并允许选择退出（opt-out）、或设置两个区域让学生主动选择（active choice）。这些选项的差异恰恰体现了默认选项设置（default）对行为的影响——呼应前文器官捐献默认选项的例子。

现实证据也支持负外部性的存在：West Point 一项随机对照实验（Carter et al., 2017）发现，允许在课堂使用电脑会使期末考试成绩下降 0.18 个标准差，无论是不限制使用还是仅允许"平板模式"，负面效应都存在。本课程采取的做法是设立"笔记本区"，安排在教室前方一侧。
:::

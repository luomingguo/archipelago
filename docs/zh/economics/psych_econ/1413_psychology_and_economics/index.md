# 14.13 心理学与经济学

## TL;DR

- 本课程将新古典经济学的完全理性、自利与无限意志力假设，替换为基于心理学实证的行为模型。
- 系统涵盖时间偏好（拟双曲贴现与承诺机制）、风险与参照点依赖（前景理论与损失厌恶）、以及社会偏好。
- 进一步探讨有限注意力、信念驱动效用、投射偏差与默认选项助推，并评估其福利与政策设计含义。

## 课程信息

主讲教师 Frank Schilbach（Spring 2020）。这门课把标准新古典经济学中"完全理性、自利、意志力无限"的行为人假设，替换为更贴近实证证据的心理学修正：有限自利、有限意志力、参照点依赖、有限注意力和信念驱动的效用。课程沿着"理论修正 → 实证检验 → 政策应用"的主线展开：先在时间偏好、风险偏好、参照点依赖、社会偏好上分别建立行为模型，再讨论有限注意力、信念效用（学习）、状态依赖偏好与投射偏差、性别与身份、默认选项与助推、偏好的可塑性，最后落到贫困、幸福与心理健康、以及行为经济学政策设计上。

# Lec 23 行为主体下的政策设计（Policy with Behavioral Agents）

> MIT 14.13 · Psychology and Economics · 主讲 Frank Schilbach

## TL;DR

- 行为福利经济学致力于在个体行为存在偏差的情形下重新定义社会福利函数。
- 区分强硬家长制、自由主义家长制（Nudge）与不对称家长制（Asymmetric Paternalism）。
- 不对称家长制主张：政策应大幅帮助犯错的有偏差者，同时对完全理性者造成最小摩擦。
- 总结行为政策的伦理边界、操纵隐患以及政府在市场透明度与消费者保护中的规制职责。

## 政府干预个人选择的第五种理由：内部性

政府对经济生活的传统干预通常被归为几类：宏观经济政策（如美联储的货币政策、财政刺激）、竞争政策（如反垄断法）、再分配与社会保险（失业保险、社会保障）、以及针对外部性和其他市场失灵的干预（如香烟税、对创新的支持）。行为经济学为政府干预个人选择提供了第五种理由：

::: definition 内部性（internality）
消费者没有完全或恰当地将自己的选择施加给（未来的）自己的成本和/或收益纳入决策考量。与外部性（externality）不同，内部性描述的是一个人的选择对自己（尤其是未来自我）造成的、未被当下决策充分权衡的代价或收益，而不是对他人的溢出效应。
:::

内部性的存在，为在不诉诸外部性的情况下干预个人选择提供了理论空间——这正是本讲讨论"家长主义"的出发点。

## 家长主义的定义与分类

::: definition 家长主义（paternalism）
- Merriam-Webster 定义：一种由权威机构承担起满足或管制其管辖范围内个人需求或行为的制度，涉及这些个人自身事务以及他们与权威及彼此的关系。
- David Laibson 的定义：试图为了人们自身的利益而影响或控制其行为——换言之，当干预的动机与外部性无关时，就构成家长主义。
:::

家长主义的正当性判断，取决于是否存在讲座此前反复讨论过的各类行为偏误，包括非标准偏好（时间偏好、风险与参照点依赖偏好、社会偏好）、非标准信念（注意力有限、学习失败、过度乐观、投射与归因偏误、动机性信念）以及非标准决策过程（性别歧视、默认/框架/助推的影响、贫困、幸福与心理健康问题）——这些正是本课程此前各讲的核心主题，本讲把它们汇聚到政策设计的问题上。

::: definition 硬家长主义与软家长主义
- **硬家长主义（hard paternalism）**：强制改变人们的选择，包括显著改变价格、强制规定选择或程序、禁止某些产品、征税。
- **软家长主义（soft paternalism）**：
  - **自由主义家长主义（libertarian paternalism, Thaler & Sunstein, 2003）**：以建设性方式影响行为，同时保留或几乎完全保留选择自由。
  - **非对称家长主义（asymmetric paternalism, Camerer et al., 2003）**：帮助那些犯错的人，同时对本来就理性行事的人尽量减少干扰。
:::

## 现实中家长主义政策的接受度并不遵循硬/软二分

反对家长主义的常见论点包括：个人比政府拥有更好的信息；干预可能因误解个人真实偏好而适得其反；如果人们本来就在自主优化，干预是多余的；对理性人而言，被扭曲的选择反而使其境况变差；政府本身可能效率低下、浪费资源，或者并不总以消费者利益为重（存在被"监管俘获"regulatory capture 的风险）；选择自由本身具有内在价值；不同人可能偏好不同的家长主义政策，难以取得一致；此外还有实际执行层面的困难。支持家长主义的论点则包括：人们确实会犯错；许多人本身并不喜欢自己做选择；软家长主义框架下理性人可以自由选择退出/不受影响，因而在很大程度上化解了上述大部分反对意见。

讲座用美国公众对肥胖率的自我认知偏差（1990–2014 年间，实际超重/肥胖人口比例从约 56% 上升到 70.4%，而自认为超重的人口比例却从约 48% 下降到 36%）说明"人们确实在犯认知错误"这一支持家长主义的经验前提是有据可依的。

但现实政策的社会接受度分布，并不完全对应理论上的软硬区分：

::: pitfall 相对受欢迎与相对不受欢迎的家长主义政策
**相对受欢迎（其中多数属硬家长主义）**：社会保障（Social Security）、面向退休人员的医疗保障（如 Medicare）、限制 401(k) 投资菜单范围、消费者安全监管（如 FDA）、义务教育、香烟"罪恶税"、卖淫禁令、一夫多妻禁令、（在部分州）强制口罩令；软家长主义的例子包括校园自动售货机禁售垃圾食品、卡路里标示法规、401(k) 默认加入。

**相对不受欢迎（均属硬家长主义）**：头盔法、安全带法、垃圾食品禁令与相关税收、其他"罪恶税"、酒精禁令、色情内容管制法、赌博管制法、（在部分州）强制口罩令、纽约市对 16 盎司以上含糖饮料的限购令。
:::

这份对比清单说明，公众对某项政策的接受与否，并不严格取决于它是硬性强制还是柔性引导，而更多取决于该政策所触及的行为领域、既有的社会规范和政治文化——这是理论分类（软/硬）与现实政治可行性之间需要区分的重要一点。此外，各州香烟税（每包最高逾 4 美元）和烈酒税（各州差异极大，最低在科罗拉多和密苏里，最高在华盛顿和俄勒冈）的巨大差异，也说明即便是社会普遍接受的"罪恶税"这类硬家长主义工具，其力度在不同司法辖区间也存在悬殊差异。

## 助推的力量与局限

::: example 自动加入养老金计划（automatic enrollment）
将 401(k) 默认养老金计划的注册方式从"自愿加入"改为"默认加入、可退出"，各年龄段的参与率都出现巨幅跃升（如 Vanguard 覆盖约 400 个计划、80 万参与者的数据显示，多个年龄组的参与率提升超过 10–20 个百分点）。这类默认选项调整仅仅改变了"不作为"的后果，完全不限制个人选择自由，却能带来极大的行为变化，是自由主义家长主义"小成本、大影响"的经典例证。
:::

::: example 提醒与表格设计对法庭出庭率的影响
针对传票接收人是否按时出庭（failure-to-appear, FTA），仅仅重新设计传票表单，就使 FTA 率从 41% 降至 36%；进一步辅以短信提醒后，FTA 率可降至 26%。这是一种典型的低成本"助推"，无需改变任何实质性法律后果或经济激励，仅通过信息呈现与提醒方式的优化即可产生可观的行为改善。
:::

不过讲座也提醒对助推效果不宜盲目乐观：

::: pitfall 学术论文中的助推效应量系统性大于实际推广后的效应量
DellaVigna & Linos 比较了发表于学术期刊的助推研究与实际"助推单位"（nudge units，专门在政府或机构内部推广行为科学干预的团队）在大规模现实场景中实施类似干预后报告的效应量，发现学术样本中的效应量普遍显著更大、更分散，而现实推广后的效应量普遍集中在更小、更接近零的区间。这提示学术文献可能存在发表偏倚（只有效果显著的研究更容易发表）或情境特殊性（实验室/试点场景的效应未必能在大规模、异质化人群中复制），实际政策制定应对助推效果的预期保持审慎。
:::

::: pitfall 并非所有人都欢迎被助推
一项针对家庭能源使用报告（Home Energy Reports，向用户展示自己与邻居的用电对比）的研究发现，相当比例的消费者愿意支付一笔正的金额来**避免**收到这类比较信息（Figure 7 显示不同支付意愿区间上均有可观的受访者比例愿意为"不被打扰"付费），说明有些人明确不喜欢被助推，即便这类信息通常被证明能有效降低能耗。这提醒政策设计者，"对大多数人有益"不等于"对所有人都受欢迎"，选择自由的保留（软家长主义的核心特征）因此具有独立价值，不只是对硬家长主义的一种妥协。
:::

::: pitfall 滑溜设计（sludge）：助推技术的阴暗面
与助推相对的是"滑溜"（sludge）：利用同样的行为设计工具（摩擦、默认选项、复杂流程）故意让人更难做出对自己有利的选择，以谋取设计者一方的利益。典型例子是商家提供购物返利（rebate）优惠，但要求消费者手动邮寄纸质申请表才能兑现，导致返利实际兑现率极低；公共部门中类似的例子包括故意复杂化的报税或选民登记流程。识别并消除滑溜设计，本身就可以是一项高价值的政策干预。
:::

## Save More Tomorrow：自由主义家长主义的教科书案例

Thaler & Benartzi (2004) 受一家希望提高员工储蓄率的公司委托设计养老金方案。该公司最初的做法是聘请财务顾问，让员工与顾问一对一沟通并根据自身财务状况制定储蓄计划——顾问会给出建议储蓄率，部分员工采纳并执行。但研究者注意到：那些主动选择不采纳顾问建议的员工，恰恰是原本储蓄倾向最弱的一群人（一种负向选择，"研究者拿到的是被筛剩下的一群人"），传统的一对一财务建议模式对这批人几乎无效。

::: definition Save More Tomorrow (SMarT) 计划的机制
1. 在下一次预定加薪之前相当长的一段时间，向员工介绍该计划；
2. 员工自愿加入；一旦加入，从其下一次加薪后的第一张工资单开始，其养老金缴存比例自动提高（提高幅度小于加薪幅度本身，因此到手工资仍然上升，只是涨幅变小）；
3. 此后每逢加薪，缴存比例持续按计划自动上调，直至达到预设上限；
4. 员工可随时通过一通电话加一份表格选择退出计划。
:::

该计划之所以属于自由主义家长主义，关键在于机制的第 2 步（自愿加入）和第 4 步（随时可退出）：整个计划完全自愿，员工可以随时离开，本质上只是**扩大**而非限制了员工的选择集。首次实施的结果（Table 2）显示出显著的动态效应：从未联系过财务顾问的员工储蓄率维持在约 6% 左右几乎不变；接受顾问建议但未加入 SMarT 的员工储蓄率约在 8–9% 区间波动；而加入 SMarT 计划的员工储蓄率从加入前的约 3.5% 一路提升，历经四次加薪后升至约 13.6%——不仅远超其他各组的初始水平，增长幅度也最为显著。

::: theorem SMarT 计划同时利用了三种行为机制
1. **将牺牲推迟到未来**：储蓄增加发生在下一次加薪时而非当下，从而规避了人们在当期表现出的短视/当下偏误（present bias）对"现在少花钱"的抵触；
2. **避免消费者感知到损失**：由于缴存增加的幅度小于加薪幅度，员工的到手收入依然在上升（只是涨幅有所减少），而不是从当前收入水平中被"扣走"一部分，从而规避了参照点依赖/损失厌恶造成的心理抵触——员工体验到的仍是一次"加薪"，而非一次"减薪"；
3. **把储蓄设为默认路径**：一旦加入，后续的持续加码是自动发生的默认设置，退出才需要主动采取行动（打电话、填表），借助默认效应和当下偏误本身，反过来帮助那些原本因拖延或短视而难以自主提高储蓄率的人坚持储蓄，而对不适合这一方案的人，退出成本也被刻意设计得很低。
:::

## 市场能否自发解决自我控制问题

面对自我控制问题（如信用卡过度消费），一种常见的经济学直觉是：如果消费者是老练的（sophisticated），他们会主动需求某种"承诺工具"（commitment device）来约束自己未来的行为，那么逐利的市场参与者自然会提供满足这种需求的产品，政府无需介入。讲座对这一直觉提出了系统性的质疑：

::: pitfall 市场本身也是自我控制问题的一部分
市场中确实存在帮助消费者建立自我控制的力量，但同时也存在**利用**消费者自我控制缺陷来获利的力量，两者同时存在、相互对抗：

1. 如果消费者确实重视并需求自我控制工具，厂商确实有利润动机去提供它；
2. 但厂商（甚至同一家厂商）也可以通过利用消费者的短视而非纠正它来获利，因此同样有动机去**削弱**消费者可能拥有的自我控制能力。

第二种力量的存在，严重限制了市场自发提供有效自我控制工具的能力。Ru & Schoar (2017) 的研究发现，信用卡公司会刻意设计产品条款以精准瞄准天真型（naive）消费者——而这些消费者恰恰是最容易被利用、且往往认为自己不需要任何帮助的人群，这使问题进一步恶化：最需要保护的人往往最不觉得自己需要保护。
:::

正因如此，政府事实上已经在许多场景中限制市场中"削弱自我控制"的力量：香烟、毒品、赌博广告的诸多形式已被禁止，利率设有上限，消费者金融保护局（CFPB）等机构专门负责这类消费者保护职能——这些既有制度安排本身，就是对"市场无法自动解决自我控制问题"这一判断的政策回应，而非纯粹理论推演的结果。

## 课程总结

::: pitfall 本讲及全课程的核心结论
- 部分形式的软家长主义能够在几乎不损害任何人选择自由的前提下，明确改善部分人群的福利，是较为稳妥、争议较小的政策工具；
- 但助推并非没有代价：设计不当的助推可能适得其反，也可能被滥用为"滑溜"损害消费者利益；
- 并非所有人都乐于被助推，这种偏好本身值得被尊重，是保留选择自由这一原则的重要理由；
- 市场无法自动解决所有问题，尤其是在自我控制这类内部性问题上，市场内部同时存在正反两股力量的拉锯；
- 消除"滑溜"式的摩擦障碍，有时本身就能带来很大的福利改善，且争议远小于增设新的家长主义干预。
:::

课程的收尾建议回到个人层面：理解自己的行为偏误、在关乎长期利益的领域（工作、人际关系等）多一些内省和主动试验、寻求他人建议，同时也不必对自己过于苛责——很多时候，人更容易看清并帮助朋友的问题，而不是自己的问题；这一原则同样适用于团队、激励机制和产品的设计。

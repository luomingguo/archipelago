# 14.13 心理学与经济学（Spring 20）

## 先行条件

14.01 微观经济学

## 课程信息

心理学与经济学（又称行为经济学）是经济学的一个新兴分支，它将心理学和其他社会科学的洞见融入经济学之中。本课程回顾主流经济模型中的基础假设，探讨人类行为如何系统性偏离这些假设，并介绍行为经济学的最新进展。应用领域涵盖劳动经济学、公共经济学、产业组织、卫生经济学、金融学和发展经济学。

主讲教师 Frank Schilbach（Spring 2020）。课程将标准新古典经济学中“完全理性、自利、意志力无限”的行为人假设，替换为更贴近实证证据的心理学修正：有限自利、有限意志力、参照点依赖、有限注意力和信念驱动的效用。课程沿着“理论修正 → 实证检验 → 政策应用”主线展开：先在时间偏好、风险偏好、参照点依赖、社会偏好上分别建立行为模型，再讨论有限注意力、信念效用（学习）、状态依赖偏好与投射偏差、性别与身份、默认选项与助推、偏好的可塑性，最后落脚于贫困、幸福与心理健康，以及行为经济学政策设计。

# Lec 8 Risk-Sharing Application

> 一句话：完全风险分担的基准预测：个体特有收入冲击主要通过转移由共同体吸收。

## 模型与推理

若家庭可无摩擦地相互保险，家庭消费应更多跟随共同体总资源，而较少随自身短期收入波动。讲座用印度与其他村庄资料比较消费—收入关系，并区分事后转移与事前安排。

## 条件与易错点

“消费不随收入变”是强基准，不是所有村庄的既定事实。共同冲击无法在共同体内部完全分散；测量误差、储蓄与家庭类型也影响经验检验。

## 可能需要的图

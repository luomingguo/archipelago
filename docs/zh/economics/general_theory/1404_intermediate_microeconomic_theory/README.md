# MIT 14.04 中级微观经济理论笔记

课程：**14.04 Intermediate Microeconomic Theory, Fall 2020**，Robert M. Townsend 授课。MIT OpenCourseWare 发布 21 讲视频及 3 场复习课；此目录保存全部对应的 transcript PDF、字幕 VTT、提取文本与中文笔记。

课程主线：从**消费者/企业最优化**出发，扩展到**不确定性、跨期选择、风险分担与合同**，再建立**一般均衡与福利定理**，最后用数据检验模型并分析其失效条件。

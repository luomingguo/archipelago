# 14.02 宏观经济学原理

> 课程：MIT 14.02 Principles of Macroeconomics, Spring 2023 · Ricardo J. Caballero 授课。

## TL;DR

- 课程围绕短期、中期与长期三个时间维度展开现代宏观经济学核心理论与政策分析。
- 短期以商品与金融市场均衡为主线，建立 IS-LM 模型分析需求管理与财政货币政策。
- 中期引入劳动力市场与菲利普斯曲线（IS-LM-PC），刻画通胀动态与潜在产出调整。
- 长期探讨索洛资本积累与技术增长，并扩展至蒙代尔-弗莱明开放经济与金融资产预期。

## 课程全景主线

1. **短期**：商品需求决定产出；金融市场决定利率，IS-LM 把两者联立求均衡。实际利率、预期通胀和信用利差影响实体融资与总支出。
2. **中期**：工资与价格逐渐调整，劳动力市场决定自然失业率与潜在产出；菲利普斯曲线将产出缺口与通胀动态联系起来。
3. **长期**：资本积累提高人均产出水平，但受边际报酬递减规律制约；技术进步是持续提升人均生活水平的根本驱动力。
4. **开放经济**：净出口受国内外需求和实际汇率影响；资本流动和汇率制度决定了财政、货币政策的相对有效性。
5. **预期**：资产价格、跨期消费和投资决策取决于对未来现金流、利率、税收与风险的信念，政策的信誉与预期管理至关重要。

::: insight
现代宏观经济学的核心价值在于提供一套结构化的思考透镜：先界定政策问题的时间尺度（短期平抑衰退还是长期促进繁荣），再识别约束条件与潜在传导瓶颈。掌握这门课程不是为了背诵教条，而是学会在复杂甚至互相冲突的数据中保持清醒的因果推断定力。
:::

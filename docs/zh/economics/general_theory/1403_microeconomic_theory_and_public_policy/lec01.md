# Lecture Slide 1: Introduction and a First Application

> 一句话：理论与证据要并用：模型给出机制和可检验预测，因果设计检验政策是否真的造成观察到的变化。

## 理论、识别与政策推理

本讲以现实政策问题引入供给、需求和均衡，同时比较随机试验、自然实验与观察性数据。因果效应是同一单位在“接受政策”与“未接受政策”两种潜在状态的差；现实只能看到其中一种，因而需要可信的反事实。

## 适用条件与易错点

相关性可能来自选择进入政策、共同趋势或反向因果。读研究时先说清处理、结果、比较组与识别假设。

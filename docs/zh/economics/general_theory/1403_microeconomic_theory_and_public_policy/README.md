# MIT 14.03 微观经济理论与公共政策笔记

课程：**14.03/14.003 Microeconomic Theory and Public Policy, Fall 2025**，David Autor 授课。MIT OCW 公开了覆盖第 1–23 讲的 21 份讲义 PDF；第 2–3 讲、第 7–8 讲各共用一份。课程页未列出讲座视频或 transcript，因此这里分析的是讲义，而不是视频字幕。

本课程的主线是：**微观模型提出机制 → 研究设计识别因果效应 → 比较政策福利与分配结果**。读每讲时都问：谁受政策影响？反事实是什么？模型条件是否成立？

## 使用说明

每份笔记包含核心结论、理论与政策推理、适用条件、可能需要的图和自测。仓库中的 `sources/` 保存原 PDF，`text/` 保存提取文本；公式、图轴和论文细节可回到原件核对。复习时建议先掌握消费者选择和市场均衡，再把差分中的差分、工具变量等因果识别方法用于政策案例。

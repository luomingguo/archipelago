# Lec 11 面向环境可持续性的设计（Design for Environmental Sustainability）

> 对应Spring 2026 Class 12。原始链接：[课程大纲](https://studylib.net/doc/28287998/syllabuspdd-spring-2026--1-)；核心阅读：[PDD第8版](https://www.mheducation.com/highered/product/Product-Design-and-Development-Ulrich.html)第12章。

## TL;DR

- 面向环境的设计把材料、制造、运输、使用与报废阶段放在同一生命周期中比较，避免只优化最显眼却影响很小的环节。
- 比较必须使用相同功能单位，并优先处理主导影响；轻量、耐用、低能耗、可维修和可回收并不总能同时最大化。
- Sprint 4要求评估量产产品及相关服务，而非只评估课程原型，并说明环境收益相较竞品是否成立。

## 生命周期边界

团队应明确原材料获取、零件制造、装配、运输、使用、维护和末端处理的系统边界。若只统计产品重量，却忽略多年使用能耗，可能把影响从一个阶段转移到另一个阶段。

::: definition [功能单位]
功能单位是环境比较所依据的等价服务，例如“五年内完成1000次清洁任务”，而不是“一台设备”。只有服务水平一致，方案间的影响才可比较。
:::

## Sprint 4的最低要求

1. 识别生产、使用和相关服务中的主要环境影响。
2. 找出影响最大的阶段与材料或能量流。
3. 提出减少热点影响的可执行方案。
4. 若产品声称具有环境收益，与竞争方案在相同功能单位下比较。
5. 必要时使用课程提供的Sustainable Minds在线分析软件。

::: pitfall [把可回收等同于可持续]
材料理论上可回收，不代表当地存在回收系统，也不代表回收收益足以抵消生产或使用阶段影响。设计声明必须说明现实回收路径和系统边界。
:::

::: insight [先找热点，再谈材料美德]
可持续设计最容易陷入符号化选择，例如把一种材料替换成“绿色材料”。先确定生命周期热点，才能判断改变材料、延长寿命、降低能耗还是重新设计商业模式更有效。
:::

## 课前准备

- 阅读教材第12章“面向环境的设计”。
- 找一个相较替代方案具有明确环境收益的产品或服务，并说明比较边界。
- 可选阅读Oliver Franklin-Wallis关于回收的文章和Ellen MacArthur Foundation的Circular Design Guide。

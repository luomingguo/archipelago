# Lec 6 工业设计——从研究到硬模型的全流程（Industrial Design）

> MIT 15.783J / 2.739J · Product Design and Development · 主讲 Matt Kressy（RISD，Designturn）

## TL;DR

- 工业设计（ID）的使命是"提升用户体验"，具体拆解为形式/美学、简化的功能性、改善的人因（Human Factors）和"精神层面"（新奇、酷、时髦的 wow factor）四个维度，这四者缺一不可。
- 本讲用一张"ID 靶心图"给出学科定位：ID 位于人因工程（HF Engineering）、雕塑/美学造型（Sculpture/Aesthetics）与功能/机械电气制造（ME, EE, DFM）三者的交叉处，天然是跨学科的中介角色，而不是纯艺术工作。
- ID 的研究阶段（Research）覆盖市场、既有产品、终端用户、人因、跨学科约束五个方向；概念开发（Concept Development）依次通过草图、实体模型、人因模型、渲染四种媒介收敛设计；设计开发（Design Development）则通过控制图纸和硬模型把设计交付给下游工程与制造。
- 用户反馈不是一次性的"验证关卡"，而应贯穿从概念草图到最终模型的每一个阶段，形成持续对话。
- "成功的设计"被定义为对某个具体人类需求或市场做出彻底承诺，在功能、形式、人因、情感四个属性上都不能有明显短板，并且必须"诚实"——不能靠视觉语言掩饰产品实际不具备的功能或品质。

## 工业设计是什么

Kressy 把 ID 的使命定义为"增强用户体验"（Enhance the User's Experience），并拆成四个具体抓手：

- **形式/美学（Form / Aesthetics）**：产品的视觉语言和造型语汇。
- **简化的功能性（Simplified Functionality）**：不是堆砌功能，而是让功能的呈现更简单、更可理解。
- **改善的人因（Improved Human Factors）**：产品与人的物理和认知交互。
- **精神/氛围（Spirit）**：wow factor、新奇感、酷、时髦——这是四者中最难量化，但决定产品是否能引发情感共鸣的一环。

::: insight ID 的学科定位：三个圆的交集
幻灯片用一张靶心图把 ID 放在三个扇区的交界：**人因工程（HF Engineering）**、**美学/造型（Aesthetics / Sculpture）**、**功能（Function，对应 ME、EE、DFM 等工程约束）**。这张图的价值在于明确否定了"ID 就是给产品做外观"的误解——工业设计师的核心工作恰恰是在美学表达、工程可行性和人机交互之间反复折衷，任何一端被忽视，设计都会失败。这也解释了为什么本讲内容大量涉及跨学科协作，而不是纯粹的造型技巧。
:::

## 工业设计流程总览

课程给出一条五阶段的项目节奏（Phase 0 规划 → Phase 1 概念开发 → Phase 2 系统级设计 → Phase 3 详细设计 → Phase 4 测试与优化 → Phase 5 量产爬坡），并在其下叠加一条更细的 ID 专属工作流：

**Research（研究）→ Concept Development（概念开发：草图 → 实体模型 → 渲染）→ Design Development（设计开发：控制图纸 → 模型）**

这条线索的直觉是"从发散到收敛"：研究阶段收集尽可能多的信息和可能性（幻灯片用一团紧密的紫色球体表示信息/概念的高密度），随着草图、模型、渲染依次推进，可能性逐步收窄，到控制图纸和最终模型时只剩下一个确定方案（对应球体数量从"一大团"逐渐减少到"一颗"）。这种可视化本身就是对 ID 流程的一种论证：早期阶段的价值恰恰在于保持大量并行选项，而不是过早收敛到单一方案。

## 研究阶段的五个维度

### 市场（Market）

- **人群画像**：谁使用、谁购买、谁体验——三者未必是同一群人（例如儿童用品的购买者是家长，使用者和体验者是孩子）。
- **社会文化因素**：产品所嵌入的文化语境，幻灯片用"Barbie 还是 Harley"这个对比来提示同一类产品在不同亚文化中的造型语言可以截然不同。
- **美学参数**：当前的视觉语汇（vocabulary）和流行趋势（trends），即产品要放在什么样的审美坐标系里。
- **环境因素**：负责任的材料选择、DFR（Design for Recyclability，可回收性设计）。

### 既有产品（Existing Products）

通过**逆向工程**研究竞品和相关产品的美学、功能行为、机械特征、材料与制造工艺；同时研究**产品定位**，即竞品的功能配置和定价策略。幻灯片展示的例子是一堆早期数字电话答录/来电显示设备的拆解对比，直观说明逆向工程不是抄袭，而是理解一个产品品类里已经验证过的设计决策空间。

### 终端用户（End User）

- **使用环境**：物理环境与心理环境。
- **使用观察**：实际被使用的功能及其使用频率层级、误用（misuse）情况、动作-时间研究（time-motion study）。
- **与用户建立对话**：持续索取反馈、经常性地实地拜访用户，而不是做一次性的问卷或焦点小组。

### 人因（Human Factors）

- **人体工程学**：物理界面、图形用户界面（GUI）、触觉反馈。
- **直觉可用性（Intuitive Use）**：形式如何传达功能（form communicates function）、产品图形、图标与视觉一致性。这一条把"人因"从纯生理尺寸问题（够不够得着、看不看得清）扩展到了认知/语义层面——用户能否不看说明书就理解按钮的作用。

### 跨学科整合（Interdisciplinary Integration）

ID 不能脱离工程约束独立存在，研究阶段必须同时纳入：

- **机械要求**：产品架构、内部元件的空间包络（component envelopes）。
- **电气要求**：射频/电磁兼容性约束、热约束。
- **制造要求**：成本、优先采用的工艺。

幻灯片用一张产品外壳网格模型叠加内部电路板布线图的图示，直观表达"造型必须为电路板、屏蔽和散热让出空间"这一现实约束——好看的外形如果装不下电路，就不是可行的设计。

## 概念开发：四种收敛媒介

::: example 概念开发的四个阶段（以一款掌上电子设备为例）
1. **草图（Concept Sketches）**：优点是快速、可迭代，能综合前期研究并同时探索功能与美学构想；常用笔、马克笔、彩色铅笔，以及硫酸纸、白纸、新闻纸等媒介。幻灯片展示的是同一款设备的十余种造型和界面布局的快速手绘变体。
2. **实体模型（Form Models）**：同样强调快速迭代，但增加了"人因评估"与"形式评估"两项——纸面草图无法回答的抓握感、比例感,只有做成实物才能判断。技术上极其"低保真"：泡沫绝缘板、Foamcore 泡沫板、现成零件（found objects/existing parts）、松木条、砖块、热熔胶、双面胶、石膏板螺丝——刻意使用廉价易得的材料，目的是把决策周期压到最短。
3. **人因模型（Ergonomic Models）**：针对身高、体重、可动部件（articulating parts）等具体人体工程学问题制作的专项模型。展示图片中研究者弯腰操作一个明显超尺寸放大的白色模型，用于放大观察某个交互细节（很可能是研究洗衣机滚筒舱口的人体可达性）。
4. **渲染（Renderings）**：优点是能表现造型的细微处理（styling subtleties）和产品图形，且可直接用作销售工具和焦点小组材料——即渲染图不只是内部沟通物，也是对外验证概念的媒介。技术手段从马克笔、绘图胶带、彩色铅笔的传统渲染，扩展到 2D 插画软件与 3D 渲染软件。幻灯片展示的成品渲染是一款带液晶屏和两个按键的 "sni" 品牌掌上设备。
:::

## 设计开发：把设计交付给下游

概念定型后，ID 的产出需要转化成工程和制造能各自理解的语言：

- **控制图纸（Control Drawings）**：作用是"向下游传达工业设计意图"，手段包括传统制图工具、带尺寸标注的 2D 计算机图纸，以及 IGS、STL 等 3D 文件格式。幻灯片展示了一款医疗设备（"UltraBaby"，很可能是超声或婴儿监测类产品）外壳的线框渲染与详细尺寸标注图，圆角半径、壁厚等公差都被精确定义——这标志着 ID 的自由造型阶段正式过渡到可制造的工程规范。
- **硬模型（Hard Models）**：代表最终的美学和功能形态，但幻灯片特别强调"不一定是可运行的原型"（Not necessarily a prototype）——硬模型解决的是"看起来/摸起来是不是这个产品"，而不是"能不能工作"这个问题。技术手段包括快速成型工艺、橡胶模具、手工搭建与铣削、喷漆、干转印贴花。展示的是同一款 "sni" 设备的透明树脂外壳分解件和喷漆完工后的成品对比。

::: pitfall 控制图纸与硬模型容易被混淆的两个角色
控制图纸和硬模型都出现在"设计开发"阶段末尾，容易被误认为是同一件事的两种呈现，但它们服务的下游对象不同：控制图纸面向工程和制造团队，核心是尺寸和公差的精确性；硬模型面向决策者、市场和用户测试，核心是视觉与触感的真实性。二者可以并行制作而非先后替代——一个只做了精确图纸而没有实物模型的团队，很难在决策评审中获得对"手感"和"氛围"的直观反馈；反之只做实物模型而没有控制图纸，工程团队无法据此开模生产。
:::

## 用户反馈应贯穿全程

幻灯片用一张示意图强调：用户与利益相关者（Users & Stakeholders）不是流程末端的验收环节，而是与草图、实体模型、渲染、控制图纸、模型五个节点都存在双向箭头——即在每一个阶段都应该主动拿阶段性成果去获取反馈，再把反馈带回设计中。这与"研究-终端用户"一节里"经常性地实地拜访用户"的要求相呼应，说明本讲把用户参与视为一种持续机制，而非里程碑评审。

## 什么是成功的设计

课程给出的收尾判断标准并不复杂，但值得作为设计评审的检查清单：

::: insight 成功设计的三条标准
1. **对某个具体的人类需求或市场做出彻底承诺**，并在功能（Function）、形式（Form）、人因（Ergonomics）、情感（Emotion）四个属性上都有交代——这四个属性与开篇"提升用户体验"的四个抓手一一对应，说明整讲内容是一个自洽的闭环，而不是零散话题的堆砌。
2. **必须诚实（Must be honest）**：产品的造型语言不能暗示它具备实际不具备的功能或品质，这是对"形式传达功能"（Form communicates function）这条人因原则的伦理约束——形式可以简化和美化功能，但不能欺骗用户。
3. **不能在任何一个属性上完全失败**：即便某个产品在美学上极为出色，若人因体验糟糕到无法忍受，整体设计仍然不成功。这条标准直接呼应了开篇"ID 位于三个学科交界处"的定位——单一维度的极致不能替代多维度的及格线。
:::

## 待澄清与局限

本讲只有 17 页幻灯片，内容以流程框架和图片示例为主，缺乏具体产品的商业结果数据（销量、成本、市场反馈等量化信息），也没有展开某一具体案例的完整设计决策过程。幻灯片中反复出现的一款掌上液晶设备（品牌 "sni"，疑似来电显示器或寻呼类设备）以及一款疑似婴儿监护/超声设备（"UltraBaby"）很可能是 Kressy 本人参与过的实际项目，但幻灯片未给出产品背景说明，因此本讲笔记只描述了幻灯片中可见的设计阶段产出，未对这些产品的最终市场结果做任何推测。

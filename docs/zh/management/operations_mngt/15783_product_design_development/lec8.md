# Lec 8 原型制作（Prototyping）

> 对应Spring 2026 Class 9。原始链接：[课程大纲](https://studylib.net/doc/28287998/syllabuspdd-spring-2026--1-)；核心阅读：[PDD第8版](https://www.mheducation.com/highered/product/Product-Design-and-Development-Ulrich.html)第14章。

## TL;DR

- 原型是为回答特定问题而建立的近似物，可用于学习、沟通、集成和里程碑判断；不必在每个维度都接近最终产品。
- 每个原型计划都应先写风险和判定标准，再选择物理模型、分析、仿真或混合方法，避免用高保真掩盖错误问题。
- 课程要求概念草模、工作模型、精炼模型和Alpha原型逐轮吸收客户反馈，并明确原型与量产产品的差异。

## 先写问题，再选原型

团队可以分别验证工作原理、尺寸关系、操作顺序、外观感知、材料表现或系统集成。一个原型若同时试图回答所有问题，通常会变得昂贵、缓慢，而且失败后难以定位原因。

::: definition [聚焦原型]
聚焦原型只在与当前问题相关的维度上逼近目标产品。例如纸面界面可验证任务流，却不能证明真实设备的触感、速度或可靠性。
:::

## 课程中的演进

| 阶段 | 主要问题 | 典型成果 |
| --- | --- | --- |
| 概念模型 | 工作原理是否值得继续？ | 草图、草模、概念验证 |
| 工作模型 | 核心功能能否运行？ | 粗略功能原型、初步性能数据 |
| 精炼模型 | 功能、体验和集成是否接近目标？ | 测试计划、精炼模型、客户反馈 |
| Alpha原型 | 完整方案能否支持商业论证？ | 可演示原型、性能与使用测试 |

::: pitfall [把制作进度当学习进度]
完成更多零件不代表降低了更多风险。没有预先判定标准的“试试看”，很容易在看到结果后改变成功定义。
:::

::: insight [原型保真度应服从决策]
决定所需证据的是下一项不可逆承诺，而不是团队能够做出多漂亮的模型。采购昂贵模具前需要尺寸和制造证据，选择交互流程时则可能只需可点击界面。
:::

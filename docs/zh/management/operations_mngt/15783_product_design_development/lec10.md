# Lec 10 工业设计（Industrial Design）

> 对应Spring 2026 Class 11。原始链接：[课程大纲](https://studylib.net/doc/28287998/syllabuspdd-spring-2026--1-)；核心阅读：[PDD第8版](https://www.mheducation.com/highered/product/Product-Design-and-Development-Ulrich.html)第11章。

## TL;DR

- 工业设计把功能、人体能力、感知、美学、品牌和制造约束整合为可理解、可使用且可生产的产品形态。
- 形式不是在工程完成后附加的外壳；握持、控制、反馈、装配与维护会反过来影响架构、材料和关键尺寸。
- 草图、外观模型、人体工学模型和功能模型回答不同问题，评审时必须说明模型证明了什么、没有证明什么。

## 工业设计的责任

工业设计既处理产品如何被感知，也处理身体如何接近、握持、移动和控制产品。它需要与工程共同决定外部几何、控制位置、界面层级、材料触感、维护入口与制造分件，而不是等内部机构冻结后再“美化”。

::: definition [产品语义]
产品语义是形态、比例、材料、控制和反馈向使用者传达的意义，例如哪里可握、哪部分会移动、当前处于何种状态。它必须与真实功能一致。
:::

## 模型与评审

- 草图比较比例、构图和操作关系；
- 外观模型检查体量、曲面、材料与品牌语言；
- 人体工学模型验证触达、姿势、力量和尺寸；
- 功能模型验证机构与性能；
- 组合模型用于发现形式、界面和工程之间的冲突。

::: pitfall [把高保真当高确定性]
精致表面会让评审者误以为尺寸、机构和用户流程已经稳定。团队应明确标出仍可变化的部分，避免视觉完成度过早锁定决策。
:::

::: insight [工业设计是接口设计]
工业设计真正整合的是人—产品、零件—零件和产品—环境之间的接口。外观只是这些接口在物体表面的可见结果，而不是独立目标。
:::

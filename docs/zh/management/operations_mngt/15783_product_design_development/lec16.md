# Lec 16 产品测试与战略转向（Product Testing and Pivots）

> 对应Spring 2026 Class 19，以Airbnb在线案例讨论。原始链接：[课程大纲](https://studylib.net/doc/28287998/syllabuspdd-spring-2026--1-)；案例购买和课前讨论链接仅在Canvas提供。

## TL;DR

- 产品测试把需要、价值主张、可用性、性能和商业模式中的关键假设转成可观察结果；一次测试应优先回答一个会改变决策的问题。
- 战略转向是在证据否定关键假设后保留已验证资产、改变方向，不是每遇到困难就换点子，也不是坚持到资源耗尽。
- 产品—市场匹配不能由团队热情或少量好评证明，应观察目标用户是否持续采用、获得预期价值并愿意承担相应成本。

## 从假设到测试

测试计划应写明目标用户、待验证假设、刺激物或原型、任务、观察指标、成功与失败阈值，以及结果分别触发什么行动。课程在Class 19前要求通过Airbnb案例的小组讨论思考测试、转向和产品—市场匹配。

::: definition [战略转向]
战略转向是在愿景或已验证学习仍有价值时，对客户、问题、方案、渠道、收益方式或增长机制作出实质改变。它必须指出哪项旧假设被什么证据推翻。
:::

## 证据层级

| 证据 | 能回答的问题 | 主要限制 |
| --- | --- | --- |
| 访谈与概念反馈 | 问题是否相关、表达是否清楚 | 意向不等于行为 |
| 任务测试 | 用户能否理解并完成操作 | 受原型保真度限制 |
| 受控试用 | 产品能否在情境中交付价值 | 时间与样本可能有限 |
| 付费、留存与复用 | 用户是否愿意承担真实成本 | 需排除补贴和新奇效应 |

::: pitfall [用肯定回答证明PMF]
“我会用”“这个想法很好”成本很低，也容易受礼貌影响。更强证据来自用户投入时间、数据、金钱或声誉，并在没有研究人员提醒时再次使用。
:::

::: insight [预先写出转向条件]
团队在看到不利结果后容易改变解释。测试前写清何种结果会继续、修改、转向或停止，能把学习从叙事竞争变成可审查决策。
:::

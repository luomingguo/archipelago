# Lec 14 OEM 战略合作协议谈判与收益分成 (Negotiating an OEM Agreement: Structure and Leverage)

> MIT 15.387 · Entrepreneurial Sales · 模块三：国际扩张与高级渠道谈判

## TL;DR

- OEM（原始设备制造）战略合作能让初创企业一夜之间借力行业巨头的全球渠道完成出货。
- OEM 合作谈判的核心博弈在于最低保底采购量（Minimum Commitments）与独家排他权（Exclusivity）。
- 绝不在没有巨额保底条款的前提下轻易出让特定行业或区域的独家授权。
- 必须严格把控白标授权（White-Label）下的品牌露出底线与源代码知识产权保护。

## 什么是 OEM 合作？初创企业的甜蜜与毒药

对于拥有核心硬核算法或专利模组的技术初创团队而言，与思科、通用电气、惠普等全球巨头签署 OEM（Original Equipment Manufacturer）捆绑协议，具有难以抗拒的诱惑：

```mermaid
flowchart LR
    A["初创核心专利算法/模组"] -->|深度集成/内嵌| B["巨头核心大型产品系统"]
    B -->|打上巨头品牌商标 (White Label)| C["巨头遍布全球的数万销售铁军"]
    C -->|出货至世界 500 强企业| D["巨额出货量与装机量"]
```

| 利益诱惑 (The Pros) | 致命风险 (The Cons) |
| :--- | :--- |
| **瞬间实现全球规模分销**：零自建渠道成本触达数万家大客户 | **丧失终端客户掌控权**：无法直接与最终用户接触，丧失产品一手反馈 |
| **顶级行业巨头品牌背书**：极大提升初创公司在风投眼中的估值 | **极度不对称的议价权**：巨头占初创公司营收 80% 时，随时要求大幅压价 |
| **稳定的现金流与版税收入**：获得预付许可费与季度版税分成 | **巨头内部政治动荡**：一旦巨头内部换帅或项目取消，初创公司将被迫陪葬 |

## OEM 协议的核心条款博弈

Howard Anderson 在本讲深入剖析了初创公司在签署 OEM 协议时必须誓死捍卫的三大阵地：

::: definition OEM 谈判三大核心防御条款
1. **最低保底采购额 (Minimum Guaranteed Royalties)**：巨头若要求获得独家经营权（Exclusivity），必须签署具备惩罚性的年度最低现金打款承诺。若巨头出货未达标，初创公司有权无偿立即收回独家授权。
2. **知识产权审计与源代码保护 (Source Code & Audit Rights)**：坚决不向巨头交付底层源代码！所有技术以封装好的二进制库（SDK）或加密固件形式交付；设立第三方独立代码托管信托（Escrow），只有在初创公司依法破产倒闭时方可有限度触发查看。
3. **“最惠国”反向条款限制 (Most Favored Nation Restrictions)**：坚决拒绝巨头提出的“无条件享受全市场最低供货价”的单边霸王条款，保留与其他厂商开展非竞争性业务的自主定价空间。
:::

::: insight
面对行业巨头提出的“排他独家协议（Exclusive Deal）”，初创团队的态度应当是：**独家必须由真金白银买单**。如果巨头不愿在合同中写明前 3 年每年数百万美元的不可撤销保底采购支票，任何口头许诺的“战略未来”都是忽悠。
:::

::: pitfall
为了促成与巨头的合作，在合同中允许巨头享有“后续联合研发衍生专利的排他性共同所有权”。这会直接锁死初创企业未来的融资与上市通道，因为所有投资人都会担心巨头利用共有专利发起侵权禁令。
:::

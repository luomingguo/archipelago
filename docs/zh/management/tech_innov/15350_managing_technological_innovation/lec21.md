# Lec 21 颠覆性自我更新：内部研发破局 (Internal Sources of Renewal: Intel Lablets)

> MIT 15.350 · Managing Technological Innovation · 模块五：创新自我更新：驾驭颠覆

## TL;DR

- 成熟科技霸主最大的危机是现有核心业务的重力场，压制了一切可能颠覆自身的探索性研发。
- 传统企业中央大实验室（如 Xerox PARC、Bell Labs）由于脱离商业前线，面临巨额成果转化损耗。
- 英特尔首席技术官戴维·坦嫩豪斯（David Tennenhouse）开创了紧挨名校设立的“微型实验室网络（Lablets）”。
- Lablets 模式通过 90 天快速迭代、大学教授联合挂帅与代码完全开源，成功催生了 PlanetLab 等分布式云先驱。

## 传统中央大实验室（Central R&D Labs）的悲剧与反思

在工业科技史上，施乐帕克（Xerox PARC）发明了个人电脑图形界面、以太网、面向对象编程与激光打印，却几乎没有一项成为施乐的利润支柱；贝尔实验室发明了晶体管与 Unix，却无法拯救 AT&T 拆分的命运。

::: definition 英特尔 Lablets 微型前沿实验室模式
由 MIT 教授、英特尔前首席技术官戴维·坦嫩豪斯（David Tennenhouse）设计的颠覆性探索架构：
- **物理规模极小**：每个站点严格限制在 30 人以内，杜绝官僚体制与行政中层；
- **物理距离极近**：设立在顶尖名校计算机系大楼步行 5 分钟范围内，实现师生与企业研发人员日常自由无缝穿梭；
- **双重领导体制**：由一名学术权威教授与一名精通英特尔内部产品线的老牌研发总监联合治所。
:::

## 经典前瞻项目实证：PlanetLab 与微型无线传感器

英特尔微型实验室并不去优化当季奔腾 CPU 的流水线时钟，而是探索下一代计算形态：
- **PlanetLab（行星实验室）**：由普林斯顿与英特尔伯克利实验室联合发起，将全球数百所顶尖大学的服务器节点连成全球分布式试验床，成为后来亚马逊 AWS 与全球边缘计算（CDN）的原始雏形；
- **无线传感器网络（Smart Dust）**：在环境监测与工业健康排查领域，英特尔提前十年布局低功耗分布式射频算法，为英特尔芯片开辟了未来物联网（IoT）的全新蓝海。

::: insight
“大公司的探索性研发，必须有一只脚伸出大楼之外。”如果你把前沿探索科学家锁在封闭的企业研发大厦里，他们最终一定会被日常的产品线补丁升级和政治协调吸干精力；**紧挨大学、拥抱开源、保持轻巧**，是企业抵御自我僵化的最强抗体。
:::

::: pitfall
用短期产品的季度 KPI 去考核探索性实验室。如果要求探索 10 年后技术形态的科学家按季度提交能带来多少百万销售额的报表，实验室在三个月内就会退化为平庸的二线技术支持维护部。
:::

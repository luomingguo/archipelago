# Lec 9 核心能力与竞争定位 (Core Definition and Competitive Positioning)

> MIT 15.390 · New Enterprises · 模块三：价值主张与产品规格

## TL;DR

- 核心能力（Core）是企业内部最具防御性、竞品在数年内极难复制的不对称优势。
- 核心能力不同于知识产权或先发优势；真正的 Core 通常表现为极低成本结构、网络效应或专属用户黏性。
- 竞争定位图（Step 11）通过二维坐标系直观展现：在客户最关心的前两大关键购买准则上，企业如何全面碾压替代品。
- 确立 Core 是一项不可逆的战略决断，团队所有资源必须向加强 Core 的方向绝对倾斜。

## 严谨创业法第 10 步：界定企业的“核心能力”（Core）

在初创企业获得初步市场验证后，行业在位巨头与模仿者将在几周内纷至沓来。初创企业凭什么生存并保持超额收益？答案在于明确自身的 **Core（核心能力）**。

::: definition 核心能力 (The Core)
你在特定维度上做得比全世界任何企业都要优秀的唯一专属能力。它是企业的护城河与不可侵犯的战略高地，竞品即使投入十倍资金与人力，在短时间内也无法轻易跨越。
:::

```text
[经典核心能力的四种底层形态]
1. 网络效应 (Network Effects)
   - 每增加一个新用户，所有老用户的系统价值同步倍增 (如双边交易平台、通信协议)。
2. 持续卓越的低成本结构 (Low-Cost Advantage)
   - 拥有独特的制造工艺、极简供应链或无摩擦分销架构 (如早期戴尔直销、西南航空单机型)。
3. 专有算法与数据飞轮 (Proprietary Data Flywheel)
   - 算法结合专属业务数据形成持续闭环，自我迭代速度远超竞品 (如 Google 搜索质量算法)。
4. 极致客户体验与品牌信任 (Unrivaled Customer Experience)
   - 极深的用户情感纽带与不可替代的信任溢价 (如 Zappos 的极致鞋履退换货服务)。
```

### 哪些要素**不能**作为核心能力？
- **“我们拥有专利/知识产权”**：专利可以被绕过，且初创公司通常打不起跨国侵权诉讼官司；
- **“我们跑得最快，拥有先发优势（First Mover）”**：先发者往往沦为市场先烈，后发追随者可以通过微创新直接收割市场；
- **“我们有一支优秀的创始团队”**：团队是执行工具，而非企业资产层面的护城河。

::: insight
核心能力一旦确定，就必须在公司内部上升为最高宪法。任何分散核心能力资源的新业务拓展，无论短期利润看起来多么诱人，都必须坚决拒绝。
:::

## 严谨创业法第 11 步：二维竞争定位图（Competitive Positioning）

如何向客户与投资人证明你在海滩阵地中的绝对统治力？必须绘制基于客户视角的 **二维竞争定位坐标系**。

```mermaid
quadrantChart
    title 竞争定位象限分析 (以工业自动化预警系统为例)
    x-axis 低现场部署摩擦力 --> 极简即插即用 (零停机)
    y-axis 低故障预警准确率 --> 军工级高灵敏度 (>98%)
    quadrant-1 战略制高点：本项目方案
    quadrant-2 专业昂贵外包检测机构
    quadrant-3 现状：传统人工巡检与定期保养
    quadrant-4 传统大型工业软件系统
    "现状人工巡检": [0.2, 0.25]
    "专业外包检测": [0.35, 0.75]
    "大型工业软件": [0.75, 0.35]
    "本项目方案": [0.88, 0.9]
```

### 绘制竞争定位图的三大准则
1. **坐标轴必须代表客户的首要购买标准（Key Purchasing Priorities）**：
   - 横纵坐标绝对不能写自吹自擂的技术指标（如“拥有 50 项发明专利”或“采用最新深度学习框架”）；
   - 必须是客户最痛、最关心的指标（如“安装耗时”、“每小时故障停机挽回金额”）。
2. **本项目必须坚定落于右上角（Top-Right Quadrant）**：
   - 右上角是唯一的目标定位，代表在客户最核心的两大衡量标准上具有压倒性统治力。
3. **竞品矩阵必须包含真实替代品与“不作为（Status Quo）”**：
   - 最大的竞争对手往往不是直接同行，而是客户“什么都不买、继续用 Excel 或人工凑合”的惯性行为。

::: pitfall
小心“虚幻的十项全能”。初创企业若在表格中宣称自己在成本、速度、功能、外观、客服等所有 10 个维度全面超越巨头，这不仅无法取信于投资人，更暴露了创始人对战略取舍（Trade-offs）的极度无知。
:::

# 15.301 管理心理学实验研究 (People, Teams, and Organizations Laboratory)

> MIT Course 15 · Work and Organizational Studies · 工作与组织研究 · 课号 15.301

## TL;DR

- Dan Ariely 领衔的行为经济学实验实验室，揭示人类在管理决策中普遍存在的非理性模式。
- 框架效应（Framing Effect）、损失厌恶、社会规范与市场规范冲突的实证检验。
- 掌握行为科学严谨的双盲随机对照实验（A/B Testing）设计与因果推断数据分析。

## 课程简介 / Description

This course combines a few different goals: develop a critical eye for making inferences from data; be able to carry out simple data analysis; learn about managerial psychology; develop interesting new questions about managerial psychology and test these questions.

# Lec 11 动态物料需求计划与供应链滚动优化（Dynamic Requirements Planning for Supply Chain Optimization）

## TL;DR

- 格雷夫斯、克莱特与赫策尔（Stephen Graves, David Kletter & William Hetzel, 1998）开创了动态物料需求计划理论。
- 将工业界广泛运行的 MRP 滚动排程与离散时间随机动态线性系统状态空间方程（State-Space）实现严谨理论统一。
- 推导建立了线性生产平滑控制律（Smoothing Rule），在需求预测频繁震荡下有效遏制了供应链内部的计划神经质（Nervousness）。

## 一、传统 MRP 的内在系统性缺陷：系统神经质（System Nervousness）

在制造业的信息化演进史中，物料需求计划（Material Requirements Planning, MRP）是企业资源规划（ERP）软件最核心的运算引擎。MRP 通过将主生产计划（MPS）按照多级物料清单（BOM）与固定装配提前期，逐层反向时间推导展开（Time-phased explosion），自动生成各子零件的建议采购与投产订单。

然而，全球工业界在几十年的实际运行中，饱受 MRP 算法固有结构性顽疾的折磨——著名的**系统神经质（System Nervousness）**：
- 在每周的滚动计划重算时，下季度微小的最终客户需求变动，经过 BOM 树的多层非线性截断与最小起订量（MOQ）放大；
- 导致上游车间的生产作业单发生极其剧烈的震荡：上周系统要求“本周必须加急生产 5000 件”，本周一重跑 MRP，系统突然又要求“立即取消该工单并转产另一批次”！
- 这种上下翻滚的指令导致车间现场工装频繁更换、工人疲于奔命、供应商关系极度恶化。

麻省理工学院史蒂芬·格雷夫斯（Stephen Graves）团队在 1998 年发表于《Operations Research》的经典论文，首次构建了**动态需求规划（Dynamic Requirements Planning, DRP）的现代控制理论框架**。

```mermaid
flowchart LR
    A["外部动态需求流<br>MMFE 鞅演进预测"] --> B["状态空间控制器<br>Graves 线性平滑规则"]
    B --> C["平滑滤波生产排产指令<br>消除 MRP 系统神经质"]
    C --> D["平滑物理在制品库存池<br>以确定性安全缓冲对冲波动"]
```

格雷夫斯团队的雄心在于：**在数学上重构 MRP 算法，使生产系统既能敏捷追踪市场中长期的真实趋势变化，又能对短期无意义的随机噪声展现出强大的高频滤波阻尼**。

## 二、状态空间（State-Space）线性随机动态系统建模

格雷夫斯将整个多级制造系统抽象为一个严格的离散时间随机控制状态空间方程：

- **时间索引**：离散周期 $t = 1, 2, \dots$。
- **状态向量**：设 $x_t$ 为系统的综合状态向量，包含当前各级节点的在库在途库存，以及当前掌握的未来整个计划时域视界（Horizon $H$）内的全部预测需求向量 $(F_{t, t}, F_{t, t+1}, \dots, F_{t, t+H})$。
- **控制向量**：$u_t$ 为在周期 $t$ 实际下达的各级制造与采购指令向量。

### 系统状态转移微分方程
$$x_{t+1} = A x_t + B u_t + C w_{t+1}$$

其中：
- $A, B, C$ 为由网络物理结构（提前期、BOM 消耗矩阵）确定的系统结构矩阵；
- $w_{t+1}$ 为下一周期新涌入的由 MMFE 鞅模型驱动的预测修正冲击向量（满足 $\mathbb{E}[w_{t+1} \mid \mathcal{F}_t] = 0$）。

目标函数为最小化系统全生命周期的贴现二次型成本泛函（Linear-Quadratic-Gaussian, LQG）：

$$\min \mathbb{E} \left[ \sum_{t=0}^{\infty} \beta^t \left( (x_t - x^*)^T Q (x_t - x^*) + (u_t - u_{t-1})^T R (u_t - u_{t-1}) \right) \right]$$

其中：
- 矩阵 $Q$ 惩罚库存偏离安全库存目标水位的积压与超储损失；
- 矩阵 $R$ 惩罚**生产指令相对于上一期的突变剧烈程度（Production Smoothing Penalty）**，这正是数学上对遏制“系统神经质”的精准形式化定义！

## 三、格雷夫斯线性平滑控制律与安全库存闭式解

利用离散时间代数黎卡提方程（Discrete Algebraic Riccati Equation, DARE），格雷夫斯推导出了极其优雅的全局最优闭式线性状态反馈控制律：

::: theorem [Graves-Kletter-Hetzel 动态平滑定理 (1998)]
系统抵抗预测神经质的最优生产排产决策具有广义线性低通滤波器形式：

$$u_t^* = (1 - \alpha) u_{t-1}^* + \alpha \cdot \text{Baseline Requirements}_t + K (x_t - x^*)$$

其中：
- 平滑系数 $\alpha \in (0, 1)$ 是根据持有成本矩阵 $Q$ 与调优阻尼矩阵 $R$ 精确权衡计算得出的特征根；
- 生产指令不再被动跟随每周 MRP 结果做 100% 剧烈跳跃，而是以指数平滑滤波器的形式吸收预测冲击。
:::

### 理论对全网安全库存的动态校准
在引入平滑控制律后，生产排产的波动被成功熨平，但被熨平的生产方差必然部分转化为物理库存的瞬态吸收。格雷夫斯推导出了系统各节点所需配置的**动态安全库存协方差闭式解析式**：

$$SS_i^* = z \sqrt{\left[ (I - (A - BK))^{-1} C \Sigma_w C^T ((I - (A - BK))^{-1})^T \right]_{ii}}$$

这一公式彻底告别了传统 MRP 教科书中拍脑袋拍出的“维持 2 周周转量”的盲目经验法则，使供应链数字化系统能够根据全网 BOM 拓扑与控制增益矩阵，自动实时吐出数学上最优的安全库存配额。

::: example [航空航天精密机械制造厂的计划平稳化实践]
某为波音与空客提供钛合金发动机起落架机匣的制造企业，其加工中心调刀换模极其复杂。原先由 SAP ERP 系统计算出的工单每周大幅震荡，机床每月换线 40 余次，产能浪费在试切与升温调试上。引入 Graves 动态规划平滑算法后，系统在软件层面对滚动预测实施动态滤波。排产计划的月度波动性骤降 72%，换模次数减少一半，在全厂库存总额微降 5% 的同时，有效生产工时直接释放了 **18%**。
:::

## 我的理解

Graves 团队的工作代表了现代控制理论（Control Theory）与运营管理学的绝妙结合。

1. **阻尼与敏捷的动态平衡**：在系统动力学中，一个对外部所有微小输入都极度敏捷响应的系统，必然是一个极度神经质且容易发生共振发散的系统。优秀的系统架构师必须学会像设计汽车悬挂避震器一样，为制造排程系统设计具有合理阻尼常数 $\alpha$ 的缓冲滤波层。区分“信号”与“噪声”，是供应链排产的最高心法。
2. **状态空间视角统一离散与连续**：传统的运筹学课程往往把库存控制（离散概率）与工业自动化控制（连续传递函数）割裂教学。Graves 的模型证明，当我们将多级物料、在途提前期与预测视界整合成一个高维状态向量 $x_t$ 时，MRP 本质上就是一个多输入多输出（MIMO）的经典状态空间控制系统。卡尔曼滤波与 LQG 控制器可以直接降维打击工业排产难题。
3. **安全库存的本质是物理能量缓冲池**：如果说信息平滑规则是软件算法层面的减震阀，那么物理安全库存就是现实硬件层面的重力储能飞轮。宁可让原材料以低成本形态在仓库货架上静止缓冲，也绝不能让后方昂贵的数控机床与高级技工陷入无休止的紧急调班与空转等待之中。

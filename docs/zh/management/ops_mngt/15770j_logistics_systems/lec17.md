# Lec 17 供应链网络设计：设施选址与混合整数规划（Supply Chain Network Design）

## TL;DR

- 长期不可逆资本决策：制造基地、中央配送中心与区域分仓的拓扑网络布局。
- 电容限制设施选址问题（CFLP）的标准混合整数线性规划（MILP）形式化构建。
- 运力成本、固定开仓资本折旧与关税贸易壁垒综合多准则权衡求解。

## 一、战略网络设计的沉没资本约束

如果说日常的库存调度和车队派车是几小时至数天内的“战术与操作级决策”，那么**供应链网络设计（Supply Chain Network Design）**则是影响企业未来 5 至 15 年生死存亡的“最高战略级决策”。

兴建一座年产千万套的自动化制造超级工厂，或者在全球租赁五座数万平米的保税枢纽配送中心：
- 涉及数以亿计的重资产沉没投资；
- 牵涉极其漫长的基建施工、环评审批与政府招商引资商务谈判；
- 一旦选址失误或产能过剩，企业将背负沉重的固定资产折旧包袱，在后续激烈的市场价格战中瞬间失血倒闭。

因此，必须借助严密的数学规划模型，推演全网物流总成本最优的拓扑骨架。

## 二、容量受限设施选址问题（CFLP）的 MILP 形式化建模

我们考虑一个经典的三级供应链网络：包含一组候选仓储设施点 $J$ 以及一组已知空间地理位置的客户需求点 $I$。

```mermaid

    Sources --> Candidates --> Customers
```

### 1. 集合与已知参数定义
- $I$：客户需求点集合，每个客户 $i \in I$ 的年需求量为 $d_i$；
- $J$：候选物流中心设施集合，每个候选点 $j \in J$ 的最大处理容量上限为 $Cap_j$；
- $f_j$：在地点 $j$ 建设或租赁物流中心所需的年度固定摊销成本（Fixed Cost）；
- $c_{ij}$：从物流中心 $j$ 运送单位货物到客户 $i$ 的全流程运输与装卸变动成本。

### 2. 决策变量定义
- $y_j \in \{0, 1\}$：0-1 二值整数变量。若在地点 $j$ 建立物流中心，则 $y_j = 1$；否则 $y_j = 0$；
- $x_{ij} \ge 0$：连续实数变量。从物流中心 $j$ 运输到客户 $i$ 的实际物料供应总量。

### 3. 混合整数线性规划（MILP）数学模型
$$\min \sum_{j \in J} f_j y_j + \sum_{i \in I} \sum_{j \in J} c_{ij} x_{ij}$$
$$\text{s.t.} \quad \sum_{j \in J} x_{ij} = d_i, \quad \forall i \in I \quad (\text{必须 100\% 满足所有客户需求})$$
$$\sum_{i \in I} x_{ij} \le Cap_j \cdot y_j, \quad \forall j \in J \quad (\text{设施容量限制；且若未开启 } y_j=0 \text{ 则发运量强制为 0})$$
$$y_j \in \{0, 1\}, \quad x_{ij} \ge 0, \quad \forall i \in I, j \in J$$

::: definition [大 M 法（Big-M Constraint）在设施连通中的运用]
在无容量限制模型中，常采用 $x_{ij} \le M y_j$ 强行绑定物流流动与开关决策（$M$ 为足够大的上界，如 $M = \sum d_i$）。但在实战求解中，过大的 $M$ 会导致线性松弛（Linear Relaxation）下界极度松弛，拖慢分支定界（Branch-and-Bound）搜索速度，应优先采用紧凑的物理容量约束。
:::

## 三、网络设计敏感性分析与地缘情景演练

在商用求解器（如 Gurobi、CPLEX）求得基准最优解后，战略规划咨询团队的核心价值在于开展深度的情景压力测试（Scenario Planning）：

| 测试情景 | 参数扰动设定 | 系统拓扑应对推演 |
| :--- | :--- | :--- |
| **国际油价暴涨 50%** | 运输单价 $c_{ij}$ 成倍上浮 | 最优解趋向于**增开更多区域分仓**，以固定建仓成本换取干线里程压缩 |
| **仓储自动化技术突破** | 固定开仓成本 $f_j$ 增加，但单位变动操作费骤降 | 最优解趋向于**极致集中化**，关闭中小型小仓，打造巨型无人超级母仓 |
| **地缘贸易关税摩擦** | 跨国进口关税壁垒提升至 25% | 最优解打破单一低成本外包依赖，全面重构近岸（Near-shoring）本土双链布局 |

## 我的理解

供应链网络设计是运筹学在工业界最具魅力的沙盘推演舞台。在一张空白的全球地图上，数以万计的变量交织成庞大的成本网络。MILP 算法为我们扫清了直觉与地域偏见的迷雾，用冷峻严谨的数学逻辑，在数万个排列组合中锁定那个能够为企业每年省下数千万真金白银的最优拓扑。它是所有微观物流调度的承载母舰，决定了整个商业帝国的基本盘。

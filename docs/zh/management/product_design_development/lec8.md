# Lec 8 原型制作实务：从概念模型到工程验证模型（Prototyping）

> MIT 15.783 · Product Design and Development · 主讲 Allison Rae（Paramount Industries / Rhode Island School of Design）

## TL;DR

- 本讲由原型制造供应商 Paramount Industries 的从业者主讲，视角是"给定一个原型需求，该选哪种工艺、材料、精度和交付周期"，而非泛泛讨论原型的战略价值。
- 核心是一套五级"模型类型"分类：概念模型（Concept）→ 外观模型（Looks-Like）→ 外观兼功能模型（Looks-Like/Works-Like）→ 工装样件（Tooling Pattern）→ 工程验证模型（Engineering Check Model），每一级对应不同的目的、输入、工艺/材料、公差和数量。
- 具体制造工艺分两大类：**增材快速成型**（SLA、SLS、FDM、ZCorp 石膏粉末打印）用于早期、复杂几何、少量件；**其他成型/加工方法**（手工制作、聚氨酯浇注、真空吸塑、熔模铸造、CNC 加工）用于中后期、需要接近量产材料特性或较大批量的场景。
- 原型工装（铝或预硬钢，寿命 12–25 万件）是量产工装（硬化钢多腔模，百万件级）之前的过渡方案，用更低成本和更短周期验证生产几何与材料，但仍达不到量产工装的产量和成本效率。
- 选择原型方案前应先回答一组"资质问题"（模型类型、输入数据形式、是否需要量产材料、公差、数量、时间、预算），并把原型当作为高风险问题提供答案的工具，逐个击破而非一次性追求"完美原型"。

## 讲者背景与视角

本讲由 Paramount Industries 的 Allison Rae 主讲，她同时任教于罗德岛设计学院（RISD）工业设计系。Paramount 最初是一家纯原型制作供应商，后来才逐步扩展出工业设计、产品工程、产品验证、面包板模型、计算机动画和平面设计等能力——这个演化路径本身说明：原型制作在实践中往往是新产品开发服务链条上最早成型、也最容易衍生出上下游能力的环节。这一讲的内容因此偏向工艺目录和决策清单，而非理论框架，适合与前几讲关于原型战略角色（学习、沟通、集成、里程碑）的内容互补：前几讲回答"为什么做原型、做几个原型"，这一讲回答"具体用什么工艺把原型做出来"。

## 快速成型（Rapid Prototyping）工艺

讲义给出一张对比表，覆盖四类主流增材制造工艺，均以 3D 数模为输入：

::: example 快速成型工艺对比
- **SLA（立体光固化，Stereolithography）**：液态光敏树脂逐层固化。标准树脂用于外观模型和铸造母模，柔性树脂（flex resin）用于需要一定弹性的外观模型；层厚约 0.005 in，公差 ±0.002–0.005 in，交付约 2 天，表面精细度最高（1 级，1–4 级由细到粗）。
- **SLS（选择性激光烧结，Selective Laser Sintering）**：热塑性粉末（尼龙、玻纤尼龙、类 Santoprene 弹性体、蜡/苯乙烯投料）逐层烧结。尼龙适合活动铰链、卡扣等功能验证；玻纤尼龙更耐用；Somos 弹性体件手感接近软触材料；Castform 蜡质件可直接作熔模铸造母模。交付约 2–4 天，公差 ±0.007 in。
- **FDM（熔融沉积成型）**：ABS 或聚碳酸酯长丝逐层熔融堆积，用于复现最终 ABS/PC 材料的力学特性，层厚 0.005–0.016 in，表面较粗（4 级）。
- **ZCorp（石膏粉末打印）**：成本最低（约 150 美元/托盘），用于早期形态研究模型，可直接打印彩色，但精度和强度均较低。
:::

这些工艺的共同特点是：直接从 3D 数模出发、无需定制工装、能实现复杂几何，因此天然适合开发早期、迭代频繁、单件或小批量的场景。选择哪种具体工艺，本质上是在**精度、表面质量、材料力学特性、单件成本与交付周期**之间做权衡，而不存在"最优解"。

## 其他原型/成型方法

对于快速成型无法满足的需求（如更接近量产材料、更大数量、特殊几何），讲义列出五类传统方法：

::: example 非快速成型的原型工艺
- **手工制作（Fabrication）**：从餐巾纸草图或部件图直接雕刻/搭建，材料不限，是唯一能容纳"3D CAD 之外的复杂度"或"混合多种材料"的方式，数量通常 1–5 件。典型案例是蜡雕（wax sculpting）——用于制作熔模铸造所需的正型母模，工匠用手工雕刻刀具在蜡料上塑形，可实现极精细的细节。
- **聚氨酯浇注（Urethane Casting）**：以 SLA 或手工母模为基准翻制硅橡胶（RTV）模具，再浇注聚氨酯树脂，可复制出接近量产材料手感的刚性、柔性、透明、中空及嵌件/共注件，交付 1–2 周，数量 10–50 件，常用于制作销售样品和"外观兼功能"件。
- **真空吸塑（Thermoforming）**：把加热软化的塑料片材吸附在模具（pattern）表面成型，适合薄壁外壳和吸塑包装等简单几何，交付 0.5–2 周。
- **熔模铸造（Investment Casting）**：先制作蜡质正型母模，浸挂陶瓷浆料并撒细砂形成陶瓷壳，加热脱蜡后浇入金属熔液，可铸造出机加工难以或无法实现的金属零件（从锌到钛），交付 2–4 周。
- **CNC 加工**：以零件图或 3D 数模为输入，通过计算机数控铣削/车削直接切削出塑料或金属件，精度不受几何复杂度限制，可用于原型或量产。
:::

::: note
可以看出，从快速成型到这五类方法，材料越来越接近最终量产材料、公差要求越来越严格、数量需求逐步上升，但相应的交付周期和单件复杂度也随之提高——这与"模型类型"分级（见下节）是同一条演化脉络的两种描述方式：一个从"目的"切入，一个从"工艺"切入。
:::

## 原型工装与量产工装

当需要用注塑等量产工艺本身来验证材料和几何、但尚不到量产规模时，会用到**原型工装（Prototype Tooling）**：

- **铝模**：交付 1–10 周，公差 ±0.002 in/in，适合中等耐温热塑性材料，寿命约 25,000–50,000 件，比量产工装更快、更便宜，用于验证生产材料和部件几何。
- **预硬钢（P-20）模**：性能与铝模类似，但模具寿命更长、能容纳更复杂的模具结构和更广的材料范围，寿命约 100,000–250,000 件。
- 工艺上均通过机加工、电火花（EDM）、仿形加工制作型腔，交付周期一般 4–6 周。

对照之下，**量产工装（Production Tooling）**采用硬化钢、多腔模具，几乎不受材料限制，能支持百万件以上的产量并显著摊薄单件成本，但交付周期取决于复杂度、且投入远高于原型工装。原型工装的价值在于：用远低于量产工装的成本和时间，在真实工艺（如注塑）下提前暴露材料收缩、脱模、飞边等问题，避免这些风险被带入量产工装阶段才发现。

## 模型类型分级（Types of Models）

讲义提出的核心框架是按"目的"划分的五级模型体系，每一级明确了目的、输入、工艺/材料、公差、数量：

::: insight 五级模型体系
1. **概念模型（Concept Model）**：目的是研究比例、探索造型、验证人机工程，输入可以只是草图或口头描述，甚至没有 3D 数模。工艺以手工制作（泡沫、隔热材料或聚氨酯发泡、泡沫芯、黏土，乃至拆解拼装现有产品的零件）为主，也可用快速成型或简单机加工；公差不重要，数量通常只做一件。讲义给出的实例是一台网络存储设备的手工泡沫模型——因为当时尚无 3D 数据，选择手工制作是为了追求速度；另一实例是面包板式概念模型，选择手工搭建是因为需要容纳多种材料的混合装配。
2. **外观模型（Looks-Like Model）**：目的是纯粹的美学验证，展示表面处理、颜色、透明件、标签和触感材料，不涉及功能。
3. **外观兼功能模型（Looks-Like/Works-Like, LL/WL）**：在外观模型基础上叠加功能要求——拔模角度只在影响性能时才考虑，仅为实现功能而做工艺补强（coring），材料需复现量产材料的力学表现，并可包含电池、电子元件、弹簧、LED 等真实部件。工艺以快速成型、浇注（聚氨酯/硅胶）、库存塑料机加工为主，公差按需收紧，数量 1–12 件。讲义给出两个实例：一是以 SLA 母模翻制 RTV 硅胶模具再浇注聚氨酯，选择该路线是为了复制量产树脂的手感；二是一台手持气象仪的聚氨酯浇注外壳，选择该工艺是为了在精度、颜色和质感上逼近量产件。
4. **工装样件（Tooling Pattern）**：为后续制模提供母模或参照几何，典型做法是手工制作以容纳高度复杂的几何形态（讲义实例为多个高细节玩具人偶/载具模型）。
5. **工程验证模型（Engineering Check Model）**：目的是确认几何精度、测试量产材料、验证功能是否达标，输入必须是完整 3D 数模和详细零件图，工艺涵盖快速成型（SLS/FDM/SLA）、以量产材料做 CNC/机加工、以及用原型模具试模，公差要求严格，数量通常只做一件。讲义给出三个实例：一是 SLA 打印的座椅骨架结构件，选择该工艺是为了兼顾精度和速度；二是 SLS 玻纤尼龙打印的电动工具外壳，选择该材料是为了承受耐久性测试；三是铝制原型注塑模具打出的多色牙刷手柄，用于验证材料结合力并进行市场测试。
:::

医疗器械案例进一步展示了这条链路如何串联成一个完整流程：从泡沫形态研究模型（foam study model）→ SLS 验证模型（verification model）→ 最终用可高温高压灭菌的 GE Ultem 工程塑料通过 CAM/CNC 加工出临床试验用原型（clinical trial prototype）。每一步材料和工艺的升级，都对应着从"探索造型"到"接近真实使用场景验证"的风险收敛过程。

## 如何为项目选择原型方案

::: example 原型需求的资质清单（Qualifying Questions）
1. 需要哪种类型的模型（概念/外观/外观兼功能/工装样件/工程验证）？
2. 现有输入是什么形式（草图、控制图纸、还是完整 3D 数据）？
3. 是否必须使用量产材料？
4. 公差要求是什么？
5. 需要多少件？
6. 什么时候需要？
7. 预算约束是什么？
:::

这组问题本质上是把"模型类型分级"反过来用作决策工具：先回答这七个问题，再倒推该用哪种工艺组合（快速成型 / 浇注 / 机加工 / 原型工装），而不是先入为主地选定某种"看起来先进"的工艺。

## 用原型驱动产品开发效率

讲义最后把上述工艺目录收束到一条通用原则：**提高产品开发效率的关键是问对问题，而不是做更多原型**。具体做法是：识别项目中的风险点，把这些风险转化为"若被回答将能降低或消除风险"的具体问题，再选择最小、最快、最省的模型/原型去回答某一个具体问题，一次只针对一个问题，得到答案后再重复这个过程；必要时也可以用原型之外的其他工具（如仿真、供应商打样、用户测试）来回答同样的问题。这与本课程系列其他讲次强调的"原型服务于学习而非展示"的立场是一致的，只是这一讲把重点放在"用什么工艺、什么材料能最快最省地拿到答案"这一执行层面。

::: pitfall 容易忽视的取舍
讲义没有给出"哪种工艺最好"的排序，本身就是一个提醒：脱离具体问题（要回答什么风险、多少数量、多长周期、多少预算）去比较 SLA 和 SLS 谁更好，或去比较原型工装和量产工装谁更划算，都是伪命题。工艺选择应服从于当前这一轮原型要回答的具体问题，而不是追求"一次做出接近成品的原型"。
:::

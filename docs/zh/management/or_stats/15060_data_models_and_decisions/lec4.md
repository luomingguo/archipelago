# Lec 4 连续随机变量、协方差与资产配置基础 (Continuous Random Variables, Covariance & Linear Combinations)

> MIT 15.060 数据、模型与决策 · 讲义 4 · 授课教师：Prof. Dimitris Bertsimas / Prof. Robert Freund

## TL;DR

- 连续随机变量通过概率密度函数（PDF）的曲面下面积度量区间概率，单点概率恒为零。
- 协方差与相关系数形式化量化了两个随机变量之间线性协同波动的方向与强度。
- 随机变量和的方差由各自方差与两两协方差共同决定，构成了投资组合风险核算的基石。
- 负相关或低相关资产的组合能显著消除非系统性风险，实现“无痛降低波动”的对冲效应。

## 1. 连续随机变量与概率密度函数（PDF）

现实商业世界中的诸多变量——如制造公差、原油价格、服务等待时长、客户生命周期价值——均在连续实数区间内变动。

::: definition [连续随机变量与概率密度函数 (PDF)]
设 $X$ 为连续随机变量。若存在非负可积函数 $f(x)$，使得对任意实数区间 $[a, b]$，均有：
$$P(a \le X \le b) = \int_{a}^{b} f(x) \, dx$$
则称 $f(x)$ 为 $X$ 的概率密度函数（Probability Density Function, PDF）。
其必须满足：
1. $f(x) \ge 0, \quad \forall x \in \mathbb{R}$
2. 全域积分规范性：$\int_{-\infty}^{+\infty} f(x) \, dx = 1$
累积分布函数为积分原函数：
$$F(x) = P(X \le x) = \int_{-\infty}^{x} f(t) \, dt \implies f(x) = \frac{d F(x)}{dx}$$
:::

注意：对于连续随机变量，$f(x_0)$ 并非概率本身，而是该点局部的概率相对集中密度。任何具体单点的概率严格为零：$P(X = x_0) = \int_{x_0}^{x_0} f(t) dt = 0$。

```mermaid

    PDF[概率密度函数 f_x] -->|积分计算面积| Prob[区间概率 P a<=X<=b]
    JointPDF[联合分布 f_x_y] --> Cov[协方差 Cov X, Y]
    Cov --> Corr[相关系数 rho]
    Corr --> Portfolio[资产组合方差优化]
```

## 2. 联合随机变量、协方差与相关系数

当管理问题涉及多个不确定因素时（例如：原材料价格与终端市场需求，或者股票 A 与股票 B 的回报率），孤立研究单个变量的边际分布是不够的，必须捕捉变量之间的联动模式。

### 2.1 协方差定义与计算

设 $X$ 与 $Y$ 为随机变量，其均值分别为 $\mu_X$ 与 $\mu_Y$。协方差衡量两者的平均线性偏离同向程度：
$$Cov(X, Y) = E\left[(X - \mu_X)(Y - \mu_Y)\right] = E[XY] - E[X]E[Y]$$

若 $X$ 与 $Y$ 相互独立，则 $E[XY] = E[X]E[Y]$，必有 $Cov(X, Y) = 0$。但反之不成立（零协方差仅代表无线性相关，可能存在强非线性依赖）。

### 2.2 相关系数（Pearson Correlation Coefficient）

由于协方差数值受 $X$ 和 $Y$ 自身量纲影响（例如将美元改为美分，协方差暴增 10,000 倍），我们通过标准化消除量纲：
$$\rho_{XY} = \frac{Cov(X, Y)}{\sigma_X \sigma_Y}, \quad -1 \le \rho_{XY} \le +1$$
- $\rho = +1$：完全正线性相关；
- $\rho = -1$：完全负线性相关（完美的风险对冲载体）；
- $\rho = 0$：线性不相关。

## 3. 随机变量线性组合与现代资产组合理论基础

在供应链网络规划与金融投资中，决策者往往掌控着由多个随机变量加权构成的复合产出。

::: theorem [随机变量线性组合的期望与方差]
设 $W = aX + bY$，其中 $a, b$ 为常数权重：
$$E[W] = a E[X] + b E[Y]$$
$$Var(W) = a^2 Var(X) + b^2 Var(Y) + 2ab \, Cov(X, Y) = a^2 \sigma_X^2 + b^2 \sigma_Y^2 + 2ab \rho_{XY} \sigma_X \sigma_Y$$
扩展到 $n$ 个资产的组合 $R_p = \sum_{i=1}^n w_i R_i$（权重和 $\sum w_i = 1$）：
$$Var(R_p) = \sum_{i=1}^n w_i^2 \sigma_i^2 + \sum_{i=1}^n \sum_{j \ne i}^n w_i w_j Cov(R_i, R_j)$$
:::

### 3.1 对冲魔术：双资产投资组合风险分散

考虑两项资产 $A$ 与 $B$：
- 资产 $A$：期望回报率 $E[R_A] = 12\%$，波动率 $\sigma_A = 20\%$；
- 资产 $B$：期望回报率 $E[R_B] = 8\%$，波动率 $\sigma_B = 10\%$。
令投资权重各占一半（$w_A = 0.5, w_B = 0.5$）。组合预期回报恒为：
$$E[R_p] = 0.5 \times 12\% + 0.5 \times 8\% = 10\%$$

检验不同相关系数 $\rho_{AB}$ 对组合标准差 $\sigma_p$ 的影响：

| 相关系数 $\rho_{AB}$ | 组合方差 $Var(R_p)$ | 组合标准差 $\sigma_p$ | 相比加权均值 ($15\%$) 降幅 |
| :--- | :--- | :--- | :--- |
| **+1.0 (完全正相关)** | $0.25(0.04) + 0.25(0.01) + 2(0.25)(0.02) = 0.0225$ | **15.00%** | 0% (无分散效果) |
| **+0.5 (适度正相关)** | $0.01 + 0.0025 + 0.5(0.5)(0.02)(0.5) = 0.0175$ | **13.23%** | 下降 1.77% |
| **0.0 (互不相关)** | $0.25(0.04) + 0.25(0.01) + 0 = 0.0125$ | **11.18%** | 下降 3.82% |
| **-0.5 (适度负相关)** | $0.0125 - 0.0050 = 0.0075$ | **8.66%** | 下降 6.34%（低于最低资产波动）|
| **-1.0 (完全负相关)** | $0.0125 - 0.0100 = 0.0025$ | **5.00%** | 下降 10.00% |

::: example [消除波动的自由午餐]
当 $\rho_{AB} = -0.5$ 时，组合的整体风险（$8.66\%$）甚至严格小于低风险资产 $B$ 自身的波动率（$10\%$）！这就是马科维茨（Markowitz）所盛赞的“金融学中唯一的免费午餐”。
:::

::: pitfall [极端行情下的相关性崩溃（Correlation Breakdown）]
在构建风险对冲组合时，分析师通常使用历史平稳期数据估算 $\rho$。然而在金融流动性枯竭或全球供应链危机爆发时，原本呈负相关或弱相关的资产往往会发生“流动性抽逃共振”，相关系数瞬间趋近于 $+1$。忽略相关系数的动态脆性是诸多量化对冲基金爆仓的根源。
:::

::: insight [我的理解：协方差项主导了复杂系统的全局风险]
仔细审视组合方差展开式：方差项包含 $n$ 个独立方差，而协方差项却包含 $n(n-1)$ 个交叉项！当资产类别或业务线增加到 30 个时，系统包含 30 个个体方差和高达 870 个交叉协方差。这意味着系统全局稳定性的 $95\%$ 以上完全由相互作用的协方差项支配。在组织设计与供应链网络中，关注部门之间的协同与冲突摩擦，远比单独强化每个子节点的绩效更为根本。
:::

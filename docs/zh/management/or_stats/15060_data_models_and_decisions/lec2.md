# Lec 2 决策分析 II：条件概率与概率树（Great Apps 案例）(Decision Analysis II: Conditional Probabilities & Great Apps Case)

> MIT 15.060 数据、模型与决策 · 讲义 2 · 授课教师：Prof. Dimitris Bertsimas / Prof. Robert Freund

## TL;DR

- 条件概率刻画了新信息输入后，事件发生可能性的动态修正过程。
- 概率列联表替代抽象代数公式，能够直观高效地实现先验概率到后验概率的贝叶斯反转。
- 完全信息期望价值（EVPI）为消除未来所有不确定性设定了支付意愿的理论绝对上限。
- 不完全市场测试的信息价值（EVSI）取决于测试本身的准确度及其改变当下最优决策的能力。

## 1. 条件概率法则与贝叶斯反转的直觉表达

管理决策很少在绝对黑箱中进行。在做出昂贵的资本承诺之前，企业通常有机会获取先行指标、专家意见、原型机测试或试销数据。如何利用这些不完美的信号来更新原始信念？

::: definition [条件概率与乘法法则 (Conditional Probability)]
设 $A$ 和 $B$ 为两个随机事件，且 $P(B) > 0$。在事件 $B$ 已经发生的条件下，事件 $A$ 发生的条件概率定义为：
$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$
其等价乘法形式为联合概率展开：
$$P(A \cap B) = P(A \mid B) P(B) = P(B \mid A) P(A)$$
:::

在很多商业场景中，现实给出的数据方向往往与决策所需方向相反。例如，软件测试团队知道“当一款应用真正畅销时，试玩好评的概率是多少（测试灵敏度 $P(\text{Positive} \mid \text{Success})$）”；但投资委员会在看到好评报告时，迫切需要回答的却是：“已知测试给出了好评，该应用真正畅销的概率是多少（后验概率 $P(\text{Success} \mid \text{Positive})$）？”这就是经典的贝叶斯反转问题。

```mermaid
flowchart TD
    Prior[先验概率 P(Success)] --> Test[市场测试/原型验证]
    Test --> Reliability[测试可靠性指标 P(Signal | State)]
    Reliability --> Joint[联合概率矩阵 P(State ∩ Signal)]
    Joint --> Marginal[边际信号发生率 P(Signal)]
    Marginal --> Posterior[后验修正概率 P(State | Signal)]
```

通过概率列联表（Probability Contingency Table），分析师无需记忆繁琐的贝叶斯公式展开式，即可利用行与列的和完成直观求解。

## 2. Great Apps of Ann Arbor 商业案例分析

密歇根州安阿伯市的移动应用孵化器“Great Apps”正考虑投资 30 万美元全面开发并上线一款面向大学生群体的时间管理移动应用。

### 2.1 商业参数与先验判断

根据历史同类产品统计，该应用上线后的市场表现呈现三种可能状态：
- **大获成功（Major Success, $S_1$）**：净商业回报（扣除基础运营费后）为 120 万美元；先验概率 $P(S_1) = 0.20$。
- **适度保本（Moderate, $S_2$）**：净商业回报为 40 万美元；先验概率 $P(S_2) = 0.30$。
- **惨败出局（Failure, $S_3$）**：净商业回报为 0 美元；先验概率 $P(S_3) = 0.50$。
- 研发投资成本为固定 30 万美元。若不开发，净收益为 0。

若直接决策（无测试）：
$$EMV(\text{Launch}) = 0.20 \times (120 - 30) + 0.30 \times (40 - 30) + 0.50 \times (0 - 30) = 18 + 3 - 15 = +6 \text{ 万美元}$$
$$EMV(\text{Do Nothing}) = 0$$
在先验状态下，开发上线的预期收益为正（6 万美元），理性选择是立项研发。

### 2.2 试用版测试（Beta Test）与可靠性矩阵

管理层可耗费资金进行小范围校园封闭测试。测试结果仅有两种输出信号：
- **积极反馈（Positive, $+$）**
- **消极反馈（Negative, $-$）**

测试历史准确率矩阵（似然率 $P(\text{Signal} \mid S_i)$）如下表：

| 真实状态 | 积极反馈 $P(+ \mid S_i)$ | 消极反馈 $P(- \mid S_i)$ |
| :--- | :--- | :--- |
| 大获成功 ($S_1$) | 0.80 | 0.20 |
| 适度保本 ($S_2$) | 0.60 | 0.40 |
| 惨败出局 ($S_3$) | 0.10 | 0.90 |

### 2.3 联合概率与后验概率的列联表求解

利用联合概率公式 $P(S_i \cap \text{Signal}) = P(\text{Signal} \mid S_i) P(S_i)$ 构建联合概率矩阵：

| 状态 $S_i$ | 先验 $P(S_i)$ | 联合 $P(S_i \cap +)$ | 联合 $P(S_i \cap -)$ |
| :--- | :--- | :--- | :--- |
| 成功 $S_1$ | 0.20 | $0.20 \times 0.80 = 0.16$ | $0.20 \times 0.20 = 0.04$ |
| 保本 $S_2$ | 0.30 | $0.30 \times 0.60 = 0.18$ | $0.30 \times 0.40 = 0.12$ |
| 惨败 $S_3$ | 0.50 | $0.50 \times 0.10 = 0.05$ | $0.50 \times 0.90 = 0.45$ |
| **边缘和** | **1.00** | **$P(+) = 0.39$** | **$P(-) = 0.61$** |

::: example [计算测试反馈后的后验信念]
1. 若测试结果为积极（$+$），各状态后验概率：
   $$P(S_1 \mid +) = \frac{0.16}{0.39} \approx 0.410, \quad P(S_2 \mid +) = \frac{0.18}{0.39} \approx 0.462, \quad P(S_3 \mid +) = \frac{0.05}{0.39} \approx 0.128$$
2. 若测试结果为消极（$-$），各状态后验概率：
   $$P(S_1 \mid -) = \frac{0.04}{0.61} \approx 0.066, \quad P(S_2 \mid -) = \frac{0.12}{0.61} \approx 0.197, \quad P(S_3 \mid -) = \frac{0.45}{0.61} \approx 0.738$$
:::

可见，一旦测试返回消极信号，失败概率将从原本的 $50\%$ 陡增至 $73.8\%$。

## 3. 信息价值：EVPI 与 EVSI 的度量衡

获取数据是有财务成本的。管理者必须预先核算：我们最多愿意为这份测试报告支付多少预算？

### 3.1 完全信息期望价值（EVPI）

假设存在一位“全知先知”，能在决策前准确预告真实市场状态。
- 若先知预告 $S_1$：选择上线，赚取净利 90 万。
- 若先知预告 $S_2$：选择上线，赚取净利 10 万。
- 若先知预告 $S_3$：选择放弃开发，亏损为 0（避免了 30 万净亏损）。

完全信息下的期望收益为：
$$EMV_{\text{with Perfect Info}} = 0.20 \times 90 + 0.30 \times 10 + 0.50 \times 0 = 18 + 3 + 0 = 21 \text{ 万美元}$$

完全信息期望价值定义为有完全信息时的期望值减去基准无信息决策期望值：
$$EVPI = EMV_{\text{with Perfect Info}} - EMV_{\text{Prior}} = 21 - 6 = 15 \text{ 万美元}$$
这意味着，市场上没有任何市场调研或咨询报告的合理报价能够超过 15 万美元。

### 3.2 不完全样本信息期望价值（EVSI）

现在考虑不完美的现实封闭测试。在得到测试信号后，分别计算最优决策：
1. **收到积极信号（$+$，概率 0.39）**：
   $$EMV(\text{Launch} \mid +) = 0.410 \times 90 + 0.462 \times 10 + 0.128 \times (-30) = 36.9 + 4.62 - 3.84 = 37.68 \text{ 万}$$
   显然大于放弃开发的 0 万。故采取上线。
2. **收到消极信号（$-$，概率 0.61）**：
   $$EMV(\text{Launch} \mid -) = 0.066 \times 90 + 0.197 \times 10 + 0.738 \times (-30) = 5.94 + 1.97 - 22.14 = -14.23 \text{ 万}$$
   此时上线预期亏损 14.23 万，因此理性决策是**终止项目，选择不开发（收益为 0）**！

进行测试情况下的总期望收益（未扣除测试费）：
$$EMV_{\text{with Test}} = P(+) \times 37.68 + P(-) \times 0 = 0.39 \times 37.68 + 0 = 14.70 \text{ 万美元}$$

样本信息期望价值定义为：
$$EVSI = EMV_{\text{with Test}} - EMV_{\text{Prior}} = 14.70 - 6.00 = 8.70 \text{ 万美元}$$

只要外部测试外包报价低于 8.70 万美元，实施测试就能为企业创造净超额期望收益。

::: pitfall [基率谬误（Base Rate Fallacy）]
在解释测试结果时，管理者常误以为“90% 的测试准确率意味着测试阳性时产品有 90% 的成功率”。这完全混淆了 $P(+ \mid S)$ 与 $P(S \mid +)$。在稀有事件中，若先验基率极低，即使测试假阳性率极小，阳性反馈中依然充斥着大量的伪信号。
:::

::: insight [我的理解：信息的经济价值在于改变决策的能力]
如果一项调研不管测出什么结果，都不会改变领导层最初既定的战略行动，那么这项调研的 EVSI 在数学上就恒等于 0。许多大企业耗费巨资委托第三方咨询公司撰写所谓的评估报告，仅仅是为了给早已确定的决策提供合规背书或免责道具。从管理科学的角度来看，无法推翻原定选择的数据投入是纯粹的资本浪费。
:::

# Lec 14 生产运营案例：Filatoi Riuniti 纺织厂产能优化与外协决策 (Production Management: Filatoi Riuniti Case)

> MIT 15.060 数据、模型与决策 · 讲义 14 · 授课教师：Prof. Dimitris Bertsimas / Prof. Robert Freund

## TL;DR

- Filatoi Riuniti 案例构建了包含多工序能力、自制与外协分包权衡的复杂现实 LP 模型。
- 瓶颈识别不能依赖直觉，必须通过求解器对梳棉、精纺与加捻各车间的工时负荷进行全要素核算。
- 当内部关键产能达到物理上限时，外协（Outsourcing）成为跨越生产前沿面的有效杠杆。
- 影子价格测算为资本开支规划（如是否购置二手高速精纺机）提供了精准的 NPV 测算支撑。

## 1. 案例背景与商业决策困境

意大利比耶拉（Biella）工业区是全球顶级精纺毛纺织业的核心集群。百年老厂“Filatoi Riuniti”专门为米兰高级定制时装屋生产高端精纺羊绒与美利奴羊毛纱线。

随着秋季订货季的到来，工厂总经理马尔科（Marco）面临严峻的生产排产抉择：来自巴黎与米兰的订单总需求远超工厂车间的额定加工能力。由于高级定制面料具有严格的交期违约惩罚条款，企业必须在以下路径中寻找最优组合：
1. **产品组合筛选（Product Mix）**：在 4 种主打纱线规格中，优先排产哪些高附加值品种？
2. **自制与外协外包决策（Make-or-Buy / Subcontracting）**：对于产能无法覆盖的订单缺口，是否委托外部签约代工厂代工？外部代工不仅需要支付高额加工费，而且由于外部质量公差偏大，代工产品的最终售价需要折让 $5\%$。

```mermaid
flowchart TD
    Orders[全球定制客户订单需求 4 种高端纱线] --> Plant{Filatoi Riuniti 车间网络}
    Plant --> Process1[工序 1: 梳棉与洗毛车间 (Carding)]
    Process1 --> Process2[工序 2: 精纺车间 (Spinning - 关键瓶颈)]
    Process2 --> Process3[工序 3: 加捻与并线车间 (Twisting)]
    Plant -.-> Outsourcing[外部合格代工厂外协加工]
    Process3 --> Revenue[交付客户确认营收]
    Outsourcing --> Revenue
    Revenue --> Objective[优化目标: max 综合净利润]
```

## 2. 生产网络数据与数学规划模型构建

### 2.1 产品工艺路径与产能参数矩阵

工厂生产 4 种规格的羊毛纱线：$P_1$（超细纯羊绒）、$P_2$（羊绒混纺）、$P_3$（高支美利奴）、$P_4$（经典华达呢纱）。各品种在各工序的单位机器工时消耗、市场需求上限以及财务毛利数据如下：

| 指标参数 | $P_1$ (羊绒) | $P_2$ (混纺) | $P_3$ (美利奴) | $P_4$ (华达呢) | 车间月度可用最大总工时 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **梳棉工序 (小时/千公斤)** | 3.5 | 2.0 | 1.8 | 1.2 | **4,200 小时** |
| **精纺工序 (小时/千公斤)** | **8.0** | **5.5** | **4.0** | **2.5** | **8,000 小时 (主要制约)** |
| **加捻工序 (小时/千公斤)** | 2.0 | 2.5 | 3.0 | 1.5 | **5,000 小时** |
| **自制单位贡献毛利 ($/千公斤)**| $4,500 | $3,200 | $2,600 | $1,800 | — |
| **外协单位贡献毛利 ($/千公斤)**| $2,800 | $2,100 | $1,750 | $1,200 | — |
| **市场最大订购意向 (千公斤)** | 600 | 800 | 1,200 | 1,500 | — |
| **长期合同最低供货义务** | 200 | 200 | 300 | 400 | — |

### 2.2 决策变量定义与代数方程构建

定义两组互补的决策变量（单位：千公斤）：
- $x_j$：内部车间**自制排产**产品 $P_j$ 的数量（$j = 1, 2, 3, 4$）；
- $y_j$：交由外部代工厂**外协生产**产品 $P_j$ 的数量（$j = 1, 2, 3, 4$）。

总目标函数为最大化全厂自制毛利与外协毛利之和：
$$\max \quad Z = \sum_{j=1}^4 \text{Margin}_j^{\text{make}} \cdot x_j + \sum_{j=1}^4 \text{Margin}_j^{\text{buy}} \cdot y_j$$
$$Z = 4500 x_1 + 3200 x_2 + 2600 x_3 + 1800 x_4 + 2800 y_1 + 2100 y_2 + 1750 y_3 + 1200 y_4$$

约束条件体系：
1. **内部车间机器工时硬约束（外协产品 $y_j$ 不占用本厂工时）**：
   $$\text{梳棉：} \quad 3.5 x_1 + 2.0 x_2 + 1.8 x_3 + 1.2 x_4 \le 4200$$
   $$\text{精纺：} \quad 8.0 x_1 + 5.5 x_2 + 4.0 x_3 + 2.5 x_4 \le 8000$$
   $$\text{加捻：} \quad 2.0 x_1 + 2.5 x_2 + 3.0 x_3 + 1.5 x_4 \le 5000$$
2. **总交付量满足合同底线并不超过市场容量上限**：
   $$\text{最低合同约束：} \quad x_j + y_j \ge \text{Contract}_j, \quad j = 1, 2, 3, 4$$
   $$\text{市场容量上限：} \quad x_j + y_j \le \text{Demand}_j, \quad j = 1, 2, 3, 4$$
3. **变量非负约束**：$x_j \ge 0, \ y_j \ge 0$。

## 3. 求解输出分析与高管战略决策

通过求解器进行单纯形优化计算，得到最优运营排产方案与对偶信息如下：

### 3.1 最优排产与外协结构

| 产品类型 | 内部自制量 $x^*$ (千公斤) | 外部外协量 $y^*$ (千公斤) | 总交付量 (千公斤) | 市场满足率 |
| :--- | :--- | :--- | :--- | :--- |
| **$P_1$ (超细羊绒)** | **600** (全部自制) | 0 | 600 | 100% |
| **$P_2$ (混纺纱线)** | **581.8** | **218.2** | 800 | 100% |
| **$P_3$ (美利奴)** | 0 | **1,200** (全部外协) | 1,200 | 100% |
| **$P_4$ (经典华达呢)**| 0 | **1,500** (全部外协) | 1,500 | 100% |
| **总计** | 1,181.8 | 2,918.2 | 4,100 | 全额交付 |

全月最高净毛利总额为：**$10,238,180 美元**（约 1,024 万美元）。

### 3.2 机器负荷与影子价格的战略诊断

车间工时利用率与影子价格输出揭示了惊人的管理真相：
- **梳棉车间**：消耗工时 3,263.6 小时，上限 4,200 小时，**闲置 936.4 小时，影子价格 = $0/小时**；
- **精纺车间（Spinning）**：消耗工时 **8,000.0 小时，负荷率 100%！紧约束，影子价格 = $200.00/小时**！
- **加捻车间**：消耗工时 2,654.5 小时，上限 5,000 小时，**闲置高达 2,345.5 小时，影子价格 = $0/小时**。

::: example [自制与外协的单位工时生产力法则]
为什么模型选择把高单价的 $P_1$ 全部自制，而把 $P_3$ 和 $P_4$ 全部外协？
关键指标是**内部自制相对于外协所节省的毛利差，除以其消耗的瓶颈工时（精纺工时）**：
- $P_1$：工时生产力 $= \frac{4500 - 2800}{8.0} = \frac{1700}{8.0} = 212.5$ 美元/精纺工时；
- $P_2$：工时生产力 $= \frac{3200 - 2100}{5.5} = \frac{1100}{5.5} = 200.0$ 美元/精纺工时；
- $P_3$：工时生产力 $= \frac{2600 - 1750}{4.0} = \frac{850}{4.0} = 212.5 \dots$；
- $P_4$：工时生产力 $= \frac{1800 - 1200}{2.5} = \frac{600}{2.5} = 240.0 \dots$；
通过对偶转轴，模型精确地把极其宝贵的精纺工时优先分配给自制效益最高的环节，剩余缺口全部由外协平滑补齐。
:::

### 3.3 资本开支决策：购置二手精纺机的可行性

当地破产的一家竞品工厂正挂牌拍卖一台八成新的高速瑞士环锭精纺机，每月可提供 1,200 个精纺工时。开价 60 万美元（使用寿命 3 年）。总经理马尔科是否应参与竞拍？

- **经济学验证**：当前精纺车间影子价格为 200 美元/小时，灵敏度报告显示允许增加量为 1,500 小时。
- 引入这台机器后，每月为全厂创造的额外超额毛利为：
  $$\Delta \Pi_{\text{month}} = 1,200 \times 200 = 240,000 \text{ 美元/月}$$
- **仅需 2.5 个月，增量毛利即可完全收回 60 万美元的机器采购成本**！3 年累计现值净收益将数以百万计。

::: pitfall [外协质量风险与品牌反噬]
模型假定外协仅造成 $5\%$ 的折让。但在奢侈品行业，若代工厂爆发童工丑闻或环保排污超标，引发的品牌公关声誉危机是静态 LP 目标函数无法捕捉的隐性成本。
:::

::: insight [我的理解：优化模型不仅是生产排产表，更是战略开支的指南针]
传统工厂管理者看报表，只看哪个车间工人们最忙碌，随后凭感觉提报预算。而 Filatoi Riuniti 案例证明，线性规划模型是一台“战略显微镜”：加捻车间即使拥有最新型的自动化设备，因为下游不需要，其边际影子价值就是零；而看似平平无奇的精纺车间，哪怕每多转一分钟，都在以每小时 200 美元的速度为企业吐出纯利润。优化模型让每一分钱的资本支出都能精确砸在系统的咽喉要害之上。
:::

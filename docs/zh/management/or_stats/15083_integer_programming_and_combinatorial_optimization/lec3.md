## TL;DR

- 有效不等式（Valid Inequality）在绝不剔除任何合法整数解前提下大幅削减松弛体积。
- 求解器预处理（Presolve）利用区间算术与探测技术消除高达 $80\%$ 的冗余约束。
- 背包覆盖不等式（Knapsack Cover Cuts）将组合冲突转化为强力割平面。

## 1. 削减虚胖：为什么必须增强表述？

在第 1 讲中我们看到，简单的业务逻辑代数直译往往会产出极其虚弱的松弛多面体。
连续松弛多面体中充斥着海量的“分数假解”——这些解虽然满足当前的线性不等式，但根本没有任何一个整数点能够落在它们附近。

为了在分支定界算法启动之前，先把多面体中那些脱离整数凸包的巨大虚胖空间削减掉，现代优化求解器（如 Gurobi, CPLEX, SCIP）依赖两大核心工程支柱：
1. **预处理技术（Presolve & Probing）**；
2. **有效不等式生成（Valid Inequalities）**。

## 2. 工业求解器的秘密武器：预处理（Presolve）

在用户提交模型后的前几百毫秒内，求解器绝不会直接解单纯形表，而是执行极其严密的**预处理流水线**：

### 2.1 区间代数与变量界限收紧（Bound Tightening）
考察不等式：
$$a_k x_k + \sum_{j \ne k} a_j x_j \le b$$
设所有变量拥有上下界 $l_j \le x_j \le u_j$。
则其他变量在最坏情况下所能消耗的最小值为：
$$m_k = \sum_{j \ne k, a_j > 0} a_j l_j + \sum_{j \ne k, a_j < 0} a_j u_j$$
若 $a_k > 0$，则变量 $x_k$ 必然受到一个全新的、更加紧致的**代数隐式上界**限制：
$$x_k \le \frac{b - m_k}{a_k}$$
若算出的这个新上界比用户原来设定的 $u_k$ 更小，求解器立即原地将 $u_k$ 收缩！通过多轮交替迭代传播，变量的活动区间被急剧压缩。

### 2.2 逻辑探测（Probing）
对每个 0-1 变量试探性令 $y = 1$：
- 顺着约束关系向前推导，若直接导致某连续变量上下界倒挂（$l_j > u_j$），则当场判定 $y=1$ 不可能成立，**直接固定变量 $y = 0$**！
- 若当 $y = 1$ 时，必然推出另一个变量 $z = 1$，则求解器立即永久向模型中注入一条新的全局有效逻辑不等式：$z \ge y$！

## 3. 背包覆盖不等式（Knapsack Cover Inequalities）

在整数规划中，最普遍出现的约束形态是**0-1 背包约束（Knapsack Constraint）**：
$$\sum_{j=1}^n a_j x_j \le b, \quad x_j \in \{0, 1\}, \quad (a_j > 0, b > 0)$$

::: definition 覆盖集 (Cover) 与最小覆盖
一个指标子集 $C \subset \{1, \dots, n\}$ 称为一个**覆盖（Cover）**，若该子集内所有物品的重量总和严格超过背包容量：
$$\sum_{j \in C} a_j > b$$
若对于 $C$ 中的任意单个元素 $k \in C$，去掉它后重量均不再超重（$\sum_{j \in C \setminus \{k\}} a_j \le b$），则称 $C$ 为一个**极小覆盖（Minimal Cover）**。
:::

::: theorem 经典背包覆盖有效不等式 (Knapsack Cover Cut)
若集合 $C$ 是一个覆盖集。则对于原背包约束的所有合法整数可行解，以下线性不等式**严格恒成立**：
$$\sum_{j \in C} x_j \le |C| - 1$$
:::

证明基于纯粹的常识：既然把 $C$ 里的所有物品全装进去会导致背包撑爆，那么理性的决策者在 $C$ 集合中**至多只能挑选 $|C| - 1$ 个物品！**

::: example 背包覆盖对连续松弛的致命一刀
考虑约束：$6 x_1 + 5 x_2 + 4 x_3 + 3 x_4 \le 10$（$x_i \in \{0, 1\}$）。
连续松弛最优解完全可能取一个恶心的分数极点：$x^* = (1, 0.8, 0, 0)$，此时 $6 \times 1 + 5 \times 0.8 = 10$，松弛完全可行！
但是，考察子集 $C = \{1, 2\}$：$a_1 + a_2 = 6 + 5 = 11 > 10$！$C$ 是一个极小覆盖！
对应的背包覆盖不等式为：
$$x_1 + x_2 \le 2 - 1 = 1$$
将当前连续解 $x^*$ 代入该不等式：$1 + 0.8 = 1.8 \le 1$ 矛盾！
**这一条背包覆盖割平面，像一把手术刀，瞬间将这个分数伪解从可行域中彻底斩除！**

::: insight 提炼隐式组合逻辑的代数艺术
有效不等式绝不是外来的装饰，它是离散约束在连续几何空间中的“全息投影”。
现实工业系统中的每一个 0-1 变量，都与周围的成百上千个变量交织在复杂的互斥与蕴含网络中。预处理与覆盖不等式的工作，就是在算法起跑之前，把这些隐匿在黑暗中的逻辑暗礁全部起获并写成显式的线性方程。这使得分支定界求解器一开跑，就处于高度修剪的平坦大道之上。
:::

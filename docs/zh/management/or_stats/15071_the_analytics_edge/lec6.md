# Lec 6 逻辑回归导论与专家经验的形式化建模 (An Introduction to Logistic Regression: Modeling the Expert)

> MIT 15.071 数据分析优势 · 讲义 6 · 授课教师：Prof. Dimitris Bertsimas / Allison O'Hair

## TL;DR

- 逻辑回归（Logistic Regression）是二元分类问题的奠基石，解决了普通线性回归预测概率溢出 $[0, 1]$ 边界的致命缺陷。
- Sigmoid 逻辑斯蒂函数将无限实数轴映射为严格单调的概率值，Logit 变换将非线性发生比转化为线性可加模型。
- 最大似然估计（Maximum Likelihood Estimation, MLE）通过寻找使观测样本联合发生概率最大的参数求解系数。
- 在高危医学诊断与信贷风控中，形式化的逻辑回归模型在一致性与抗疲劳度上全面碾压人类专家经验。

## 1. 为什么二元分类不能使用普通线性回归（OLS）？

在商业与工程实践中，存在大量非黑即白的二元离散抉择：
- 这位信用卡申请人未来是否会违约？（$Y \in \{0, 1\}$）
- 这位急诊室送来的急性胸痛患者是否正在发生心肌梗死？（$Y \in \{0, 1\}$）
- 这封电子邮件是否属于欺诈钓鱼垃圾邮件？（$Y \in \{0, 1\}$）

若机械套用普通最小二乘线性回归（Linear Probability Model, LPM）：
$$P(Y = 1 \mid X) = \beta_0 + \beta_1 X_1 + \dots + \beta_k X_k$$
会立刻遭遇**三大不可克服的理论死穴**：

::: pitfall [线性概率模型 (LPM) 的三大灾难]
1. **概率越界荒谬性**：线性函数的值域在 $[-\infty, +\infty]$ 之间。当自变量取极端值时，模型会输出诸如 $P = 1.35$ 或 $P = -0.22$ 这类在概率论公理中完全非法的数值；
2. **严重异方差性（Heteroscedasticity）**：二元伯努利变量的方差为 $Var(Y \mid X) = p(X)(1 - p(X))$，方差完全由自变量自身决定，彻底摧毁了 OLS 的同方差性假定；
3. **边际递减效应失效**：在真实世界中，患者收缩压从 120 升高到 130，心梗风险可能仅微升 $1\%$；但若血压从 190 飙升到 200，其诱发心梗的边际致命概率呈急剧指数级爆发。线性模型强行假设边际增长率处处恒定。
:::

```mermaid
flowchart LR
    Binary[二元决策因变量 Y in 0, 1] --> Conflict[普通 OLS: 预测值超出 0-1 边界]
    Binary --> Sigmoid[引入 Sigmoid 激活函数 S 型曲面]
    Sigmoid --> Logit[Logit 变换: ln p / 1-p 恢复线性关系]
    Logit --> MLE[最大似然估计求解系数: max 联合发生概率]
    MLE --> Classification[输出平滑后验概率 P Y=1 | X]
```

## 2. 逻辑斯蒂函数与几率比（Odds Ratio）

为了将无界线性预测值 $\beta^T X$ 约束在严格的 $(0, 1)$ 概率区间内，我们引入标准 **Sigmoid 函数**：
$$p(X) = P(Y = 1 \mid X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \dots + \beta_k X_k)}} = \frac{e^{\beta^T X}}{1 + e^{\beta^T X}}$$

### 2.1 几率（Odds）与 Logit 变换

定义事件发生的**几率（Odds）**为“发生概率与不发生概率之比”：
$$\text{Odds} = \frac{p(X)}{1 - p(X)} = e^{\beta^T X} = \exp\left(\beta_0 + \sum_{j=1}^k \beta_j X_j\right)$$
- 若某支球队赢球概率 $p = 0.80$，则其输球概率为 $0.20$，几率 $\text{Odds} = \frac{0.80}{0.20} = 4$（即赢的希望是输的 4 倍）。

对几率取自然对数，即得到著名的 **Logit 变换（对数几率）**：
$$\text{Logit}(p) = \ln\left(\frac{p(X)}{1 - p(X)}\right) = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_k X_k$$

::: theorem [逻辑回归系数的几率比乘数法则]
在逻辑回归中，解释变量系数 $\beta_j$ 的严格数学与经济学解读为：
**在控制其他所有协变量保持不变的前提下，自变量 $X_j$ 每增加 1 个单位，事件发生的几率（Odds）将乘以乘数因子 $e^{\beta_j}$（几率比 Odds Ratio, OR）**：
$$\frac{\text{Odds}(X_j + 1)}{\text{Odds}(X_j)} = e^{\beta_j}$$
- 若 $\beta_j > 0 \implies e^{\beta_j} > 1$：几率上升，属于危险/促进因素；
- 若 $\beta_j < 0 \implies e^{\beta_j} < 1$：几率下降，属于保护/抑制因素；
- 若 $\beta_j = 0 \implies e^{\beta_j} = 1$：该变量对事件发生概率无任何边际影响。
:::

## 3. 最大似然估计（Maximum Likelihood Estimation, MLE）

逻辑回归不再采用最小二乘法求解，而是使用**最大似然估计法（MLE）**。
设样本数据中各观测点相互独立，观测到样本标签序列 $(y_1, y_2, \dots, y_n)$ 的联合似然函数（Likelihood Function）为：
$$L(\beta) = \prod_{i=1}^n p(x_i)^{y_i} (1 - p(x_i))^{1 - y_i}$$

取对数得到对数似然函数（Log-Likelihood）：
$$\ln L(\beta) = \sum_{i=1}^n \left[ y_i \ln p(x_i) + (1 - y_i) \ln(1 - p(x_i)) \right]$$

通过牛顿-拉夫逊迭代法（Newton-Raphson）或拟牛顿法，寻找能够使当前这批样本观测结果出现概率达到全局最大的最优参数向量 $\beta^*$。

## 4. 案例实战：模拟临床专家诊断（Modeling the Expert）

在医疗健康领域，优质资深全科医生（Expert Physicians）的稀缺构成了全球医疗体系的重大瓶颈。能否利用逻辑回归模型学习顶级医学专家的诊断模式，构建一个客观、稳定且不知疲倦的“机器专家”？

### 4.1 喉咙链球菌感染（Strep Throat）自动化初筛

患者因急性喉咙剧痛前往诊所就医。病因可能是自限性的普通病毒性感冒（无需抗生素），也可能是危险的 A 组链球菌感染（必须及时服用青霉素抗生素以防风湿性心脏病）。培养皿化验需要耗费 48 小时，医生必须在接诊当下做出经验处方。

基于 1,500 例真实急诊病患数据拟合逻辑回归模型，因变量为培养皿确诊链球菌阳性（$Y=1$）：
- $X_1$：体温高热（$\text{Fever} > 38^\circ\text{C}$，0-1 变量）
- $X_2$：扁桃体化脓渗出物（$\text{Exudate}$，0-1 变量）
- $X_3$：颈部淋巴结肿大伴压痛（$\text{Lymph}$，0-1 变量）
- $X_4$：是否缺乏咳嗽症状（$\text{NoCough}$，0-1 变量，链球菌通常无咳嗽）

回归结果输出：
$$\text{Logit}(p) = -2.45 + 0.82 (\text{Fever}) + 1.25 (\text{Exudate}) + 0.74 (\text{Lymph}) + 0.96 (\text{NoCough})$$

::: example [计算一位高危患者的确诊概率]
某位患者体温 $39^\circ\text{C}$（Fever=1），扁桃体化脓（Exudate=1），有淋巴结肿痛（Lymph=1），且不咳嗽（NoCough=1）：
$$\text{Logit}(p) = -2.45 + 0.82(1) + 1.25(1) + 0.74(1) + 0.96(1) = -2.45 + 3.77 = +1.32$$
代入 Sigmoid 函数计算确诊概率：
$$p = \frac{1}{1 + e^{-1.32}} = \frac{1}{1 + 0.267} = \mathbf{78.9\%}$$
由于确诊概率高达近 $80\%$，模型坚决建议立即进行经验性抗生素阻断治疗。
:::

### 4.2 机器专家对抗人类专家：决策一致性与认知疲劳

医学社会学的大量双盲测试表明：人类专家在做诊断时极易受到无关环境要素的严重干扰：
- 疲劳效应：周五下午 5 点接诊的医生，开具昂贵且不必要抗生素的概率比周一上午高出整整 $35\%$；
- 锚定效应：如果刚刚接诊的连续两位病患均确诊重症，医生倾向于对第三位病患做出过度诊断。
而逻辑回归模型具有绝对的**逻辑一致性（Consistency）**：输入相同的指标组合，无论在深夜还是黎明，模型永远输出绝对一致的概率期望。

::: pitfall [混淆矩阵阈值划分中的成本不对称]
逻辑回归输出的是连续概率 $p \in [0, 1]$。将其转换为最终行动必须选定分类阈值 $t$（如 $p \ge t$ 则诊断为阳性）。初学者常盲目设定默认阈值 $t = 0.50$。但在恶性肿瘤或心梗初筛中，**假阴性（漏诊放走癌症）的死亡代价极其沉重，而假阳性（误判做进一步活检）的代价相对可控**。分类阈值必须依据混淆矩阵的非对称损失矩阵进行优化设定。
:::

::: insight [我的理解：算法建模专家，不是淘汰专家，而是赋能基层]
顶级名医用三十年临床摸爬滚打积累的宝贵临床直觉，本质上就是一套高维隐式的非线性决策函数。逻辑回归的魅力，在于用数学工具将那些沉淀在名医脑海深处模糊的“行医语感”，显式提炼为白纸黑字的参数体系。一旦被模型固化，这一套智慧就可以通过智能手机瞬间分发到非洲偏远乡村、高原诊所的每一位基层全科医生手中。这是数据分析对人类生命最崇高的赋能。
:::

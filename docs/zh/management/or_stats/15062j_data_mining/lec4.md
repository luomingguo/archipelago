# Lec 4 费希尔线性判别分析（LDA）与降维分类 (Discriminant Analysis & Fisher Iris Case)

> MIT 15.062J 数据挖掘 · 讲义 4 · 授课教师：Prof. Roy Welsch / Nitin Patel

## TL;DR

- 线性判别分析（LDA）由现代统计学之父罗纳德·费希尔（Ronald Fisher）于 1936 年提出，兼具监督分类与特征降维双重功能。
- 费希尔准则追求将高维数据投影至低维直线，使得类间方差最大化、同时类内方差最小化。
- 当假定各类别服从同方差多元正态分布时，贝叶斯分类器精确退化为线性判别超平面。
- 经典鸢尾花（Fisher's Iris）案例生动展现了多维花萼花瓣形态空间向一维判别轴的极优投影折叠。

## 1. 费希尔判别分析的几何几何直觉

在面对多维分类任务时，我们常常希望对高维特征实施降维（Dimensionality Reduction），以便进行直观的可视化展示与降低计算复杂度。

然而，如果在降维时不考虑样本的类别标签信息，盲目采用无监督的主成分分析（PCA），可能会发生严重的灾难：
PCA 仅仅寻找全样本总方差最大的投影方向；若两个类别的中心在某个方向上分得很开，但各自类内的波动更大，PCA 的投影方向可能会让两个类别在低维轴上完全重叠挤压在一起，彻底丧失分类能力！

1936 年，现代数理统计学的奠基人罗纳德·费希尔爵士（Sir Ronald Fisher）发表了经典论文《分类问题中多重测量的应用》，提出了**监督式判别投影准则**：
**寻找一个最优的投影投影方向向量 $w$，将样本投影到一维直线上后，使得不同类别之间的中心距离尽可能拉得最开（类间离散度最大），同时同一个类别内部的样本点尽可能抱团紧缩（类内离散度最小）**！

```mermaid
flowchart TD
    HighDim[高维特征输入: 包含类别标签的样本点阵] --> FisherCriterion[费希尔核心准则: 最大化广义瑞利商 J_w]
    FisherCriterion --> BetweenClass[分子: 类间离散度矩阵 S_B (拉大类别中心差距)]
    FisherCriterion --> WithinClass[分母: 类内离散度矩阵 S_W (压缩同类内部波动)]
    BetweenClass --> Eigen[广义特征值分解: S_W^-1 S_B w = lambda w]
    WithinClass --> Eigen
    Eigen --> Projection[最优判别投影超平面: 类别重叠度降至理论极低]
```

## 2. 费希尔准则与广义瑞利商推导

设二分类样本集包含类别 $C_1$（样本量 $N_1$）与类别 $C_2$（样本量 $N_2$）。
原始特征向量为 $x \in \mathbb{R}^p$，均值向量分别为 $\mu_1$ 与 $\mu_2$。

将样本投影到一维标量轴：$y = w^T x$。
投影后的两类均值分别为 $\tilde{\mu}_1 = w^T \mu_1$，$\tilde{\mu}_2 = w^T \mu_2$。

### 2.1 离散度矩阵构造

- **类间离散度矩阵（Between-class Scatter Matrix, $S_B$）**：
  $$S_B = (\mu_1 - \mu_2)(\mu_1 - \mu_2)^T$$
  投影后的类间距离平方为：$(\tilde{\mu}_1 - \tilde{\mu}_2)^2 = w^T S_B w$。
- **类内离散度矩阵（Within-class Scatter Matrix, $S_W$）**：
  $$S_W = \sum_{x \in C_1} (x - \mu_1)(x - \mu_1)^T + \sum_{x \in C_2} (x - \mu_2)(x - \mu_2)^T = (N_1 - 1)\Sigma_1 + (N_2 - 1)\Sigma_2$$
  投影后的两类内部方差和为：$\tilde{s}_1^2 + \tilde{s}_2^2 = w^T S_W w$。

### 2.2 最大化广义瑞利商（Generalized Rayleigh Quotient）

费希尔目标函数定义为投影类间方差与类内方差之比：
$$J(w) = \frac{w^T S_B w}{w^T S_W w}$$

对向量 $w$ 求导并令其为零，由于标量比例不影响方向，该极值问题转化为求解**广义特征值问题**：
$$S_B w = \lambda S_W w \implies S_W^{-1} S_B w = \lambda w$$

注意到 $S_B w = (\mu_1 - \mu_2) \left[ (\mu_1 - \mu_2)^T w \right]$ 始终沿着均值差向量 $(\mu_1 - \mu_2)$ 的方向。由此直接解得费希尔最优投影方向的解析解：
$$w^* \propto S_W^{-1} (\mu_1 - \mu_2)$$

::: theorem [费希尔投影方向的物理内涵]
最优投影方向 $w^*$ 并不是简单连接两个类别均值的直线 $(\mu_1 - \mu_2)$；
而是用**类内协方差矩阵的逆 $S_W^{-1}$** 对均值差向量实施了坐标变换（马氏距离度量标准化），自发沿着数据本身方差较小、重叠较少的方向进行倾斜偏转，从而在低维轴上达成惊人的分离纯度。
:::

## 3. 经典案例：费希尔鸢尾花数据集（Fisher's Iris Data）

在 15.062J 的案例中，我们重温了这组全人类机器学习界最著名的开山圣杯——费希尔于 1936 年收集自加拿大加斯佩半岛的 150 朵野生鸢尾花测量数据。

包含三个鸢尾花亚种：**山鸢尾（Setosa）**、**变色鸢尾（Versicolor）**与**维吉尼亚鸢尾（Virginica）**，每个品种各 50 朵样本。测定 4 项形态几何特征（单位：厘米）：
1. 花萼长度（Sepal.Length）
2. 花萼宽度（Sepal.Width）
3. 花瓣长度（Petal.Length）
4. 花瓣宽度（Petal.Width）

### 3.1 降维投影输出分析

由于存在 $K = 3$ 个类别，LDA 在数学上最多能够提取出 $K - 1 = 2$ 个相互正交的线性判别轴（$LD_1$ 与 $LD_2$）：
- **第一判别轴 $LD_1$ 解释了高达 $99.1\%$ 的类间方差**！
  其权重主要由花瓣长度（$+0.83$）与花瓣宽度（$+0.65$）主宰。
- 在投影后的一维轴上，山鸢尾（Setosa）与其他两个亚种之间形成了一条完全不可逾越的鸿沟（间距极大且类内紧凑），实现了 **$100\%$ 的零错误分离**；
- 变色鸢尾与维吉尼亚鸢尾在四维原始空间中严重交织重叠，但在二维判别平面上，仅用一条斜线即可实现高达 **$98\%$ 的极高分类准确率**。

## 4. 贝叶斯统计视角下的判别函数推导

LDA 不仅能由费希尔几何直觉推导，更能从严密的贝叶斯统计推断中自然导出：

::: definition [高斯线性判别函数 (Gaussian LDA)]
假设每个类别的特征向量服从多元正态分布 $X \sim N(\mu_k, \Sigma)$，且**假定所有类别拥有完全相同的协方差矩阵 $\Sigma$（同方差假定）**。
对贝叶斯后验概率对数展开并化简，二次项 $x^T \Sigma^{-1} x$ 相互抵消，得到纯线性的判别函数：
$$\delta_k(x) = x^T \Sigma^{-1} \mu_k - \frac{1}{2} \mu_k^T \Sigma^{-1} \mu_k + \ln P(C_k)$$
两个类别的决策分界面 $\delta_1(x) = \delta_2(x)$ 在高维空间中是一个严格的**超平面（Hyperplane）**！
:::

若打破“各类别同方差”的假定，允许每个类别拥有独立的协方差矩阵 $\Sigma_k$，二次项无法抵消，决策边界将弯曲为二次曲面，算法随之升级为**二次判别分析（Quadratic Discriminant Analysis, QDA）**。

::: pitfall [奇异矩阵与小样本问题（Small Sample Size Problem）]
在现代生物信息学或基因微阵列数据中，特征维度 $p$（几万个基因表达）远大于样本容量 $n$（几十个病人）。此时类内离散度矩阵 $S_W$ 必然处于严重的降秩不可逆状态（奇异矩阵），直接导致 $S_W^{-1}$ 无法求解。在实务中必须引入**正则化判别分析（Regularized LDA）**，向对角线添加岭收缩惩罚项（$S_W + \gamma I$）。
:::

::: insight [我的理解：LDA 是一门懂得在混乱中选择倾斜角度的摄影艺术]
把三维立体的世界压缩成二维照片，如果拍摄的角度选得糟糕，前景的树干就会把后景的游人彻底挡住，融成一团无法分辨的剪影；而费希尔 LDA 就像一位经验无比老到的摄影大师。他绕着数据星系反复审视，终于找到了那个最绝妙的俯瞰机位——快门按下的瞬间，原本纠缠不休的万千样本，各自乖巧地向左右两端自然散开。降维不是粗暴的删减，而是寻找秩序的艺术。
:::

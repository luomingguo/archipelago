# 15.835 创业营销与增长攻坚 (Entrepreneurial Marketing)

> MIT Course 15 · Marketing · 市场营销 · 课号 15.835

## TL;DR

- 在零品牌知名度、预算极端匮乏的不确定性约束下，推动初创项目冷启动与破局增长。
- 跨越鸿沟理论（Crossing the Chasm），识别早期创新采用者并建立灯塔客户标杆效应。
- 低成本增长黑客（Growth Hacking）、病毒式裂变传播机制与精准获客漏斗迭代。

## 课程简介 / Description

Because there is no universal marketing solution applicable to all entrepreneurial ventures, this course is designed to help students develop a flexible way of thinking about marketing problems in general.

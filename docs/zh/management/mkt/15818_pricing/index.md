# 15.818 定价

## TL;DR

- 定价超越传统 3C 成本与竞争约束，核心在于主动创造、校准、传达并获取客户经济价值（4C 价值框架）。
- 客户经济价值（EVC）以参照品价格与差异化净价值界定上限，结合价格弹性与联合分析科学测算支付意愿。
- 借助价格围栏、非线性折扣、收益管理算法与动态拍卖机制，实现价值向企业长期利润的高效捕获。


## 课程信息

主讲教师为麻省理工斯隆管理学院（MIT Sloan School of Management）的 Catherine Tucker 教授。这是一门研究生水平的定价实务课程，横跨营销（Marketing）、运营管理（Operations Management）、经济学（Economics）与产业组织（Industrial Organization）等领域，旨在教授学生如何为产品与服务定价。

课程的核心立场是：定价不应被动服从成本、客户或竞争对手施加的约束（传统的"3C"），而应主动去创造、校准、传达并获取价值（本课程重新定义的"4C"）。课程讲义即为教材本身——授课教师认为市面上现有教材在定量分析深度上不足以支撑实务定价决策。

## 核心分析框架

课程围绕定价决策的完整链条展开：

1. **价值分析（EVC）**：以客户经济价值（Economic Value to the Customer）为核心工具，量化产品相对最直接竞品的差异化价值，并据此推导价格上限。
2. **客户认知与行为**：客户往往不了解真实参照价格，也会用价格本身反过来推断产品质量与自我形象，定价策略必须同时考虑价值创造与认知框架。
3. **价格测量与弹性**：通过调研方法（开放式提问、联合分析）与真实历史数据测算客户对价格的真实反应与价格弹性。
4. **价格细分与获取价值**：利用围栏机制、非线性定价、拍卖与算法定价等手段，把已创造的价值真正转化为企业利润。
5. **竞争与谈判**：在竞争对手的定价反应与 B2B 议价谈判场景中，保护并延续已建立的定价体系。

## 阅读与使用说明

1. **讲义结构**：每篇讲义均配备独立的 `## TL;DR` 核心要点总结，提炼本讲最重要的定价决策洞见。
2. **案例驱动**：本课程高度依赖真实企业案例（如 Atlantic Computer、Zantac、Segway、TurboTax 等），讲义均完整保留原始案例的具体数字与细节，而非抽象转述。
3. **定量工具**：涉及 EVC 计算、价格弹性、非线性定价等处，均保留原始公式的严格数学表达。
4. **商业洞察标记**：使用规范的语义容器（如 `::: definition`、`::: example`、`::: pitfall`、`::: insight`），帮助技术背景读者建立结构化的定价分析思维。

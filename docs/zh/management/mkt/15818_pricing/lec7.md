# Lec 7 应对竞争性定价侵蚀（Out-Pricing）

> MIT 15.818 · Pricing · 主讲 Prof. Catherine Tucker

## TL;DR

- 本讲系列此前刻意忽略了竞争对手，以避免让竞争对手主导定价决策；本讲聚焦如何在合法边界内应对竞争，核心是价格固定（price fixing）与掠夺性定价（predatory pricing）的法律红线，以及低于此红线的战术空间。
- 判断价格侵蚀风险要看需求走势、产能松紧与差异化程度：需求下滑、产能过剩、差异化不足的品类（如啤酒）容易爆发价格战；产能紧张、需求稳步上升、差异化充分（如剃须刀-刀片模式或两边市场）的品类则相对安全，可用交叉价格弹性量化风险。
- 应对定价威胁时，公开承诺"价格跟随"往往比暗示成本优势或扩张产能更有效；与媒体沟通定价意图时应提前解释涨价/降价理由，避免被误读为挑衅。
- 除了直接降价，企业还可以通过产品（如推出低价迎战品牌）、促销和渠道（分销合作、关键影响者）三个"P"来应对竞争性降价；直接降价则面临"钱包不够深""质量被误判""客户群体不忠诚"三类陷阱，需谨慎评估。

## 价格竞争的法律边界

> 同行的人很少聚在一起，即便只是为了娱乐消遣，谈话最终也往往会演变成对公众利益的合谋，或某种变相涨价的手段。——亚当·斯密

### 价格固定与围标

在美国，价格固定（price fixing）可依据《谢尔曼反托拉斯法》第一条以刑事重罪起诉。价格固定是指竞争者之间达成协议以提高、固定或以其他方式维持其商品或服务的销售价格。竞争者不需要就完全相同的价格达成一致，也不需要该行业每个竞争者都参与该合谋——价格固定可以有多种形式，任何限制价格竞争的协议都构成违法。任何与竞争对手就价格或其他竞争要素直接沟通的行为在美国与欧盟反垄断法下都被严格禁止；即使是间接的价格沟通，结合其他合谋意图证据，也可能构成反垄断起诉的依据。

::: pitfall FTC 侦测价格固定时关注的模式
- 价格长期保持一致，尤其是当价格此前存在差异时。
- 涨价缺乏成本上升的支撑。
- 折扣被取消，尤其是在历来提供折扣的市场。
- 供应商对本地客户的收费高于对远方客户的收费，可能意味着本地价格被固定。
:::

::: pitfall 触发 FTC 关注的员工行为红旗
- 提及行业范围或行业协会的价格表。
- 表明提前（非公开）掌握竞争对手定价信息。
- 声称某个客户或合同"归属于"某个特定供应商。
- 将某次投标描述为"礼节性""象征性""陪标"性质的投标。
- 任何表明供应商之间就价格进行过讨论或达成过默契的陈述。
:::

::: example 价格固定的成功起诉案例
- 苏富比拍卖行前董事长 Alfred Taubman 因操纵向客户收取的费用被判入狱一年，实际服刑 9 个月，并被处以 750 万美元罚款。Taubman 承认与佳士得的对手有过十几次会面，但坚称双方从未合谋："我们非常小心，从不讨论任何违法的事，我们深知法律，我很清楚这一点。"
- 2004 至 2006 年间，多家航空公司合谋对跨大西洋航班征收高额燃油附加费。维珍航空因主动揭发合谋行为而免于经济处罚；英国航空被英国公平贸易办公室罚款 2 亿美元，被美国司法部罚款 3 亿美元；货运经理 Keith Packer 因参与操纵美欧间货运价格服务被判处美国监狱 8 个月，并处 2 万美元罚款。
- Sea Star Line 公司收益管理高级副总裁 Peter Baci 因操纵美国与波多黎各之间的货运价格被判入狱 4 年；他在法庭上辩称自己只是奉命行事，但这在量刑时未被采纳。
:::

### 掠夺性定价

以驱逐竞争对手为目的的低价销售可依据《谢尔曼法》的反垄断条款被起诉。但美国最高法院在 1986 年裁定，未能真正驱逐竞争对手的票价战对消费者而言是"福音"，政府必须谨慎，避免"冻结反垄断法本应保护的正当竞争行为"。

## 预判并应对竞争性价格侵蚀

值得注意的是，从经验数据看，竞争性价格侵蚀正变得不那么令人担忧：据 RSR Research（2010 年 1 月）调查，认为"来自竞争对手的定价攻势"是一大挑战的受访者比例从 48% 降至 38%；相反，价格侵蚀更多地由提升销售的内部压力所驱动。

### 评估价格侵蚀风险

::: theorem 高风险与低风险的定价环境
**高风险特征**：需求下滑、产能过剩、差异化价值差异不大。啤酒是这类产品的经典例子——它是一种高固定成本、差异化程度低的产品，且面临葡萄酒等替代品带来的需求下滑压力。

**低风险特征**：产能紧张、需求稳步增长、差异化价值充分（"剃须刀-刀片"模式或两边市场是理想状态）。
:::

::: example 需求下滑但差异化保护定价的对比案例
2009 年 4 月，亚马逊在英国以每首 29 便士（约合 0.5 美元）的价格出售 100 首热门 MP3 单曲，苹果 iTunes 商店的应对方式不是跟随降价，而是把最热门单曲的价格提高到 99 便士（约 1.5 美元）。苹果之所以能这样做，是因为 iTunes 拥有转换成本与体验优势带来的差异化保护。
:::

::: definition 交叉价格弹性（Cross-Price Elasticity）
交叉价格弹性衡量本企业产品销量的百分比变化相对于竞争对手价格百分比变化的比率：

$$E_{A,B} = \frac{\%\ \text{产品 A 需求变化}}{\%\ \text{产品 B 价格变化}}$$

也可以用 Excel 中对数-对数变换后的斜率公式来计算：以自身销量的对数为 $y$，竞争对手价格的对数为 $x$。理想情况下该值应接近零；一旦超过 0.5 就需要警惕。
:::

### 评估竞争对手的定价复杂程度

需要了解竞争对手的价格/成本结构，判断其战略博弈能力是否成熟——你只能在最不擅长博弈的竞争对手的水平上玩这场定价游戏。

::: example 课堂定价博弈实验
规则：参与者需为一件物品选择 0 至 50 美元之间的售价，若该价格比全体参与者的平均报价低 20%（即报出均价的 80%），则赢得该物品；理想折扣是 20%——折扣过大，客户不会转换品牌忠诚度；折扣过小，客户又会怀疑产品质量。

不同群体的平均迭代轮数（即需要经过多少轮才能收敛到均衡）：

| 群体 | 平均迭代轮数 |
|---|---|
| 计算机科学家 | 3.8 |
| 投资组合经理 | 2.8 |
| 高中生 | 1.6 |
| CEO | 1.0 |

CEO 群体最快收敛到均衡价格，反映出策略定价不仅依赖企业自身对博弈论的理解，也依赖对竞争对手博弈论理解程度的判断。
:::

### 释放定价威胁信号

::: insight
选择性地披露自身能力与未来计划信息，有助于避免有害的负和博弈——目的是打消竞争对手降价、挑战企业定价决心的念头。
:::

::: pitfall 三种释放威胁信号的策略及其效果
- **扩张产能以显示"来势汹汹"**：一些战略学者认为，扩张产能能让企业显得极具威慑力，令竞争对手不敢降价。但航空业的经验恰恰相反——航空业只有在 9/11 后削减产能，才重新恢复盈利能力；到 2003 年，行业客座率从 9/11 后恢复到历史最高的 73.4%。
- **宣称拥有成本优势可能适得其反**：一家早期汽车电脑软件公司曾宣称，凭借外包呼叫中心带来的成本优势，竞争对手无法在价格上压过自己，结果竞争对手也纷纷把客服部门迁往海外，反而导致整个呼叫中心行业的价格上涨。
- **最有效的策略是公开承诺以价格反击**：在 Winn-Dixie、Big Star 对阵 Food Lion 的案例中，价格匹配承诺使得两年后 Food Lion 在 79 种常购品牌商品上把价格提高了一倍。然而，后来曝光的 Best Buy 内部"秘密备忘录"显示其在暗中规避自己的价格匹配政策，说明这类承诺政策本身也存在被规避的风险。
:::

### 与媒体谈论定价

企业在与媒体沟通时，应像管理股东与证券分析师的预期一样，谨慎管理竞争对手对自身定价策略的解读。

::: example 良好与糟糕的媒体沟通对比
**良好沟通示例**：桌面虚拟机软件公司 Parallels 的 CEO Serguei Beloussov 表示，他正效仿苹果的做法，将 Parallels Desktop 定位为具备更高品质与服务的高端产品，明确表示不会与主要竞争对手 VMware Fusion 打价格战。他相信提升产品与支持、增加相较竞品更多的功能才是扩大市场份额的正道；Mac 用户不像 Windows 用户那样价格敏感，愿意为体验良好的产品支付更高价格。

**糟糕沟通示例**：1997 年，康柏电脑（Compaq）CEO Eckhard Pfeiffer 宣称，公司新的商业模式与激进降价不会引发外界预期中主要 PC 厂商之间的价格战；公司称新公布的 DeskPro 价格比同类戴尔产品便宜 6%–8%；Pfeiffer 表示全面价格战将会避免，因为其他厂商的降价"将来自他们自己的利润率"——但从当时的市场压力看，这一说法本身显得难以持续。
:::

::: pitfall 变更定价时若不解释理由，可能引发不必要的报复
一家心理监护仪制造商因需要出售一批不符合 FTC 拟议新规的设备而降价，但由于未向竞争对手解释降价原因，反而引发了一场价格战，竞争对手误解了其真实意图。
:::

## 用产品、促销、渠道这另外 3P 应对竞争性价格侵蚀

::: insight
除了直接降价，企业还可以通过操控客户对降价的感知——利用产品（Product）、促销（Promotion）与渠道（Placement）——来削弱竞争性降价对自身的冲击。
:::

### 产品

::: example 迎战品牌（Fighting Brand）
推出专门用于打价格战的低端品牌前，建议先阅读 Mark Ritson 发表于《哈佛商业评论》（2009 年 10 月）的文章《你应该推出迎战品牌吗？》。英特尔用 Celeron 芯片而非高端 Pentium 芯片打价格战，取得了相当程度的成功；相比之下，达美航空的 Song 子品牌并未能有效抵御 JetBlue 的竞争。
:::

::: example 改进产品：诺顿杀毒软件应对迈克菲
迈克菲推出"Net-to-Zero"返现活动后，赛门铁克（Symantec）通过客户调研发现，客户其实更希望获得跨产品（杀毒软件 + 系统工具）的可管理性，而非单纯的价格让步。于是赛门铁克转向价值捆绑策略，推出集成度高、界面统一易用的 Norton SystemWorks 套件。最终赛门铁克在零售端建立起盈利领先优势，而迈克菲则退守并持续投入企业市场。
:::

### 促销

价格战的一大风险是促销信息容易被淹没，但促销本身其实可以成为对抗价格侵蚀的有效工具。

::: example 西南航空的广告反击
面对美国航空（American Airlines）发起的价值定价攻势，西南航空没有跟进降价，而是发起广告campaign，宣称："我们很想匹配他们的新票价，但那样我们就得涨价了。"
:::

::: pitfall 沟通不宜过于复杂
一家医疗器械制造商警告其医院客户：如果自己被迫退出市场，医院将任由那家规模更大的竞争对手摆布——形成垄断后，短期降价终将转变为长期涨价。但由于医院方面无法判断这一警告的可信度，这一策略效果并不理想。
:::

### 渠道

::: pitfall 不得强迫经销商拒绝分销低价商品
2003 年，3M 因根据《谢尔曼法》第二条构成事实上的排他性经销安排被判有罪——3M 向客户提供大额现金付款，换取客户只从 3M 独家采购透明胶带，赔偿金额共计 6,800 万美元。2001 年，Bed Bath & Beyond 计划引入 Waterford/Crystal 与 China 系列产品，但 Federated 与 May Co. 抢先签下独家协议，目的正是阻止 Bed Bath & Beyond 销售 Lenox/Waterford 产品，该案在纽约州被成功起诉并处以数百万美元罚款。

判定构成非法行为通常需要满足以下三条标准中的任意两条：产品抵制是横向的（涉及两个或以上竞争者）而非纵向的（涉及分销链不同层级）；意图在于抑制价格竞争；涉及拥有市场支配力或掌控关键供应来源的企业。
:::

::: example 与关键影响者合作：Intuit 应对微软的威胁
当微软威胁进入小企业财务软件市场时，Intuit 启动了一项专项计划，主动联系为 QuickBooks 提供支持服务的 20 万余名会计师，以巩固自己在渠道影响者层面的地位。
:::

### 为什么不直接降价

::: pitfall 三类直接降价的陷阱
1. **钱包不够深陷阱（Shallow-Pockets Trap）**：竞争对手可能财力更雄厚——如 1990 年代沃尔玛与 Kmart 的对抗。溴化物制造商陶氏化学（Dow）曾以另一种方式击败了受政府支持的德国溴化物卡特尔 Bromkonvention 的掠夺性定价：Bromkonvention 以低于陶氏的价格向美国市场倾销溴化物，陶氏没有跟进降价，而是指示其代理商低价买入美国市场上的溴化物，再转手运回德国以高于买入价、但仍低于 Bromkonvention 报价的价格出售获利。最终该卡特尔无法长期承受低于成本销售，被迫让步。
2. **低质量陷阱（Low Quality Trap）**：客户会因低价而推断产品质量低下。
3. **客户群体不忠诚陷阱（Fragile Market Share Trap）**：靠降价吸引来的客户往往缺乏忠诚度。Sprint 发现其近期推出的 25% 折扣计划反而导致了更高的客户流失率——问题在于，原本可能流失的客户仅占其年末订户总数的 2.6%，而剩下 97.4% 的忠实客户如今也开始要求同样的折扣。
:::

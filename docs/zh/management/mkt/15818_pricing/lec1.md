# Lec 1 超越 3C 的定价框架（Pricing Beyond the 3 Cs）

> MIT 15.818 · Pricing · 主讲 Prof. Catherine Tucker

## TL;DR

- 定价对利润的杠杆效应远高于降本：8% 利润率的企业若价格实现率提升 1%，利润可增长 12.5%，而固定成本降低 1% 只带来约 4% 的利润增长。
- 传统的成本定价、客户定价、竞争定价（3C）在本课程中被重新定义为定价必须克服的三种约束，而非应当遵循的三种方法——盲目套用三者会分别导致亏损、客户绑架和价格战。
- 课程用"创造价值、校准价值、传达价值、获取价值"（Create / Calibrate / Communicate / Capture Value）的新 4C，替代传统 3C 作为定价决策的分析主线。

## 为什么要专门研究定价

定价是企业能撬动的最高杠杆之一，但企业普遍缺乏系统的定价能力：

::: example 定价杠杆的量级
- 8% 利润率的企业，若在销量不变的前提下把价格实现率（price realization）提高 1%，利润可提升 12.5%；同等幅度的固定成本削减只带来约 4% 的利润提升（Dolan, 1992）。
- 2001 年 Continental Airlines 全年运送 4,400 万人次，平均票价 193 美元。若每张票只涨价 2 美元（约 1.04%），当年即可由亏转盈。
- 调研显示 80% 的管理者清楚自己产品的生产成本，但只有 23% 清楚客户的支付意愿；41% 的企业认为，缺乏具备定价工具能力的人才，是其推行定价体系改革的最大障碍。
:::

## 3C 是约束，不是方法论

入门营销课程通常把成本（Cost）、客户（Customer）、竞争（Competition）作为定价应当参照的"3C"。本课程的立场是：3C 描述的是定价必须应对的三类约束，若把它们直接当成定价方法，会分别导致三种典型的坏策略。

### 成本定价（Cost-Based Pricing）

$$\text{Price} = (1 + \text{percent markup}) \times (\text{Unit Variable Cost} + \text{Average Fixed Cost})$$

::: pitfall 成本定价的四个实操陷阱
1. **成本本身很难准确核算**。某婴儿睡袋公司因未计入包装成本而按成本加成定价却持续亏损；费城 Diamond Deliveries 的自行车配送部门被管理层视为核心业务，实际全成本每单 9.24 美元，报价却只有 4.69 美元，每单亏损 4.55 美元。
2. **成本与销量互为因果，形成循环论证**。销量下降会推高单位成本，但下滑期恰恰不是涨价的好时机（如 Wang Computer 的教训）；反之销量上升会摊薄成本，但若始终按小规模产能下的平均成本定价，企业可能永远发现不了规模经济或经验曲线带来的降本空间（某飞机制造商每次销量翻倍，单机人工工时下降 10%）。
3. **在高固定成本、边际成本趋近于零的行业中，成本定价失去意义**，因为固定成本在不同产品间的分摊本身就是主观决策。作业成本法（activity-based pricing，按对固定成本的贡献确定加成）在这类场景下优于常规成本定价——医疗器械分销商 Owens & Minor 对成人纸尿裤和超声胶片设置不同加成率后改善了定价表现。
4. **忽视自己创造的价值会导致系统性低价**，Pet Rock 是典型案例。
:::

企业应该反过来问：定价策略会如何反过来影响自己的成本结构，而不是先算出成本再倒推价格。

### 客户定价（Customer-Based Pricing）

指让客户主导定价决策，常见于 B2B（销售允许采购方压价）与 B2C（担心涨价引发用户反弹）场景。

::: pitfall 客户定价的三个失灵机制
1. **客户不会主动透露真实估值**：Radiohead 专辑《In Rainbows》采用"随意付费"模式，62% 的听众选择付 0 元，人均付费仅 2.26 美元。
2. **客户需要被教育价值所在**：TiVo 早期很难让客户理解它相对传统 VHS 录像机的价值。
3. **客户一旦习惯掌控定价权，涨价会引发强烈反弹**：TurboTax 对每次追加报税收取 9.95 美元后遭用户在 Amazon 打出 1.5 星差评，被迫撤回并退款；Capcom 则以强硬姿态为《生化危机 5》60 美元定价辩护，坚持不退让。
:::

企业应该反过来问：什么样的价格能让客户相信它与产品价值相匹配，以及如何通过细分反映客户估值的差异，而不是被动接受客户报价。

### 竞争定价（Competition-Based Pricing）

指定价策略完全跟随竞争对手，而非基于自身产品。既包括简单照抄竞品价格、放弃自主定价研究，也包括为达成市场份额目标而持续折价追赶。

::: pitfall 竞争定价的三个后果
1. **让企业忽视自身独特价值主张**：某放射影像软件公司拥有独有的 3D 能力，却按行业领先者的价格定价，损失数百万美元。
2. **容易引发价格战**：当市场总量固定或萎缩时，抢占份额意味着竞争对手必然受损，这会直接触发报复性降价——2005 年 Anheuser-Busch 与 Miller 之间的价格战即由销量停滞触发。
3. **份额最大化不等于利润最大化**：即使在规模经济显著的行业，不同客户群体的盈利能力差异也很大；英国有线电视运营商长期忽视这一点，一味把网络扩展到偏远乡村以追求份额。
:::

企业应该反过来问：哪些客户细分最值得盈利地服务，以及如何在保护自身免受价格战侵蚀的同时获取这些细分市场，而不是简单跟随竞争对手报价。

## 课程的新 4C

::: insight
3C 常被当作定价"该做什么"的清单，但更准确地说，它们描述的是三种定价"不该做什么"。三者共同的问题在于：企业都是在被动响应某个约束（成本、客户或竞争），而不是主动塑造这个约束。本课程后续内容将围绕如何塑造客户反应和竞争反应展开，使企业不必永远受困于成本地板、客户压价或竞品价格。
:::

课程用以下新 4C 重新组织定价分析框架，后续各讲将依次展开：

- **Create Value（创造价值）**：产品/服务本身能为客户带来多少差异化价值。
- **Calibrate Value（校准价值）**：量化这些价值，即本课程 [Lec 2](./lec2.md) 展开的 EVC（Economic Value to the Customer）分析。
- **Communicate Value（传达价值）**：让客户感知到并相信这些价值，对应客户不确定性下的定价策略（[Lec 3](./lec3.md)）。
- **Capture Value（获取价值）**：通过客户细分、价格结构设计等手段真正捕获所创造的价值（[Lec 5](./lec5.md)、[Lec 7](./lec7.md)）。

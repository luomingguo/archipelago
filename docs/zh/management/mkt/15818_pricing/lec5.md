# Lec 5 价格细分客户（Pricing to Segment Customers）

> MIT 15.818 · Pricing · 主讲 Prof. Catherine Tucker

## TL;DR

- 需求曲线向下倾斜的根本原因是客户对产品估值存在差异；本讲最核心的洞察是不应该问"该在需求曲线上哪个点定价"，而应该问"能沿需求曲线向不同客户收取多少个不同的价格"。
- 客户导向的价格细分（Customer-Based Segmentation）按客户可观察特征直接定价，需要满足三个条件：群体归属可无歧义识别、该特征与 EVC 相关、产品不能在群体间被转售套利；此路径还受制于反价格歧视法律（Robinson-Patman Act）与文化可接受性。
- 产品导向的价格细分（Product-Based Segmentation）让客户通过选择产品版本自我甄别，关键是找到与 EVC 相关的差异化属性，并同时满足"扭曲"（Distortion，能拉开高低估值客户的选择）与"补偿"（Compensation，不会吓跑低估值客户）两个条件。
- 一个放射影像软件的算例说明：产品导向细分虽不如完美的客户识别理想，但通过"完整版"与"缺文档折扣版"两档产品，仍能捕获部分原本被"渗透定价"策略放弃的利润，其可行性取决于 $(DV_{HB}-DV_{LB})Q_H \ge Q_L DV_{LB}$ 这一盈利条件。

## 一、需求曲线为何具有误导性

上一讲我们认真思考了如何测量需求曲线（参见 [Lec 4](./lec4.md)），但同样重要的是思考它为什么向下倾斜——答案是客户对我们产品的估值存在差异。

::: insight 本课程最核心的洞察
不应该思考"该在需求曲线上哪一点定价"，而应该思考"沿着这条需求曲线，能向不同客户收取多少个不同的价格"。
:::

在一个典型的双档设定中：

$$Price_a^H \le DiffValue_{ab}^H + Price_b^H$$

$$Price_a^L \le DiffValue_{ab}^L + Price_b^L$$

如果企业按"低"价格定价，就等于把钱留在了桌面上。核心问题始终是：企业如何一方面对低估值类型收取更低价格以吸引其"入场"，另一方面又说服高估值类型支付高价。本讲中反复出现的"高"（High）与"低"（Low）类型，只是需求曲线上多种客户类型的简化代称，价格策略的目标始终是为所有这些类型分别定价。

## 二、是否应从单一定价策略转向细分定价：战略评估

1. 我的产品是否具有差异化价值？
2. 我能否识别出两个以上理论上估值不同的客户价值画像？
3. 是否有实证证据表明这些不同客户群体真的存在预期中的 EVC 差异？
   - 价格弹性差异很大，就是不同群体存在不同 EVC 的证据。
4. 是否有实证证据表明同一价值画像内部的客户，其 EVC 已经足够接近？
   - 判断细分是否已经做够的方法，是尝试对当前群体再进一步细分：如果新算出的价格弹性彼此之间没有明显差异，就说明已经细分到位；反之则说明细分还不够。

::: pitfall 营销学的"细分"与定价分析的"细分"不是一回事
营销人员谈到客户细分时，常常想到的是"牛仔裤老爸""瑜伽妈妈""Y 世代"这类人群画像；但定价分析师使用"细分"一词时，所指要精确得多——实证分析的目标始终是识别出"高"与"低"两类估值类型并分别定价。
:::

实现细分主要有两条路径：客户导向细分和产品属性导向细分。客户导向的价格细分中，企业根据客户的可观察特征来决定其应支付的价格；产品导向的价格细分中，则是客户根据产品的可观察特征自行决定要支付的价格，企业的任务是设计恰当的定价表并在不同产品之间维护恰当的"价格围栏"（price fence）。

## 三、客户导向的价格细分

### 实施挑战

::: pitfall 客户导向细分的三个前提条件
1. **群体归属必须有无歧义的识别标志**：例如兽医持有兽医学校证书，企业可以要求出示证书以享受折扣。
2. **该特征必须与 EVC 相关**：这一点并不总是显而易见。课堂讨论的实证案例中，医生群体内部的估值差异其实很大——这在现实世界中同样是个问题。例如 Quickbooks 曾以为老客户对升级的估值较低（因为他们已拥有软件）而给予更低定价，但实际上老客户内部本身就存在估值更低和估值更高两类人，简单地一刀切并不准确。
3. **产品不能在群体之间被转售套利**：一名有商业头脑的兽医完全可能买入软件后转卖给医院牟利。这也解释了为什么客户导向的细分主要出现在服务或体验类产品中，而非可转售的实物商品。
:::

### 带有反竞争意图的价格歧视

对相互竞争的买家就同一"商品"收取不同价格，或在提供"补贴"（用于广告等服务的补偿）上有差别对待，可能违反 **Robinson-Patman 法案**。这类价格歧视可能让被优待的客户获得与自身效率无关的市场优势。价格歧视本身通常是合法的，尤其是当价格差异反映了向不同买家供货的真实成本差异，或是企业为匹配竞争对手报价所做的应对时。

::: definition Robinson-Patman 法案的具体法律测试
1. 该法适用于商品而非服务，适用于买卖而非租赁。
2. 商品必须属于同等级别和质量。
3. 必须存在对竞争造成损害的可能（私人原告还需证明对自身业务造成了实际损害）。
4. 销售通常须发生在州际贸易中（即跨州销售）。
:::

反垄断机构重点审查的情形包括：企业在某些地区低于成本销售、同时在其他地区收取更高价格；同款商品之间无法用成本节约或匹配竞对报价来解释的价格差异；促销补贴或服务未能按比例平等地提供给所有客户。

::: example Robinson-Patman 法案的实际案例
- 默克（Merck）曾以目录价 92% 的折扣向医院出售药品，但前提是医院需达到特定的市场份额目标，因未能向 Medicare/Medicaid 提供同等折扣而被起诉涉嫌欺诈。
- Robinson-Patman 法案也解释了为什么走进 Costco 会进入一个奇特的"平行世界"：麦片以双包装出售，可乐以 32 罐（而非 24 罐）成箱出售，打印机墨盒以三支装（而非单支或双支）出售——这类打包设计正是为了规避该法案对"同等商品不同价"的限制。
- 自 Brooke Group Ltd. v. Brown & Williamson 与 Volvo Trucks North America, Inc. v. Reeder-Simco GMC 两案判决之后，成功起诉的案例已大为减少，原告需要证明实际损害，而非仅仅证明歧视意图。
:::

### 客户导向价格歧视的伦理问题

1. **价格歧视必须合法**：除 Robinson-Patman 法案（1936）外，还涉及 B2B 相关监管、欧盟相关立法；Wheeler Lea 修正案禁止商业中的不公平或欺骗性行为；Racketeer Influenced and Corrupt Organizations Act（RICO）曾被用于起诉 Victoria's Secret 目录价格差异，以邮件欺诈罪论处；部分州法律禁止基于性别的价格细分。
2. **价格歧视必须在文化上可被接受**：即便合法，也可能被大众感知为不公平甚至误认为违法。
   - 2/3 的成年互联网用户误认为在线零售商对不同人收取不同价格是违法的。
   - 彭博社（Bloomberg）曾对一家中餐馆发起舆论攻势，起因是该餐馆英文菜单比中文菜单每道菜贵 1 美元，但事后很难找到可用于起诉的法律条款。
   - 某连锁超市曾因对针对西班牙裔顾客的门店统一加价 10% 而引发争议。
   - 有时争议可以通过更好的措辞化解：迪士尼如果宣布"对成人多收费"，接受度会远低于现在的说法——"为儿童提供折扣"。
3. **隐私问题**：利用客户历史数据进行的客户导向价格歧视，常被认为侵犯隐私，这一顾虑在欧洲愈发重要，近年来在美国也逐渐凸显。
4. **不做价格细分同样可能带来严重后果**：2000 年代初，90% 的艾滋病患者因无力承担相关药物的定价而得不到治疗——这提示我们，企业因找不到合适的细分指标而放弃价格细分，同样可能造成不良后果。

::: insight 客户的"无力感"是抵触情绪的重要来源
客户对价格歧视的不公平感，部分源于自己在被划入哪个"档位"时缺乏选择权。这促使许多企业重新设计细分策略，转而强调客户自己可以选择落入哪个档位（例如通过主动出示证件、主动选择渠道等方式），而非被动地被企业归类。
:::

## 四、产品导向的价格细分

在产品导向的价格细分中，客户根据产品的可观察特征自行决定支付哪个价格，企业的任务是设计合适的定价表，并在不同产品之间维护恰当的价格围栏。

### 成功的必要条件

1. **能识别出一个与总体 EVC 相关的、无歧义的差异化价值维度**（例如便利性），并据此设计产品结构。
2. **"扭曲"（Distortion）**：这个差异化价值维度必须与总体 EVC 高度相关，使高估值类型宁愿为它支付溢价也不愿放弃——换句话说，企业需要主动向下扭曲产品质量，迫使低估值类型通过"忍受较差的版本"来暴露自己的类型。舒适度、速度、可靠性、易用性都是不错的切入点。
3. **"补偿"（Compensation）**：这个差异化价值维度又不能过于关键，以至于低估值类型宁愿完全不买也不接受它的缺失；定价应对低估值类型给予相应补偿。这正是经济舱不适感对应折扣票价的原因。

::: insight 扭曲与补偿是一种"框架"技巧
虽然"扭曲"与"补偿"是建立在信号博弈经济学上的高度分析性概念，但这恰恰是定价从科学变为艺术的地方——你需要判断产品的哪个特征或维度可以被向下扭曲，同时又不至于真正惹恼客户。一个有效的思路是：与其把选择框定为"从低配产品向上扭曲质量"，不如反过来框定为"从高配产品向下扭曲质量"。
:::

### 产品属性细分的不同类型

::: example 八类产品属性细分及其代表案例
1. **可靠性**：商用烤箱温度计价格是家用款的 10 倍，因为它承诺 2 度以内的精度，而非家用款的 10 度精度——低估值类型需要通过"接受烘焙成品不够稳定"来暴露自己的类型。
2. **容量**：8GB iPhone 定价 199 美元，16GB 定价 299 美元——低估值类型需要通过"接受无法使用全部多媒体容量"来暴露自己的类型。
3. **愉悦度**：一家为非营利机构送货的印刷公司，其"经济线"业务负责人被刻意选为态度不友善的员工。
4. **购买便利性**：经典案例是优惠券——2005 年共发放 2,530 亿张优惠券，低估值类型需要通过剪券、记得使用优惠券的麻烦来暴露自己的类型。
5. **数量**：低估值类型通过放弃批量折扣来暴露自己的类型。
6. **渠道**：Bestbuy.com 的价格比 Best Buy 实体店更低，但体验更少接触感——低估值类型需要通过"愿意在购买前看不到实物"来暴露自己的类型。
7. **地理**：超市会依据所在地区定不同价格，但这种差异往往更多反映当地竞争状况，而非战略性的价格细分。
8. **附加项目定价（Add-on Pricing）**：经典案例是酒店对网络接入等附带项目单独收费，以此把低估值类型（度假客）与高估值类型（商务客）区分开——低估值类型需要通过"愿意不用网络"来暴露自己的类型。这种方式与基于特性的产品细分很像，区别在于该特性是明确可选的；缺点是容易让客户感觉是在不断被收取"额外费用"，每次单独发生时都令人不悦。
9. **交付时机**：高估值类型愿意为更早拿到商品支付溢价，最简单的形式是加急运费溢价，更复杂的形式是先对早期采用者撇脂定价，再逐步向后期采用者降价——低估值类型需要通过"愿意等到产品进入大众市场"来暴露自己的类型。这类撇脂策略也可能引发客户不满，正如苹果 iPhone 定价策略所经历的那样。
:::

### 产品线价格细分面临的挑战

::: pitfall 产品线细分的七类风险
1. **寻找与 EVC 相关的属性本身很难**：一家滑板制造商销售配备更好轮子和更好配色的高端系列，以及图案简陋、轮子明显是塑料感的"低配"折扣系列——结果低配款反而卖断货，在 eBay 上的转售价甚至超过了高配款。
2. **维护产品线内不同产品的完整性**：客户可能对低配产品进行"逆向改造"。例如原本用于船只的 GPS 设备被改造用于飞机。
3. **低档用户的公平感受**：某目录公司发现为"大码"商品单独定价，反而拉低了所有商品的整体销量；Dell 曾因新的 XPS 定价方案（"高价值"客户能获得更快的技术支持）而遭到全体客户的反弹。
4. **价格细分可能无意间暴露真实成本**：一家速凝绷带材料制造商，在把产品作为新奇手工材料出售时，无意中暴露了这款产品的真实制造成本有多低。
5. **价格围栏一旦被发现，可能引发负面舆论**：Best Buy 就曾因被曝出一个只对店员内部展示的"秘密网站"（用来向店内顾客解释为何网上价格比店内更低）而陷入舆论风波。
6. **维持产品线分离本身的成本效益**：维护不同产品特性可能相当昂贵，某些情况下甚至需要放弃产品导向的价格细分——某婴儿背带公司就因管理成本过高而停产了其有机材质产品线。类似地，返利（rebate）最初和优惠券出于同样的初衷设计，但零售商逐渐沉迷于客户"忘记寄回返利表格"所带来的额外利润，令产品细分的初衷逐渐让位于短期利润目标。
7. **需要维持足够的定价权**：真正的障碍通常是非战略性的竞争对手——只有当竞争对手也"配合"时，价格围栏才能维持。一些出人意料的行业却能维持这种定价权，例如干洗店长期对女式衬衫收费高于男式衬衫；反过来，广告效果监测行业中，商标侵权监控服务本是一项有利可图的附加服务（主要面向律师等"高估值类型"），但这一细分市场的利润空间正被"统一定价"的初创公司蚕食。
:::

## 附录：放射影像软件案例

一家放射影像服务公司开发出一款存储放射影像的软件，其边际成本为零。潜在客户分为两类：医院和兽医。

该软件的差异化价值在于能让医疗提供者同时对比多张影像——最多可同时比较 10 张。医院和兽医都更偏好能同时查看更多影像，但医院对"能同时对比 10 张影像"这一能力的估值明显高于兽医，因为人体解剖结构远比一般猫狗的解剖结构复杂。

### 理想策略

市场由 $Q_H$ 家医院和 $Q_L$ 名兽医构成。由于该软件足够独特，EVC 方程可简化为以"不购买"（价格为零）作为参照产品：

$$P_H \le DV_{HA} + DV_{HB}$$

$$P_L \le DV_{LA} + DV_{LB}$$

当前该公司采用"渗透定价"策略，对所有客户统一按 $DV_{LA}+DV_{LB}=P_L$ 定价以最大化销量，因此当前利润为：

$$\Pi_{current} = P_L(Q_H + Q_L)$$

理想情况下，若企业能准确分辨客户是高估值还是低估值类型并分别定价，利润将为：

$$\Pi_{dream} = P_H Q_H + P_L Q_L$$

相比当前策略，这将带来 $(P_H-P_L)Q_H$ 的利润提升。但现实中，若对兽医和医院分别定价，兽医完全可能把软件转卖给医院套利。

### 产品导向的价格细分方案

产品导向的价格细分让产品设计本身促使客户通过选择不同产品版本来暴露自己是高估值还是低估值类型。高估值类型在两个维度上更看重该软件：可同时对比的影像数量（记为 A）与便于使用的高质量文档（记为 B）：

$$DV_{HA} > DV_{LA} \qquad DV_{HB} > DV_{LB}$$

企业设计两款产品：**完整版**和**折扣版（不含文档）**。目标是让高估值类型选择完整版、低估值类型选择折扣版，且高估值类型不会为省钱而假装成低估值类型购买折扣版。这要求完整版价格不高于折扣版净收益加上放弃文档所损失的差异化价值——这正是约束条件 EVC 方程：

$$P_C = P_D + DV_{HB}$$

对高估值类型而言，折扣版价格的设定内生地决定了他们的参照价格；对低估值类型而言，外部选项仍是"不购买"（价格为零）。为确保低估值类型购买产品，企业需将折扣版定价为：

$$P_D = DV_{LA}$$

由于折扣版的存在改变了高估值类型的参照价格，企业相应地将完整版定价为：

$$P_C = DV_{LA} + DV_{HB}$$

### 与完美细分的对比

理想情况下，企业希望对低估值类型收取：

$$P_L \le DV_{LA} + DV_{LB}$$

但在产品导向细分下，企业实际对低估值类型收取的是 $P_D = DV_{LA}$，即向下扭曲了 $DV_{LB}$ 部分的价格，以补偿低估值类型放弃文档、借此暴露自己类型的代价。

理想情况下，企业希望对高估值类型收取：

$$P_H \le DV_{HA} + DV_{HB}$$

但实际收取的是 $P_C = DV_{LA} + DV_{HB}$，即向下扭曲了 $(DV_{HA}-DV_{LA})$ 部分的价格，用以"贿赂"高估值类型购买非折扣版本而非折扣版本。

### 盈利性条件

产品导向价格细分要有利可图，必须比现行的统一定价策略更赚钱：

$$\Pi_{pbsegmentation} \ge \Pi_{current}$$

$$P_C Q_H + P_D Q_L \ge P_L(Q_H+Q_L)$$

代入并展开：

$$(DV_{LA}+DV_{HB})Q_H + DV_{LA}Q_L \ge (DV_{LA}+DV_{LB})(Q_H+Q_L)$$

化简后得到该方案的盈利性条件：

$$(DV_{HB}-DV_{LB})Q_H \ge Q_L DV_{LB}$$

::: insight 盈利条件的直觉
只有当"高估值类型因获得文档而愿多付的溢价"（左边）足以覆盖"低估值类型因被迫放弃文档而需要的补偿总额"（右边）时，产品导向的价格细分才值得实施——这与 [Lec 2](./lec2.md) 中"差异化价值必须可信地被测量和捕获"的逻辑一脉相承。
:::

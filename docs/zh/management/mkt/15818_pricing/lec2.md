# Lec 2 客户经济价值（EVC）定价（Pricing Economic Value to the Customer）

> MIT 15.818 · Pricing · 主讲 Prof. Catherine Tucker

## TL;DR

- EVC（Economic Value to the Customer）的核心洞察是：客户只会在产品效用不低于最优替代品时才购买，据此可推出价格上限公式 $Price_a \le DifferentiationValue_{ab} + Price_b$。
- 实施 EVC 分析需要五步：明确产品带来的"利益"而非"特性"、诚实识别最直接竞品及其真实成交价、找出差异化价值的具体来源、可信地测量这些价值、把参照价与差异化价值相加得到 EVC。
- EVC 是价格的理论上限，不是建议售价；实践中企业通常会对差异化价值打折（常见约 50%），具体折扣幅度取决于终端效应、共担成本效应、心理账户等六类因素。
- EVC 有三种用法：作为定价公式（适用于竞品价格明确、差异化价值易测算易传达的场景）、作为新产品定价指南（如 Zantac 案例）、作为存量产品的定价诊断工具（判断是定价过高还是价值传达失败）。

## 定义：从效用比较推导价格上限

EVC 建立在一个基本假设上：客户只有在产品 a 的效用不低于最直接替代品 b 时才会购买，即 $Utility_a \ge Utility_b$。产品效用等于其价值减去价格：

$$Value_a - Price_a \ge Value_b - Price_b$$

整理后得到价格上限公式：

$$Price_a \le [Value_a - Value_b] + Price_b = DifferentiationValue_{ab} + Price_b$$

::: definition 经济价值（Economic Value to the Customer, EVC）
产品 a 相对于最直接竞品 b 的经济价值，等于竞品价格加上 a 相对 b 的差异化价值：$EVC_a = Price_b + DifferentiationValue_{ab}$。这是理论上企业能够收取的最高价格，超过该价格客户会转向竞品。
:::

::: example Atlantic Computer 服务器案例
Atlantic Computer 开发出一款服务器软件，能让单台服务器承载竞品两台服务器的网页容量。相较购买竞品的两台服务器，客户使用这台高效服务器可节省 4,000 美元人工成本、500 美元电费与 1,500 美元软件授权费，即差异化价值为 6,000 美元。竞品两台服务器的价格为 6,800 美元。因此 $EVC = 6{,}000 + 6{,}800 = 12{,}800$ 美元。
:::

## 实施 EVC 分析的五个步骤

1. **识别产品提供的"利益"而非"特性"**：把特性准确翻译为客户利益是关键技能——Xerox 从"卖复印机"转向"按复印张数收费"，正是抓住了客户真正在意的利益点而非机器本身的特性，因而大幅提升了盈利能力。
2. **诚实识别最直接的竞争对手并核实其真实成交价**：
   - B2B 视频通话服务倾向于把自己与专线视频会议系统比较，但真正的最直接竞品其实是免费的 Skype。
   - 某网络备份公司按竞品的公开报价算出 EVC 时，价格比自己现有定价高出一倍，但他们忽略了所有竞品实际按七折（甚至更低）成交的事实。
   - 需要正确把握计量单位和时间跨度，某清洁剂厂商未考虑自身产品清洁效率是竞品两倍，导致定价上留下大量未捕获价值。
3. **找出差异化价值的具体来源**：价值主张必须具体，避免泛泛而谈、像通用软件生成的空话。
4. **可信地测量这些价值创造的量级**：理想情况下由独立实验室做可量化测试（如某空气过滤器厂商委托实验室测量空气中尘埃颗粒数并推算对哮喘患者的影响）；也可邀请现有客户参与基准测试研究，客户往往乐于配合，因为这相当于免费的咨询（如工业品分销商 W.W. Grainger 向 15 家客户提供咨询与测量激励换取参与）。
5. **把参照价格与差异化价值相加得到 EVC**。

## EVC 不是建议售价：该折让多少差异化价值

::: pitfall 常见误解
EVC 分析常被误读为"应当按 EVC 定价"，但 EVC 描述的只是理论价格上限，企业通常会主动放弃一部分差异化价值。
:::

这种"让利"行为有神经科学基础——最后通牒博弈实验显示，人们在分配收益时天然倾向于公平分享，而非榨取对方的全部剩余价值，这支持了一种约 50% 的经验折扣法则。Atlantic Computer 最终没有按 12,800 美元的 EVC 定价，而是对 6,000 美元差异化价值打五折，最终定价 9,800 美元。

### 应更接近 EVC 定价的情形

::: definition 六类调整差异化价值折扣幅度的效应
- **终端利益效应（End-Benefit Effect）**：产品是某个知名且昂贵终端用途中不可或缺的一环时，可以定价更接近 EVC——新娘手捧花虽小，却是昂贵婚礼中不可替代的一环，花商借此定出远高于普通花束的价格。
- **共担成本效应（Shared-Cost Effect）**：当成本由第三方承担时可定价更高——商务酒店能为高档床垫、床品收取溢价，因为差旅费用通常由客户所在公司报销。
- **有利心理账户（Advantageous Mental Account）**：产品若落入客户"度假基金""退税款"等专门心理账户，可定价更接近 EVC——某旅行社推出与 2008 年布什退税支票时间吻合的 300 美元拉斯维加斯度假返现活动，取得成功。
:::

### 可能需要大幅低于 EVC 定价的情形

::: definition 三类压低定价的效应
- **不确定性效应（Uncertainty Effect）**：产品属性能否兑现存在不确定性时——某抗屑洗发水因功效无法被专家验证、消费者预期其效果因人而异，难以获得价格溢价。
- **新颖性效应（Newness Effect）**：属性太新、客户难以理解时，需要先低价渗透，并明确标示这是"限时"折扣——1969 年一项研究对比五个品牌在两家门店的表现，标注"原价折扣"的门店长期表现优于未标注折扣来源的门店。
- **支出占比效应（Expenditure Effect）**：产品占客户总支出比例越大，讨价还价压力越大——工业地毯清洁公司能对办公室经理收取比专职清洁公司更高的价格，因为其单笔支出占比相对较小。
:::

此外，出于伦理或法律原因（如飓风 Rita 期间瓶装水被限价、北卡罗来纳州"哄抬物价法"）也应主动压低价格。是否出于战略原因（赢家通吃市场、抢占初始客户锁定、抢先压制竞争对手反应）定价，将在课程第 3–6 周详细讨论。

## EVC 的三种用法

### 作为定价公式

最适合以下场景：竞品价格公开且明确、产品差异化价值易于量化、差异化价值易于可信地传达给客户。Atlantic Computer 是接近理想的应用场景——卖方精确知道客户如何使用产品，并掌握客户使用该技术带来的成本节约或净收益细节，这通常出现在制造业或工程场景中（EVC 分析方法最初正是由咨询公司为这类行业开发）。EVC 也常被用作销售话术工具，帮助销售人员回答"凭什么卖这么贵""为什么不选便宜 3,000 美元的竞品"等问题——但前提是这套体系不能复杂到销售人员宁愿绕过它。

### 作为新产品定价指南

::: example Zantac 定价案例
作为胃溃疡药物市场的第二个进入者，Zantac 本可以贴着先行者 Tagamet 的价格定价。但 EVC 分析显示，由于每日两次给药（相较更频繁的给药方式）和更少的副作用，Zantac 拥有巨大的差异化价值，最终定价高出 Tagamet 50%，两年内成为市场领导者。
:::

### 作为存量产品的定价诊断工具

用于判断表现不佳的存量产品究竟是定价过高，还是价值传达/沟通出了问题：

- **定价过高**：Segway 相对其 EVC 被大多数客户认为在 3,000 美元定价上偏贵，公司因此转向寻找降低人均使用成本的模式，如一日城市观光租赁。
- **价值信息未聚焦核心差异化价值**：Michelin 最初在广告中平均用力强调耐久性、速度、安全性等所有差异化点，客户测试显示最容易感知和传达的其实是安全性，切换聚焦后取得巨大成功。
- **价值信息传达无效**：Duracell 发现"更耐用"这一定量信息不被客户相信，转而强调"关键时刻更可靠"的定性信息后取得更好效果。

::: insight
在启动降价决策之前，必须先做一轮 EVC 分析，以防管理层在诊断错误（把价值传达问题误判为定价过高问题）的情况下做出错误决策。
:::

# 补充讲义 B2B 议价谈判（B2B Negotiations）

> MIT 15.818 · Pricing · 主讲 Prof. Catherine Tucker

## TL;DR

- B2B 定价的特殊之处在于议价谈判本身直接决定最终成交价，这与消费品市场（汽车除外）几乎不议价的情况截然不同。
- 用"价格瀑布"（price waterfall）拆解从交易价一路扣减返利、津贴、折扣直到"到手价"（pocket price），常能发现最大宗、最应盈利的客户实际单价反而更低。
- 谈判中应先建立经济价值再谈价格、主动抢先报价、用固定的价格菜单代替临时议价，并对措辞严格自律，避免使用暗示可议价空间的软化词。
- 一项针对 64 家企业流失供应商原因的研究显示，因价格流失客户的占比仅 8.1%，远低于交付问题（70.2%）——价格谈判技巧的价值不应被过度神化。

## 价格瀑布分析

企业必须清楚了解当前议价流程实际导向了怎样的价格结果。

::: pitfall 常见现象
把每位客户的实际单价与其采购量作图，往往会发现：最大批量、本应最有利可图的客户，其实按单位计算支付的价格反而高于利润率更低的客户——这不是能维系长期健康客户关系的定价结构。
:::

::: definition 价格瀑布（Price Waterfall）
用于逐层拆解出每位客户的真实净价格：从"交易价格"（Transaction Price）出发，依次扣减净返利（Net Rebate）、净津贴（Net Allowance）、净折扣（Net Discount），最终得到"到手价"（Pocket Price）——即企业实际获得的净收入。
:::

## 谈判本身

价格在销售代表心中的分量，往往比在回头客心中的分量更重；企业永远无法确定价格是否定得过高，除非真的丢掉了这单生意。

- **先建立经济价值，再谈价格**：呼应 [Lec 2](./lec2.md) 的 EVC 分析——先让客户认可产品价值，再进入价格讨论。
- **主动率先提出价格**：如果你不主动谈价格，客户会替你谈。调研显示 94% 的销售代表不会在客户主动提及之前谈价格，其中三分之一甚至从不口头说出价格，只会写下来或用手指出。

### 通过价格菜单落实定价政策

- 建立一致、透明的折扣标准——固定价格与灵活报价两类都要有明确规则。
- 不对回头客做临时性、随意性的折扣。
- 奖励忠诚度与试用行为，而不是单纯奖励采购量。

::: example 64 家企业更换供应商原因调研
研究显示，企业更换供应商的原因中，价格因素仅占 8.1%，远低于交付问题（70.2%）、质量问题（9.4%）和服务问题（6.2%）。这提示价格谈判技巧固然重要，但客户流失的主因往往并非价格本身。
:::

## 措辞：直接说出价格，不做修饰

谈判时应态度坚定、避免任何软化或暗示让步空间的措辞。

::: pitfall 应避免使用的表达
- "常规价""正常价""标价""目录价""最低价""最优价""折后价""基础价""通常价格"等修饰性描述。
- "我能做到的最好价格了"
- "这个价格我们还能再谈谈"
- "我们的价格比任何人都低"
- "我们的价格还不到一个薯片袋的钱"
- "100 美元听起来怎么样？我这个报价大概靠谱吗？"
- "告诉我你的心理价位，我该怎么做才能拿下这单？"
:::

::: insight
这些措辞禁忌的共同逻辑是：任何试探性或描述性语言都会向对方传递"价格仍有弹性"的信号。B2B 谈判中价格本身应当被当作一个已经建立在经济价值之上的事实来陈述，而不是一个有待协商的起点。
:::

## 结尾寓言

::: example 两个"傻瓜"与南瓜生意
两个乡下人用中彩票赢来的 100 美元向相熟的南瓜农场主进货，以每个 1 美元的价格买入 100 个南瓜，找了个好地方停车，又以每个 1 美元的价格原价卖出。卖完一车又进一车，如此往复。数次清点后，他们发现手头依然只有 100 美元，百思不得其解。其中一人恍然大悟：“问题很简单——我们得换一辆更大的卡车！”这则寓言讽刺了只关注走量、却从未反思单位经济性（unit economics）与定价本身的经营思维。
:::

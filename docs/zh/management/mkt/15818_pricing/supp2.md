# 补充讲义 非线性定价（Non-linear Pricing）

> MIT 15.818 · Pricing · 主讲 Prof. Catherine Tucker

## TL;DR

- 当企业需要向同一客户销售多单位产品时，数量折扣、按用量计价（计量定价）与剃须刀-刀片模式是三种常见的非线性定价手段。
- 数量折扣的理论基础是让客户通过购买数量自我甄别估值高低，但要求产品不易被囤积或转售，否则会被套利，且在美国受《罗宾逊—帕特曼法案》约束。
- 无论采用哪种非线性定价形式，最终成败都取决于是否选对了"计价指标"（pricing metric）——按客户真正感知价值的维度计价，而非按易于测量但与价值脱节的维度（如按小时）计价。

## 数量折扣

::: definition 数量折扣的自我甄别逻辑
提供数量折扣的基本理论是：借此同时服务高估值与低估值两类客户。高估值客户通过大批量采购向企业"表明身份"；低估值客户则通过少量、但单价更高的购买方式表明自己对产品的估值较低。
:::

::: pitfall 数量折扣的实施难点
- **退货管理复杂**：客户可能为了拿到折扣而多买，随后却按平均单价要求退款，造成实际执行上的困扰。
- **理想商品应难以被囤积或转售**：例如香蕉这类商品，经销商无法长期囤积，转售也困难且成本高——这是数量折扣能够成立的重要前提。
- **必须排除消费者囤货套利的可能**，否则高估值客户的折扣优势会被低估值客户通过囤货获取的折扣所侵蚀。
- **《罗宾逊—帕特曼法案》（Robinson-Patman Act）**：该法案专门用于限制企业利用这类非线性价格结构，让连锁大店获益而伤害独立小店（"Mom and Pop"）的利益，是美国实施数量折扣时的重要合规约束。
:::

## 计量定价

在许多场景下，按实际使用量收费的计量定价（metered pricing）安排更为可取，客户单纯按使用量付费。

::: definition 剃须刀—刀片模式
计量定价的一种变体：客户先低价购买一个耐用品（如剃须刀本体），随后持续以较高价格购买消耗品（如刀片）。这一模式的实质是通过消费品端持续按用量收费，实现对高频、高价值客户的差异化捕获（也是 [Lec 8](./lec8.md) 中"剃须刀—刀片定价"误区讨论的技术基础）。
:::

## 价值导向的计价指标

::: insight
无论采用数量折扣还是计量定价，多单位定价成败的关键都在于选对"计价指标"（pricing metric）——即按照哪个维度向客户收费。多数信息服务按"每次下载"收费比按"每分钟"收费更合理；几乎任何场景下，按小时计价都很少是合适的选择。计价指标的选择本质上是 [Lec 2](./lec2.md) EVC 分析中"把单位和时间跨度定对"这一步骤在多单位定价场景下的延伸——计价指标必须贴合客户实际感知价值的方式，而不是贴合企业内部最容易测量的维度。
:::

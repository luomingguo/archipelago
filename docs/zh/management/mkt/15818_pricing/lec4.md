# Lec 4 测量客户对价格的反应（Measuring Customer Reactions to Prices）

> MIT 15.818 · Pricing · 主讲 Prof. Catherine Tucker

## TL;DR

- 测量价格反应有一张二维矩阵：为新产品定价该用调查（简单问卷或联合分析），改进存量产品定价该用历史数据（价格弹性）或田野实验，而非在错误的工具类别里打转。
- 直接问客户"愿意付多少钱"的开放式问卷普遍不可靠，客户会因场景依赖、判断力不足或印象管理而答非所愿；单一情形（Monadic）测试和联合分析（Conjoint Analysis）通过让客户"选择"而非"报价"来获得更可信的数据。
- 价格弹性 $E_d = \frac{\%\Delta Q_d}{\%\Delta P_d}$ 衡量销量对价格变化的敏感度，可用对数线性回归稳健估计，并可反推出利润最大化加成公式 $P = MC \times \frac{1}{1 - 1/|E_d|}$。
- 历史定价数据分析受限于数据质量、价格缺乏变动、数据过时和混杂因素；田野实验能控制这些问题，但要警惕价格变动幅度不足、客户反弹和多重实验相互干扰。

## 一张矩阵：为新产品定价还是改进存量定价

本讲同时回答两类问题：如何用调查工具为新产品定价，以及如何通过测量价格弹性改进存量产品的定价。这两类问题分别对应"不受控"与"实验性改进"两种方法：

| 测量对象 | 不受控方法 | 实验性改进方法 |
|---|---|---|
| 首次为产品定价 | 问卷调查 | 联合分析（Conjoint） |
| 改进存量产品定价 | 历史销售数据（扫码/门店数据） | 田野实验 |

## 一、不受控的价格调查

### 开放式提问的问题

最直接的做法是问客户"这罐可乐应该卖多少钱？"，但这类问题从一开始就有问题：它并不要求客户真的掏钱购买，因而把"价格认知"和"支付意愿"混为一谈。

::: definition Van Westendorp 价格敏感度测量法（Price Sensitivity Meter）
1976 年提出，向客户依次提出四个问题：什么价格会让你觉得太贵而不考虑购买？什么价格会让你觉得太便宜以至于怀疑品质？什么价格开始显得偏贵？什么价格是"物有所值"？下限取"太便宜"与"偏贵"两条线的交点，上限取"太贵"与"便宜"两条线的交点。
:::

::: pitfall Van Westendorp 方法已被证伪
该方法原本是为了衡量上一讲讨论的"价格—质量信号"对某产品的重要程度，但后来被扭曲成一种估算价格区间的工具，其方法论已被业内质疑。它之所以经久不衰，很可能只是因为：a) 交叉线图看起来很像供需曲线；b) "Van Westendorp"这个名字听起来足够权威。
:::

开放式提问的普遍问题包括：

- **客户几乎总会回答"看情况"**。可乐的支付意愿本身就随场景剧烈波动——赶时间又家里囤了很多可乐时可能只值 0.20 美元，被困酒店客房、唯一选择是迷你吧时则可能值 5 美元。
- **人们不擅长做这类开放式判断**。这类似于让人猜一只手提箱有多重——人们普遍猜不准；但如果给两只箱子让人判断哪个更重，几乎人人都能答对。这说明比较判断远比绝对判断可靠。
- **Lyon (2002) 的研究**发现，20% 的受访者所说的"合适价格"竟然低于他们自己所说的"太便宜"的价格，暴露出这类问答内部逻辑并不自洽。
- **过大的价格区间**只会给客户一个凭直觉拍板的借口。

### 单情形定价研究（Monadic Pricing Studies）

Monadic 研究只向受访者提出一个关于产品的具体问题，例如"如果一罐可乐定价 0.99 美元，你有多大可能购买？"或更接近真实决策的"如果可乐 0.99 美元、百事可乐 1.09 美元，假设你今天还没喝过汽水，你会买哪个？"

这类措辞让受访者只需做选择而非报价，更不容易造成混淆，能在特定场景下获得更准确的回答；如果测试的价格范围足够宽，甚至可以据此重建出一条需求曲线。

::: pitfall Monadic 研究的潜在问题
- 把客户注意力集中在"合理价格"附近，可能屏蔽掉像 5 美元这样的极端回答——而这类极端回答恰恰可能是有利可图的细分市场依据。
- 需要大量受访者才能得出结论；切勿使用"价格阶梯"式追问（"0.89 美元呢？0.79 美元呢？"），这会诱导受访者表现得像在讨价还价。
- 需确保问题没有过度聚焦于价格本身。
:::

### 价格调查技术的三大通病

::: pitfall 客户可能故意压低报出的支付意愿
- 某化工品分销商被客户告知，他们愿为废物处理服务支付的价格比市场价低 75%。
- 客户报价有时只是为了在调查者面前塑造某种自我形象，而非反映真实支付意愿。例如飞利浦一项调查中，青少年受访者都说想要黄色的手提音响，但离开房间时却清一色选择了黑色款。
- 客户也可能纯粹对自己的支付意愿没有把握。一项美国新娘婚礼调查发现，新娘对预算的自我报告比实际支付意愿高估了五倍。
:::

### 实施方式的取舍

- **面对面调查**：关键是找到合适的场景。仓促的场景会产生更差的数据；最好的数据来自受访者有充裕时间、调查本身变成一种集体活动的场合。
- **在线调查**：核心问题是数据可靠性——询问受访者使用什么浏览器时，40% 的人会撒谎，而提高报酬后这一比例反而上升。
- **焦点小组（Focus Groups）**：主持人的激励机制常常会扭曲结果与分析；但如果没有主持人，价格类问题往往根本得不到解答。

## 二、用联合分析改进价格调查

::: definition 选择式联合分析（Choice-Based Conjoint）
一种实验室调查方法，测量客户对不同属性组合（bundle）的估值，最常用（也最适用）于产品设计阶段。
:::

### 实施步骤

1. 选定一组有限的产品特性用于组合排列，价格应是其中一项特性。
2. 软件向受访者呈现不同产品组合之间的选择，并务必保留"不购买"这一选项。
3. 软件通过 logit 回归分析给出回归输出。
4. 客户对各项产品特性的估值，可以通过除以价格系数的比例换算成具体金额，从而得到 EVC 估算值（参见 [Lec 2](./lec2.md) 的 EVC 框架）。

### 优点

- 通过引入特性信息，缓解了传统调查中价格被人为过度关注的问题。
- 输出的"效用值"（utility-values）能帮助研究者更准确地测算 EVC。
- 速度快、成本相对低。

::: pitfall 不适合使用联合分析的情形
- 客户很可能把价格当作该属性质量的信号——这一问题往往相当严重，意味着必须严格限制属性数量，通常超过 3 个就太多了。
- 客户对产品特性本身理解不足。
- 产品是一个更复杂的关联产品系统的一部分。
:::

## 三、用历史数据改进存量产品定价

### 价格弹性

价格弹性衡量销量对价格变化的敏感程度，定义为价格变化 1% 时销量变化的百分比：

$$E_d = \frac{\%\Delta Q_d}{\%\Delta P_d} = \frac{\Delta Q_d / Q_d}{\Delta P_d / P_d}$$

::: insight 弹性与收入方向的关系
弹性能帮助分析师判断价格变化后收入会持平、上升还是下降：弹性等于 1 时降价前后收入不变；弹性大于 1 时降价会提高收入；弹性小于 1 时涨价会提高收入。价格弹性平均在 -2 左右，但"平均值"本身参考意义有限，因为不同产品、不同细分市场之间弹性差异极大。
:::

### 估计一个稳定的价格弹性

标准公式 $\Delta Q_d/Q_d$ 除以 $\Delta P_d/P_d$ 的问题在于，取初始值还是最终值会导致结果不同。只要在比较不同细分市场弹性时保持口径一致（例如分母取哪个值，分子就取对应的值），这一点通常不影响结论。这种不一致源于该公式假设价格与销量之间是线性关系；更聪明的做法是改为假设需求曲线具有恒定弹性：

$$Sales = aP^b$$

两边取对数：

$$\log Sales = \log a + b \log P$$

其中常数 $b$ 就是价格弹性，可以通过电子表格分析求出。

### 电子表格分析

用 Excel 等工具从历史数据中计算价格弹性相当直接：

1. 新建"销量对数"与"价格对数"两列，用 `=LOG()` 函数把原始销售数据转换为对数形式。
2. 在新单元格中插入函数 `=SLOPE(已知 y 值, 已知 x 值)`。
3. 已知 y 取销量对数，已知 x 取价格对数。
4. 得到的负数即为价格弹性。

::: pitfall 简单斜率估计的局限
仅靠 `SLOPE()` 无法判断估计值的可靠程度。可改用 Excel 的"数据分析"加载项中的"回归"（Regression）选项，得到标准误（衡量估计精度）和 R 方（衡量价格能解释多少销量变动）；若无法安装该加载项，也可以使用数组函数 `LINEST()`。
:::

### 价格弹性有何用处？

::: example 电子产品零售商的电池定价
一家电子产品零售商此前对电池全国统一定价。价格弹性分析显示，在达拉斯"价格敏感度"最高的某款电池，在波士顿的价格敏感度却最低——换言之，得州顾客对该电池的可接受价格区间极窄，而波士顿顾客则宽松得多。该零售商据此调整了各地定价，卖出更多电池并提高了利润（Associated Press, 2007）。
:::

- **作为经验定价法则**：尤其适用于 SKU 数量庞大的零售行业，但需附带严重的健康警告——它实际上假设了竞争对手不存在、企业已经在做最优定价，并且边际成本递增。

推导利润最大化加成公式：企业收入 $Revenue = P \times Q$，对销量求边际收入：

$$MarginalRevenue = P\frac{\delta Q}{\delta Q} + Q\frac{\delta P}{\delta Q} = P\Big[1 + \frac{\delta P}{\delta Q}\times\frac{Q}{P}\Big]$$

由价格弹性定义 $E_d = -1 \big/ \big(\frac{\delta P}{\delta Q}\times\frac{Q}{P}\big)$ 代入，得：

$$MarginalRevenue = P\Big[1 - \frac{1}{E_d}\Big]$$

利润最大化企业设定 $MR = MC$，即 $MarginalCost = P\big[1 - \frac{1}{E_d}\big]$，两边整理后得到加成公式：

$$P = MarginalCost \times \frac{1}{1 - |1/E_d|}$$

::: example 用弹性反推加成幅度
若估计价格弹性 $E_d = 2$，则价格应约为成本的两倍；若 $E_d = 3$，则价格应为成本的 1.5 倍（即 50% 加成）；若需求弹性较弱、$E_d = -1.5$，则价格应为成本的三倍。
:::

::: pitfall 使用加成公式的两个提示
- 请使用价格弹性的绝对值——该公式已经针对负值做了调整。
- 不要在价格弹性小于 1 时使用该公式。个人经验是，弹性低于 1.5 时该公式效果并不理想。
:::

### 历史定价分析的局限

1. **需要准确的定价数据**：某网络空间服务商的市场部门就曾因销售团队未记录实际折扣而陷入困境。
2. **需要价格本身有过变动**：某窗帘制造商因过去十年始终维持同一价格，根本无法计算出弹性。
3. **数据太陈旧会描述过时的场景**：不要使用五年以上的定价数据——某图书目录公司因纳入了互联网时代之前的数据，计算出的价格弹性被人为拉低。
4. **可能被其他混杂因素误导**：例如冰淇淋在炎热天气里定价更高且卖得更好；若采用多变量分析而非单变量分析计算价格弹性，则可以控制这类"可观测"的偏差来源。

### 改进历史定价分析的方法

1. **（关键）对每类客户、每个地区、每种产品分别计算不同的价格弹性**，而非只算一个笼统的整体值。
2. **不要只用汇总的销量和价格数据**：DHL 曾采用一款软件，纳入了打电话询价但最终未下单的"失败成交"客户的反应数据，借此把"报价转化率"从 17% 提升到 25%。
3. **使用面板数据计量方法**，在回归中控制地点和时间因素——但这在人力和数据获取成本上都可能相当昂贵。

## 四、用田野实验改进定价分析

历史数据分析的许多问题，都源于价格变化的原因本身也与销量变化的原因相关联（例如天气同时影响冰淇淋定价与销量）。受控的价格实验可以规避这一点，且往往效果显著——Ambassadors Travel Group 通过实验发现自身价格弹性只有 0.3，据此将利润提高了 15%。

::: insight 田野实验的门槛正在降低
过去田野实验通常被视为大企业才能负担的正式实验，但 Google Analytics 等新工具正在让预算有限的企业也能轻松开展价格实验。
:::

### 田野实验面临的挑战

::: pitfall 田野实验的常见陷阱
1. **确保有足够的价格变动幅度**：曾有一个实验把所有价格统一下调 15%，这种设计只有在你真的打算把所有价格都降 15% 时才有意义。
2. **实验过于显眼会激怒客户**：Amazon 曾因 DVD 定价实验被发现，被迫向愤怒的客户退款 7,000 美元。
3. **缺货或实验组本身出问题（如邮寄环节故障）会破坏结论的可靠性**。
4. **多个价格实验并行会让单个实验难以解读**：Fingerhut 每年运行 30,000 场定价实验，互补品和替代品之间的相互影响让结果解读变得困难。
:::

## 附：数学附录

### 中点弹性公式

如果担心简单弹性公式的近似误差，又不打算做适合对数变换的详细历史分析，可以改用中点弹性公式：

$$E_d = \frac{(Q_2-Q_1)/[(Q_1+Q_2)/2]}{(P_2-P_1)/[(P_1+P_2)/2]} = \frac{(Q_2-Q_1)(P_1+P_2)}{(P_2-P_1)(Q_1+Q_2)}$$

### 从对数形式推导价格弹性的微积分推导

恒定弹性需求函数为 $Q = aP^b$。令 $u=\ln Q$，$v=\ln P$，则：

$$E_d = -\frac{d\ln Q}{d\ln P} = -\frac{du}{dv}$$

通过链式法则将其展开为关于 $Q$、$P$ 的微分形式，即可从对数线性回归的斜率系数 $b$ 直接读出价格弹性的估计值。

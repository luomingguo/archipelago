# Lec 6 IT 系统与拍卖机制定价（Pricing and IT）

> MIT 15.818 · Pricing · 主讲 Prof. Catherine Tucker

## TL;DR

- 定价 IT 系统理论上能革新定价，但成功有限：它们主要做两件事——自动计算价格弹性、在约束（如有限或易逝产能）下给出优化建议；而实际部署常沦为被人工"超控"的管理工具，或被用于软件本不擅长的场景。
- Google Adwords 用拍卖机制取代了历史数据驱动的定价优化：拍卖能激励买家说出真实支付意愿，比依赖过去行为假设未来的传统 IT 定价系统更可靠；关键经验是把拍卖用于产品最细粒度、最具体的版本上。
- 两边平台（two-sided platform）需要同时设定两组接入费（access fee）与使用费（usage fee）；定价策略应补贴对另一方溢出效应更大、价格敏感度更低的一方，若溢出效应与价格敏感度方向不一致，则需要在两者间权衡。
- 两边平台定价的常见陷阱包括：补贴了错误（不具吸引力）的用户群体、产品供给持续不足、忽视高额使用费引发的法律风险，以及来自竞争性产品线的定价掣肘（如 Kindle 与 iPad 的定价对比）。

## 定价 IT 系统：理论潜力与现实落差

理论上，IT 的进步有能力彻底改变定价方式，但实践中成效参差不齐。这类系统通常承担两项功能：

1. **自动计算价格弹性**：当企业拥有多个 SKU 或多种数据来源时尤其有用（参见此前电池案例，见 [Lec 2](./lec2.md) 中 EVC 相关讨论的定价基础）。
2. **在约束条件下给出建议价格**：约束通常是有限或易逝的产能，这一过程被称为价格优化（price optimization）。

### 价格优化软件的良好应用场景

::: definition 拥挤外部性（Congestion Externality）与收益管理
当产品存在很高的固定容量与高度波动的需求时，某些时段会出现拥挤，需要主动管理。典型例子是城市道路的拥堵定价——高峰时段提高道路使用费以劝退部分司机；水上乐园、主题公园等也属同类场景。

另一类经典应用是避免闲置产能。正如一位餐厅营销人员所说："餐厅里最贵的东西就是一张空桌子。" 大多数企业希望尽可能接近满负荷运转——酒店预订一间客房，就直接排除了另一位顾客预订同一间房的可能。在"现在低价卖出"与"等待、可能在最后一刻以更高价卖出"之间的权衡，催生了收益管理（revenue management）这一实践。
:::

::: insight
收益管理的优化技术固然重要，但同等重要的是构建正确的价格围栏（price fence）供优化算法在其上运作。收益可以通过三条途径提升：识别新的定价围栏、防止跨围栏套利、改善客户对定价公平性的感知。
:::

在收益管理的传统领域之外，也存在一些成功案例，但它们大多依赖于对价格弹性更好的理解，而非成本结构优化——理论上优化系统也可以对成本表进行优化，但目前几乎没有软件系统能做到这一点，主要原因是管理者自己也不清楚成本结构。

### 这类系统遇到的问题

::: pitfall 价格优化软件的三类常见误用
1. **被当作价格管理工具而非优化工具使用**：一家大型百货公司投入巨资购买了昂贵的价格优化软件，但采购部门在实际使用中把关键指令设为"人工超控"，主要仍靠自己的"超级直觉"来定价，软件形同虚设。
2. **被用于软件未曾设计的用途**：据《今日美国》（USA Today，2007）报道，7-Eleven 曾发现，当他们努力"压低"某些成本以便降低部分商品售价时，这种努力常常并不划算——多个降价商品的销量并未随之改变。该公司因此购买了价格优化软件以提前获得这类洞察。负责商品定价的经理 Kay Trapp 表示："我们认为这让我们变得更聪明了。"
3. **把为无产能约束行业开发的优化软件用于本无容量限制的场景**：例如某些为航空公司机票销售设计的优化软件，被用在完全没有容量约束的行业时，软件不得不人为制造出虚假约束，才能声称自己在"做优化"。
:::

## 案例研究：Google Adwords 定价

上述许多问题的根源在于：IT 系统假设人们未来的定价行为会与过去一样，并且假设人们不会试图智胜（outsmart）定价软件。更合理的思路是让 IT 系统专注于提供激励，使人们愿意主动告诉企业自己真实的支付意愿——这正是 Google 通过其针对搜索关键词的自动化拍卖系统 "Adwords" 所做的事。凭借这套机制，Google 已成为在线广告领域的市场领导者。

### Adwords 拍卖机制

::: example Google Adwords 竞价流程
- 企业注册 Adwords。
- 选择希望广告展示在其旁边的具体搜索词。
- 为每个词出价。
- （大致而言）出价最高的企业广告展示在第一位，但其支付的价格是第二高出价者的出价，而非自己的出价——之所以说"大致"，是因为 Google 还会根据"质量得分"（Quality Score，即广告的实际点击率）调整实际支付价格。
- 第二高出价者的广告排在第二位，支付第三高出价者的出价，以此类推。
:::

### 从 Google 身上学到的经验

1. **拍卖有助于为商品定价**：拍卖极其擅长鼓励买家表达真实估值。设想典型的第二价格拍卖，中标者支付第二高出价——在什么情况下最高出价者会选择比自己真实估值出价更低？正因如此，卖方在可能的情况下都更偏好使用拍卖。据一项针对私募股权公司的调查，约 80% 的受访机构表示作为卖方时倾向使用拍卖，而约 90% 的同一批机构表示作为买方时倾向避免拍卖（《并购》期刊 Auction Process Roundtable，2006 年 12 月，第 31–32 页）。拍卖因此成为收益管理技术的有力替代——企业不必依赖历史数据与假设，而是直接给客户正确的激励去说出真实支付意愿。艺术品、房产这类难以通过其他方式定价、但单价足够高、值得专门组织拍卖的商品是典型受益者；需要快速批量出售的商品（如二手车置换、部分金融工具、荷兰式拍卖的鲜花）同样适合拍卖，以确保快速成交。
2. **识别正确类型的网络互动来定价至关重要**：按点击付费（pay-per-click）相较按展示付费（pay-per-impression）取得了巨大成功；按行动付费（pay-per-action）的成功则不那么明确。
3. **尽可能在最微观的层面上定价对盈利能力至关重要**：Goldfarb 与 Tucker（2009）的研究表明，最具盈利能力的搜索词恰恰是那些搜索量最少、最细分（micro level）的关键词。研究提供的证据显示，当市场足够"薄"——即处于长尾（long tail）部分时，Google 反而能够收取更高的价格。核心启示是：若想复制 Google 利用电子拍卖取得的成功，关键在于把拍卖用到产品尽可能微观、具体的版本上。
:::

::: insight
留给读者的思考题：为什么广告主愿意为出现在搜索结果首位支付更高的平均单次点击价格？
:::

## 软件平台的定价

### 什么是两边平台

互联网上大多数新兴商业模式实际上都是两边平台（two-sided platform），MIT Sloan 毕业生创立的公司尤其如此，这类平台有时也被称为双边网络或双边市场——两个群体通过一个共同的平台或市场彼此互动。

::: insight
在此前课程涉及的 Keurig 案例中，我们深入思考了如何在存在锁定（lock-in）效应时进行策略定价。锁定与"剃须刀-刀片"（razor-blade）定价的市场，与两边平台市场之间存在很强的关联。举例来说，如果 Keurig 只充当烘焙商与消费者之间的中介、而不亲自销售咖啡，它就会是一个两边平台。两者的关键区别在于：在纯锁定市场中，客户购买产品的决策赋予企业对该客户的议价能力；而在两边平台中，客户的购买决策同时也赋予平台运营者对网络另一侧参与者购买决策的影响力。
:::

::: definition 两边平台的三种主要类型（Evans and Schmalensee, 2007）
1. **交易所（Exchanges）**：把分散的买卖双方汇聚到一起的网络，例如 craigslist.org、购物中心、eBay.com。
2. **软件系统**：平台通常是操作系统，两个群体是计算机用户与程序开发者，例如 Linux、Windows、Xbox、Playstation。
3. **内容型市场（Content-Based Markets）**：例如报纸类市场，一侧是广告主，另一侧是希望获取内容的用户；内容既可以是用户生成的（如 Facebook），也可以由网站自身生成（如 yellowpages.com、Salon.com，或许还有 Google）。
:::

这类市场通常具有高固定成本与强网络效应的特征。

### 两边平台的定价策略

两边平台的定价策略更复杂，因为潜在需要设定两组接入费（access fee）与使用费（usage fee）：接入费是使用网络技术本身需要支付的价格，与使用量无关；使用费则是通过网络与他人互动所需支付的价格。

::: theorem 两边定价的基本原则
1. **识别对另一方溢出效应更大的一方**：夜店里女性顾客更多，往往更能吸引大量男性顾客，而反过来的效应较弱——浏览者给广告主带来的收益大于广告主给浏览者带来的收益。可以用（此前课程介绍的）Excel 弹性估算技巧衡量两侧弹性差异，需要补贴绝对弹性较低的一方：在夜店的例子中，男性对女性存在与否的弹性高于女性对男性的弹性。
2. **识别价格更敏感的一方**：例如律师的客户比律师本人对价格更敏感。
3. 若价格敏感度与溢出效应指向同一方，问题就很简单；若两者方向不一致，则策略上应降低价格敏感一侧的接入费，提高对网络效应不敏感一侧的使用费。
:::

::: example 定向补贴换取平台采纳
另一种策略是针对性地补贴某个用户群体，换取其同意使用你的平台——例如环球影业（Universal Studios）曾被说服只发行 HD-DVD 格式的影碟。
:::

### 两边平台定价策略的落地实践

::: example 交易所类平台
- **eBay** 是成功的两边交易所网络的经典范例，对卖家同时收取挂牌费与交易费。
- **Chemdex** 曾提供化学品、酶、实验设备、多肽等生物科技产品及各类化学试剂的在线交易市场，吸引近 15 万名用户，从超过 2,000 家供应商处订购商品，数据库列有约百万种产品，从烧杯到特种生化制品。IPO 时其季度销售额仅为 165,000 美元（主要来自 Genentech），同期亏损 680 万美元，却在 IPO 中募得 1.125 亿美元，首日股价上涨 60%，(含未上市股份的)公司估值一度超过 7.5 亿美元，其后市值萎缩至峰值的 1%。它靠对交易额收取 1% 的费用赚钱；问题在于其全部营销资源（"领取免费 T 恤！"）都投向了消费者，而真正的挑战其实是说服供应商支付 5% 的挂牌费，供应商完全看不到这笔费用的价值所在。
:::

::: example 软件系统类平台
- **Adobe** 的定价模式具有革命性：免费提供 Reader，靠销售 Adobe Distiller 盈利。
- **OpenTable** 向加盟餐厅收取一次性 1,000 至 1,300 美元的系统安装费，此后每月收取 100 至 200 美元，外加每完成一次预订收取 1 美元——这限制了它能服务的餐厅数量。顾客每完成一次预订可获得 1 美元的奖励积分。截至 2009 年，OpenTable 已为 8,400 家餐厅服务过 7,500 万名食客。
:::

::: example 内容型市场
平台必须决定是向用户收费还是采用广告驱动模式，这一选择往往并不显而易见。Facebook 面临的最大挑战，正是如何在用户与广告主之间的互动中找到变现方式，核心障碍是隐私顾虑。
:::

### 两边平台定价面临的挑战

::: pitfall 补贴错误的用户群体
FreePC 在 1999 年吸取了这一教训：它向愿意观看无法最小化或关闭的互联网广告的消费者免费提供电脑与网络接入，但很少有广告主愿意针对这批极度在意成本的消费者投放广告，FreePC 在亏损 8,000 万美元后放弃了这一模式。YouTube.com 可能也面临着不适合变现的内容结构——太多内容具有高度私人性质，难以匹配合适的广告。
:::

::: pitfall 产品供给不足
在 Playstation、Xbox 这类两边技术市场中，企业在产品发布初期常常持续性地供给不足，真正的赢家往往是那些在 eBay 上炒卖主机的"黄牛"——Playstation 3 发售后不久曾在 eBay 上炒到约 1,500 美元，而其零售价仅为 599 美元。
:::

::: pitfall 缺乏对法律风险的认识
使用费有时会高到引发法律问题。"Rewards Network" 是一个允许餐厅向潜在顾客提供优惠券的两边平台：为吸引餐厅加盟，它向餐厅预付 1 万至 2.5 万美元的现金，作为回报，餐厅需向 Rewards Network 提供相当于该预付款 150% 至 200% 的用餐抵用额度——例如预付 1 万美元，Rewards Network 便有权向其会员出售价值 2 万美元的该餐厅用餐抵用额。该公司吸引了 300 万名顾客与 1 万家餐厅加盟，但随后因涉嫌高利贷利率遭遇了一起对其不利的集体诉讼。
:::

::: example 来自产品线定价的竞争性掣肘
为什么 Kindle 定价如此之高？部分观察人士认为这是为了不冲击亚马逊标准出版业务的定价体系；亚马逊在把电子书定价推高至 9.99 美元以上时也遇到了阻力。相比之下，iPad 的定价甚至更高——499 美元的 iPad 制造成本约为 290 美元。
:::

# 9.00 心理学导论

MIT 9.00（Fall 2011，主讲 John Gabrieli）的通识入门课，覆盖心理学的三个分析层次——大脑、个人、群体——如何共同解释感知、认知、情绪与社会行为。课程按"证据链"方式组织：每一讲都从一个反直觉的现象或经典研究出发，追问其设计、结果、推论与局限，而不是罗列结论。

## 覆盖范围与缺口

原课程共约 23 讲，目前只翻译整理了以下 11 讲的笔记；其余讲次（科学方法与研究方法论、视觉 I、注意、记忆 II、思维与推理、语言、情绪与动机、人格、精神病理学、成人发展、社会心理学 II 等）尚未收录，正文中提到这些讲次时一律以纯文本描述主题，不建立跳转链接。

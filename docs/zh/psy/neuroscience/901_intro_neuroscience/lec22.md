# Lec 22 情绪：恐惧、依恋与社会决策

> MIT 9.01 Introduction to Neuroscience · Lecture 22 · Sebastian Seung

## TL;DR

- 经典巴甫洛夫恐惧条件反射依赖杏仁核：外侧核整合听觉条件刺激与电击非条件刺激，中央核驱动自主神经与冻结反应。
- 丘脑直通杏仁核的“快通路”提供低分辨率危险预警，丘脑-皮层-杏仁核的“慢通路”执行精细识别与情绪评估调控。
- 杏仁核激活下丘脑释放 CRF 激活垂体-肾上腺（HPA 轴），海马富集糖皮质激素受体则对皮质醇产生负反馈制动。
- 神经肽催产素与加压素调节伏隔核与腹侧苍白球多巴胺回路，驱动社会依恋、信任与配偶结对；前额叶则抑制冲动。

## 1. 驱动问题
- 核心问题：哪些神经回路使刺激获得情绪意义并影响行为？
- 为什么不显然：心率、面部表情、主观感受和决策可以相关，却不是同一个测量量。
- [工作记忆与非陈述性学习](./lec21.md) 的学习机制在本讲的恐惧条件作用中重现。

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 | 容易混淆的对象 |
| --- | --- | --- |
| 情绪表达（expression） | 可观察的行为与生理变化 | 人的主观情绪体验 |
| 杏仁核（amygdala） | 参与恐惧学习、线索评价等过程的内侧颞叶结构 | 唯一的「情绪中心」 |
| 恐惧条件作用 | 中性线索与厌恶刺激配对后，线索本身引发恐惧反应 | 天生对该线索恐惧 |
| 催产素/加压素 | 讲义在田鼠伴侣偏好中讨论的肽类调节信号 | 单独决定一切人类亲密关系 |
| 最后通牒博弈（ultimatum game） | 提议者分配金钱、回应者可拒绝并让双方得零的任务 | 所有人类公平行为的充分模型 |

## 3. 证据链
### S.M. 病例与恐惧学习
- **设计**：比较双侧杏仁核损伤的 S.M. 对他人恐惧表情的识别、恐惧学习与社会判断。
- **结果**：讲义描述三项能力均受影响；另有恐惧线索训练后杏仁核中央核对厌恶音的反应增加。
- **推论**：杏仁核参与线索获得威胁意义，而不只是在已有恐惧时被动亮起。
- **软肋**：单病例不能推出杏仁核对所有情绪都是充分或唯一的器官。

### 田鼠伴侣偏好操纵
- **设计**：比较草原田鼠与山地田鼠；在草原田鼠中用催产素拮抗剂，并在另一模型中改变加压素受体表达。
- **结果**：讲义称拮抗剂削弱或逆转伴侣偏好，受体分布变化可改变部分配对行为。
- **推论**：特定调节系统与回路位置共同影响配对行为，不能只看激素是否存在。
- **软肋**：田鼠实验不能直接给出人类爱情的完整机制。

### 最后通牒博弈的影像比较
- **设计**：让回应者面对公平或不公平提议，比较脑活动（讲义引用 Sanfey 等，2003）。
- **结果**：不公平相对公平提议与前岛叶、前额叶及前扣带活动差异相关。
- **推论**：社会决策涉及情绪评价与控制的并行过程。
- **软肋**：fMRI 相关活动不能单独证明某区域产生拒绝决定。

## 4. 理论之争
| 立场 A | 立场 B | 哪个证据可区分 |
| --- | --- | --- |
| 情绪等于主观感受 | 表达、生理与体验是相关但不同的层面 | S.M.、条件恐惧与影像任务测到不同指标 |
| 单一种「情绪中心」控制全部情绪 | 恐惧、攻击、依恋与社会评价涉及部分不同回路 | 杏仁核、下丘脑、田鼠受体与博弈结果 |

## 5. 分析层次
- 神经/生理：杏仁核输入/输出区、下丘脑、肽类受体和社会决策相关皮层活动。
- 认知/信息加工：中性线索学会预测威胁；公平提议需价值与社会规范评价。
- 行为：恐惧表情识别、攻击姿态、伴侣偏好与拒绝不公平分配。
- 社会/文化：博弈包含人际公平规范，但课件未做跨文化比较。

## 6. 边界与失败案例
- 「杏仁核是恐惧中心」是课堂简写；刺激也可产生其他情绪，恐惧回路不止一个区域。
- 面部表情、皮肤电与自我报告是不同指标，不应互当替身。

## 7. 联结
- [工作记忆与非陈述性学习](./lec21.md) 的条件配对机制帮助解释恐惧学习；[视觉 III：V1 之后](./lec11.md) 的视觉表征提供面孔线索。
- 自举例：收到一次诈骗短信后，类似措辞会让我警觉；这可来自线索与负面结果的学习，但警觉不等于每次判断都准确。


::: insight 演化生存环路的情感升华
情绪并非理性思考的非理性杂音，而是哺乳动物演化过程中高度优化的适应性价值评估与快速防御算法。杏仁核双通路设计允许生命在“误将绳索当成毒蛇”（低成本虚报）与“误将毒蛇当成绳索”（致命漏报）之间做出最符合自然选择的生存决策。当古老的神经肽调节与新皮层的自顶向下调控发生耦合，生物本能便升华成了深沉的社会依恋与道德共情。
:::

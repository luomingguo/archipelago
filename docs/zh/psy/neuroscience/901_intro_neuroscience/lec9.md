# Lec 9 视觉 I：眼睛与视网膜

> MIT 9.01 Introduction to Neuroscience · Lecture 9 · Sebastian Seung

## TL;DR

- 光转导通过视紫红质光照异构化与 cGMP 降解关闭阳离子通道，导致光感受器见光发生超极化。
- 双极细胞分为 ON 与 OFF 通路，通过代谢型（mGluR6）与离子型谷氨酸受体实现信号符号翻转。
- 水平细胞介导的侧向抑制赋予神经节细胞同心圆中心-周边拮抗感受野，专司局部空间对比编码。
- 中央凹区域视锥细胞具有 1:1 的极高神经节细胞汇聚比，构筑了高敏锐度的昼光中心视觉。

## 1. 驱动问题
- 核心问题：光如何变为视神经中的脉冲？
- 为什么不显然：照相机的比喻会掩盖一个反直觉事实——感光细胞见光时超极化，最终的 ON-center 神经节细胞却可能增加放电。
- 本讲从视网膜出发；[视觉 II：色觉与 V1 通路](./lec10.md) 追踪信号到丘脑和 V1。

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 | 容易混淆的对象 |
| --- | --- | --- |
| 感受野（receptive field） | 刺激其中某个位置会改变该神经元放电的空间范围 | 整个视野 |
| 光转导（phototransduction） | 光使 cGMP 减少、暗电流通道关闭，令感光细胞超极化 | 「光直接产生动作电位」 |
| ON/OFF 双极细胞 | 对亮度变化作相反电压反应的两条视网膜通路 | 神经节细胞的中心-周边结构 |
| 中心-周边拮抗（center-surround antagonism） | 感受野中心与外围受刺激后产生相反作用 | 只测绝对亮度的探测器 |
| 中央凹（fovea） | 视锥密集、视敏度高的视网膜区域 | 视盘形成的盲点 |

## 3. 证据链
### 视神经感受野定位（讲义中的记录方法）
- **设计**：记录一根视神经轴突的放电，同时把视觉刺激移到不同位置。
- **结果**：只有特定位置的刺激改变放电；ON-center 示例在中心受光时高于背景放电率。
- **推论**：这根轴突报告的是输入中的一个空间特征，而非整张未经处理的图像。
- **软肋**：讲义给出方法与示意曲线，没有群体样本或效果量。

### 视网膜通路和光暗反应
- **设计**：比较讲义里的感光细胞电压图、双极细胞说明与神经节细胞中心-周边图。
- **结果**：感光细胞见光超极化；ON 与 OFF 双极细胞方向相反；ON-center 偏好亮中心、暗外围，OFF-center 偏好暗中心、亮外围。
- **推论**：信号符号翻转与侧向相互作用使视网膜能够编码局部对比。
- **软肋**：这里主要是机制示意；本讲没有逐个突触做因果操纵。

## 4. 理论之争
| 立场 A | 立场 B | 哪个证据可区分 |
| --- | --- | --- |
| 视网膜传递各处绝对亮度 | 视网膜强调局部对比 | 中心-周边放电偏好和讲义中的 Chevreul 错觉 |

## 5. 分析层次
- 神经/生理：感光细胞 → 双极细胞及侧向连接 → 神经节细胞轴突。
- 认知/信息加工：感受野提取局部变化，不传送整个场景。
- 行为：不同视网膜位置的视敏度不同；中央凹与盲点功能不同。
- 社会/文化：本讲未展开。

## 6. 边界与失败案例
- 视杆与视锥分别偏重弱光敏感度、日间颜色和高视敏度；任一类都不能独自解释全部视觉能力。
- ON-center 示意不能推出所有神经节细胞有同一感受野。

## 7. 联结
- [视觉 II：色觉与 V1 通路](./lec10.md) 解释视网膜输出的路径；[视觉 III：V1 之后](./lec11.md) 讨论更高阶特征。
- 自举例：一块灰色瓷砖靠着较暗瓷砖时看起来更亮，即使照到它本身的光没有改变。


::: insight 视网膜的局部计算本质
视网膜绝非被动的感光胶片，而是一座高度集成的模拟-数字前向预处理器。通过光感受器的非线性动态压缩、水平细胞的侧向负反馈与双极细胞的符号分流，视网膜在输出视神经脉冲之前，就已经剔除了高达 90% 以上的环境背景冗余，完成了空间反差提取与动态范围自适应。这一计算架构展示了神经系统在物理能量与信息表征之间的精妙工程权衡。
:::

# Lec 10 视觉 II：色觉与 V1 通路

> MIT 9.01 Introduction to Neuroscience · Lecture 10 · Sebastian Seung

## TL;DR

- 视网膜视锥三色编码经下游神经节细胞与 LGN 转化为红-绿与蓝-黄颜色拮抗信号，双阶段模型统一了经典视知觉理论。
- 离视网膜投射在视交叉处实现鼻侧纤维对侧交叉，将左右对侧视野而非单眼信号严密投射至对侧半球 LGN。
- LGN 六层结构严格隔离大细胞（M 通路）、小细胞（P 通路）与单眼输入，维持精确的视网膜拓扑映射。
- 初级视觉皮层（V1）第 IVC 层接受 LGN 输入后，通过简单细胞与复杂细胞汇聚产生线段方向选择性与眼优势柱。

## 1. 驱动问题
- 核心问题：视网膜如何编码颜色，信息又如何到达 LGN 和 V1？
- 为什么不显然：场景里的两块区域可以有相同亮度，却因阴影语境看起来不同。
- [视觉 I：眼睛与视网膜](./lec9.md) 已说明局部对比，这讲加入波长与皮层路径。

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 | 容易混淆的对象 |
| --- | --- | --- |
| 反射率（reflectance） | 表面反射入射光的比例 | 亮度；亮度还取决于照明 |
| 三色编码（trichromacy） | 三类视锥敏感度提供三维颜色输入 | 后续神经元的颜色拮抗 |
| 颜色拮抗（color opponency） | 神经元比较红-绿或蓝-黄信号 | 视锥本身的光谱敏感度 |
| 离视网膜投射（retinofugal projection） | 视网膜 → 视束 → LGN → 视放射 → V1 | 「视网膜直接连 V1」 |
| V1 方向选择性 | 细胞放电随条纹或边缘方向变化 | 视网膜中心-周边感受野 |

## 3. 证据链
### 棋盘阴影错觉（Adelson 的课堂演示）
- **设计**：在含阴影线索的棋盘图里比较方格的视觉明度。
- **结果**：讲义显示，明度感受依赖周围场景；并提示「亮度 = 入射光 × 反射率」。
- **推论**：若要估计表面反射率，视觉系统必须推断照明，不能只读像素强度。
- **软肋**：这里是感知演示，本讲未给出被试数量或定量比较。

### 视锥曲线与颜色后效
- **设计**：并看三种视锥敏感度曲线与红-绿、蓝-黄后效示意。
- **结果**：讲义标出约 430、530、560 nm 的敏感度峰值，并描述下游神经节细胞的颜色拮抗。
- **推论**：三色编码和拮抗编码发生在不同处理阶段，不必把两种理论看作互斥。
- **软肋**：这是生理研究的概述与演示，未附单项研究的样本资料。

### 视野交叉路径图
- **设计**：沿视交叉追踪左右半边视野进入 LGN、V1 的纤维。
- **结果**：左半边视野由右半球处理，右半边由左半球处理。
- **推论**：交叉以「视野」为单位，不是整只眼睛全数交叉。
- **软肋**：解剖示意本身不是损伤或记录实验。

## 4. 理论之争
| 立场 A | 立场 B | 哪个证据可区分 |
| --- | --- | --- |
| 三色理论与拮抗理论只能二选一 | 视锥三色输入接到下游拮抗神经元 | 视锥曲线与拮抗反应共同支持分阶段解释 |
| 知觉直接读取亮度 | 知觉利用语境估计反射率 | 棋盘阴影演示 |

## 5. 分析层次
- 神经/生理：视锥、颜色拮抗神经节细胞、LGN 与 V1。
- 认知/信息加工：从含糊的照明中估计表面颜色和明度。
- 行为：后效与同时对比改变主观颜色。
- 社会/文化：本讲未展开。

::: insight 从拓扑映射到空间滤波
从视网膜到初级视觉皮层 V1 的信息重构，本质上是由点阵采样向局部空间时域 Gabor 小波基展开的数学升华。LGN 负责维持高保真的单眼拓扑通道，而 V1 借由局部微回路的非对称兴奋汇聚与抑制性调谐，破天荒地将离散亮度差解耦为具有物理几何意义的边缘方向与空间频率，开启了视觉世界结构化表征的序幕。
:::

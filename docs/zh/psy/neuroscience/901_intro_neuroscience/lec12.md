# Lec 12 听觉：从声波到空间定位

> MIT 9.01 Introduction to Neuroscience · Lecture 12 · Sebastian Seung

## TL;DR

- 耳蜗基底膜沿纵轴呈现刚度渐变，基底部响应高频、顶端响应低频，奠定了中枢听觉系统的频率拓扑组织。
- 内毛细胞静纤毛偏折拉开顶端细丝（Tip Links）机械敏感通道，诱发钾内流极化，实现微秒级机械电转导。
- 低频声源水平定位依赖内侧上橄榄核（MSO）的双耳时间差（ITD）计算，符合杰弗里斯延迟线重合检测模型。
- 高频声源水平定位依赖外侧上橄榄核（LSO）的双耳强度差（ILD）与对侧抑制比较，耳廓滤波提供垂直定位线索。

## 1. 驱动问题
- 核心问题：空气中的压力波如何变成神经元可读的频率、强度与位置？
- 为什么不显然：声波进入液体会强烈反射，而且声源方向并不直接写在一只耳朵的频谱里。
- 与 [味觉与嗅觉](./lec13.md) 一样，本讲要解释物理刺激如何转导为神经信号。

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 | 容易混淆的对象 |
| --- | --- | --- |
| 阻抗失配（impedance mismatch） | 空气与耳蜗液体的机械性质不同，声能易反射 | 耳朵完全隔音 |
| 基底膜位置编码（place code） | 声波频率决定基底膜振幅峰值的位置 | 全部频率由一颗细胞读取 |
| 纤毛转导（hair-cell transduction） | 纤毛弯曲改变毛细胞电位和递质释放 | 毛细胞直接是听神经轴突 |
| 耳蜗放大器（cochlear amplifier） | 外毛细胞的运动反馈增强基底膜振动 | 内毛细胞的主要神经输出 |
| 双耳时间差（interaural time difference） | 同一声波抵达两耳的时间差 | 双耳强度差 |

## 3. 证据链
### 基底膜与听神经频率调谐
- **设计**：讲义比较不同纯音下基底膜振幅峰值位置、听神经放电随频率的曲线。
- **结果**：基部较窄较硬，偏高频；顶端较宽较软，偏低频。单根听神经纤维有特征频率。
- **推论**：耳蜗先把频率变成空间位置，后续通路再保留音调拓扑。
- **软肋**：图主要引用教材；本讲没有给同一受试群体的测量资料。

### 外毛细胞放大与耳声发射
- **设计**：比较内、外毛细胞连接图与「播放咔哒声后听到耳蜗回声」的示例。
- **结果**：讲义说不到 5% 的螺旋神经节细胞接受外毛细胞突触，而外毛细胞可增加基底膜振动；耳蜗可产生耳声发射。
- **推论**：外毛细胞主要调节机械输入，内毛细胞承担大部分神经输出。
- **软肋**：耳声发射是反馈活动的线索，不等于单独证明所有分子环节。

### 上橄榄核的双耳时间差曲线
- **设计**：比较双耳到声时间差与上橄榄核神经元放电率；讲义还用仓鸮猎物定位作情境。
- **结果**：某些双耳细胞对特定时间差放电最多，讲义图示范围为毫秒级。
- **推论**：两耳信息汇合后，可用时间差推断水平方向。
- **软肋**：这是图示生理结果；低频相位锁定是该方案的适用条件。

## 4. 理论之争
| 立场 A | 立场 B | 哪个证据可区分 |
| --- | --- | --- |
| 音调只由整体振动强度表示 | 基底膜位置与神经元特征频率编码音调 | 基底膜峰值与频率调谐曲线 |
| 单耳足以确定所有方向 | 双耳时间差与耳廓反射共同提供方向线索 | 上橄榄核曲线；绕过耳廓后垂直定位受损的讲义示例 |

## 5. 分析层次
- 神经/生理：听小骨 → 耳蜗毛细胞 → 听神经 → 耳蜗核 → 上橄榄核 → 下丘 → MGN → 听皮层。
- 认知/信息加工：频率位置编码、双耳巧合检测和音调拓扑（tonotopy）。
- 行为：辨认音调、音量和空间方向。
- 社会/文化：本讲未展开。

## 6. 边界与失败案例
- 双耳时间差在高频下不如低频稳定；讲义强调相位锁定的限制。
- 2007 年讲义对具体纤毛离子通道的命名属于历史课件内容，本笔记不把它当作现行定论。

## 7. 联结
- [视觉 III：V1 之后](./lec11.md) 的视网膜拓扑与听觉音调拓扑是两种有序地图；[味觉与嗅觉](./lec13.md) 比较不同感官的受体机制。
- 自举例：耳机只给一侧声音时，我能听清内容，却失去真实空间中两耳到声时间差的一部分。


::: insight 物理极值与重合检测的数学之美
听觉系统对物理极限的压榨令人惊叹：内耳毛细胞的偏折位移仅在亚纳米量级，而 MSO 神经元利用轴突物理长度延时与重合检测，将微秒级（微秒量级！）的双耳时差直接转换为神经元放电的空间位置编码。这种模拟延迟线网络不仅是自然界最高效的自相关计算芯片，更印证了时间神经编码精度的极致巅峰。
:::

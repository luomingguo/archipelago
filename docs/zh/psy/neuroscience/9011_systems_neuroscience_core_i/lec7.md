# Lec 7 视觉系统 I：视网膜、LGN、V1

> MIT 9.011 Systems Neuroscience Core I · Lecture 7 · Peter H. Schiller

## TL;DR

- 视觉系统自视网膜神经节细胞出发，经丘脑 LGN 拓扑映射中继至初级视觉皮层 V1。
- Dacey 等生理研究证实受体输入特异性并不直接等同于颜色拮抗，拮抗信号由下游网络计算生成。
- LGN 在形态学与功能上维持严格分层，分别承接不同感光细胞亚群的并行前向驱动。
- V1 建立高精度的视网膜拓扑映射，并在此基础上发展出线段方向、双眼视差等局部皮层模块。

## 1. 驱动问题
- 核心问题：感光细胞、视网膜神经节细胞、LGN 与 V1 之间怎样形成有组织的通路？
- 为什么不显然：肉眼只看到一个完整场景，无法直接看出内部的多层细胞和模块化地图。
- 公开提纲列出各层输入、拓扑与基本变换；下讲 [视觉系统 II：ON/OFF 与 M/P 通道](./lec8.md) 再细分通道。

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 视网膜神经节细胞 | 视网膜向脑输出信号的细胞 | 感光细胞本身 |
| LGN（外侧膝状体） | 位于丘脑、接收视网膜输出的中继结构 | 视觉皮层 V1 |
| 视网膜拓扑（retinotopy） | 相邻视野位置在神经地图上保持相邻 | 不同细胞处理完全相同位置 |
| 皮层模块 | V1 中结构与反应性质有组织的局部集合 | 单个「物体识别中心」 |

## 3. 证据链
### 指定阅读：Dacey 等（1996）的视网膜水平细胞研究
- **设计**：在猕猴视网膜中用生理与解剖方法追踪 H1/H2 水平细胞接收的不同视锥输入。
- **结果**：H1 主要接 L/M 视锥，H2 强接 S 视锥并弱接 L/M；两类输入同符号，水平细胞本身未显示光谱拮抗。
- **推论**：受体选择性不等于颜色拮抗；不能把拮抗变换直接定位在这些水平细胞上。
- **软肋**：此项研究来自课程**指定阅读摘要**，并非公开的第 7 讲实验幻灯片；公开提纲只列系统组织。

::: insight 视网膜拓扑的守恒与重构
视网膜到初级视觉皮层 LGN 与 V1 的投射展现了中枢神经系统在“保持几何相邻”与“升维特征提取”之间的巧妙妥协。拓扑映射保证了空间邻近点之间侧向抑制回路的连接物理成本最小化，而在局部超柱（Hypercolumn）内部，皮层则通过非线性突触整合将原本平面的二维光点阵列投射到了方向、空间频率和双眼视差的高维特征流形之中。
:::

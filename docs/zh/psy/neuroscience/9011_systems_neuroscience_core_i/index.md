# MIT 9.011 系统神经科学核心 I（Systems Neuroscience Core I）

> MIT 9.011 · Fall 2002 · 主讲 Peter H. Schiller · 脑与认知科学系

MIT 9.011《系统神经科学核心 I》（Systems Neuroscience Core I / The Brain and Cognitive Sciences I）是麻省理工学院脑与认知科学系面向研究生与高年级本科生的旗舰系统神经科学核心课。由灵长类视觉与动眼系统神经生理学泰斗彼得·席勒（Peter H. Schiller）教授主讲。本课程公开资料聚焦席勒教授的经典灵长类视觉系统模块（原课程日程第 7–11 讲），以经典电生理记录、可逆药理阻断、化学损毁与行为心理物理学紧密交织的硬核证据链，深度剖析灵长类视觉从视网膜光电换能、LGN 拓扑分层、初级视觉皮层（V1）模块化解析，到 M/P 平行处理通道、深度与色彩恒常性、上丘跳视神经去抑制门控及 MT 区运动知觉因果微电刺激的全链路神经计算机制。

## TL;DR

- 视网膜与皮层拓扑映射：视网膜神经节细胞经丘脑外侧膝状体（LGN）建立视网膜拓扑投射，V1 通过模块化超柱实现局部特征解析。
- 平行通道分流与功能互补：ON/OFF 通路分流明暗边界，大细胞（M 通路）与小细胞（P 通路）分别解耦快速动态运动与高分辨率形状色彩。
- 高阶感知属性的层级解缠：双眼视差构建立体视觉，V4 神经元超越波长提取表面反射率，消解自然界复杂的视角与光照混淆。
- 运动知觉与动眼控制闭环：上丘黑质去抑制门控精准释放跳视，中颞区（MT）神经元微电刺激确立了微观神经放电与宏观运动知觉的因果链。

## 学习建议

- **聚焦因果性实证范式**：席勒教授的核心贡献在于用药理微量注射（如 APB 阻断 ON 通路）与皮层微电刺激打破单纯的“相关性观察”；学习时请重点辨析“损伤/刺激操纵”与“生理放电记录”在因果论证中的互补关系。

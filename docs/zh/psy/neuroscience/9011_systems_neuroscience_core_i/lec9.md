# Lec 9 视觉系统 III：深度、颜色与形状

> MIT 9.011 Systems Neuroscience Core I · Lecture 9 · Peter H. Schiller

## TL;DR

- 深度知觉依赖双眼视差（Binocular disparity），V1 与纹外皮层特定神经元对水平视差具有选择性调谐。
- 颜色恒常性要求视觉系统超越波长直接读取表面反射率，V4 区神经元在此阶段发挥关键色调计算作用。
- 形状识别从 V1 的线段与边缘局部滤波，逐步汇聚为中级视觉的轮廓闭合与高阶几何基元表征。
- 深度、颜色与形状由皮层条带与不同功能区多路复用，不可将复杂知觉简单还原为单一孤立脑区。

## 1. 驱动问题
- 核心问题：眼动、透视、阴影、视差、双眼立体、波长和轮廓怎样分别约束视觉解释？
- 为什么不显然：一个物体「看起来有形状」可能同时利用多种线索。
- [视觉系统 II：ON/OFF 与 M/P 通道](./lec8.md) 介绍通道，本讲把通道放进具体知觉功能。

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 双眼立体（stereopsis） | 用两眼图像差异推断深度 | 单眼透视 |
| 视差（parallax） | 观察点改变时相对位置变化的深度线索 | 颜色线索 |
| 色适应/后像 | 长时间刺激改变随后的颜色体验 | 光源本身变色 |
| 形状特征 | 线段、空间频率等可支撑形状分析的局部量 | 对整件物体的最终识别 |

## 3. 证据链
### 公开提纲中的多线索比较
- **设计**：此处没有公开实验图；提纲列出眼动、透视、阴影、视差、双眼立体及皮层损伤等需要比较的线索。
- **结果**：提纲只确定课堂讨论范围，没有给单项结果。
- **推论**：必须把「哪些线索存在」与「哪些线索因果必要」分开；后一问题需损伤或操纵证据。
- **软肋**：不能从题目列表推断每条线索的效果量。

### 指定阅读：通道干扰对知觉能力的不同影响
- **设计**：Schiller 与 Logothetis（1990）综述猴视觉通道的选择性干扰。
- **结果**：课程摘要说颜色拮抗通道受扰时，颜色、精细形状及立体知觉受损；宽频通道受扰时，较高时间频率的运动/闪烁受损。
- **推论**：功能差异支持多通道处理，但单个能力仍可能依赖多条通道。
- **软肋**：这是指定综述的摘要，非本讲公开幻灯片。

## 5. 分析层次
- 神经/生理：感光细胞、神经节、皮层区域与损伤模式。
- 认知/信息加工：把透视、视差、波长与局部轮廓组合成物体解释。
- 行为：色盲、后像、双眼立体及形状选择任务是提纲列出的现象。
- 社会/文化：未展开。

::: insight 不变性知觉的层级解缠
深度、颜色与形状的计算共同面临“观察者视角”与“光照环境”变动带来的巨大变异性。视觉皮层采用层次化网络结构，逐层解缠（Disentangle）场景几何线索与物体内在属性：双眼视差消除深度模糊，V4 色彩恒常性过滤光源波谱，下颞叶网络消除仿射形变。这一连串非线性变换构成了生物视觉超越被动采样的智能核心。
:::

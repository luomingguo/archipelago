# Lec 16 轴突导向 I：吸引、排斥与中线

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 16 · William Quinn & Troy Littleton

## TL;DR

- 轴突生长锥利用丝状伪足与片状伪足的肌动蛋白动力学，敏锐感知微环境中的分子导向线索。
- 导向分子分为化学吸引与化学排斥，包含接触依赖与扩散长程两类。
- 底板分泌 Netrin 吸引连合轴突越过腹侧中线；越过中线后轴突表面上调 Robo 受体响应 Slit 排斥信号，阻止回穿。
- 肝配蛋白与 Eph 受体梯度在视顶盖建立反向亲和力，精确调控视网膜拓扑投射图谱的形成。

## 1. 驱动问题
- 生长锥如何选择目标，而且经过中线后不反复返回？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| 生长锥 | 感知线索并重组细胞骨架的轴突末端。 |
| ephrin/Eph | 拓扑投射中的排斥性线索。 |
| Netrin/DCC | 中线吸引通路。 |
| Slit/Robo | 中线后的排斥通路。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：Sperry 两栖动物视网膜—靶区实验：切断视神经并旋转眼球，追踪再生投射及捕食方向。
- **讲义所述结果**：投射趋向旧拓扑位置，行为方向随之错位。
- **推论**：支持位置身份线索。
- **软肋**：再生动物模型不等于哺乳动物。

### 课堂例子二
- **设计/比较**：脊髓背侧连合轴突培养与 netrin/DCC、Slit/Robo 遗传干预。
- **讲义所述结果**：前者促进接近底板，后者帮助越过中线后离开。
- **推论**：两类线索与受体状态共同决定路径。
- **软肋**：存在冗余线索。

## 5. 分析层次
- 分子：诱导/导向/黏附信号；细胞：命运、迁移和生长锥；回路：输入定位与修剪；行为：最终运动或感觉表现。证据首先落在实验实际观测的层次。

## 6. 边界与失败案例
- 单一线索不总是足够或必需；相同分子在不同受体背景下可能有不同作用

::: insight 中线抉择与受体开关的自适应重构
脊髓连合轴突穿越中线的历程，是发育神经生物学最经典的导航范例。面对同一个中线底板，轴突最初被 Netrin 吸引如饥似渴地奔赴中线；一旦跨越中线，细胞内生化信号立即剧烈反转，迅速将排斥受体 Robo 搬上膜表面，把原先的温柔诱饵变成了凶险退避的驱赶墙。这种动态改变自身感受性的导航算法，确保了数十亿根神经纤维在混沌组织中永不走回头路。
:::

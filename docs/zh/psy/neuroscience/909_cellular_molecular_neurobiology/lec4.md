# Lec 4 动作电位 I：阈值与电压钳

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 4 · William Quinn & Troy Littleton

## TL;DR

- 枪乌贼巨大轴突与电压钳（Voltage clamp）技术打破了膜电位与膜电流互相纠缠的正反馈恶性循环。
- 膜去极化越过动作电位阈值时，内向跨膜钠电流超过外向钾漏电流，诱发全或无脉冲发放。
- 电压钳记录解耦了早期瞬态内向电流（钠依赖）与晚期持续外向电流（钾依赖）的动态变化。
- 离子替换与药理学阻断实验证实，内向电流的翻转电位精确契合能斯特钠平衡电位。

## 1. 驱动问题
- 动作电位为什么在阈值附近突然出现？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| 驱动力 | $I_i=g_i(V_m-E_i)$。 |
| 膜电容 | $I_C=C_m\,dV_m/dt$。 |
| 阈值 | 内向和外向电流竞争的动力学转折。 |
| 电压钳 | 固定电压记录电流。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：鱿鱼巨轴突电压钳：给不同电压步阶，记录快速内向和较慢外向电流。
- **讲义所述结果**：不同电压步阶出现快速内向和较慢外向电流。
- **推论**：钳制电压有助于拆分电压门控电导的时间过程。
- **软肋**：需良好空间钳制及阻断/离子替换来确认电流身份。

### 课堂例子二
- **设计/比较**：阈值反馈分析：Na⁺ 通道开放使去极化增强，进一步开放 Na⁺ 通道。
- **讲义所述结果**：去极化可增加 Na⁺ 电导并继续放大去极化。
- **推论**：阈值附近的动作电位源于电流正反馈。
- **软肋**：阈值随先前活动和通道状态改变。

::: insight 电压钳对非线性动力学的破局
动作电位的爆发是自然界最著名的非线性动态分叉过程：去极化激活钠通道，钠内流进一步加速去极化。霍奇金与赫胥黎之所以能封神，核心在于发明了电压钳负反馈电路——用电子学强行钳制膜电位，切断正反馈链条，将混沌的动态雪崩拆解为可被微积分方程精确量化的电导动力学。
:::

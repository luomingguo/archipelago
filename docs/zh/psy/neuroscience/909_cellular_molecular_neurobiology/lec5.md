# Lec 5 动作电位 II：门控与失活

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 5 · William Quinn & Troy Littleton

## TL;DR

- 霍奇金-赫胥黎模型引入 m、h、n 三组独立门控变量，分别描述钠电导激活、钠电导失活与延迟整流钾电导激活。
- 动作电位去极化峰值后，电压门控钠通道发生时间依赖性快速球棒（Ball-and-chain）失活关闭。
- 延迟整流钾通道复极化迟滞造成超极化后电位，重置膜电位并限制神经元最大发放频率。
- 钠通道失活与高钾通透性共同造就了绝对不应期与相对不应期，确保神经脉冲单向传导。

## 1. 驱动问题
- 去极化怎样启动动作电位，又怎样及时终止？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| Na⁺ 激活 | 快速内流正反馈。 |
| Na⁺ 失活 | 持续去极化下电导降低。 |
| K⁺ 延迟整流 | 较慢外向电流帮助复极。 |
| 反转电位 | 离子电流改变方向的电位。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：钳制电压并用 TTX 等药理阻断，分离快速内向与迟发外向电流。
- **讲义所述结果**：快速内向与迟发外向电流呈不同时间过程。
- **推论**：Na⁺ 激活和 K⁺ 延迟开放需要不同动力学变量。
- **软肋**：课堂笔记没有完整原始电流图及阻断剂剂量。

### 课堂例子二
- **设计/比较**：讲义提到处理胞质侧及失活区肽段干预 Na⁺ 失活。
- **讲义所述结果**：干预失活区后 Na⁺ 电流及动作电位时间过程改变。
- **推论**：Na⁺ 失活参与终止动作电位。
- **软肋**：课堂摘要缺样本数、分子结构和其他通道对照。

::: insight 四阶动力学与时序单向阀
霍奇金-赫胥黎四阶微分方程的数学美感，淋漓尽致地体现在 m^3h 与 n^4 的门控组合中。三个 m 颗粒的协同激活带来陡峭的动作电位上升支，而独立 h 颗粒的延迟失活则像一枚精巧的单向定时器。正是这种内在分子构象的时滞差异，赋予了神经元不可逆的时序单向阀特性，奠定了全神经系统信息单向传导的基石。
:::

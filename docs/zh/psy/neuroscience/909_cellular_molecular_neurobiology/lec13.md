# Lec 13 从基因到结构与行为

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 13 · William Quinn & Troy Littleton

## TL;DR

- 经典正向遗传学通过化学诱变（EMS）或转座子插入构建随机突变库，利用特定行为表型反向定位基因。
- 昼夜节律周期基因 period 与 timeless 的发现，揭示了以负反馈转录-翻译振荡为核心的分子生物钟。
- 基因表达的时空特异性决定了神经系统的区域形态划分与特定亚型神经元的分化发育。
- 单基因突变对复杂行为的特异性阻断，打破了“单基因不足以调控系统行为”的偏见，确立行为生物学基石。

## 1. 驱动问题
- 怎样把脊髓、脑区和基因层面连到行为？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| 脊髓背/腹侧 | 感觉输入与运动输出的不同通路。 |
| 丘脑 | 多类感觉/运动信息的中继。 |
| 皮层分工 | 枕叶、颞叶、额叶等参与不同处理。 |
| 基因组学 | 用序列与表达研究发育机制。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：讲义沿脊髓背根/腹根及皮层—脊髓通路画出感觉和运动方向。
- **讲义所述结果**：图中背侧与腹侧通路承担不同的信息方向。
- **推论**：回路的解剖走向约束感觉和运动解释。
- **软肋**：结构示意不是直接的损伤或放电干预。

### 课堂例子二
- **设计/比较**：比较运动皮层/通路、基底节与小脑相关损伤的表现。
- **讲义所述结果**：不同损伤可出现不同运动问题。
- **推论**：提示多个节点共同控制动作。
- **软肋**：病例摘要不能单独定位疾病机制。

## 4. 理论之争
| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 单一脑区直控所有行为 | 多节点通路共同参与 | 损伤位置和任务表现对应。 |

## 5. 分析层次
- 分子：诱导/导向/黏附信号；细胞：命运、迁移和生长锥；回路：输入定位与修剪；行为：最终运动或感觉表现。证据首先落在实验实际观测的层次。

## 6. 边界与失败案例
- 讲义基因组数字来自旧课堂时代，不宜当作今天的基因数量；脑区功能标签是粗略定位

::: insight 分子反馈振荡与行为时钟的同构
昼夜节律的分子解析展示了生命世界最高级的自组织时空秩序：无意识的蛋白质分子在细胞核与细胞质之间的周期性穿梭、磷酸化与降解，经过数小时的分子延迟，构成了自我维持的转录负反馈环。这套内生生物钟不依赖任何神经电脉冲即可自发计时，并将节律信号输出至神经内分泌与觉醒回路，展现了基因组驱动行为的深层因果魔力。
:::

# Lec 14 神经系统发育 I：诱导与轴向模式

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 14 · William Quinn & Troy Littleton

## TL;DR

- 施佩曼-曼戈尔德组织原移植实验证实胚胎背侧中胚层能够诱导宿主形成完整的第二神经轴。
- 神经诱导遵循默认模型（Default model）：外胚层细胞默认发育为神经组织，BMP 信号使其转化为表皮。
- 组织原分泌 Noggin、Chordin 与 Follistatin 等因子拮抗阻断 BMP，促成背侧外胚层神经化。
- 神经管前后轴与背腹轴形态发生素浓度梯度协同指定神经元前体细胞空间命运。

## 1. 驱动问题
- 胚胎细胞如何决定成为神经组织，并在背腹轴上获得不同身份？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| Spemann 组织者 | 能诱导邻近胚层改变命运的区域。 |
| BMP 抑制 | 支持神经外胚层形成。 |
| Shh | 腹侧模式化信号。 |
| 形态发生素 | 浓度/时间影响细胞命运的信号。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：组织者移植到另一胚胎区域，观察邻近组织是否产生第二轴或神经组织。
- **讲义所述结果**：组织者异位移植后邻近组织的命运与轴向结构发生变化。
- **推论**：局部诱导信号可重塑早期胚胎身份。
- **软肋**：诱导能力依赖移植阶段，摘要无完整胚胎数量。

### 课堂例子二
- **设计/比较**：操纵脊索/底板 Shh 信号或把脊索放到异位。
- **讲义所述结果**：腹侧神经身份随信号位置改变。
- **推论**：支持腹侧梯度指令。
- **软肋**：不同信号并存，单一 Shh 浓度不能解释全部背腹命运。

## 4. 理论之争
| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 命运早已不可改变 | 周边分泌信号诱导身份 | 异位移植与信号阻断。 |

## 5. 分析层次
- 分子：诱导/导向/黏附信号；细胞：命运、迁移和生长锥；回路：输入定位与修剪；行为：最终运动或感觉表现。证据首先落在实验实际观测的层次。

## 6. 边界与失败案例
- BMP、Shh、Notch 等通路各有不同上下文；“默认神经命运”是模型条件而非所有组织的通则

::: insight “抑制的抑制”之发育辩证法
神经系统的发生机制展现了发育生物学充满诗意的辩证逻辑：大脑并不是被某种“神经化指令”强行塑造出来的，成为神经元其实是胚胎外胚层的天然宿命。外周组织通过充斥高浓度的 BMP 抑制定型信号将其压制为表皮，而组织原做的事情仅仅是分泌拮抗剂，驱散这层压制，让神经元在其本来的默认命运中觉醒。
:::

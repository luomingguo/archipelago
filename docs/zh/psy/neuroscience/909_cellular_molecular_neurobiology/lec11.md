# Lec 11 学习与记忆 I：突触可塑性

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 11 · William Quinn & Troy Littleton

## TL;DR

- 埃里克·坎德尔以海兔（Aplysia）缩鳃反射为模式生物，破译非联合学习与突触可塑性分子机制。
- 习惯化表现为感觉神经元至运动神经元突触前电压门控钙通道失敏，突触前递质释放减少。
- 敏化由易化中间神经元释放五羟色胺触发，通过 cAMP-PKA 通路磷酸化封闭钾通道。
- 钾电导降低延长了突触前动作电位时程，大幅增加钙离子内流，最终显著增强突触前囊泡胞吐。

## 1. 驱动问题
- 短时学习如何转为较持久的突触改变？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| 敏化 | 强刺激后反应增大。 |
| PKA | cAMP 下游蛋白激酶。 |
| CREB | 相关基因转录因子。 |
| LTP | 高频刺激后持续的突触增强。 |
| NMDA 受体 | 需配体与去极化共同解除 Mg²⁺ 阻塞。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：Aplysia 感觉—运动突触施加 5-HT。
- **讲义所述结果**：PKA 调节 K⁺ 通道，动作电位变宽，Ca²⁺ 流入和释放增加。
- **推论**：多次刺激后的持久促进需蛋白合成/CREB。
- **软肋**：不同时间尺度不能混为同一事件。

### 课堂例子二
- **设计/比较**：海马 CA3—CA1 Schaffer 侧支两输入实验：一路高频刺激后该路 EPSP 增强，另一独立输入未必增强。
- **讲义所述结果**：高频刺激后被刺激输入增强，独立输入未同样增强。
- **推论**：LTP 可具有输入特异性。
- **软肋**：课堂摘要未给 EPSP 增强的持续时间、样本和统计。

## 4. 理论之争
| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 所有学习等于统一的释放增加 | 不同回路/时间尺度有不同前后端机制 | 短时药理、长期蛋白合成与输入特异性。 |

## 5. 分析层次
- 分子：受体、递质或融合蛋白；细胞：电流与突触电位；回路/行为：传递可靠性或学习。区分实验读数与行为推断。

## 6. 边界与失败案例
- Aplysia 回避反射和海马 LTP 都是模型，不能直接等同人类完整记忆；阻断 CREB 可能多效

::: insight 记忆从神经回路向分子尺度的还原
坎德尔获诺贝尔奖的开创性贡献，在于打破了心理学将“学习与记忆”视为不可解神秘体验的传统藩篱。通过在海兔仅有数万个神经元的简易神经系中追踪动作，他将“惊吓导致的敏化反应”确凿无疑地锚定为单个感觉突触前膜上钾通道的磷酸化闭合。这种跨越宏观行为心理学与微观离子通道生物物理学的因果统一，为整个现代记忆生物学立下了不朽丰碑。
:::

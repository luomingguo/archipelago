# Lec 19 视觉 I：视网膜与光转导

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 19 · William Quinn & Troy Littleton

## TL;DR

- 视杆细胞与视锥细胞通过外段盘膜上的感光色素捕获光子，启动生化光转导级联。
- 光照促使发色团 11-顺式视黄醛异构化为全反式视黄醛，激活 G 蛋白转导蛋白。
- 活化的转导蛋白刺激磷酸二酯酶水解环鸟苷酸（cGMP），胞质 cGMP 浓度暴跌导致阳离子通道关闭。
- 暗电流因通道关闭而中断，光感受器膜电位由暗中的约 -40 mV 迅速转为超极化，减少谷氨酸释放。

## 1. 驱动问题
- 光照为何会让感光细胞超极化，而不是像典型兴奋性输入那样去极化？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| 视杆/视锥 | 低照度敏感度与颜色/高分辨率的不同权衡。 |
| 视网膜回路 | 感光细胞—双极细胞—神经节细胞。 |
| 视紫红质 | 视杆细胞中的 opsin 与 retinal。 |
| cGMP 门控通道 | 暗中保持阳离子流入。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：比较暗与光下感光细胞的通道状态：光激活 opsin—transducin—磷酸二酯酶链，cGMP 降低、通道关闭，感光细胞超极化。
- **讲义所述结果**：光照后 cGMP 降低、暗电流通道关闭、细胞超极化。
- **推论**：opsin 下游级联把光转为放大的电响应。
- **软肋**：学生笔记没有该例原始电流轨迹和具体实验条件。

### 课堂例子二
- **设计/比较**：讲义比较视杆与视锥的汇聚和分布：视杆对低照度敏感、汇聚较多，视锥在中央凹利于精细视觉。
- **讲义所述结果**：视杆汇聚较多，中央凹视锥利于精细视觉。
- **推论**：低光敏感度与空间分辨率存在权衡。
- **软肋**：课堂给出的数量和频率估计属于旧版资料。

## 5. 分析层次
- 分子/细胞：受体和转导；回路：感觉投射或脑区循环；行为：辨别、动作与任务表现。推断必须逐层核实。

## 6. 边界与失败案例
- 感光细胞通常用级差电位，视网膜神经节细胞才发动作电位；不能把所有视觉细胞看成同样编码

::: insight 单光子放大的生物物理极限
视杆细胞的光转导级联将生物分子的物理催化极限发挥到了极致：仅仅一个光子的能量，就能在数毫秒内激活数百个转导蛋白分子，进而促使数万个 cGMP 发生酶解，关闭数百万计的钠离子内流通道，产生可被精密测量的微伏级超极化。这种高达十万倍的单分子级联放大，让脊椎动物在无星无月的极致暗夜中依然能够捕捉到宇宙最微弱的微光。
:::

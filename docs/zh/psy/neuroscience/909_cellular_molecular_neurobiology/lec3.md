# Lec 3 静息电位的离子基础

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 3 · William Quinn & Troy Littleton

## TL;DR

- 能斯特方程（Nernst equation）计算单一离子的电化学平衡电位，钾离子平衡电位接近静息膜电位。
- 高盛-霍奇金-卡茨（GHK）电压方程综合考虑钠、钾、氯离子浓度及相对通透性，精准决定复合膜电位。
- 静息状态下细胞膜对钾离子的静息漏通透性远高于钠离子，是维持约 -70 mV 极化电位的根本动力。
- Na+/K+-ATP 酶（钠钾泵）逆浓度梯度主动运输 3 个钠离子出胞与 2 个钾离子入胞，构筑生电性稳态。

## 1. 驱动问题
- 没有动作电位时，膜内外为何仍保持电压差？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| 离子梯度 | 提供化学驱动力。 |
| 能斯特电位 | 单一离子扩散力与电场力平衡的电位。 |
| 选择性通透 | 各离子开放通道程度不同。 |
| Na⁺/K⁺-ATPase | 长期维持离子梯度。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：讲义的 K⁺ 选择性膜算例：K⁺ 外流产生内负电场直至净驱动力为零。
- **讲义所述结果**：K⁺ 外流逐渐形成反向电场，平衡时净流为零。
- **推论**：离子梯度与选择性通透共同决定单离子平衡电位。
- **软肋**：真实膜还通透其他离子，静息电位不一定等于 E_K。

### 课堂例子二
- **设计/比较**：比较通道阻断和泵维持梯度的作用：瞬时电压随开放通道变化，长期梯度依赖主动转运。
- **讲义所述结果**：讲义区分开放通道造成的即时离子流与泵维持梯度的长期作用。
- **推论**：短时膜电位与长期浓度梯度要分开解释。
- **软肋**：学生笔记没有提供泵阻断的完整时间曲线。

## 4. 理论之争
| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 泵直接决定瞬时膜电压 | 泵维持梯度而通道决定瞬时离子流 | 比较急性阻断和长期抑制。 |

## 5. 分析层次
- 分子与细胞：考察通道、膜电流或细胞反应；回路与行为：看这些机制怎样影响整体信号或表现。讲义主要提供课堂机制及例子。

## 6. 边界与失败案例
- 能斯特方程只给单一离子的平衡电位；静息电位通常不能直接等同 E_K

::: insight 负电位的非对称耗散结构
神经元静息电位不是被动的静态平衡，而是典型的普利高津耗散结构。细胞耗费了基础代谢高达三分之一以上的 ATP 能量，源源不断地维持胞内高钾、胞外高钠的极端非对称浓度场。正是这种远离热力学平衡态的离子势能蓄水池，为动作电位的雪崩式暴发展开提供了随时待发的生物物理炸药。
:::

# Lec 20 视觉 II：皮层视觉通路

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 20 · William Quinn & Troy Littleton

## TL;DR

- 休伯尔与威泽尔开创皮层微电极记录，证实初级视觉皮层神经元具备严密的方向选择性。
- 简单细胞拥有分立的亮/暗拮抗子区，通过排列成直线的 LGN 同心圆感受野前向线性汇聚构建。
- 复杂细胞不具备固定子区，对感受野内任意位置的特定取向光条均响应，展现空间平移不变性。
- V1 皮层沿垂直纵深分布眼优势柱与方向功能柱，形成解析空间位置、方向与颜色的超柱功能基本单元。

## 1. 驱动问题
- 视觉信息如何分向识物与空间/运动处理？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| 腹侧通路 | 从枕叶向颞叶侧的物体与形状处理。 |
| 背侧通路 | 向顶叶侧的空间/动作处理。 |
| 巨细胞/小细胞通路 | 视网膜—丘脑上行的不同输入倾向。 |
| 注意 | 选择部分信息作进一步处理。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：学生笔记的单页通路图把 LGN、V1/V2 和腹侧/背侧走向连接。
- **讲义所述结果**：单页图把 LGN、V1/V2 与腹侧、背侧走向相连并标注不同处理倾向。
- **推论**：视觉处理可在皮层通路间分工。
- **软肋**：这是教学示意，没有独立实验设计或原始数据。

### 课堂例子二
- **设计/比较**：图旁列出不同通路损伤对应的物体或视空间辨识问题。
- **讲义所述结果**：图旁列出腹侧/背侧损伤关联的不同辨识表现。
- **推论**：损伤关联可提出识物与空间处理的分工假说。
- **软肋**：该页缺病例任务、病灶范围与对照，不能精准定位。

## 4. 理论之争
| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 两条完全隔离的信息管道 | 多个交互通路各有处理倾向 | 跨任务损伤与记录比较。 |

## 5. 分析层次
- 分子/细胞：受体和转导；回路：感觉投射或脑区循环；行为：辨别、动作与任务表现。推断必须逐层核实。

## 6. 边界与失败案例
- 讲义只有一页可辨内容；腹侧/背侧是粗略分工，颜色、动作、注意并不严格各占一条线

::: insight 线性汇聚与不变性抽象的范式
休伯尔与威泽尔提出的简单细胞与复杂细胞分层模型，不仅奠定了现代视觉神经科学的基础，更启发了包括卷积神经网络（CNN）在内的整个人工智能计算机视觉体系。通过前级多个点状感受野向后级的线性排列汇聚提取“方向特征”，再通过非线性池化获得“空间不变性”，神经回路向我们展示了如何用最质朴的加减法逻辑，从混沌像素中提炼出关于世界形状的永恒几何。
:::

# Lec 21 听觉：耳蜗与毛细胞

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 21 · William Quinn & Troy Littleton

## TL;DR

- 耳蜗将声波机械压力波转化为流体行波，沿基底膜从基底向蜗顶空间共振。
- 柯蒂氏器毛细胞顶端静纤毛浸润在富含高钾且具 +80 mV 电位的内淋巴液中。
- 剪切运动拉紧顶端细丝弹簧，机械门控非选择性阳离子通道物理敞开，驱动大量钾离子顺电化学梯度内流去极化。
- 外毛细胞借助马达蛋白 Prestin 产生压电机械运动，提供正反馈能量放大，赋予听觉极高的灵敏度与频率选择性。

## 1. 驱动问题
- 空气压力波怎样变成听神经可传递的频率信息？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| 基底膜 | 位置不同，对不同频率有不同响应。 |
| 内毛细胞 | 主要把机械位移转为神经信号。 |
| 外毛细胞 | 帮助放大/调谐耳蜗运动。 |
| tip link | 连接纤毛并影响机械门控。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：讲义的耳蜗剖面图比较基底端与顶端：高频与低频使不同部位基底膜响应更强。
- **讲义所述结果**：耳蜗图把高、低频刺激分别放在基底膜不同位置。
- **推论**：频率可由基底膜最大位移位置编码。
- **软肋**：图示不是定量位移测量，仍需听神经记录。

### 课堂例子二
- **设计/比较**：比较纤毛偏转方向与通道状态：富 K⁺ 内淋巴环境下，适向偏转开放机械门控通道，毛细胞去极化并改变递质释放。
- **讲义所述结果**：纤毛偏转改变机械门控通道与递质释放，持续位移下响应适应。
- **推论**：毛细胞把机械位移转为电活动，并动态调节灵敏度。
- **软肋**：2005 年课堂尚未确定该通道分子身份，摘要缺动力学数据。

## 4. 理论之争
| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 频率只由单细胞放电次数编码 | 基底膜位置和毛细胞动力学共同编码 | 基底膜位移与听神经记录。 |

## 5. 分析层次
- 分子/细胞：受体和转导；回路：感觉投射或脑区循环；行为：辨别、动作与任务表现。推断必须逐层核实。

## 6. 边界与失败案例
- 毛细胞主要用级差电位，听神经纤维发动作电位；内外毛细胞功能不应混同

::: insight 颠覆常识的钾驱动电池
生物学教科书通常把“钾外流导致超极化”奉为圭臬，但在内耳耳蜗中，大自然打破了这套常规：血管纹主动泵送制造了奇特的高钾内淋巴液与高达 +80 mV 的内耳电池电位。毛细胞借此让本应向外流动的钾离子变成了迅猛内流的去极化驱动介质。这种独特的生物物理设计免除了细胞为了排出钠离子而消耗过量 ATP 的负担，保障了毛细胞在数十千赫兹超高频振动下的能量可持续性。
:::

# Lec 7 电突触与化学突触

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 7 · William Quinn & Troy Littleton

## TL;DR

- 缝隙连接电突触由连接蛋白六聚体形成亲水通道，支持离子与次级信号分子直接双向低阻传导。
- 电突触传导近乎瞬时无延迟，专司神经元群体的快速同步化放电与防御反射回路。
- 化学突触通过递质合成、囊泡打包、钙依赖释放与受体结合传导信号，伴随典型 0.5–2 ms 突触延搁。
- 化学突触具备单向传递、信号放大、可逆抑制与高可塑性调谐优势，构成学习记忆的结构主体。

## 1. 驱动问题
- 相邻细胞如何传信号，何时需要跨越突触间隙？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| 电突触 | 离子电流直接耦合两细胞。 |
| 化学突触 | 前端释放递质、后端受体响应。 |
| 神经肌肉接头 | 乙酰胆碱传递的经典模型。 |
| 乙酰胆碱酯酶 | 迅速终止乙酰胆碱信号。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：讲义比较电耦合的快速直接传导和化学突触的囊泡、间隙、受体链条。
- **讲义所述结果**：电耦合可直接传流，化学突触多一个释放—受体环节。
- **推论**：两种突触有不同的速度与调节潜力。
- **软肋**：该页是课堂机制比较，没有统一的定量速度记录。

### 课堂例子二
- **设计/比较**：Loewi 蛙心实验摘要：刺激迷走神经后，把第一颗心的灌流液转移给第二颗心。
- **讲义所述结果**：第二颗心也出现减速。
- **推论**：支持可扩散化学信使。
- **软肋**：课堂转述缺具体对照和原始时间记录。

## 4. 理论之争
| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 所有传递只是电流延续 | 可扩散信使介导部分传递 | 灌流液转移与受体阻断。 |

## 5. 分析层次
- 分子：受体、递质或融合蛋白；细胞：电流与突触电位；回路/行为：传递可靠性或学习。区分实验读数与行为推断。

## 6. 边界与失败案例
- 蛙心证明某类化学传递存在，不能推断所有突触都是化学突触；药物也可能影响多环节

::: insight 速度牺牲与计算能力的权衡
电突触追求的是极致的速度与毫无保留的集体共振，而化学突触用数毫秒的传导延迟为代价，换取了极其广阔的计算自由度。将电信号翻译为化学分子，打破了单纯的线性电荷守恒：微量递质可通过 G 蛋白产生数万倍的生化级联放大，更可引入兴奋与抑制的双极权衡。正是这个看似低效的化学间隙，为复杂心智的诞生留出了唯一的突触缝隙。
:::

# Lec 22 嗅觉与其他感觉

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 22 · William Quinn & Troy Littleton

## TL;DR

- 巴克与阿克塞尔发现哺乳动物基因组中近千个七次跨膜 GPCR 基因组成的庞大嗅觉受体超家族。
- 气味分子结合受体激活特异性 G 蛋白，刺激腺苷酸环化酶产生大量胞质第二信使 cAMP。
- cAMP 直接门控打开阳离子通道，随后的钙激活氯通道介导氯离子外流进一步放大去极化。
- 味觉则利用味蕾顶端微绒毛的离子通道与二聚体 GPCR 异构体感知五种基本风味。

## 1. 驱动问题
- 少量受体类型怎样表示很多气味，味觉又如何使用不同转导途径？

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| 嗅觉受体 | 气味分子激活的受体家族。 |
| 组合编码 | 一个气味激活多个受体的模式。 |
| 嗅球小球 | 同类嗅觉神经元输入汇集的区域。 |
| 味蕾细胞 | 负责味觉刺激转导的上皮细胞。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：讲义比较单嗅觉细胞受体表达与投向嗅球小球的汇聚。
- **讲义所述结果**：不同气味激活不同小球组合。
- **推论**：支持组合编码。
- **软肋**：旧讲义给的受体/气味数量不作今日精确事实。

### 课堂例子二
- **设计/比较**：舌味蕾及颅神经通路图示比较盐、酸与甜/苦的转导思路。
- **讲义所述结果**：讲义列出味蕾到颅神经的通路及多种转导方式。
- **推论**：不同味质不必共用单一种离子机制。
- **软肋**：图示没有味觉阈值和细胞类型的定量记录。

::: insight 氯离子反转电位与两级信号增益
嗅觉受体神经元最令人拍案叫绝的电生理把戏，在于利用氯离子的反向驱动力。在这些纤毛中，NKCC1 协同转运体将胞内氯浓度维持在异常高位，使得氯平衡电位远高于静息膜电位。当气味触发微弱的钙离子内流后，紧随其后的钙激活氯通道敞开导致大量的阴离子外流——这在数学上完全等价于巨大的内向正电流！通过这两级电流接力，单个分子就能激起神经冲动的烈焰。
:::

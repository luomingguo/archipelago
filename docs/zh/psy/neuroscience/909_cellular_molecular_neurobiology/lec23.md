# Lec 23 痛觉与温度感受：公开页聚焦触觉

> MIT 7.29J / 9.09J Cellular and Molecular Neurobiology · Lecture 23 · William Quinn & Troy Littleton

## TL;DR

- 躯体感觉依托四类特化低阈值机械感受器：梅克尔盘、迈斯纳小体、帕西尼小体与鲁菲尼小体。
- 压电离子通道 Piezo2 机械拉伸敏感开启介导快速触觉换能，TRPV1 则介导有害高温与辣椒素刺激。
- 触觉精细本体感觉信号沿脊髓背柱-内侧丘系向大脑快速传导，痛温觉信号经脊髓前外侧束投射。
- 躯体感觉皮层保留经典体表感官侏儒映射，指尖与口唇因高受体密度占据最大皮层表征面积。

## 2. 关键概念（最多 5 个）
| 概念 | 一句话定义 |
| --- | --- |
| 快适应 | 更突出变化和振动。 |
| 慢适应 | 更突出持续压力或形状。 |
| Meissner 小体 | 浅层轻触相关。 |
| Merkel 细胞复合体 | 持续压力与精细触觉相关。 |
| Pacinian 小体 | 深层高频振动相关。 |

## 3. 证据链
### 课堂例子一
- **设计/比较**：可辨扫描页把 Meissner、Merkel、Pacinian、Ruffini 受体列在皮肤不同深度，并比较适应速度。
- **讲义所述结果**：页上四类机械感受器位于不同皮肤层并有不同适应速度。
- **推论**：多类外周受体分解触觉的时间和空间特征。
- **软肋**：单页是教学概述，并无该页独立实验或痛/温数据。

### 课堂例子二
- **设计/比较**：讲义把背根神经节神经元与多个外周感受末梢相连。
- **讲义所述结果**：页上背根神经节示意连接多个外周感受末梢。
- **推论**：末梢分布可能影响指尖轻触与深层振动的读数。
- **软肋**：图例没有测定感受野大小或刺激阈值。

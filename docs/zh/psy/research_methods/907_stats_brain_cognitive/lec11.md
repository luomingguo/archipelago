# Lec 11 Monte Carlo 与 bootstrap

> MIT 9.07 · 脑与认知科学统计学 · 主讲 Emery N. Brown

## TL;DR

- 经验累积分布函数（ECDF）：格里文科-坎泰利定理保证样本经验阶梯分布在全实数线上一致收敛于真实未知的总体分布。
- 非参数 Bootstrap 置信区间：通过有放回重采样模拟从总体反复抽样的虚拟世界，无需正态假设即可构建经验分位数置信带。
- 蒙特卡洛积分的降维打击：利用大数定律将高维积分转化为独立随机采样的算术平均，计算误差率恒定为 $O(1/\sqrt{N})$。

## 1. 核心问题

- **驱动问题**：- 视网膜放电间隔的 Gamma 参数、第三四分位数等统计量都有误差；公式难推时如何评估这种误差？
- 重抽样的结果仍依赖原始样本是否代表目标总体，以及观测是否独立。
- **统计本质**：神经生物与行为数据本质上是由微观随机过程（离子通道开关、递质释放、神经元脉冲时延）驱动的高噪声样本，统计学提供了连接不确定性数据与生理因果律的严谨数学公理体系。
- **课程坐标**：本讲作为全课程第 11 讲，深度承接前后的理论进阶，构筑从基础概率空间向复杂参数估计与推断决策跃迁的关键量化基石。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 经验 CDF | 给原样本的每个观测值赋概率质量 $1/n$ | 已知真实总体分布 |
| 非参数 bootstrap | 从原样本有放回抽取 $n$ 个值，重算统计量 | 无需随机抽样或独立性 |
| 参数 bootstrap | 从已拟合的参数模型模拟 $n$ 个值，重算统计量 | 不依赖模型是否正确 |
| Monte Carlo 误差 | 有限重抽样次数 $B$ 带来的计算波动 | 原样本的统计不确定性 |
| bootstrap 分布 | 多次重算估计量得到的近似抽样分布 | 参数的贝叶斯后验 |

## 3. 证据链与数学推导

### 讲义分析：971 个视网膜放电间隔
- **设计**：讲义用经验 CDF 与拟合 Gamma 模型分别重抽样，每次保持 971 个观测，重算矩估计的形状参数 $\alpha$ 和速率参数 $\beta$。
- **结果**：原估计 $\hat\alpha=0.6284$；非参数 bootstrap 标准误约 $0.0281$，参数 bootstrap 标准误约 $0.0452$。$\hat\beta=0.0204$ 时，两种标准误分别约 $0.0007$、$0.0017$。
- **推论**：两种生成机制给不同不确定性估计；参数模型允许原样本中未出现的值，可能形成更宽分布。
- **软肋**：这不证明参数法一定更正确；需核对 Gamma 拟合、样本独立性和重抽样次数。

### 讲义分析：第三四分位数
- **设计**：从原样本有放回重抽样，重算放电间隔的第 75 百分位数。
- **结果**：原样本值为 43 ms；讲义给 bootstrap 均值约 43.73 ms、标准误约 5.12 ms，以及区间约 $33.69$–$53.77$ ms。
- **推论**：非参数统计量也有抽样不确定性，bootstrap 可估其大小。
- **软肋**：朴素分位数 bootstrap 的边界和偏差在某些分布中不理想；区间解释取决于构造方法，不是参数的后验概率。

## 4. 理论之争与计算模型

| 立场 A | 立场 B | 区分证据 |
| --- | --- | --- |
| 从经验分布重抽样，少加模型假设 | 从拟合 Gamma 模型模拟，可涵盖未见值 | 后验/样本外预测与拟合诊断 |
| 观测独立可按单点重抽样 | 同一神经元间隔有时间依赖 | 自相关与分块重抽样比较 |

## 6. 边界条件与失效情形

- - 非参数 bootstrap 只能抽到原样本已有值；极端尾部若原样本未覆盖，无法凭重抽样制造信息。
- 参数 bootstrap 能产生新值，但模型误设会传播到所有模拟样本。
- 有时间或群组依赖时，逐观测独立重抽样会低估或误判不确定性。
- **常态与极端的辩证**：大样本渐近理论（如 CLT、MLE 渐近正态）在小样本或强相关神经元群体中面临严重失效风险；必须通过非参数自举或精确检验监控统计稳健性。

### 统计神经科学家的心智诊断：自举法的魔法——揪着自己的头发离开经验的地面

当你在复杂的神经成像实验中设计了一个极度刁钻的统计指标，其数学分布超越了世界上所有已知概率分布函数的解析极限，你该如何为其计算置信区间与标准误？

布拉德利·埃弗隆（Bradley Efron）的 Bootstrap 自举法展示了人类计算时代最不可思议的算法奇迹。

无需复杂的积分，无需假设总体正态，我们只需将手头的样本视为微缩的“总体宇宙”，在计算机内存中进行上千次有放回的虚拟抽样。

这种“以样本模拟总体”的惊人自指，宛如统计学领域的闵希豪森男爵，揪着自己的头发把人类从解析数学无解的泥潭中生生拔出。它向我们证明：只要有充足的算力与理性的重采样准则，经验数据本身就蕴含着推断自身不确定性的全部密码。
:::

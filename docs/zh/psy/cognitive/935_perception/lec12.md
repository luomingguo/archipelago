# Lec 12 明度恒常性与颜色视觉

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 明度恒常性的因子分解困境：到达眼睛的亮度是光源照度与表面反射率的物理乘积，大脑必须分离光照变化以提取材质本真。
- 锚定理论与最高亮度归一：视觉系统在局部框架内将反射率最高者锚定为白色，其余表面依据相对比例阶梯式定标灰度。
- 色度三色理论与视蛋白吸收峰：S、M、L 三类锥体细胞在光谱上的重叠响应，将无限维电磁波长压缩为三维视网膜响应向量。
- 对立色加工神经通道：神经节细胞与 LGN 通过算术加减法构建出红-绿（L-M）、蓝-黄（S-(L+M)）与明度黑-白对立通道。

## 1. 核心问题

- **驱动问题**：- 为什么同一到眼光强可对应不同表面明度，同一颜色经验也可来自不同光谱？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 12 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 反射率/照明 | 表面属性与光源共同决定进入眼睛的光。 | 入眼光由反射率与照明混合，不能只读其一。 |
| 明度恒常性 | 照明变化下估计相对稳定的表面明度。 | 恒常性是有用估计，不是精确反射率恢复。 |
| 单受体单变量原理 | 一个锥体响应混合波长与强度。 | 单锥体响应不能同时定波长与强度。 |
| metamer | 不同光谱给三类锥体相同响应。 | 异谱同色不表示物理光谱相同。 |
| 对手通道 | 把锥体信号重组为亮度及色对立轴。 | 对手轴是组合编码，不是独立颜色受体。 |

## 3. 证据链

### 棋盘阴影错觉
- **设计/比较**：让两块物理亮度相同的棋盘区域处于不同阴影/棋盘语境。
- **讲义所述结果**：两块可被判断为不同明度。
- **推论**：视觉系统尝试扣除光源并推断表面反射率。
- **软肋**：具体知觉还受局部对比与几何线索共同影响。

### 异谱同色比较
- **设计/比较**：用不同光谱配比使三类锥体产生相同或近似响应。
- **讲义所述结果**：观察者可把不同光谱匹配为同色。
- **推论**：三锥体编码丢失光谱细节，颜色是有限维估计。
- **软肋**：匹配依赖观察者锥体和适应状态，不能推出客观光谱相同。

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 物理：光源×反射率；受体：S/M/L 锥体；回路：对手编码；知觉：明度/颜色匹配。

## 6. 边界条件与失效情形

- - 对手通道不是独立的“红探测器”；单个锥体响应不能分离波长和强度。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

### 认知科学家的心智诊断：明度恒常性的奇迹——大脑在白炽与阴影中寻找物体的本真

一块白垩土在昏暗月光下反射的光子数量，远远少于一块煤炭在烈日直射下反射的光子数量；但我们依然能毫不费力地认出白垩是白的、煤炭是黑的。

视网膜接收到的亮度是光源照度与表面反射率的物理乘积（$L = I 	imes R$），求解反射率在数学上是一个典型的单方程双未知数不可解问题。

大脑通过空间侧抑制、锚定原则以及对阴影边缘（模糊交界）与反射边缘（锐利交界）的精妙区分，在毫秒内完成了照度与反射率的因子分解。我们看到的不是光子，而是物体恒常的物理本质。
:::

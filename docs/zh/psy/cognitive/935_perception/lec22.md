# Lec 22 注意与躯体感觉：触觉机械感受器与痛觉

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 四类机械感受器的分工矩阵：快适应（FA I 迈斯纳 / FA II 帕西尼）测动态滑移与高频振动；慢适应（SA I 默克尔 / SA II 鲁菲尼）测形态曲率与拉伸。
- 触觉两点辨别阈与躯体感觉皮层拓扑：指尖与嘴唇具有微米级空间辨别力对应 S1 皮层巨大代表区，背部与大腿辨别阈低数十倍。
- 主动触摸（Haptics）与动态探索程序：主动手指摸索（侧向摩擦测粗糙度、施压测硬度、包络测形状）结合了肌肉运动与皮肤触觉输入。
- 痛觉与触觉的双重输入通路：A-delta 有髓纤维传递锐痛快感，C 无髓纤维传递迟钝灼痛，闸门控制学说阐明触觉振动对痛觉的脊髓层级抑制。

## 1. 核心问题

- **驱动问题**：- 注意怎样调制神经竞争，手指移动时触觉如何识别细纹理？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 22 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 注意性竞争 | 同一感受野多刺激时，选择改变神经响应。 | 注意调制不是纹理的外周受体信号。 |
| 慢适应小感受野 | 较适合持续压力和粗空间形状。 | 慢适应不等于永远不改变放电。 |
| 快适应受体 | 较适合滑动/振动的时间变化。 | 快适应也能编码细纹理的时间频率。 |
| 触觉时间编码 | 扫过细纹理使空间结构转成时间波形。 | 时间波形随扫动速度改变。 |
| 本体感觉 | 肌肉、肌腱与关节提供身体姿态信息。 | 本体感觉来自肌肉/关节等，不等于皮肤轻触。 |

## 3. 证据链

### 猴皮层单细胞注意比较
- **设计/比较**：同一感受野呈两个刺激，要求猴关注较有效或较无效的一个。
- **讲义所述结果**：神经响应随关注对象改变，多刺激时调制较明显。
- **推论**：注意可在固定输入下改变竞争性表征。
- **软肋**：单细胞变化与最终知觉之间仍需行为/因果验证。

### 纹理滚筒与手指扫过
- **设计/比较**：用不同点密度纹理接触或滑过指尖，比较不同机械受体放电。
- **讲义所述结果**：粗纹理在小感受野可有空间读数；细纹理更依赖快适应时间波形。
- **推论**：探索动作把表面空间结构转为可用的时间编码。
- **软肋**：扫动速度改变时间频率，不能脱离动作比较纹理。

## 4. 理论之争与计算模型

| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 触觉只是一张静止皮肤压力图 | 主动扫过和多受体时间响应提供额外材质信息 | 固定纹理、改变扫动速度/受体类型。 |

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 外周：皮肤机械受体；神经：受体放电与注意调制；动作：手指探索；知觉：粗细纹理与身体位置。

## 6. 边界条件与失效情形

- - 本讲 transcript 还讨论温度、痛觉和本体感受；此笔记聚焦与课程主线紧密相连的注意及触觉纹理，相关感受器不能混为机械感受器。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

::: insight
### 认知科学家的心智诊断：指尖上的视觉——触觉机械感受器与主动探索的具身性

触觉不是被动的皮肤压痕，触觉是具身探索的行为产物。

迈斯纳小体、帕西尼小体、默克尔盘与鲁菲尼小体，分别以高频振动、慢适应形态等不同的调谐频段，在指尖上构建了一套与耳蜗和视网膜高度对偶的机械滤波系统。

当我们用指尖滑过丝绸与砂纸时，高频微振动在时间序列上被解析为质感纹理。触觉提醒我们：知觉永远与动作深层咬合，心智是在运动与触摸的因果反馈中确证自身与外部世界的边界。
:::

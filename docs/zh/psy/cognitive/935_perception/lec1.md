# Lec 1 知觉导论：从感觉线索推断外部世界

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 逆问题不适定性：同一感觉输入对应无穷多个外界三维世界状态，感觉证据本身无法唯一确定外部物理实体。
- 无意识推断与先验：知觉本质上是大脑将即时含噪信号与演化及经验沉淀的环境统计先验相结合的最优概率估计。
- 五步因果链条：物理实体 → 物理信号 → 受体机械/光电换能 → 神经编码 → 知觉推断，贯穿全感官计算框架。
- 错觉的诊断价值：错觉不是大脑的系统故障，而是系统在非常规物理边界下暴露其先验假设的绝佳科学探针。

## 1. 核心问题

- **驱动问题**：- 为什么知觉是一个不能仅凭感觉输入求出唯一答案的逆问题？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 1 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 感觉换能 | 受体把光、声或化学刺激转成神经信号。 | 换能只产出信号，不说明外界对象身份。 |
| 知觉推断 | 从信号估计外部物体和事件。 | 推断可错，不等于随机猜测。 |
| 不适定逆问题 | 不同外界原因可能产生同一感觉输入。 | 不适定意为非唯一，并非完全无解。 |
| 先验 | 从环境统计和经验获得的可能性约束。 | 先验可随经验和情境改变。 |

## 3. 证据链

### 课堂二维投影演示
- **设计/比较**：比较大而远与小而近物体在视网膜上的投影。
- **讲义所述结果**：不同物体可产生近似相同的二维大小。
- **推论**：视网膜图像不足以唯一恢复真实尺寸和距离。
- **软肋**：需要额外距离线索；图示是构造例而非行为实验。

### 听觉连续错觉
- **设计/比较**：用足以掩蔽目标声音的噪声替换其中一段。
- **讲义所述结果**：听者可报告目标在噪声后仍连续存在。
- **推论**：系统偏好“被遮挡而持续”的声源解释。
- **软肋**：若噪声不足以掩蔽原声，持续解释的前提失效。

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 物理层：刺激产生光/声；神经层：受体编码；计算层：推断外部原因；行为层：报告与辨别。

## 6. 边界条件与失效情形

- - 错觉说明常用推断在特殊刺激下出错，不代表正常知觉只靠一种固定先验。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

::: insight
### 认知科学家的心智诊断：知觉不是被动照相，而是灵魂的概率画卷

人类最大的认识论错觉，莫过于以为自己的眼睛是窗户，外部世界真实地映照在视网膜上。

马尔与赫姆霍兹告诉我们：视网膜上的图像只是一堆模糊、倒立且退化的二维光斑。面对这片光斑，在纯粹几何学上存在无穷多个真实世界三维构型的可能。

大脑之所以能在一瞬间看清世界，是因为亿万年的演化把整个宇宙的统计规律（光来自上方、物体通常刚性、表面连续有界）作为强先验写入了神经回路。知觉永远是一场“受约束的幻觉”（Controlled Hallucination）——我们看到的不是现实本身，而是心智对现实做出的最优雅、最合理的概率赌注。
:::

# Lec 2 听觉频率选择性与耳蜗非线性

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 耳蜗主动频率分析：基底膜具有位置调谐特性，高频响应于蜗底，低频响应于蜗顶，将复杂声波分解为重叠频带。
- 外毛细胞非线性放大：外毛细胞提供声级依赖的主动机械增益，弱声放大数万倍，强声压缩抑制，实现 120 dB 宽动态范围。
- 耳声发射与双频畸变：耳蜗主动非线性在输入双频时会产生输入中没有的组合畸变频率（如 2f1-f2），可反向测得耳声发射（OAE）。
- 感音神经性听力损失：外毛细胞受损同时导致听阈上升、滤波变宽与响度重振，证实助听器无法通过简单线性放大解决听障。

## 1. 核心问题

- **驱动问题**：- 耳蜗如何把复杂声波分成频率通道，并在弱声时放大有用信号？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 2 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 耳蜗位置编码 | 不同基底膜位置对不同频率响应较强。 | 位置最敏感不等于只响应该频率。 |
| 特征频率 CF | 单条听神经纤维最敏感的频率。 | CF 是调谐最低阈值，不是绝对频率标签。 |
| 听觉滤波器 | 重叠频率通道决定掩蔽范围。 | 滤波器是功能近似，不是单个实体。 |
| 外毛细胞放大 | 主动、声级依赖的耳蜗增益。 | 外毛细胞主要调机械增益，内毛细胞主要输出。 |
| 耳声发射 OAE | 耳蜗非线性振动可反向传到耳道。 | OAE 可测外周状态，不能概括中枢听觉。 |

## 3. 证据链

### 掩蔽带宽任务
- **设计/比较**：在逐渐加宽的噪声中测纯音检测阈值。
- **讲义所述结果**：覆盖目标滤波器的噪声增加时阈值上升，带外继续增加影响变小。
- **推论**：阈值拐点可估计有效听觉滤波宽度。
- **软肋**：受试可能选择偏离目标频率的滤波器；需 notch-noise 等控制。

### 双频非线性演示
- **设计/比较**：给耳朵同时输入两种频率并测耳道输出。
- **讲义所述结果**：可出现输入中没有的组合频率或耳声发射。
- **推论**：耳蜗包含主动非线性而非纯线性滤波。
- **软肋**：耳声发射主要反映外周机制，不能证明整个听觉通路正常。

## 4. 理论之争与计算模型

| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 耳蜗是线性固定滤波器 | 外毛细胞使调谐与增益随声级改变 | 比较弱声/强声调谐及组合频率输出。 |

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 机械：基底膜振动；细胞：内/外毛细胞分工；神经：听神经调谐；行为：掩蔽阈值。

## 6. 边界条件与失效情形

- - 特征频率不是神经纤维只响应一个频率；滤波宽度也不是脱离声级的常数。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

::: insight
### 认知科学家的心智诊断：耳蜗的非线性奇迹——生物工程学对物理极限的超越

如果人类耳朵仅仅是一个被动的傅里叶变换麦克风，我们在摇滚乐现场会被震聋，而在寂静黑夜里听不见蚊子的振翅。

外毛细胞的主动机械反馈机制（Cochlear Amplifier）是大自然最惊心动魄的微纳工程杰作：面对弱声，它主动振动提供数万倍的非线性放大；面对强声，它主动收缩实行强力动态压缩。

助听器之所以不能简单等比放大声音，正是因为病人的频率调谐已经变宽、动态压缩已经丢失。理解了耳蜗的非线性，我们才能真正理解生命是如何在 120 分贝的恐怖声压跨度中，既保护了脆弱的内毛细胞，又保留了分辨微小半音的极致灵敏。
:::

# Lec 11 中层视觉 II：形状表征与图形-背景分离

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 模态与无模态双重补全：遮挡物前的虚幻表面表现为模态补全，被遮挡在后的物体连续部分表现为隐性的无模态几何补全。
- T 型交点作为遮挡的关键语法：当一条轮廓线被另一条轮廓线拦腰截断形成 T-Junction 时，茎干必为后景，横栏必为前景遮挡物。
- 极小性原则与柯氏表面重构：视觉系统在可能的三维拓扑解释中，严格偏好表面弯曲度最小、形状复杂度最低的光滑几何解。
- 边界所有权神经编码：V2/V4 神经元在保留方位选择性的同时，特异性响应“轮廓属于左侧物体还是右侧物体”，完成图形分割。

## 1. 核心问题

- **驱动问题**：- 被遮挡的轮廓为什么还能被看作完整物体？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 11 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| modal completion | 补全后主观看见不存在于图像中的边。 | 主观可见边不要求实际亮度梯度。 |
| amodal completion | 推断遮挡后方延续，却不实际看到被遮挡细节。 | 非显式完成不产生真实可见细节。 |
| Kanizsa 轮廓 | 通过诱导图形产生主观边界。 | Kanizsa 边界依赖诱导布局。 |
| good continuation | 平滑共线片段倾向接成一条轮廓。 | 良好连续性可被其他线索推翻。 |
| 遮挡层次 | 由 T-junction 等估计前后表面。 | 被遮挡结构常不唯一。 |

## 3. 证据链

### Kanizsa 图形演示
- **设计/比较**：摆放缺口圆盘/角形诱导符而不画完整明度边。
- **讲义所述结果**：观察者可报告清楚的主观轮廓。
- **推论**：可见边界不必处处对应物理亮度梯度。
- **软肋**：并非所有排列都能诱发同等完成；整体几何关键。

### T-junction 与遮挡
- **设计/比较**：固定局部线段，改变截断和连续关系。
- **讲义所述结果**：知觉会把被截断线段安排在后方并作非显式补全。
- **推论**：遮挡与良好连续性共同约束物体解释。
- **软肋**：完成不等于恢复真实隐藏像素，可能有多个合理形状。

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 低层：局部方位边；中层：轮廓整合和层次；高层：物体假设；行为：modal/amodal 报告。

## 6. 边界条件与失效情形

- - amodal completion 不会把缺失部分实际变成可见的细节，实验应区分“知道完整”与“看见边”。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

### 认知科学家的心智诊断：看不见的遮挡——心智对三维深度的几何补全

卡尼萨三角形（Kanizsa Triangle）在视网膜上根本不存在一条物理边缘，但每一个正常人都能清晰看到一个比背景更白、遮挡在圆盘之上的明亮三角形。

这种模态补全（Modal Completion）与无模态补全（Amodal Completion）向我们展示了中层视觉最具创造力的计算逻辑：

大脑宁愿假设存在一个无色透明的遮挡物，也不愿接受世界上存在三个恰好缺角咬合的荒谬巧合。视觉系统是彻底的概率决定论者——它在最深处贯彻着“一般视点假设”，永远偏好赋予场景具有立体纵深的因果解释。

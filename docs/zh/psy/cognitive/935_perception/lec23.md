# Lec 23 化学感官：嗅觉受体组合编码与味觉拓扑

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 嗅觉受体的组合密码系统：约 400 种嗅觉受体并非一一对应气味，而是以组合密码（Combinatorial Code）的方式表征万种气味分子的化学结构。
- 嗅球肾小球的精确空间图谱：表达相同受体的嗅感觉神经元轴突汇聚到嗅球的特定微球，将化学气味分子转化为二维神经空间激活花样。
- 味觉五大基本维度的特化受体：甜、苦、鲜由 G 蛋白偶联受体（T1R/T2R）检测，咸与酸由离子通道直接介导，味觉皮层保留特定味觉热点。
- 风味的多感官神经融合：日常生活中的“风味”（Flavor）是舌尖味觉、鼻咽后嗅觉、三叉神经温痛辛辣感以及口腔触觉在眶额皮层的终极交响。

## 1. 核心问题

- **驱动问题**：- 有限嗅受体如何区分气味，为什么‘食物味道’不等于舌头的味觉？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 23 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| odorant | 能到达嗅上皮并激活嗅受体的挥发分子。 | 挥发性是必要线索之一，不保证可嗅。 |
| 组合编码 | 气味由多受体响应模式而非一对一标签表示。 | 组合编码不等于无限无歧义表示。 |
| 嗅球小球 | 同类受体神经元轴突汇聚区域。 | 小球汇聚不意味着每气味只激活一个小球。 |
| 鼻后嗅觉 | 咀嚼时气味经咽后通路到鼻腔。 | 鼻后嗅觉属于嗅觉输入，不是舌味蕾。 |
| flavor | 味觉、鼻后嗅觉及口腔其他感觉的整合。 | flavor 比五种基本味质更丰富。 |

## 3. 证据链

### 人类气味追踪示例
- **设计/比较**：课堂描述蒙眼、耳罩和厚手套限制其他线索，让受试沿地面气味路径移动。
- **讲义所述结果**：人类仍可在一定程度上追踪气味路径。
- **推论**：嗅觉信息可支持空间行为，不只提供食物喜恶。
- **软肋**：课堂转述未给样本、浓度和控制细节，不能拿来量化人狗差异。

### 味觉与鼻后嗅觉比较
- **设计/比较**：区分舌头基本味质与咀嚼时鼻后嗅觉；课堂举鼻塞时食物变乏味。
- **讲义所述结果**：鼻后嗅觉受限时风味丰富度可下降，而基本味质仍在。
- **推论**：flavor 是多感官对象，不等于五种基本味质的线性和。
- **软肋**：鼻塞例是日常经验，不是该讲独立控制实验；口腔温度/质地也参与。

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 分子：嗅/味受体；外周：嗅上皮、味蕾；回路：嗅球及味觉通路；行为：气味追踪和风味评价。

## 6. 边界条件与失效情形

- - 挥发性不保证能被嗅到；味觉的酸、咸偏好还依赖浓度与内部状态。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

### 认知科学家的心智诊断：风味的多感官交响——化学分子与记忆的终极缠绕

气味分子与嗅觉受体的结合遵循精妙的组合密码（Combinatorial Code），极少数的受体种类能够通过组合编码分辨上万种气味。

而我们日常所谓的“味道”（Flavor），从来不是舌头上五种基本味觉的孤立产物；它是舌尖味蕾、鼻咽后嗅觉分子流、三叉神经温痛感以及口腔咀嚼触觉在脑眶额皮层（OFC）完成的高维多感官融合。

不仅如此，嗅觉通路直接绕过丘脑，直通边缘系统的杏仁核与海马体。一缕微弱的气味，可以在瞬间跨越数十年的光阴，唤醒童年最深处的场景与泪水。知觉在终点与记忆、情感和生命的历史融为一体。
:::

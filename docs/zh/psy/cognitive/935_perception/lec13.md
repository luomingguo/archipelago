# Lec 13 颜色知觉机制与运动初探

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 颜色恒常性与 Retinex 算法：大脑通过跨大范围视场的相对色度比值推断全局环境光源色谱，确保在夕阳或阴天均能识别真实物体颜色。
- 对立色后像与适应疲劳：长时间注视特定饱和色导致相应对立通道疲劳，在注视中性白场时爆发出相反对立色的强烈负后像。
- 运动知觉的时空相关器：赖卡特运动检测器（Reichardt Detector）通过在空间相邻受体间引入时间延迟线与乘法器，测出方向与速度。
- 视动反射与眼动眼震补偿：视觉系统利用前庭-动眼反射（VOR）与平滑追随运动，抵消躯体移动对视网膜造成的全局像移模糊。

## 1. 核心问题

- **驱动问题**：- 光源变化如何不完全改变物体颜色，空间—时间变化又怎样给出运动方向？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 13 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 颜色恒常性 | 在光源变化下估计相对稳定表面颜色。 | 恒常性允许系统性错觉。 |
| 光源估计 | 利用场景多表面线索推断照明光谱。 | 光源解释不同可改变物体色。 |
| 表观运动 | 离散刺激可造成连续运动体验。 | 表观运动不要求物体连续位移。 |
| 运动能量检测 | 结合位置与时间延迟得到方向偏好。 | 方向检测需空时联合，非单张静态滤波。 |
| 运动后效 | 适应某方向后静止刺激可显反向运动。 | 后效反映适应，不独定位神经环节。 |

## 3. 证据链

### 颜色语境比较
- **设计/比较**：保持局部像素近似相同，改变背景光源/表面语境。
- **讲义所述结果**：颜色报告可随对光源的解释而变化。
- **推论**：颜色恒常性依赖场景推断，不是完美恢复反射谱。
- **软肋**：三锥体输入本身丢失光谱细节，个体对光源假设可不同。

### 表观运动和后效
- **设计/比较**：按时间顺序在相邻位置呈现静态刺激，或先看持续单向运动再看静止图形。
- **讲义所述结果**：可体验连续运动或反向后效。
- **推论**：方向通道利用空时联合输入，并会适应。
- **软肋**：错觉不独定 Reichardt 与能量模型的具体神经实现。

## 4. 理论之争与计算模型

| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 运动方向可由单张静态图直接读出 | 方向需联合位置与时间并整合适应状态 | 改变时序与先前运动曝光。 |

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 光谱：照明与反射率；视觉通路：锥体和方向选择输入；计算：颜色/运动因果推断；行为：颜色与方向报告。

## 6. 边界条件与失效情形

- - 颜色恒常性是有用估计，不是精确恢复物理反射谱；静态图的空间滤波器本身不能决定方向。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

::: insight
### 认知科学家的心智诊断：颜色的心智主观性——物理世界本无色，皆是演化的赋彩

牛顿在《光学》中写道：“光线并不是有颜色的。”物理世界里只有不同波长与强度的电磁波。

颜色完全是三色感光细胞与对立色神经节细胞在人类神经系统内部合成的心理主观表征。

但这绝非虚无的幻觉：演化之所以创造出红-绿与蓝-黄对立色通道，是为了让灵长类祖先在一片苍翠混沌的树冠中，一眼识破成熟的红色果实与带毒的嫩叶。颜色是大脑为无机物理世界涂抹上的生物适应性界面。
:::

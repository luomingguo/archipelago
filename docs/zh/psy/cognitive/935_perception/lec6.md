# Lec 6 听觉场景分析与语音知觉机制

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 范畴知觉与语音音位：语音发音起始时间（VOT）在物理上连续变化，但听觉系统展现出非线性断崖式的范畴切分效应。
- 共振峰轨迹与语音解码：元音由声道形状形成的共振峰频率（F1/F2）表征，辅音由共振峰快速瞬态过渡模式识别。
- 多模态麦格克效应：视觉看到的口型（如 /ga/）与耳朵听到的声音（如 /ba/）在皮层自动融合，产出全新的合成知觉（/da/）。
- 语境与自上而下修复：音素恢复效应（Phonemic Restoration）证实高级语言知识能够逆向重构被环境咳嗽完全覆盖的音素。

## 1. 核心问题

- **驱动问题**：- 声音混合和说话者变化下，听者怎样维持语音类别与目标流？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 6 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 生成模型 | 假定声源如何产生并混合成当前声波。 | 生成模型说明声源假设，不是直接分类器。 |
| 先验/似然 | 环境规律与当前信号在假设下的匹配程度。 | 先验不是即时证据，似然不是主观偏好。 |
| 声源—滤波器模型 | 声带声源经声道共振形成语音。 | 基频来自声带，元音共振来自声道。 |
| 共振峰 | 声道共振模式，常帮助区别元音。 | 共振峰与音高不是同一物理量。 |
| 范畴知觉 | 连续声学变化可能被归为分立音素。 | 类别边界可变，物理参数仍连续。 |

## 3. 证据链

### 语音范畴任务
- **设计/比较**：连续改变辅音的 voice onset time，测音素类别报告。
- **讲义所述结果**：回答可在某一范围迅速切换。
- **推论**：语音类别不是物理变量本身的离散跳变。
- **软肋**：边界随语言经验和上下文变化，不能用单一阈值解释全部语音。

### McGurk 多感官演示
- **设计/比较**：让听者接收不一致的口型画面和语音声音。
- **讲义所述结果**：报告可能不同于纯听觉条件。
- **推论**：视觉口型参与语音推断。
- **软肋**：错觉大小受刺激质量、同步和个体差异影响。

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 声学：基频与共振峰；神经：听觉和视听整合；计算：声源假设的后验；行为：语音分类。

## 6. 边界条件与失效情形

- - 贝叶斯公式指出要比较什么，不自动说明大脑如何高效搜索巨大假设空间。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

::: insight
### 认知科学家的心智诊断：范畴化的飞跃——言语知觉如何把连续物理量折叠为离散符号

声学波形在物理频率与发音时延（VOT）上是完全平滑连续的，但我们在倾听母语时，听到的却永远是泾渭分明的 /ba/ 或 /da/。

这种范畴知觉（Categorical Perception）揭示了认知系统最核心的运算策略：为了抵御环境噪声并加速通信解码，大脑在前额叶与颞叶的交界处，主动在连续的物理感知流上划下了非线性的分类断崖。

正是这种将混沌连续的物理世界强行离散化为抽象符号的能力，才构成了人类语言与逻辑思维得以诞生的神经基石。
:::

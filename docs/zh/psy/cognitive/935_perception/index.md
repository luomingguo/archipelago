# MIT 9.35 知觉（Perception）

> MIT 9.35 · Spring 2024 · 主讲 Josh McDermott · 脑与认知科学系

MIT 9.35《知觉》（Perception）是麻省理工学院脑与认知科学系面向本科生与研究生的经典核心课程。本课程围绕认知神经科学中最核心的计算命题展开：**知觉是一个不适定的逆问题（Ill-posed Inverse Problem）**。外部物理世界的真实状态向感觉器官投射出高度退化、含噪且充满歧义的信号（视网膜上的 2D 光斑阵列、鼓膜上的单维压力时间序列）。大脑之所以能够毫不费力地在毫秒级时间内重构出稳定、连续且生动的 3D 物理与社会现实，是因为心智在底层将微弱的即时物理输入与漫长演化和个体经验积累的环境先验统计知识（Priors）紧密结合，进行着精密的贝叶斯无意识推断（Unconscious Inference）。全课程覆盖听觉、视觉、触觉、嗅觉与味觉，横跨心理物理学、神经电生理学、计算建模与临床脑损伤。

## TL;DR

- 不适定逆问题的本质：感觉器官仅测量物理线索而非物体本身；知觉是大脑结合环境先验对外部原因做出的最优概率估计。
- 听觉与视觉的计算对偶：耳蜗与视网膜分别在频域与空域进行滤波分流，通过外毛细胞主动放大与中央凹分配实现超宽动态范围。
- 模块化知觉计算层级：从早期感受野滤波（V1/耳蜗），到中层轮廓分组与场景分析，再到高层不变性物体识别与高阶纹理统计。
- 全感官整合与注意调控：涵盖颜色、运动、深度、三维视点、触觉以及化学感官，揭示注意系统如何在有限神经带宽中做最优分配。

## 学习方法与复习策略

- **追踪信息流的物理因果链**：在阅读每一讲时，始终牢记五步因果链条：`外部物理原因 → 感觉物理信号 → 受体机械/光化学换能 → 神经中枢编码 → 知觉统计推断`；
- **重视错觉的诊断价值**：错觉不是大脑的系统故障，而是系统在极其特殊的物理边界条件下暴露其先验假设的探针；
- **闭卷自测机制**：完成每一讲后，合上笔记独立回答文末的思考题与自测，确保能精准解释核心实验设计与竞争理论的证伪条件。

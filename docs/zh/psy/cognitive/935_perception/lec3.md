# Lec 3 声音空间定位、音高与心理物理学

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 双耳定位双工理论：低频主要利用微秒级双耳时间差（ITD），高频利用头部声影造成的双耳强度差（ILD）。
- 耳廓谱滤波与高度定位：耳廓不对称凹凸对不同垂直仰角的声音产生特征性谱滤波缺口，提供单耳高低与前后定位线索。
- 韦伯-费希纳定律与信号检测论：心理物理学量化物理刺激与主观知觉的关系，严格区分感受性指标 d' 与反应偏向准则 c。
- 多维听觉属性表征：音高由周期性决定，响度由振幅与频响加权决定，音色由频谱包络与时间瞬态起音共同塑造。

## 1. 核心问题

- **驱动问题**：- 怎样把两耳线索与主观报告联系起来，同时避开反应偏差？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 3 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 双耳时间差 ITD | 声到两耳的时间差，常用于低频定位。 | 时间差不是声源距离差本身。 |
| 双耳声级差 ILD | 头部遮挡造成的强度差，常用于高频定位。 | 声级差也受频率和遮挡影响。 |
| 耳廓频谱线索 | 帮助区分前后/上下。 | 耳廓线索不等于双耳线索。 |
| 心理测量函数 | 刺激强度与正确或检出概率的关系。 | 阈值是约定概率点，不是开关。 |
| 阶梯法 | 根据前次答题调整刺激，在阈值附近取样。 | 阶梯法规则不同会收敛不同正确率。 |

## 3. 证据链

### 定位线索比较
- **设计/比较**：改变声源频率与左右到达时间、声级差。
- **讲义所述结果**：低频时间差和高频声级差的可用性不同。
- **推论**：声音方向是多线索联合估计。
- **软肋**：同一双耳线索可对应多个空间位置，还需耳廓/头动线索。

### 恒定刺激与阶梯任务
- **设计/比较**：在多个强度随机给刺激或按回答调节难度。
- **讲义所述结果**：可得到随强度平滑变化的正确率与约定阈值。
- **推论**：阈值是概率准则而非绝对界线。
- **软肋**：阶梯规则决定目标正确率；期待与回答策略仍会改变估计。

## 4. 理论之争与计算模型

| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 阈值是固定感觉边界 | 阈值由任务、概率准则与偏差共同定义 | 比较强迫选择、随机呈现与阶梯规则。 |

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 物理：时间差、声级差和频谱；神经：双耳/外耳加工；心理：方向及响度判断；方法：心理物理任务。

## 6. 边界条件与失效情形

- - 距离不能只由声级推出；熟悉声源、混响和频谱都会参与判断。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

### 认知科学家的心智诊断：双耳间的微秒魔法——大脑如何在时间与强度中重构空间

声波在两耳之间传播的时间差（ITD）只有区区几百微秒，甚至不足一个动作电位发放的持续时间。

然而，脑干中的内侧上橄榄核（MSO）神经元却利用延迟线与重合检测器，把微秒级的时间差精确转化为空间方位的神经拓扑。

这再次印证了知觉的核心法则：空间不是感觉器官直接测得的物理量，空间是大脑通过多维线索（双耳时差、强度差、耳廓谱滤波）从一维压力信号中逆向计算出来的心理建构。
:::

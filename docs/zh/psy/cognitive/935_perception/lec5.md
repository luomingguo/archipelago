# Lec 5 听觉场景分析：分组与流分离

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 听觉流分离与交替音序列：交替高低音（ABA-）随着频率差距增大或播放速率加快，从单一整合流分裂为两个并行听觉流。
- 格式塔原则在听觉中的投影：时间邻近性、音高邻近性、空间位置一致性与音色连续性共同约束听觉流的自组织边界。
- 鸡尾酒会效应的计算破局：听觉系统利用基频轨迹、空间线索与语用预测，在单维混合声波中实时切分多个并发说话者。
- 听觉连续错觉：被强噪声遮挡的纯音在主观上被感知为连续不断，证明心智坚决偏好最经济的遮挡解释而非破碎物理波形。

## 1. 核心问题

- **驱动问题**：- 多个声源在鼓膜叠成一条波形时，系统如何拆成不同听觉流？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 5 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 同时分组 | 判断同一时刻频率成分是否同源。 | 同时分组处理频带归属，非时间延续。 |
| 顺序分组 | 判断前后声音是否属同一持续声源。 | 顺序分组处理跨时间连续性。 |
| ABA 分流 | 交替声调可被听成一流或两流。 | 同序列可随注意和聆听时间分流。 |
| 共同调制 | 多频带包络同步变化提示同一声源。 | 共同起伏可提示同源，也可能由偶然同步产生。 |
| 优先效应 | 短延迟反射声的定位受先到声主导。 | 先到声定位优势不等于反射声听不见。 |

## 3. 证据链

### ABA 声调序列
- **设计/比较**：调节 A/B 频率差和呈现速度，并让听者报告一流或两流。
- **讲义所述结果**：频率差增大或节奏加快时更易听见分流，分流还可随时间增强。
- **推论**：顺序组织利用相似性与持续性，不是瞬时固定分组。
- **软肋**：注意与任务也可改变报告；同一物理序列可能有不同经验。

### 共同调制掩蔽释放
- **设计/比较**：在目标频带外加入与掩蔽噪声共同起伏的噪声。
- **讲义所述结果**：某些条件下目标纯音反而更易被检出。
- **推论**：系统把共变噪声归为一物体，从而分离目标。
- **软肋**：改善不说明新增噪声本身提高信噪比；需控制滤波和准则。

## 4. 理论之争与计算模型

| 解释 A | 解释 B | 区分证据 |
| --- | --- | --- |
| 仅靠各频率的局部能量决定对象 | 跨频带、时间与空间一致性影响对象组织 | 操纵谐波性/共同调制/时间间隔。 |

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 物理：混合波形；神经：多频带与时间线索；认知：流的归属；行为：分流报告和检测阈值。

## 6. 边界条件与失效情形

- - 先验帮助在自然环境分组，但伪造同步/谐波关系也能制造错误声源归属。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

::: insight
### 认知科学家的心智诊断：嘈杂酒会中的听觉奇迹——场景分析是心智的聚光灯

在喧嚣的鸡尾酒会中，几十个人的说话声、碰杯声与爵士乐在鼓膜上交织成一条杂乱无章的单维波形。任何传统的工程解混算法在此处都会陷入绝境。

人类心智却能凭借共同起始（Common Fate）、谐波共振、基频轨迹与空间位置，像一把精密的手术刀，将混合声波瞬间剥离为清晰独立的听觉流（Auditory Streams）。

这表明知觉计算的核心不在于信号接收，而在于**基于客体性（Objecthood）的结构重组**——我们在嘈杂的宇宙中寻找的不是分散的频率，而是一个个有生命意图的行动者。
:::

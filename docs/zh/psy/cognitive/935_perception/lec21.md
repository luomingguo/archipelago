# Lec 21 注意机制 II：基于物体的注意与注意瞬脱

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 基于物体的注意选择机制：当注意被引导至物体的某一端时，注意力在同一个物体轮廓内部的扩散速度显著快于跨越至相邻独立物体。
- 注意瞬脱的意识闸口限制：在快速序列视觉呈现（RSVP）中，T1 目标被识别后 200–500 毫秒内呈现的 T2 目标遭到严重的意识漏报。
- 不注意视盲与变化视盲：若没有焦点注意的主动覆盖，即使屏幕中央发生巨大的场景改变或走过显眼目标，观察者仍会发生系统性视盲。
- 意识经验与注意调控的解耦：无注意状态下刺激仍可在初级皮层触发隐性神经启动，但唯有获得注意增益才能点燃额顶网络并登入全局工作空间。

## 1. 核心问题

- **驱动问题**：- 注意提高目标处理时，为何明显变化或第二个目标仍可能被漏掉？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 21 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| 神经增益 | 注意使目标相关响应或信噪比改变。 | 响应增强不必然增强主观可见性。 |
| 不注意盲视 | 集中于别的任务时漏报未预期刺激。 | 漏报不等于刺激完全没有处理。 |
| 变化盲视 | 短中断后明显场景变化未被报告。 | 变化盲视需变化瞬间被遮断/分心。 |
| 注意瞬脱 | 快速序列中第一个目标后短窗内第二个更难报告。 | 瞬脱是时间瓶颈，不是空间盲区。 |
| 报告限制 | 没报告不等于所有处理为零。 | 报告能力与感觉能力应区分。 |

## 3. 证据链

### 变化检测中断任务
- **设计/比较**：让场景前后有改变，并用闪烁/遮挡打断变化瞬间。
- **讲义所述结果**：观察者可漏掉大变化，尤其未选择其位置时。
- **推论**：注意影响可报告、可稳定记忆的场景表征。
- **软肋**：漏报不等于刺激毫无无意识加工。

### 快速双目标序列
- **设计/比较**：在 RSVP 中改变第二目标与第一目标的时间间隔。
- **讲义所述结果**：某些短间隔内第二目标报告率下降。
- **推论**：注意有明显时间选择瓶颈。
- **软肋**：任务、目标相似性及报告顺序均可改变瞬脱。

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 神经：目标响应增益；认知：选择/工作记忆；行为：变化和第二目标报告；方法：控制刺激与回答偏差。

## 6. 边界条件与失效情形

- - 神经响应增强不总是主观经验增强；未报告不能证明完全没有神经处理。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

::: insight
### 认知科学家的心智诊断：视而不见的盲区——注意瞬脱与意识的瓶颈

当你凝视一个快速连续呈现的字符流时，如果在识别出第一个目标后 200–500 毫秒内出现第二个目标，你的意识会完全对第二个目标失明（注意瞬脱 Attentional Blink）。

不仅如此，由于缺乏自上而下的注意聚焦，哪怕一只大猩猩从篮球场中央踱步而过，半数人也全然看不见（不注意视盲 Inattentional Blindness）。

这些著名的实验残酷地击碎了我们对自身清醒程度的自负：我们在每一秒钟所遗落的真实世界，远远超过我们所看见的方寸之地。
:::

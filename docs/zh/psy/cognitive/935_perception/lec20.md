# Lec 20 注意机制 I：空间注意与特征搜索

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 注意的有限容量瓶颈：庞大的感知输入流必须通过选择性注意分配神经代谢资源，空间提示范式证实注意能显著缩短反应时并提升敏锐度。
- 特征整合理论的双阶段假说：单维特征（如红色、水平线）自动平行加工触发“弹出效应”（Pop-out），结合特征必须依赖焦点串行扫描。
- 视觉搜索斜率与搜索不对称：特征存在搜索具有平坦斜率（零搜索代价），特征缺失搜索伴随显著时间惩罚，证实肯定特征的前注意提取。
- 自下而上凸显与自上而下目标驱动：腹侧/背侧注意力网络通过顶下小叶与额叶视野区（FEF）协同控制视觉聚光灯在时空中的导向转移。

## 1. 核心问题

- **驱动问题**：- 注视不变时注意能否移动，为什么有些目标一眼找到、另一些需要逐项搜索？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 20 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| covert attention | 不移动眼睛却改变处理优先级。 | 不动眼也能改变处理优先级。 |
| Posner 线索 | 目标前线索改变有效/无效位置的反应时间。 | 线索收益可能含决策/准备效应。 |
| top-down 注意 | 由目标和预期控制选择。 | top-down 与显著性捕获可同时作用。 |
| bottom-up 捕获 | 突发或显著刺激吸引注意。 | 显著不等于必然进入报告。 |
| set-size slope | 搜索反应时随干扰项数量变化的速率。 | 斜率还受目标—干扰项相似度影响。 |

## 3. 证据链

### Posner 线索任务
- **设计/比较**：固定注视并先给空间线索，比较目标出现在有效与无效位置。
- **讲义所述结果**：有效线索常带来反应优势，无效线索造成代价。
- **推论**：注意可以在无眼动时定向。
- **软肋**：反应时还含准备和决策成分，需要眼动控制。

### 视觉搜索比较
- **设计/比较**：让目标由单一特征或多个特征结合定义，并改变干扰项数量。
- **讲义所述结果**：某些特征目标较快发现，复杂结合条件常更随项目数变慢。
- **推论**：选择资源影响特征结合和对象定位。
- **软肋**：目标—干扰项相似度也影响斜率，不能只用‘特征/结合’二分。

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 视觉输入：多目标；神经/认知：选择和竞争；行为：反应时与正确率；任务：目标/干扰项操纵。

## 6. 边界条件与失效情形

- - 反应变快不能独证明感觉增益，可能还来自决策准则或运动准备。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

::: insight
### 认知科学家的心智诊断：注意的聚光灯——有限神经能量的战略抉择

如果说感觉系统是海量信息的漏斗，那么注意机制就是心智的绝对节流阀。

特里斯曼的特征整合理论（FIT）告诉我们：颜色、方向等基本特征可以在全视野范围内进行平行的前注意加工，但若要把这两种特征绑定在同一个物体上，必须调集空间注意的聚光灯。

在有限的脑代谢资源约束下，注意决定了哪些信号能够穿透感觉的表层，获得意识的加冕，并载入长时记忆的丰碑。
:::

# Lec 9 外侧膝状体（LGN）与初级视觉皮层（V1）

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 外侧膝状体分层拓扑架构：LGN 六层严格区分同侧/对侧眼输入与大/小细胞通道，保留视网膜拓扑对应并受皮层自上而下反馈调控。
- V1 简单细胞与方位选择性：休伯尔与维泽尔证实简单细胞通过线性整合一排排 LGN 同心感受野，首次涌现出对特定方位条纹的敏感性。
- 复杂细胞与位置不变性：复杂细胞响应特定方位的移动条纹，对其在感受野内的具体绝对相位和明暗正负具备平移不变性。
- 皮层超柱与功能冰块模型：方位柱、眼优势柱与色斑在 1mm³ 的 V1 皮层模块内紧密交织，构成视觉场景特征解构的基本功能单元。

## 1. 核心问题

- **驱动问题**：- 视觉信号进入皮层后，为什么不再只是中心—周边亮点检测？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 9 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| LGN | 丘脑的外侧膝状体，保留分层视网膜输入。 | LGN 是中继和加工节点，不是被动电线。 |
| 视网膜拓扑 | 邻近视野对应相近神经区域。 | 拓扑邻近不等于细胞功能相同。 |
| V1 简单细胞 | 对特定位置、方位/空间频率敏感。 | 方位偏好不等于自然物体识别。 |
| V1 复杂细胞 | 仍有方位选择但对局部相位较宽容。 | 相位宽容不等于对所有变换不变。 |
| 调谐曲线 | 系统改变刺激特征得到响应函数。 | 调谐曲线受所测刺激集合约束。 |

## 3. 证据链

### 单细胞方位调谐
- **设计/比较**：在动物视觉区记录放电，改变条纹方位、位置和空间频率。
- **讲义所述结果**：某些 V1 细胞对特定方位/位置响应最强。
- **推论**：皮层对局部图像特征作选择性分解。
- **软肋**：响应偏好不代表细胞只编码一个自然物体。

### 简单/复杂细胞比较
- **设计/比较**：移动相同方位条纹在感受野内的相位或位置。
- **讲义所述结果**：复杂细胞相对简单细胞更容忍相位变化。
- **推论**：层级组合可增加局部不变性。
- **软肋**：层级模型并非排除反馈、并行输入或其他细胞类型。

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 视网膜：并行输入；丘脑：分层中继；V1：方位/眼别调谐；行为：特征检测与视觉任务。

## 6. 边界条件与失效情形

- - 调谐曲线测的是某刺激集合下的响应，不能单凭一条曲线推出细胞对真实世界的完整功能。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

::: insight
### 认知科学家的心智诊断：休伯尔与维泽尔的启示——从光斑到方向特征的皮层降维

在初级视觉皮层（V1）中，视网膜圆形的同心光斑被神奇地转换为对特定方向条纹响应的简单细胞与复杂细胞。

这种经典的层次连接模型（Feedforward Hierarchy）启发了后世半个世纪的人工智能卷积神经网络（CNN）。

但更深刻的是 V1 的功能柱架构：方位、眼优势与空间频率在毫米级的皮层冰块结构中实现了完美的连续映射。大脑将三维世界的视觉投射，以高度结构化的拓扑阵列解构为一套完备的正交基底函数。
:::

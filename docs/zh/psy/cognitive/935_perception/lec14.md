# Lec 14 运动知觉 II：孔径问题、光流与高阶运动

> MIT 9.35 · Perception · 主讲 Josh McDermott

## TL;DR

- 孔径问题与一维运动歧义：单个局部感受野受限于有限孔径，只能测定垂直于边缘的法向速度，无法确定物体的真实全向位移。
- 交叉约束（IOC）几何求解：中颞叶（MT / V5 区）通过整合多个不同朝向边缘的法向运动向量集合，以交点约束计算出真实运动。
- 光流场与自我运动导航：膨胀焦点（Focus of Expansion, FOE）提供前进方向定位，全局视流梯度引导三维环境避障与着陆。
- 生物运动知觉的极速识别：光点小人（Point-Light Walker）实验证实人类仅凭十几个孤立光点的联动模式，能在 200 毫秒内识破动作与性别。

## 1. 核心问题

- **驱动问题**：- 一段直边的局部运动为何不足以求出真实方向，视觉系统怎样整合它？
- **计算本质**：知觉是大脑在面对感觉输入（高噪声、低维投影、非唯一逆问题）时，调动演化与经验先验对真实物理环境展开的贝叶斯最大后验概率估计（MAP）。
- **模块承接**：本讲作为全课程第 14 讲，深度承接前后感官因果链条，构筑感知向认知升维的关键计算台阶。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆处 |
| --- | --- | --- |
| aperture problem | 小视窗中直边只能约束法向速度分量。 | 局部法向速度不是完整二维速度。 |
| 端点线索 | 角点/线端可提供较完整的运动方向。 | 端点较有信息，但也会受遮挡。 |
| MT/V5 | 整合较大视野内局部运动的皮层区域。 | MT 整合不意味着 V1 无运动信息。 |
| 随机点一致性 | 部分点同向移动比例决定全局方向难度。 | 一致性比例改变任务难度而非速度本身。 |
| plaid 刺激 | 两组运动光栅叠加，区分成分与整体运动。 | plaid 可听成成分或整体，取决于条件。 |

## 3. 证据链

### 小窗直边演示
- **设计/比较**：只显示移动边缘的一小段，再加入端点信息。
- **讲义所述结果**：局部法向运动可见，但真实二维速度不唯一；端点减少歧义。
- **推论**：全局运动要合并不同方位或无歧义局部特征。
- **软肋**：端点仍可能受遮挡、噪声和对象分组影响。

### plaid 与随机点比较
- **设计/比较**：给两个不同运动光栅或加噪随机点，比较 V1/MT 响应与方向判断。
- **讲义所述结果**：部分细胞偏向成分方向，部分偏向整体 pattern 方向。
- **推论**：MT 等通路参与跨局部信号整合。
- **软肋**：神经响应与行为相关不独证明单一区域足够或唯一。

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **物理与环境层（Physical）** | 外部声光电磁刺激的传播与衰减 | 刺激遵循空间、时间与几何光学/声学客观物理法则 |
| **受体与生理层（Physiological）** | 感受器官机械/光电换能与突触传递 | 感受野构建、动作电位编码与功能柱分层拓扑 |
| **计算与推断层（Computational）** | 贝叶斯先验结合、约束求解与特征绑定 | 克服逆问题不适定性，生成最可能的目标表征 |
| **行为与心理物理层（Behavioral）** | 心理物理辨别阈值、觉察反应时与主观错觉 | 行为表现暴露大脑底层所依赖的隐性计算先验 |

- **分析层次小结**：- 图像：位置随时间变；V1：局部方向测量；MT：大范围整合；知觉：物体速度与眼动补偿。

## 6. 边界条件与失效情形

- - 视网膜运动也可能由眼/身体运动造成；估计世界运动还需眼动指令和前庭线索。
- **常态与极端的辩证**：错觉与推断失效绝非心智故障，而是知觉推断机制在脱离日常自然生态统计分布的人工极端刺客刺激下，其内在假设被孤立放大的必然体现。

::: insight
### 认知科学家的心智诊断：孔径问题的破局——局部模糊向全局一致的运动升维

当一个运动物体的一段笔直边缘穿过单个神经元的感受野时，感受野就像一个小孔径，它永远只能探测到垂直于边缘的法向运动分量。

初级视皮层的每一个简单细胞都被困在自己的局部孔径之中。

然而，中颞叶（MT 区）的高阶运动神经元通过汇聚大量不同方向的局部信号，利用交叉约束（Intersection of Constraints, IOC）与矢量平均算法，瞬间解开了局部的运动歧义，恢复出物体真实的全局运动方向。这向我们展示了神经计算如何通过层级汇聚完成跨越维度的意义重构。
:::

# MIT 9.59J / 24.905J 心理语言学实验（Laboratory in Psycholinguistics）

> MIT 9.59J · Spring 2017 · 主讲 Edward Gibson · 脑与认知科学系 / 语言学系

MIT 9.59J（交叉列课 24.905J）《心理语言学实验》（Laboratory in Psycholinguistics）是由麻省理工学院著名认知科学家爱德华·吉布森（Edward "Ted" Gibson）教授领衔的经典实验方法与理论核心课程。本课程打破了乔姆斯基传统生成语法学派仅凭学者“扶手椅直觉”（Armchair Intuition）判定句子合法性的唯理主义范式，严格秉持定量行为实验与信息论（Information Theory）双重原则，深入探究人类句子理解与产生的认知计算架构。课程覆盖眼动追踪、自定步速阅读（Self-paced Reading）、句法工作记忆限制、基于噪声信道的贝叶斯句子解释（Noisy-Channel Model）、语用在线计算、以及皮拉罕语递归争议与萨丕尔-沃尔夫假说的跨文化心理语言学实证检验。

## TL;DR

- 实验范式革命：将主观语法直觉转化为严谨的因子设计行为实验，利用自定步速阅读时延与眼动注视测量在线认知加工负荷。
- 依赖局部性与工作记忆：吉布森依存局部性理论（DLT）证实，长距离句法整合代价取决于跨越的新话语实体数量，造成中心嵌套句子理解崩溃。
- 噪声信道贝叶斯句子理解：人类大脑将输入视为经过噪声干扰的信号，结合世界知识先验与编辑距离似然度，进行理性的语义纠错与解释。
- 语言与认知相对论边界：对颜色命名、数概念以及亚马逊皮拉罕语递归的实证调查表明，语言塑造高阶量化思维，但基本知觉具备普遍生理底座。

## 学习建议

- **聚焦计算假设与变量控制**：心理语言学的精髓在于用精巧的对比实验解耦混杂变量。阅读每一篇笔记时，请务必关注作者如何构造最小对比句（Minimal Pairs），并思考其究竟测量了存储负荷还是检索干扰。

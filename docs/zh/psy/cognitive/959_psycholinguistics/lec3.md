# Lec 3 语言理解中的多重约束

> MIT 9.59J / 24.905J · 实验心理语言学 · 主讲 Edward Gibson

## TL;DR

- 花园路径 vs. 约束满足：模块化花园路径模型主张句法优先（最小依附原则）；约束满足模型主张多维线索即时交互。
- 次范畴化与题元线索：当主语动画特征或动词论元结构（如 examined by）不兼容直接宾语分析时，花园路径效应瞬间被消除。
- 眼动轨迹与重测代价：眼动仪测量早期凝视时间与回视跳视（Regressions），证实大脑在听到词汇瞬间即整合所有语境约束。

## 1. 核心问题

- **驱动问题**：听者在遇到歧义时，句法是否先独立决定解释？
- **计算本质**：语言理解并非抽象符号规则的静态匹配，而是在有限工作记忆容量、时间不可逆性与物理噪声信道约束下，心智进行的多重线索贝叶斯最优概率推断。
- **课程坐标**：本讲作为全课程第 3 讲，构成了从实验范式量化向高阶句法、语义与文化相对论跃迁的核心环节。

## 2. 核心概念

| 概念 | 一句话定义 | 易混淆对象 |
|---|---|---|
| 花园路径 | 早期分析后来需要重析的句子 | 永远歧义 |
| 模块性 | 句法初期相对隔离于语境和世界知识 | 任务独立 |
| 指称语境 | 场景中可被话语指向的候选物 | 句内语境 |
| 眼动 | 用注视时间与位置估计增量理解 | 事后口头报告 |

## 3. 证据链

讲义回顾缩略关系从句歧义：Ferreira 与 Clifton (1986) 的首遍眼动在“by the lawyer”附近显示重析，即使先行名词不适合作施事；Trueswell 等 (1994) 改进材料后发现合理性与词汇信息可在早期影响分析。Tanenhaus 等的视觉场景实验进一步显示，候选物数量改变对“on the towel”的理解。证据来自**不同任务与材料**，不能合并成单一精确时间点。

## 4. 理论之争与计算模型

句法优先说预期早期误读不受语境影响；约束互动说语境、词汇、合理性可以同步竞争。较严的材料控制和早期眼动是区分工具。

## 5. 分析层次的整合

| 系统层次 | 核心研究维度 | 本讲关键机制与实证 |
|---|---|---|
| **语言与文化层（Linguistic & Cultural）** | 语料库频率统计、跨语言对比与句法参数 | 词汇分布规律、句法结构选择与文化约束 |
| **计算与算法层（Computational & Algorithmic）** | 贝叶斯有噪信道推断、依存局部性代价量化 | 惊异度（Surprisal）计算、线索直接检索匹配 |
| **行为与生理层（Behavioral & Physiological）** | 毫秒级自定步速阅读时延、眼动注视与脑电 P600 | 反应时差异直接映射即时在线认知加工阻力 |

- **层次小结**：眼动层观察选择；认知层是多个信息源加权；社会层包括说话者意图与共同场景。

## 6. 边界条件与失效情形

- 注视并不直接等于内部句法树；视觉场景中的候选物是否明确也影响推断。
- **常态与极端的辩证**：实验室单句呈现与自然语境存在生态效度差异；特定语言（如英语）中稳健的词序效应不应草率外推为全人类语言普遍规则。

::: insight
### 心理语言学家的心智诊断：解构花园路径——心智不是盲目的单行道

经典句法学派曾把人类大脑想象成一个愚蠢的死脑筋机器：它坚守着“最小依附原则”，在句子前半段盲目向前冲，直到撞在花园路径的南墙上撞得头破血流，才狼狈不堪地回溯重构。

真实的心智远比这聪明得多。

多重约束满足模型向我们揭示了贝叶斯大脑的极致灵动：动词的一个微小语义倾向、主语是有生命的记者还是无生命的证据、甚至说话者眼神的一次回转，都在以光速向句法解析器注入概率先验。

我们之所以很少在日常对话中被歧义绊倒，不是因为语法规则完美无缺，而是因为心智在每一毫秒都在全息整合整个宇宙的常识。
:::

## 9. 开放问题与前沿探索

- **未决之谜**：怎样同时操纵词汇概率与场景候选数以估计各自贡献？
- **大模型与认知对齐**：现代大语言模型（LLM）的注意力权重分配是否在统计物理上复现了人类的依存局部性理论？自回归解码的逐词惊异度与人类阅读时间的相关性为计算心理语言学提供了全新研究范式。

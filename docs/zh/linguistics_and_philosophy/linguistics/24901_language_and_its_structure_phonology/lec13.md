# Lec 13 声调音系学 I：非洲语言声调扩散、悬空声调与自主音段公理（Tone I: African Languages & Autosegmental Foundations）

在生成音系学的发展史上，非洲语言声调系统的研究掀起了一场震撼性的理论革命。经典 SPE 理论曾坚称所有特征都必须依附于单个音段（Segment），然而非洲语言中的声调却展现出匪夷所思的独立性：元音被删除了声调依然存活、单个声调可以在多个音节上自由蔓延，甚至存在完全没有辅音或元音实体的“纯声调语素”。在麻省理工学院 24.901 第十五讲中，Michael Kenstowicz 教授系统推演约翰·戈德史密斯（John Goldsmith 1976）的**自主音段音系学（Autosegmental Phonology）**，建立承调单位（TBU）、良构条件（WFC）以及不相交公理。

## TL;DR

- **分段理论的声调危机**：多对一（单音节复合调）、一对多（跨音节调扩散）、声调稳定性（元音删除声调留存）与悬空声调打破了扁平特征假说。
- **双层自主音段架构**：声调层（Tonal Tier）与音段/骨架层（Skeletal Tier）彼此平行，通过抽象的关联线（Association Lines）相互绑定。
- **戈德史密斯良构条件（WFC）**：承调单位必须关联声调、声调必须关联承调单位、关联线绝对严禁交叉。
- **门德语（Mende）声调旋律实证**：词库中只储存抽象旋律模板（H, L, HL, LH, LHL），通过自左向右的一对一匹配与末尾扩散规则生成全词声调。

## 1. 经典分段音标模型的破产：声调的四大反常行为

如果声调像 $[+\text{high}]$ 或 $[+\text{nasal}]$ 一样只是元音矩阵内部的一个从属二元特征，那么它理应与元音共存亡。然而非洲尼日尔-刚果语系（如门德语、约鲁巴语、伊博语、蒂夫语）的丰富语料呈现了四大不可思议的经验反例：

1. **一对多扩散（One-to-Many Spreading）**：一个单一的高调（H）特征可以在两个、三个甚至四个连续音节上拉伸展开，在物理声学上表现为一个平直的高音平台；
2. **多对一复合（Many-to-One Contours）**：一个单短元音在表层可以承载升调（Rise, 由低到高 LH）或降调（Fall, 由高到低 HL），在扁平矩阵中单个音段无法同时兼具 $[+\text{high}]$ 与 $[-\text{high}]$；
3. **声调稳定性（Tone Stability）**：当形态规则将两个元音相遇处的某个元音强制删除时（Vowel Deletion），**被删除元音所承载的声调绝不消失**，而是顽强地漂移附着到相邻的幸存元音上；
4. **悬空声调（Floating Tones）**：许多语法范畴（如伊博语的领属格、约鲁巴语的时态标记）在音段上没有任何辅音或元音，它仅仅是一个漂浮在空中的孤立高调（H）或低调（L）。

## 2. 自主音段理论（Autosegmental Theory）的几何公理

面对传统模型的危机，戈德史密斯（Goldsmith 1976）在其 MIT 博士论文中提出了石破天惊的构想：**声调不是元音的附属品，而是自成一个独立的几何平面（Tonal Tier）**。

```text
声调层 (Tonal Tier):          H               L
                             │ \             │
                             │   \           │  (关联线 Association Lines)
                             │     \         │
骨架层 (Skeletal Tier):       V      V        V
承调单位 (TBU):              σ1     σ2       σ3
```

- **承调单位（Tone-Bearing Unit, TBU）**：通常是音节核元音（$V$）或音拍（Mora, $\mu$）；
- **关联线（Association Lines）**：表达声调与承调单位在时间轴上的共时激活；
- **声调稳定性机制**：元音脱落仅仅切断了骨架层的联系，声调依然完整漂浮，随后通过音系通用规则重现锚定（Re-docking）。

::: theorem 戈德史密斯良构条件（Well-Formedness Condition, WFC）
在底层式向表层形式映射的过程中，音系联结必须严格遵守三大公理：
1. **全映射原则**：所有承调单位（TBU）必须至少与一个声调相关联；
2. **全覆盖原则**：所有声调特征必须至少与一个承调单位相关联；
3. **无交叉公理（No-Crossing Constraint）**：**关联线在任何推导阶段均绝对严禁发生几何交叉！**
:::

无交叉公理表达了时间序列不可倒流的心智本质：若关联线交叉，意味着两个互不相容的声音事件在时间拓扑上陷入死锁。

## 3. 经典门德语（Mende）声调旋律映射算法

西非门德语（Leben 1973, Goldsmith 1976）为自主音段映射提供了完美的实证范本。在门德语名词中，无论一个单词包含一个、两个还是三个音节，其全词声调旋律只能从五种预设模板中选取：
$$\text{五大独立声调旋律}: \mathbf{H}, \quad \mathbf{L}, \quad \mathbf{HL}, \quad \mathbf{LH}, \quad \mathbf{LHL}$$

不同音节长度的词汇在匹配这些抽象旋律时，展现出惊人的一致性数学规律：

| 抽象旋律模板 | 单音节词 (1 $\sigma$) | 双音节词 (2 $\sigma$) | 三音节词 (3 $\sigma$) | 几何映射推导规则 |
| :---: | :---: | :---: | :---: | :--- |
| **H 模板** | *kɔ́* (高) | *pɛ́lɛ́* (高-高) | *hɑ́wámá* (高-高-高) | 孤立 H 自左向右依次关联并向右扩散 |
| **L 模板** | *kpà* (低) | *bɛ̀lɛ̀* (低-低) | *kpàkàlì* (低-低-低) | 孤立 L 向右扩散全词 |
| **HL 模板** | *mbû* (降调 HL) | *ngílà* (高-低) | *félàmà* (高-低-低) | 1个音节承载复合调；多音节则依次平分，末音节吃下剩余 |
| **LH 模板** | *mbǎ* (升调 LH) | *fàndé* (低-高) | *ndàwúló* (低-高-高) | 1个音节承载升调；多音节自左向右映射，最后一个声调向右扩散 |
| **LHL 模板** | *mbâ̌* (曲折调) | *nyàhâ* (低-降) | *níkílì* (低-高-低) | 三个声调完美与三个音节形成一对一双射 |

::: example 门德语映射演算法的执行步骤
以三音节词 *ndàwúló* 匹配 **LH 模板** 为例：
1. **自左向右一对一映射**：第一个 TBU（*ndà*）关联第一个声调 L；第二个 TBU（*wú*）关联第二个声调 H；
2. **末端扩散（Rightward Spreading）**：第三个 TBU（*ló*）无独立新声调，受 WFC 第一条强力驱动，最右侧的声调 H 向右扩散连向第三个音节，形成 $[L - H - H]$。
:::

整个过程没有为个别词汇硬编码任何孤立规则，统一的映射算法在不同长度的骨架上自动计算出确定性的表层声调。

::: insight 自主音段理论的范式飞跃
自主音段理论是生成音系学自诞生以来最具深远意义的突破。它粉碎了自亚里士多德以来将语言符号视为一维“珍珠链”的线性教条，首次确立了多维平行几何层级的本体论地位。这一关于声调扩散与解离的拓扑模型，随后被全面推广至特征几何（鼻音与发音部位扩散）、元音和谐律以及非连续词根形态学中，成为现代形式音系学的通用语言。
:::

# Lec 07 声学语音学 I：源-滤波理论、元音共振峰与 Praat 实验（Acoustics of Vowels & Praat）

语言的生理发音固然关键，但声波才是跨越人际、抵达听觉神经的唯一物理实体。早期的生理直觉必须通过精密的声学数学分析予以验证。在麻省理工学院 24.901 第八讲中，Michael Kenstowicz 教授正式切入声学语音学（Acoustic Phonetics），系统讲授声音波动方程、傅里叶分析、贡纳尔·范特（Gunnar Fant）的**源-滤波理论（Source-Filter Theory）**，建立单端开口管共鸣模型，并演示如何利用现代语音学标准工具 **Praat** 测量元音共振峰（Formants）。

## TL;DR

- **声音的声学物理本质**：声波是空气介质中压力起伏与分子疏密波的能量传播，周期 $T$ 与频率 $f = 1/T$ 决定感知音高。
- **傅里叶分析与声门源**：复杂的周期性声波可分解为基频 $F_0$ 及其整数倍谐波（Harmonics），声门脉冲随频率每倍频程衰减约 12 dB。
- **源-滤波理论（Source-Filter Model）**：声带振动提供激励源谱（Source），声道的几何形状构成声学谐振滤波器（Filter），最终在唇部向自由空间辐射。
- **元音共振峰与发音几何映射**：第一共振峰 $F_1$ 与舌位高度呈负相关；第二共振峰 $F_2$ 与舌位靠前程度呈正相关；圆唇动作整体拉低所有共振峰。

## 1. 声学波动理论与傅里叶定理

当发音器官产生扰动时，空气分子的弹性碰撞将声压波动（Sound Pressure Fluctuations）以约 $c = 340\text{ m/s}$（声道潮湿空气中约 $350\text{ m/s}$）的速度向前传递。

::: definition 简谐波与复合波
- **简谐波（Sine Wave）**：由振幅 $A$、频率 $f$ 与初始相位 $\phi$ 唯一定义的单频振动：
  $$y(t) = A \sin(2\pi f t + \phi)$$
- **傅里叶定理（Fourier's Theorem）**：任何复杂的周期性声波，均可数学分解为一系列具有不同振幅、频率和相位的简谐波的正弦叠加。其中最低的频率称为**基频（Fundamental Frequency, $F_0$）**，其余各分量为基频的整数倍，称为**谐波（Harmonics: $2F_0, 3F_0, \dots, nF_0$）**。
:::

说话人声带每秒振动的次数决定了基频 $F_0$。成年男性的 $F_0$ 通常在 $100\text{--}150\text{ Hz}$，女性在 $180\text{--}250\text{ Hz}$，儿童可达 $300\text{ Hz}$ 以上。

## 2. 范特源-滤波理论（Source-Filter Theory）

现代声学语音学的理论基石是瑞典声学家贡纳尔·范特建立的**源-滤波模型**。元音的生成可以精确拆解为三个独立的声学传递函数相乘：

$$P(f) = S(f) \times T(f) \times R(f)$$

```text
[ 声门激励源 S(f) ]     ×     [ 声道滤波传递函数 T(f) ]     ×     [ 唇部辐射 R(f) ]     =     [ 辐射声谱 P(f) ]
基频 F0 + 衰减谐波                共振峰极点 (F1, F2, F3)                高频提升 (+6 dB/oct)           表层听觉语音
(-12 dB/octave)                 选择性增强/抑制某些频段
```

1. **源谱 $S(f)$（Glottal Source）**：声带周期性开闭产生的空气脉冲。声谱包含丰富的谐波，但能量随着频率升高迅速滚降，平均衰减斜率为 $-12\text{ dB/octave}$；
2. **滤波传递函数 $T(f)$（Vocal Tract Transfer Function）**：声带上方的咽腔、口腔和唇部构成的复杂空腔。某些频率的声波由于发生驻波干涉得到极大增强，这些增强的能量中心称为**共振峰（Formants）**；
3. **辐射效应 $R(f)$（Lip Radiation）**：声波从口唇小孔向自由空间半球形发散，带来高频微分增强，斜率约为 $+6\text{ dB/octave}$。

综合结果使得表层输出声压谱在共振峰之间整体以约 $-6\text{ dB/octave}$ 的斜率向高频平缓滚降。

## 3. 单端开口均匀管模型与央元音计算

为了数学量化共振峰，我们将声道理想化为一根**一端封闭（声门处声阻抗极大）、一端开口（嘴唇处声压为零）**的均匀圆柱管。

::: theorem 四分之一波长共鸣公理
对于长度为 $L$ 的单端闭合均匀声管，只有当声管长度等于声波波长 $\lambda$ 的奇数倍的四分之一时，管内才能形成驻波产生共鸣：
$$L = (2n - 1) \frac{\lambda_n}{4} \quad \Longrightarrow \quad \lambda_n = \frac{4L}{2n - 1}$$
由于声速 $c = f \lambda$，声管的各阶共振频率公式为：
$$F_n = \frac{(2n - 1) c}{4L} \quad (n = 1, 2, 3, \dots)$$
:::

对于成年男性，平均声道长度 $L \approx 17.5\text{ cm} = 0.175\text{ m}$，取声速 $c = 350\text{ m/s}$，我们可以精确推导出非重读央元音（Schwa $[\partial]$）的前三个理论共振峰：
- **$F_1$** ($n=1$)：$\frac{1 \times 350}{4 \times 0.175} = \frac{350}{0.7} = \mathbf{500\text{ Hz}}$
- **$F_2$** ($n=2$)：$\frac{3 \times 350}{4 \times 0.175} = 3 \times 500 = \mathbf{1500\text{ Hz}}$
- **$F_3$** ($n=3$)：$\frac{5 \times 350}{4 \times 0.175} = 5 \times 500 = \mathbf{2500\text{ Hz}}$

这与人类发 $[ \partial ]$ 时的实际声学实测数据惊人一致。

## 4. 共振峰模式与发音几何双向映射

当发音器官改变姿态时，声道不再是均匀管，而是分裂为咽部后腔与口部前腔。共振峰频率随之发生剧烈偏转：

| 元音 (GA) | 第一共振峰 $F_1$ (Hz) | 第二共振峰 $F_2$ (Hz) | 生理发音特征与声腔动力学 |
| :---: | :---: | :---: | :--- |
| **$[i]$ (*beet*)** | $270$ (极低) | $2300$ (极高) | 舌位极高且极靠前，咽腔极大，口腔前腔极小 |
| **$[\mathrm{I}]$ (*bit*)** | $400$ | $2000$ | 稍偏松弛，舌位微降 |
| **$[\varepsilon]$ (*bet*)** | $550$ | $1800$ | 中前半低 |
| **$[\ae]$ (*bat*)** | $700$ (极高) | $1700$ | 低前元音，下颚下降，口咽腔均匀展开 |
| **$[u]$ (*boot*)** | $300$ (极低) | $870$ (极低) | 高后圆唇，舌根后缩，唇部延长声道管长 |
| **$[\alpha]$ (*father*)** | $750$ (极高) | $1100$ (低) | 低后元音，咽腔极度受迫狭窄，口腔充分开放 |

::: definition 共振峰与生理参数双向对应准则
1. **$F_1$ 反映舌位高度**：$F_1$ 频率与舌位高度呈刚性反比。高元音（$[i, u]$）$F_1$ 位于 $250\text{--}350\text{ Hz}$；低元音（$[a, \alpha]$）$F_1$ 高达 $700\text{--}900\text{ Hz}$；
2. **$F_2$ 反映舌位前后**：$F_2$ 频率与舌位靠前程度呈正比。前元音（$[i, e]$）$F_2$ 位于 $1800\text{--}2400\text{ Hz}$；后元音（$[u, o]$）$F_2$ 跌落至 $800\text{--}1200\text{ Hz}$；
3. **圆唇效应拉低全谱**：双唇向前撅起有效增加了声道总长度 $L$，由 $F = \frac{c}{4L}$ 可知，圆唇动作会压低所有共振峰（尤其是 $F_2$ 与 $F_3$）。
:::

## 5. Praat 语图实验分析技术

在 Praat 软件中，声学分析主要依赖**宽带语图（Wideband Spectrogram）**与**窄带语图（Narrowband Spectrogram）**：

- **宽带语图（分析带宽 $\sim 300\text{ Hz}$，时域窗长 $\sim 5\text{ ms}$）**：时间分辨率极佳，能够清晰看到声带每次闭合形成的垂直条纹（Glottal Pulses / Striations），并在水平方向呈现宽厚的暗色共振峰能量带；
- **窄带语图（分析带宽 $\sim 45\text{ Hz}$，时域窗长 $\sim 30\text{ ms}$）**：频率分辨率极佳，时间模糊，能够将一条条紧密平行的水平谐波（$F_0, 2F_0, 3F_0, \dots$）精细解析出来。

::: insight 听觉系统的生物物理滤镜
人耳耳蜗的基底膜（Basilar Membrane）本身就是一个天然的机械式傅里叶分析仪。基底膜不同位置对不同频率的声学振动产生机械共鸣。因此，共振峰并不是语言学家的数学发明，而是人类听觉系统神经放电编码元音音色的物理本体。
:::

::: pitfall 混淆基频 $F_0$ 与第一共振峰 $F_1$
初学者最易犯的严重错误是将声调/音高（$F_0$）与元音音色（$F_1$）混为一谈。一个人无论是用极低沉的声音唱 $[i]$ 还是用高八度的尖叫唱 $[i]$，其声带基频 $F_0$ 可以从 $100\text{ Hz}$ 暴涨到 $400\text{ Hz}$，但只要发音姿态不变，其声道的共振峰滤波特性（$F_1 \approx 280\text{ Hz}, F_2 \approx 2300\text{ Hz}$）始终保持恒定！
:::

# Lec 20 节律重音理论 II：音节重量、音拍理论与重音层级（Stress II: Syllable Weight & Moraic Theory）

在前一讲探讨的交替重音系统中，音步往往机械地清点音节个数（数量不敏感系统，Quantity-Insensitive）。然而，在人类更为广泛的语言体系（包括拉丁语、古典阿拉伯语、印地语与英语）中，重音的落点被音节内部的“份量”所支配——重音具有极强的**数量敏感性（Quantity-Sensitivity）**。在麻省理工学院 24.901 第二十二讲中，Michael Kenstowicz 教授系统推导海曼（Larry Hyman 1985）与麦卡锡（John McCarthy 1986）开创的**音拍理论（Moraic Theory）**，解析位置增重原则（WbP）、古典拉丁语三音节重音法则，以及印地语（Hindi）的三级重量巅峰竞争。

## TL;DR

- **数量敏感性音系学**：重音计算不仅看音节位置，更取决于音节是轻（Light）是重（Heavy）。
- **音拍（Mora, $\mu$）作为重量原子**：音拍是时间与重量的最小离散度量；短元音拥有 $1\mu$（轻音节），长元音天然拥有 $2\mu$（重音节），声母辅音永远为 $0\mu$。
- **位置增重原则（Weight by Position, WbP）**：闭音节末尾辅音（Coda）在特定语言中被赋予独立音拍，使 $CVC$ 跃升为重音节。
- **古典拉丁语重音公理**：若倒数第二音节为重音节（$CVV$ 或 $CVC$），则重音必须落在倒数第二音节；若为轻音节（$CV$），重音强制倒退至倒数第三音节。

## 1. 音节重量分类与古典拉丁语经典法则

在古典希腊语、梵语与拉丁语等古老印欧语言中，音节被明确二分为**轻音节（Light, $\sigma_L$）**与**重音节（Heavy, $\sigma_H$）**：
- **轻音节（$\sigma_L$）**：以短元音结尾的开音节（$CV$ 或 $V$）；
- **重音节（$\sigma_H$）**：包含长元音或双元音的开音节（$CVV$），或者以辅音闭合的闭音节（$CVC$）。

### 1.1 经典拉丁语重音规则（Latin Stress Rule）

在古典拉丁语中，双音节词的重音恒定落在倒数第二音节（如 *bónus*）。而在三音节及更长的词汇中，重音的落点严格取决于**倒数第二音节（Penult）的重量**：

::: theorem 古典拉丁语重音法则（Classical Latin Stress Rule）
对于三音节及以上的拉丁语词汇：
1. **重倒数第二音节（Heavy Penult）**：若倒数第二音节为**重音节**，重音必须且绝对停留在**倒数第二音节**上！
   - *reféc-tus*（制成的）：倒数第二音节为闭音节 $[f\varepsilon k]$（含辅音尾 $k$），重音落在倒数第二音节；
   - *refé:-cit*（他重做）：倒数第二音节包含长元音 $[e:]$，重音落在倒数第二音节。
2. **轻倒数第二音节（Light Penult）**：若倒数第二音节为**轻音节**（短元音开音节），它缺乏承载重音的重量引力，重音强制向前跃迁至**倒数第三音节（Antepenult）**！
   - *ré-fi-cit*（他修补）：倒数第二音节为短开音节 $[f\mathrm{I}]$，重音强制退移至倒数第三音节 $[{\text{r}}\varepsilon]$。
:::

## 2. 音拍理论（Moraic Theory）的数理架构

为什么长元音 $CVV$ 与闭音节 $CVC$ 会奇迹般地展现出完全等价的“重音吸引力”？
音拍理论指出：人类心智通过引入**音拍（Mora, 记作希腊字母 $\mu$）**建立了一套统一的算术计量单位。

```mermaid
graph TD
    subgraph Light ["轻音节 (Light σ = 1μ)"]
        S1["音节 σ"] --> M1["音拍 μ"]
        M1 --> V1["短元音 V"]
        S1 -.->|无音拍 (0μ)| C1["声母辅音 C"]
    end
    
    subgraph HeavyV ["重元音音节 (Heavy σ = 2μ)"]
        S2["音节 σ"] --> M2["音拍 μ"]
        S2 --> M3["音拍 μ"]
        M2 --> VV1["长元音前段 V"]
        M3 --> VV2["长元音后段 V"]
    end
    
    subgraph HeavyC ["位置增重闭音节 (Heavy CVC = 2μ)"]
        S3["音节 σ"] --> M4["音拍 μ"]
        S3 --> M5["音拍 μ (WbP赋予)"]
        M4 --> V3["短元音 V"]
        M5 --> C3["韵尾辅音 C"]
    end
```

### 2.1 音拍指派公理

1. **短元音单音拍**：底层词库中的每一个短元音预先指派一个音拍（$1\mu$）；
2. **长元音双音拍**：长元音或双元音在底层预先关联两个音拍（$2\mu$）；
3. **声母辅音零音拍**：声母位置的辅音直接挂载在音节根节点 $\sigma$ 上，永远不获得任何音拍（$0\mu$）。这完美解释了为什么声母堆叠多少辅音都不会增加音节重量；
4. **位置增重原则（Weight by Position, WbP）**：

::: definition 位置增重原则（Weight by Position, WbP）
处于韵基韵尾位置（Coda）的辅音，在特定语言中根据音系参数，被后天赋予一个从属音拍（$\mu$）。
- 若某语言开启了 WbP 参数（如拉丁语、英语、古典阿拉伯语），则 $CVC$ 拥有 $1\mu (\text{元音}) + 1\mu (\text{辅音}) = \mathbf{2\mu}$，被系统正式判定为**重音节**；
- 若某语言关闭了 WbP 参数（如蒙古语、拉迪尔语），则闭音节辅音不获得音拍，$CVC$ 仅有 $1\mu$，与 $CV$ 一样被视作**轻音节**。
:::

## 3. 印地语（Kelkar's Hindi）三级重量竞争

在某些更复杂的语言中，音节重量不仅有轻与重，更细分出**超重音节（Superheavy）**。印地语（Prince & Smolensky 1993 优选论经典分析案例）展现了令人叹为观止的权重极值导向重音：

### 3.1 三级重量阶梯

$$\text{超重音节 (Superheavy, } 3\mu\text{)} > \text{重音节 (Heavy, } 2\mu\text{)} > \text{轻音节 (Light, } 1\mu\text{)}$$
- **超重音节（S）**：包含长元音加韵尾（$CVVC$）或双辅音尾（$CVCC$），承载 $3\mu$；
- **重音节（H）**：长元音开音节（$CVV$）或短元音闭音节（$CVC$），承载 $2\mu$；
- **轻音节（L）**：短元音开音节（$CV$），承载 $1\mu$。

### 3.2 印地语重音决策算法

::: theorem 印地语重音法则
全词主重音必须赋予**全词中最重的那个音节**；若全词存在多个重量完全打平的最高级音节，则**优先赋予最右侧非词尾的那个音节（Rightmost Non-Final Heaviest）**！
:::

::: example 印地语重音推导案例
1. *ka:rí:gari:*（手艺，结构为 $H - H - L - H$）：
   存在三个 $H$ 音节。由于末尾 $H$ 处于词尾，按照“非词尾最右”原则，重音落在第二音节：
   $$\text{重音形式}: \mathbf{ka: \ . \ \mathbf{r\acute{i}:} \ . \ ga \ . \ ri:}$$
2. *só:xjaba:ni:*（健谈，结构为 $H - L - H - H$）：
   首音节为 $H$。按非末尾最右，重音落在首音节：
   $$\text{重音形式}: \mathbf{\mathbf{s\acute{o}:x} \ . \ ja \ . \ ba: \ . \ ni:}$$
3. *ré:zga:ri:*（零钱，结构为 $H - H - H$）：
   中间第二音节为非词尾最右重音节，重音落在首音节与次音节竞争区。
:::

整个过程展现了音拍几何作为严格离散代数在心智计算中的完美落地。

::: insight 音拍理论对时空二元性的终极统摄
音拍理论的伟大之处在于，它用同一个几何度量单位，同时解决了跨语言中两大看似完全独立的领域：**声学时长的物理时间（长元音为双倍音拍时长）**与**形式节律的抽象重量（重音音步的强弱判定）**。音拍是连接物理世界连续声学流与心智世界离散数学语法的宏伟桥梁。
:::

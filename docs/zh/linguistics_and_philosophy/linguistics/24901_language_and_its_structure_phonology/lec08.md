# Lec 08 声学语音学 II：辅音声学特征、冲直条与嗓音起始时间（Acoustics of Consonants）

与元音平稳、准周期的谐波共鸣不同，辅音在声学语图上展现出极其繁复的非稳态动力学特征：瞬态爆破、宽频湍流摩擦、反共振零点以及剧烈的共振峰弯曲。在麻省理工学院 24.901 第九讲中，Michael Kenstowicz 教授结合彼得·拉迪福吉德（Peter Ladefoged）的经典实验体系，系统剖析塞音、擦音、鼻音与流音的声学特征，重点解析**嗓音起始时间（VOT）**的跨语言感知切分以及揭示发音部位的心智线索——**共振峰轨迹与代用焦点理论（Locus Theory）**。

## TL;DR

- **塞音四阶段声学解剖**：成阻闭塞段（静音隙）、除阻瞬间的冲直条（Burst Spike）、气流摩擦以及共振峰过渡段（Transitions）。
- **嗓音起始时间（VOT）**：从爆破除阻到声带起振的时间间隔，跨语言连续统划分为前浊（负 VOT）、不送气（短滞后）与强送气（长滞后）。
- **代用焦点理论（Locus Theory）**：齿龈音 $F_2$ 弯曲轨迹恒定指向约 $1800\text{ Hz}$ 虚拟交点，而软腭音呈现标志性的 $F_2$ 与 $F_3$“软腭夹挤（Velar Pinch）”。
- **鼻音反共振与流音特征峰**：鼻音口腔侧腔充当声学能量陷阱吸除特定频率形成零点（Zeros）；美式英语卷舌音 $[{\text{r}}]$ 则以第三共振峰 $F_3$ 的断崖式骤降为决定性特征。

## 1. 塞音的声学解剖学：闭塞、冲直条与 VOT

在宽带语图上，一个完整的塞音呈现高度模式化的四段结构：

```text
时间轴 ────────►
[ 闭塞段 (Closure) ] ──► [ 除阻爆破 (Burst) ] ──► [ 摩擦/送气 (Aspiration) ] ──► [ 元音起振 (Voicing) ]
无声静音区 (清塞音)         垂直冲直条 (Spike)         非周期性湍流白噪声            声带周期性条纹展开
或低频浊音杠 (浊塞音)       瞬态能量释放
                     │◄─────────────────── VOT ────────────────────►│
```

1. **闭塞段（Closure Silence / Voice Bar）**：发音器官完全封闭，声道无声波逸出，语图呈现空白静音区。若为带声浊塞音（如 $[b, d, g]$），语图最底部会出现微弱的低频基频振动带，称为**浊音杠（Voice Bar）**；
2. **冲直条（Release Burst Spike）**：口腔阻塞突然拉开，高压气流瞬间释放造成冲激响应，在语图上表现为一条贯穿全频段的极其细窄（$< 5\text{ ms}$）的垂直黑条；
3. **嗓音起始时间（Voice Onset Time, VOT）**：

::: definition 嗓音起始时间（Voice Onset Time, VOT）
从塞音**除阻爆破释放（Burst）的精确瞬间**，到后续元音**声带开始周期性闭合振动（Voicing Onset）**之间的时间间隔（以毫秒 ms 计）。
:::

根据 VOT 沿时间轴的相对位置，全球语言将塞音划分为三大类：

| VOT 类别 | 时间参数 | 声学机制与跨语言表现 | 代表语言范例 |
| :--- | :---: | :--- | :--- |
| **完全带声 / 前浊 (Voicing Lead)** | $\text{VOT} < 0\text{ ms}$<br>($-120\text{--}-30\text{ ms}$) | 在除阻爆破之前，声带已经开始持续振动，产生显著的 Voice Bar | 法语、西班牙语、俄语、泰语 $/b, d, g/$ |
| **清不送气 / 短滞后 (Short Lag)** | $0 \le \text{VOT} \le +25\text{ ms}$ | 爆破释放瞬间或极其微小延迟后，声带立即无缝起振 | 英语 $/s/$ 后的 $[p, t, k]$、汉语拼音 $b, d, g$ |
| **清送气 / 长滞后 (Long Lag)** | $\text{VOT} > +40\text{ ms}$<br>($+50\text{--}+100\text{ ms}$) | 除阻后声门维持宽阔开张，强烈气流经过声门发生剧烈湍流，声带显著推迟起振 | 英语词首 $[p^h, t^h, k^h]$、汉语拼音 $p, t, k$ |

## 2. 共振峰轨迹与代用焦点理论（Formant Transitions & Locus Theory）

塞音本身是一瞬间的阻断，听觉系统如何仅仅凭借声音就分辨出说话人发的是 $[b]$、$[d]$ 还是 $[g]$？
哈斯金斯实验室（Delattre, Liberman & Cooper 1955）通过合成语音实验证实：**后续元音起始段共振峰的弯曲滑动（Formant Transitions）是决定发音部位的核心感知线索**。

::: theorem 焦点理论（Locus Theory）
当发音器官从塞音闭塞姿态向后续元音转换时，声道的连续几何形变导致共振峰产生特定方向的滑动。不同发音部位对应着虚拟的共振峰起源极点——**代用焦点（Locus）**：
1. **双唇音（Bilabial $[p, b]$）**：唇部闭合整体极度拉低所有共振峰频率。因此在释放进入元音时，$F_2$ 与 $F_3$ 始终**自低位向上弯曲攀升**（虚拟焦点极低，约为 $700\text{--}800\text{ Hz}$）；
2. **齿龈音（Alveolar $[t, d]$）**：无论后续连接什么元音，$F_2$ 的过渡起始轨迹始终**恒定地反向延长指向约 $1800\text{ Hz}$** 的固定虚拟频率点；
3. **软腭音（Velar $[k, g]$）**：由于舌背与软腭接触，在除阻瞬间第二共振峰 $F_2$ 与第三共振峰 $F_3$ 在频率轴上极度靠近甚至完全粘合在一起，在语图上呈现标志性的**“软腭夹挤（Velar Pinch）”**形态。
:::

```text
   双唇音 [ba]                  齿龈音 [da]                  软腭音 [ga]
F2/F3 从极低处向上飞跃           F2 始终坚定指向 1800 Hz       F2 与 F3 在起始端夹挤黏合
kHz                           kHz                           kHz
3 |   ======= (F3)            3 |   ------- (F3)            3 |     /==== (F3)
  |  /                          |                           |    /
2 | / ======= (F2)            2 | ----\ ======= (F2)        2 | <=<====== (F2, 软腭夹挤)
  |/                            |      \                    |
1 |                           1 |                           1 |
```

## 3. 擦音、鼻音与流音的声学图谱

### 3.1 擦音（Fricatives）：湍流噪声与嘈吵度

擦音在语图上表现为持续的、非周期性的宽频杂乱噪声：
- **嘈吵咝音（Sibilants $[s, z, \int, 3]$）**：气流射向锐利的下齿障碍物，噪声能量极大，边缘清晰。$[s]$ 的共鸣腔极短，噪声集中在 $4500\text{--}8000\text{ Hz}$ 超高频；而 $[\int]$ 由于舌位后移且常伴随圆唇，前端腔体变长，能量中心下移至 $2500\text{--}3500\text{ Hz}$；
- **非嘈吵擦音（Non-sibilants $[f, v, \theta, \eth]$）**：气流未受坚硬齿刃剧烈阻截，能量微弱且在整个频带上弥散平坦。

### 3.2 鼻音（Nasals）：鼻音杂音与反共振零点（Zeros）

鼻音具有极其独特的双腔结构：口腔处于封闭盲端，气流从鼻腔逸出。
1. **鼻音杂音（Nasal Murmur）**：在 $250\text{--}300\text{ Hz}$ 处呈现一条能量极强的低频暗带；
2. **反共振零点（Antiformants / Zeros）**：封闭的口腔像一个声学黑洞，在特定驻波频率下完全吸除声能，导致语图在对应频段出现苍白的“能量真空白区”。
   - 双唇鼻音 $[m]$：口腔较深，零点位于较低频（$\sim 750\text{--}1000\text{ Hz}$）；
   - 齿龈鼻音 $[n]$：口腔较浅，零点上移至 $\sim 1500\text{--}2000\text{ Hz}$；
   - 软腭鼻音 $[\eta]$：口腔最短，零点位于 $3000\text{ Hz}$ 以上。

### 3.3 美式英语卷舌流音 $[{\text{r}}]$ 的声学印记

在英语所有辅音中，美式齿龈后近音 $[{\text{r}}]$ 拥有全世界最独特的声学指纹：**第三共振峰 $F_3$ 的断崖式暴跌**。
正常人类元音的 $F_3$ 稳定在 $2500\text{ Hz}$ 左右，但在发美式 $[{\text{r}}]$ 时，舌尖卷起或舌身隆起使咽腔和舌下腔体产生极端的声学调制，将 $F_3$ 直接下拉至 $1600\text{--}1800\text{ Hz}$，几乎与 $F_2$ 紧贴。任何语音识别算法只要捕获到 $F_3$ 的深度凹陷，即可百分之百判定为 $[{\text{r}}]$。

::: insight 语图读音作为逆向工程
声学语图是人类声道运动在频域留下的复杂全息投影。阅读语图如同侦探破案：从静音与冲直条定位塞音，从 VOT 测量声门状态，从共振峰过渡轨迹重构发音部位，从 $F_3$ 骤降识别流音。这一物理图景为抽象音系特征（如 $[+\text{coronal}], [+\text{strident}]$）提供了不容辩驳的物理现实性支撑。
:::

::: pitfall 忽略辅音与相邻元音的协同发音（Coarticulation）
辅音并不是一个个孤立的刚体拼图。在实际语音流中，软腭塞音 $[k]$ 在前元音 $[i]$ 前发音位置显著前移，在后元音 $[u]$ 前显著后移。这种发音器官物理惯性带来的共振峰位移是连续生理适应，切勿将其机械割裂为主观音位的替换。
:::

# Lec 10 路面坑洞检测与移动感知（Pothole Detection & Mobile Sensing）

> MIT 6.1820 / MAS.453 · Mobile and Sensor Computing  
> 阅读材料：Pothole Patrol [MobiSys'08] — MIT CSAIL

## TL;DR

- Pothole Patrol 将出租车队作为机会性移动计算节点，实现城市级道路质量的极低成本普查。
- 四级级联过滤器依次通过车速高通、$z$ 轴冲击峰值、$xz$ 轴比率与车速归一化筛除干扰事件。
- 优化目标函数重度惩罚误报（$\text{incorrect}^2$），以算法保守性换取市政决策的绝对信任。
- 中心化空间聚类要求同一坐标多次独立触发才判定为真实坑洞，有效过滤瞬态环境噪声。

## 1. 问题背景：市政基建与机会性感知

道路表面的沥青老化、冻融循环与重车碾压必然导致路面破损，形成危险的**坑洞（Pothole）**。坑洞不仅导致汽车爆胎与底盘受损，甚至引发恶性交通事故。传统市政维护依赖市民热线投诉或昂贵的专用激光检测车，导致路面巡检周期长达数月乃至数年。

MIT CSAIL 团队在 2008 年提出了 **Pothole Patrol（简称 $P^2$）** 系统，首次验证了以出租车队为载体的大规模移动众包感知可行性。

::: definition 机会性感知（Opportunistic Sensing）
系统不构建专用的传感器巡检车队，而是将低成本感知硬件寄生在既有的社会化移动载体（出租车、公交车、物流货车或市民智能手机）上。载体按照其原生的社会生活轨迹自然移动，系统“机会性”地采集物理世界数据，并通过延迟容忍网络（DTN）在路过开放 Wi-Fi 或蜂窝基站时异步回传。
:::

## 2. 硬件架构与车载力学基准

在智能手机尚未普及的 2008 年，$P^2$ 团队在波士顿和剑桥市的 7 辆营运出租车上部署了试验套件：
- **微型车载工控机（Node）**：置于副驾驶手套箱内，连接汽车电瓶供电；
- **外置 380 Hz 三轴加速度计**：高频采集路面垂直与水平冲击振动；
- **车顶外置 GPS 模块**：提供秒级地理位置、行驶朝向与实时航速；
- **802.11 外置无线网卡**：在出租车回场站或路过开放热点时机会性回传。

每条传感器日志元组格式为：`[Timestamp, Lat, Lon, Speed, a_x, a_y, a_z]`。

### 传感器物理固定位置选型

加速度计的安装介质对高频振动信号具有不可逆的机械滤波效应：

::: example 加速度计车载安装位置对比
1. **直接粘贴在手套箱电脑外壳**：汽车仪表台内部的塑料支架与减震海绵构成了低通机械滤波器，将路面坑洞的高频冲击吸收殆尽，信号严重失真；
2. **挡风玻璃吸盘贴附**：信号拾取良好，但长期日晒导致吸盘脱落，且线缆遮挡驾驶员视野；
3. **刚性螺栓固定在副驾驶仪表台底部金属支架**：**最优方案**。车体悬挂系统的冲击能无损传导至传感器，信号信噪比最干净。
:::

车辆行驶坐标轴定义：
- $a_y$：沿汽车前进方向（正向加速 / 刹车制动）；
- $a_x$：横向水平方向（急转弯 / 变道变向）；
- $a_z$：垂直地面方向（路面颠簸、下沉井盖与**核心坑洞特征**）。

## 3. $P^2$ 级联异常检测流水线

出租车在城市行驶过程中会频繁遭遇减速带、铁路平交道口、下沉井盖、桥梁伸缩缝、急刹车以及乘客大力关门。绝大部分颠簸都不是需要修补的沥青坑洞。

为了在资源受限的车载端实时剔除伪事件，$P^2$ 设计了以 256 采样点（约 0.67 秒窗口）为步长递推的**四级级联特征过滤器（Cascade Filter）**：

```text
原始加速度流 (380 Hz)
   │
   ▼ 过滤器 1: 车速高通门槛 (Speed High-Pass Filter)
   │   排除低速停车、红灯起步、减速带掉头（v < 20 km/h 冲击不具备物理破坏性）
   ▼
   ▼ 过滤器 2: 垂直冲击绝对峰值 (Z-Peak Filter)
   │   要求 |a_z| 瞬态冲击突破加速度基线阈值 θ_z，直接过滤平稳路面微小抖动
   ▼
   ▼ 过滤器 3: 横垂比值约束 (XZ-Ratio Filter)
   │   检查比值 |a_x| / |a_z| < t_x：急打方向盘产生的侧向力 a_x 远超坑洞垂直力
   ▼
   ▼ 过滤器 4: 速度归一化冲击比 (Speed vs. Z-Ratio Filter)
       车辆以 60 km/h 撞击小坑的 a_z 可能远大于 20 km/h 撞击深坑
       利用动力学模型 a_z_norm = a_z / v 对速度进行归一化除法
   │
   ▼
触发“疑似坑洞事件”（写入候选日志，准备上传）
```

### 3.1 非对称惩罚目标函数与参数训练

检测器中包含一组核心可调物理阈值向量 $\mathbf{t} = \{\theta_z, t_x, t_s\}$。如何确定这组阈值？

系统采集了约 280 个由工程师实地勘验的手工标注事件（包含真实坑洞、完好井盖、铁轨、伸缩缝等 5 类样本）。

::: theorem 假阳性平方惩罚目标函数
在市政管理实践中，**假阳性（False Positive, 误报）的危害远大于假阴性（False Negative, 漏报）**：
- 如果系统误报率高，市政工人们驱车数公里到达现场却发现路面完全平整，市政部门将迅速丧失对系统的信任，导致整套系统被彻底废弃；
- 如果系统偶尔漏报一个坑洞，下次其他出租车再次经过时仍有极大概率补测捕获。

因此，$P^2$ 放弃了传统的对称准确率（Accuracy），提出了重度非对称惩罚的目标函数：

$$s(\mathbf{t}) = N_\text{correct} - \left(N_\text{incorrect}\right)^2$$

通过对误报数量施加**平方惩罚**，优化算法被迫将阈值推向极度“保守”区间，哪怕牺牲一部分灵敏度，也必须确保报出的每一个候选点都具备极高的置信度。
:::

## 4. 中心端空间聚类过滤（Spatial Clustering）

即使车载端过滤器极其严格，单辆出租车压过易拉罐或石子仍可能偶尔产生孤立的伪触发。

$P^2$ 的最终决胜点在于利用群体智能在云端执行**空间聚类共识**：

```text
出租车 Taxi A 在坐标 (x, y) 报告坑洞事件
出租车 Taxi B 在坐标 (x, y) 报告坑洞事件 (数小时后)
出租车 Taxi C 在坐标 (x, y) 报告坑洞事件 (次日)
出租车 Taxi D 在坐标 (x, y) 报告坑洞事件 (三天后)
    │
    ▼ 空间距离 ≤ 10m 聚类聚合
[ 满足共识门限: 独立检测次数 ≥ 4 ] ──> 最终收录入市政维修工单系统！
```

::: definition 空间共识准则
中央服务器对所有上传的候选事件按 GPS 半径 10 米执行空间网格聚类。**唯有当同一空间网格内被至少 4 次独立的车辆行驶事件重复触发时**，系统才正式向市政工单系统报送一个确诊坑洞。孤立的瞬态干扰随着时间推移被自动作为噪声遗忘。
:::

## 5. 实战检验与市政验证数据

7 辆出租车在波士顿和剑桥市历时 10 天的真实测试中产出惊人成果：
- **覆盖里程**：累计行驶 9730 公里，去重后覆盖了 2492 公里的独立市政道路；
- **处理规模**：累计分析超过 140 万个时域分析窗口；
- **盲测地面实勘（Ground-truth Verification）**：团队对系统报送的 48 个候选坑洞进行人工实地路勘：
  - **真实沥青破损坑洞**：39 处；
  - **严重下沉凹陷井盖**：3 处（在市政标准中同样需要抬升修复）；
  - **下陷铁轨平交口**：4 处；
  - **无法查验或误报**：仅 2 处；
- **真实精确度（Precision）**：$\ge 81.25\%$（若将需修复的下沉井盖计入，可用率达 $87.5\%$）；在平坦高速公路（Storrow Drive）的实测误报率低于 $0.2\%$。

## 6. 城市机会性感知系统的设计哲学

::: insight
Pothole Patrol 为普适计算与城市物联网系统树立了一座丰碑，其成功经验在当今边缘 AI 时代依然发人深省：
1. **不要试图在端侧单点解决所有问题**：学术界往往倾向于在单个节点上训练极度复杂的深度学习模型，试图做到 99% 的单次检测准确率。而 $P^2$ 的核心智慧在于“分工”：车载边缘端仅运行计算极轻量、解释性极强的四级级联过滤器，把数据量压缩数千倍；而将最终的抗噪决胜权交给云端的“多车空间聚类共识”。
2. **理解真实世界业务系统的损失不对称性**：在机器学习课程中，交叉熵损失（Cross-Entropy）默认对各类错误一视同仁；但在现实政企工程中，错误类型的后果是极度不对称的。将业务领域的不对称代价显式编码为数学目标函数（如 $(N_{incorrect})^2$），是使算法走出实验室、被真实世界采纳的生死关键。
:::

# Lec 4 穿墙感知与无设备定位（Seeing through Walls & Device-Free Localization）

> MIT 6.1820 / MAS.453 · Mobile and Sensor Computing  
> 阅读材料：WiTrack [NSDI'15] — MIT CSAIL

## TL;DR

- 无设备定位通过捕捉无线电回波反射，免除目标携带任何专用终端的硬性约束。
- FMCW 雷达通过扫频发射与回波混频生成拍频信号，经 FFT 将微小时延映射为高精度距离。
- 静态多径消除通过时域差分滤除静止墙面与家具强反射，将动态人体微弱回波提取出来。
- 双天线对建立两条交叠椭圆约束方程，解算交点并结合先验即可实现厘米级穿墙二维定位。

## 1. 动机与无设备感知挑战

传统的室内外定位系统（如 GPS、Wi-Fi 指纹、UWB）都隐含了一个关键假设：**被定位的目标必须随身佩戴并供电一个专用硬件标签或手机**。

然而在现实场景中，这种假设往往被无情打破：
- **养老健康与独居监护**：老年人突发跌倒时往往未随身携带手机，手环可能因忘充电而离线。
- **搜救与火灾应急**：消防员与搜救队必须隔着坍塌墙体或浓烟浓雾确定幸存者的具体房间与坐标。
- **家庭入侵检测与安防**：入侵者绝不会主动连接家庭 Wi-Fi 或携带可追踪的信标。

::: definition 无设备定位（Device-Free Localization）
被感知对象无需穿戴、携带或操作任何专用电子标签或无线终端；系统完全利用电磁波在人体表面（水分子与导电组织）产生的反射、散射与遮挡，通过对空间射频场的逆向解算推断目标的三维坐标、运动轨迹乃至生命体征。
:::

### 核心物理瓶颈

1. **人体回波极其微弱**：人体表面的雷达散射截面积（RCS）通常小于 $1\text{ m}^2$，经过穿墙往返双重衰减后，反射功率比直射信号弱 40–80 dB。
2. **压倒性的静态多径干扰（Static Multipath）**：雷达发射的无线电波绝大部分能量被厚重的混凝土墙体、金属柜、天花板和混凝土地板直接反射，其反射强度高出人体数个数量级。
3. **严重非视距（NLOS）传播**：在视距被完全物理阻隔的前提下，必须精准剥离墙体介电常数引起的电磁波折射与速度滞后。

## 2. 调频连续波（FMCW）雷达原理

WiTrack 系统摒弃了超短纳秒脉冲雷达，采用更易实现高线性度的**调频连续波（FMCW, Frequency-Modulated Continuous Wave）**雷达，工作频段跨越 5.46 GHz 至 7.25 GHz。

### 2.1 扫频与拍频信号生成

FMCW 雷达持续发射载频随时间线性爬升的 Chirp 信号：在持续时间 $\tau_{chirp}$ 内，发射频率从 $f_0$ 线性扫描至 $f_0 + B$（带宽 $B$）：

$$f(t) = f_0 + \frac{B}{\tau_{chirp}} \cdot t$$

电磁波传播至距离 $d$ 的反射体并返回接收端，经历时间延迟 $\tau = \frac{2d}{c}$。

```text
频率 f
  ^
  |      发射信号 (Tx)
  |     /              接收回波 (Rx, 延迟 τ)
  |    /              /
  |   /              /
  |  /              /   |← 拍频差 f_beat →|
  | /              /
  +--------------------------------------------> 时间 t
```

接收端将回波信号与当前发射信号输入模拟混频器（Mixer），滤除高频和频分量后，输出两者的差频信号——**拍频信号（Beat Frequency, $f_\text{beat}$）**：

$$f_\text{beat} = \frac{B}{\tau_{chirp}} \cdot \tau = \frac{B}{\tau_{chirp}} \cdot \frac{2d}{c}$$

对拍频信号做快速傅里叶变换（FFT），频谱中每一个峰值的频率位置 $f_{beat}$ 直接线性对应一个物理反射体的距离：

$$d = \frac{c \cdot \tau_{chirp} \cdot f_\text{beat}}{2B}$$

::: theorem 距离分辨率与物理带宽的关系
FMCW 雷达能够区分两个沿径向排列物体的最小物理距离间隔为**距离分辨率（Range Resolution）**：

$$\Delta d = \frac{c}{2B}$$

WiTrack 系统占用带宽 $B = 1.79\text{ GHz}$，对应理论距离分辨率：

$$\Delta d = \frac{3 \times 10^8}{2 \times 1.79 \times 10^9} \approx 0.0838\text{ m} \approx 8.4\text{ cm}$$

该精度足以在空间频谱中将人体躯干的微小位移从相邻墙面反射中解耦出来。
:::

## 3. 静态多径消除算法：时域差分

在原始 FFT 距离轮廓（Range Profile）中，墙壁反射形成的巨大峰值会彻底吞没人体微弱的旁瓣。

WiTrack 的核心破解法在于：**环境中所有的建筑结构与家具都是绝对静止的，唯有人体是处于持续微动状态的动态源**。

```text
当前帧 Range Profile  S_current(f)    ──┐
                                        ├── (差分减法) ──> 动态回波 S_dynamic(f)
参考背景帧 (均值滤波) S_background(f) ──┘
```

$$S_\text{dynamic}(f, t) = S_\text{current}(f, t) - \frac{1}{K}\sum_{k=1}^{K} S_\text{current}(f, t - k)$$

通过滑动窗口消除直流分量与背景基线，静止的墙面多径被数学清零，距离谱线上仅留下目标由于走动、肢体摆动甚至呼吸所产生的动态残留峰值。

## 4. 双天线对椭圆交点几何定位

WiTrack 采用一个中央发射天线（Tx）与多个空间分置的定向接收天线（Rx）构成双基地（Bistatic）天线对。

### 4.1 单收发对约束：等距离椭圆

在双基地配置下，电磁波从 Tx 出发，经人体反射到达 Rx，总传播光程为：

$$d_{Tx} + d_{Rx} = r_i = c \cdot \tau_i$$

在二维几何中，两焦点到椭圆上任意点距离之和为常数。因此，**单个 Tx-Rx 对仅能确定目标必然位于以 Tx 与 Rx 为两个焦点的空间椭圆上**。

### 4.2 双收发对约束：双椭圆相交解算

部署两组空间分置的接收天线 $Rx_1$ 与 $Rx_2$，系统即可同时解算两条共用焦点 Tx 的椭圆曲线：

$$\begin{cases} \sqrt{(x - x_{Tx})^2 + (y - y_{Tx})^2} + \sqrt{(x - x_{Rx_1})^2 + (y - y_{Rx_1})^2} = r_1 \\ \sqrt{(x - x_{Tx})^2 + (y - y_{Tx})^2} + \sqrt{(x - x_{Rx_2})^2 + (y - y_{Rx_2})^2} = r_2 \end{cases}$$

::: example 为什么双椭圆交点能消除空间模糊？
数学上，平面内两条不重合的椭圆最多可相交于 4 个点。然而：
1. 雷达天线具备半功率波束角（例如朝向前向半平面 $y > 0$），排除了背向平面的对称交点；
2. 结合室内高度先验（人体躯干中心通常位于离地 $1.0 \sim 1.5\text{ m}$ 处），系统可以将候选解精确收敛至唯一的二维物理坐标 $(x, y)$。
:::

## 5. 微动感知：静止人体呼吸与生命体征提取

当房间内人员完全停止走动（如睡眠、跌倒昏迷）时，时域差分法提取的宏观位移峰值将消失。WiTrack 进一步利用电磁波**载波相位**对亚毫米级位移的极致敏感性进行补盲。

人体静止时，胸腔由于心肺呼吸会产生幅度约 $5 \sim 15\text{ mm}$ 的周期性起伏。微小距离变化 $\Delta d(t)$ 会导致 FMCW 回波峰值处的相位发生极其显著的旋转：

$$\Delta\phi(t) = \frac{4\pi \Delta d(t)}{\lambda}$$

在 6 GHz 频段（$\lambda \approx 5\text{ cm}$），$1\text{ cm}$ 的胸腔位移引起相角变化：

$$\Delta\phi = \frac{4\pi \times 0.01}{0.05} \approx 2.51\text{ rad} \approx 144^\circ$$

::: theorem 慢时间维频域滤波
系统沿雷达帧序列时间轴（慢时间维 Slow-time Axis）提取目标距离 Bin 处的相位演化波形 $\phi(t)$，对其执行时域带通滤波或次级 FFT：
- **呼吸频率（Respiration）**：集中于 $0.1 \sim 0.5\text{ Hz}$（每分钟 6–30 次）；
- **心跳微动（Heart Rate）**：微弱谐波分布于 $0.8 \sim 2.0\text{ Hz}$（每分钟 50–120 次）。  
系统无需直接接触，隔着墙壁即可判定室内是否存活具有生命体征的人类。
:::

## 7. 无线感知边界与物理层启示

::: insight
WiTrack 开启了从“无线通信”跨界到“无线感知”（Integrated Sensing and Communication, ISAC）的新纪元。其背后的系统工程洞见深刻改变了移动计算的研究范式：
1. **多径从“信道噩梦”变为“成像光源”**：在传统通信设计中，多径是引起符号间干扰（ISI）和深度衰落的元凶；而在 WiTrack 视角下，多径与反射正是照亮物理世界未知轮廓的雷达信号。只要带宽足够宽（大 $B$ 赋予高时域分辨），多径反射在时域就能够被逐一切开并反演为空间几何边界。
2. **射频对光学的降维补充**：光学摄像头在光照不足、浓烟、衣物遮挡及墙体阻隔下彻底致盲，且面临极其敏感的隐私侵犯争议；射频雷达以极其隐蔽的厘米波波长，在保留关键几何与生命体征的同时天然保护了人体外貌隐私，成为普适计算中最具前景的物理感知介质。
:::

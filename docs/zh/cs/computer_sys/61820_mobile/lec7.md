# Lec 7 无电池通信与智慧城市（Batteryless Connectivity & Smart Cities）

> MIT 6.1820 / MAS.453 · Mobile and Sensor Computing  
> 阅读材料：Hacking RFIDs，Caraoke [MobiSys'13]

## TL;DR

- 被动 RFID 依靠射频整流收集连续波能量，通过调制天线反射阻抗实现微瓦级反向散射。
- EPC Gen2 采用分时隙 Aloha 机制，通过动态自适应 $Q$ 参数将并发防碰撞效率稳定在 $1/e \approx 37\%$。
- 无认证与明文广播使被动标签易受窃听、克隆与重放攻击，需权衡计算成本引入轻量认证。
- Caraoke 展现了机会性复用高速公路 ETC 既有 RFID 基础设施实现城市级路况感知的极低成本模式。

## 1. 射频识别（RFID）与反向散射物理原理

在数十亿微型物体（如零售服装、仓储纸箱、药品试管）上部署电池不仅经济成本不可承受，后续电池回收与环境污染更是灾难。**无电池射频识别（RFID）**是物联网实现“泛在连接”的终极技术之一。

### 1.1 RFID 标签分类矩阵

::: definition RFID 标签类型分类
- **低频（LF, 125–134 kHz）**：波长长、穿透水和生物组织能力强，读取距离约数厘米，常用于动物芯片与汽车防盗芯片。
- **高频（HF, 13.56 MHz / NFC）**：近场电磁感应耦合，距离小于 10 cm，用于非接触式公交卡与移动支付。
- **超高频（UHF, 860–960 MHz）**：远场电磁辐射传播，读取距离可达 5–12 米，读写速率达数百 kbps，是供应链物流与零售行业事实上的全球标准。
- **主动标签 vs 被动标签**：**主动标签（Active Tag）**自带电池自发辐射；**被动标签（Passive Tag）**内部零电池，纯靠吸收读取器发出的电磁波工作。
:::

### 1.2 能量收集与阻抗调制反向散射（Backscatter）

被动 RFID 标签绝不消耗自身能源生成射频载波，而是扮演一个“可控电磁反射镜”：

```text
       ┌──────────────┐                  ┌─────────────┐
       │ RFID 读写器  │                  │  被动标签   │
       │  (Reader)    │ ── 连续波 (CW) ─> │ 能量收集电路│
       │              │                  │      │      │
       │ 接收反射调制 │ <─ 反向散射波 ─── │ 负载开关调制│
       └──────────────┘                  └─────────────┘
```

1. **射频能量收集（Energy Harvesting）**：读取器发射高功率连续波（CW, Continuous Wave）。标签天线接收微弱交变高频电信号，经由肖特基二极管阶梯倍压整流电路（Cockcroft-Walton 电荷泵）将交流射频整流为直流电，并积聚在片上电容中：

   $$V_\text{harvested} = \eta \cdot \sqrt{\frac{P_{rx} \cdot Z_A}{2}}$$

   其中 $\eta$ 为整流转换效率，$Z_A$ 为天线复阻抗。当电容电压越过启动阈值（通常仅 $0.5 \sim 1.2\text{ V}$），超低功耗数字逻辑电路瞬间复苏。
2. **反向散射调制（Backscatter Modulation）**：微控制器根据待发送的数据比特，通过一个简单的晶体管开关切换天线后级并联的**负载阻抗（Load Impedance, $Z_L$）**：
   - **阻抗匹配状态（$Z_L = Z_A^*$）**：天线最大吸收射频电磁波能量注入芯片，反射系数 $\Gamma = 0$，向外反射极微弱；
   - **阻抗失配状态（$Z_L \to 0$ 或 $Z_L \to \infty$）**：天线无法吸收能量，电磁波被几乎 100% 弹回空间，反射系数 $|\Gamma| \approx 1$。

通过在“吸收”与“全反射”之间快速切换，标签以开关键控（OOK）或二进制相移键控（BPSK）将自身电子产品代码（EPC）调制进反射波中。

::: theorem 反向散射的功耗降维打击
传统的主动无线电发射机需要耗电巨大的本振（Local Oscillator）、混频器和功率放大器（PA），发送功耗通常在 $10 \sim 100\text{ mW}$ 级别。
而反向散射仅需翻转一颗 CMOS 晶体管栅极开关，功耗仅为数微瓦（$\mu\text{W}$），耗电量骤降 **1000 到 10000 倍**，这是无电池标签能够“长生不死”的物理基石。
:::

## 2. EPC Gen2 协议与分时隙 Aloha 防碰撞机制

当货架上数百个贴有标签的货品进入同一读取器的天线波束覆盖区时，所有标签同时被能量唤醒并反射信号，空中反射波在空间发生剧烈碰撞，读取器将无法解调任何信息。

### 2.1 分时隙 Aloha（Slotted Aloha）协调机制

EPC Gen2 国际标准采用了读取器主导的分时隙 Aloha 竞争协议：

```text
Reader: 发送 Query 命令 (宣布时隙窗口大小 Q, 共有 2^Q 个时隙)
   │
   ├─> Tag 1: 在本地伪随机选择时隙 Slot = 0  ──> 立即回应 16-bit 随机句柄 RN16 ──> [成功独占读取]
   ├─> Tag 2: 在本地伪随机选择时隙 Slot = 3  ──> 计数器递减等待...
   └─> Tag 3: 在本地伪随机选择时隙 Slot = 3  ──> [时隙 3 碰撞崩溃]
```

1. **时隙宣布**：读取器向空中广播 `Query` 帧，指定整数参数 $Q$。此时空中有 $S = 2^Q$ 个离散时隙。
2. **随机槽位选择**：每个被唤醒的标签利用内部随机数发生器，在区间 $[0, 2^Q - 1]$ 内独立均匀抽取一个整数时隙计数器。
3. **时钟递减与响应**：时隙为 0 的标签立即回应 16 位随机短句柄（RN16）；其余标签在读取器每发送一个 `QueryRep` 脉冲后将本地计数器减 1。

### 2.2 吞吐量数学推导与极限

假设空间中有 $N$ 个活跃标签，竞争时隙总数为 $S$：

::: example 最优时隙数与 37% 效率上限推导
任一时隙恰好只有一个标签选中的概率（单次成功读取概率）：

$$P_\text{success} = \binom{N}{1} \left(\frac{1}{S}\right)^1 \left(1 - \frac{1}{S}\right)^{N-1} = N \cdot \frac{1}{S} \left(1 - \frac{1}{S}\right)^{N-1}$$

整轮读取的归一化吞吐量为：

$$\text{Throughput}(S) = S \times P_\text{success} = N \left(1 - \frac{1}{S}\right)^{N-1}$$

对 $S$ 求导可知，当且仅当时隙数等于并发标签数（$S = N$）时，吞吐量达到数学极值。当 $N \to \infty$ 时：

$$\lim_{N \to \infty} \left(1 - \frac{1}{N}\right)^{N-1} = \frac{1}{e} \approx 0.368$$

**结论**：即使在理想最优时隙配置下，分时隙 Aloha 的空中信道利用率上限仅为 **36.8%**（其余 63.2% 的时隙要么是无人选择的空闲槽，要么是多标签相撞的死锁槽）。
:::

### 2.3 Gen2 自适应动态调整机制（Q-Algorithm）

在未知货品密度的仓库中，读取器事先并不知道空间中有多少个标签（$N$ 未知）。EPC Gen2 引入动态增量算法：
- 若读取器在当前时隙检测到碰撞（Collision），说明槽位过少，将浮点数 $Q_{fp} \leftarrow Q_{fp} + c$；
- 若检测到空时隙（Empty Slot），说明槽位过剩，将浮点数 $Q_{fp} \leftarrow Q_{fp} - c$；
- 每次调整后对 $Q = \text{round}(Q_{fp})$ 取整更新下一个周期，使整个系统自适应追踪最大吞吐点。

## 3. 安全漏洞反思：Hacking RFIDs

由于被动标签内部硬件逻辑门电路极其受限（仅数百至数千个逻辑门），绝大多数商业 UHF RFID 标签放弃了密码学安全防线：

1. **无认证明文广播（Eavesdropping）**：任何人手持一台商用高功率读取器，都可以在数米外静默扫描读取用户背包中物品的唯一 EPC 码，导致用户资产与偏好泄露。
2. **零门槛克隆（Cloning Attacks）**：早期的电子护照或办公门禁卡未引入挑战-响应机制，攻击者仅需抓取一次卡片返回的静态 ID，写入可写白卡即可克隆伪造。
3. **隐蔽重放攻击（Replay Attacks）**：即使引入简单的静态加密哈希，缺乏动态随机数（Nonce）挑战的握手过程依然会被旁路抓包工具完整录制并重放。

## 4. Caraoke：复用 ETC 基础设施的城市感知网络

当智慧城市面临“高昂的路侧监控摄像头与线圈传感器铺装成本”时，MIT 团队在 MobiSys'13 提出了 **Caraoke** 系统，开创了机会性感知的新范式。

```text
高速路 ETC 龙门架 (既有 E-ZPass RFID 读取器)
   │
   ├─> 车辆 A 经过: 记录 <Tag_ID_A, Timestamp_t1, Gate_1>
   │
   ▼ (车辆沿高速行驶数公里)
下一个收费站龙门架
   │
   └─> 车辆 A 经过: 记录 <Tag_ID_A, Timestamp_t2, Gate_2>
         │
         ├──> 计算平均区间车速: v = (Gate_2 - Gate_1) / (t2 - t1)
         ├──> 统计道路车流量与突发拥堵预警
         └──> 零新增基建成本实现全城交通热力学画像
```

::: theorem 机会性基础设施复用哲学
Caraoke 不向城市路网追加任何一个新传感器，而是将原本仅用于收费扣费的 E-ZPass RFID 读写龙门架作为城市级大容量“速度与流向探针”。通过挖掘海量过车数据的时间差，以极低软件成本实时呈现整个波士顿城区的路况热力图。
:::

::: pitfall 位置轨迹窃取的隐私悖论
Caraoke 展现了基建复用的强大威力，但同时也暴露了巨大的隐私隐患：固定车辆的 E-ZPass ID 是不可变更的硬件指纹。如果政府或恶意第三方汇聚跨龙门架的数据，便能以秒级精度完整复原全市上百万市民的完整日常生活通勤轨迹。隐私保护学者由此提出采用密码学假名轮换（Pseudonym Rotation）机制来隔离长程追踪。
:::

## 5. 零功耗反向散射与基础设施复用启示

::: insight
从 EPC Gen2 到 Caraoke，本讲贯穿着一种颠覆性的系统架构思维：
1. **不要试图给所有节点供电，而是让物理世界自发反射**：主动无线电协议总是在追求提高电池能量密度，而反向散射彻底跳出了“能量存储”的思维定势。它让微型设备寄生于空间环境中的射频能量场，通过调制天线物理边界条件实现信息编码。这种“以静制动”的系统设计，代表了绿色物联网与万物互联的终极技术形态。
2. **数据资产的二次挖掘胜过重造轮子**：Caraoke 证明了一个优秀的系统架构师不应该总是热衷于“采购最新的传感器套件进行全域铺设”，而应当具备洞察空间中已存基础设施（如 ETC 收费站、Wi-Fi 探测、路灯电网）的洞察力。通过纯算法和数据融合对既有系统的旁路信息进行升维重构，往往能以近乎零的边际成本解决原本需要数亿美元才能完成的工程命题。
:::

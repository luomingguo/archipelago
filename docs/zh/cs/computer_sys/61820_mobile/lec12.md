# Lec 12 海洋物联网与水下反向散射（Ocean IoT & Underwater Backscatter）

> MIT 6.1820 / MAS.453 · Mobile and Sensor Computing  
> 阅读材料：PAB [ACM SIGCOMM'19 / HotNets'20] — MIT Media Lab

## TL;DR

- 海水导电性导致射频通信与 GPS 信号急剧衰减，传统主动水声调制解调器功耗高达数百瓦。
- 压电声学反向散射（PAB）利用压电陶瓷切换负载阻抗反射声波，将节点功耗压缩至微瓦级。
- 压电材料窄带谐振特性阻碍频分复用，通过可编程阻抗电路使节点谐振频点受控偏移实现 FDMA。
- 克服节点随机唤醒时延对到达时间（ToA）的破坏，采用多频载波连续波相位解模糊实现分米级定位。

## 1. 极端物理环境：为什么将 IoT 带入深海？

海洋覆盖了地球表面超过 70% 的面积，蓄积了全球 90% 以上的热量并吸收了人类工业革命以来 30% 以上的碳排放，深刻决定着地球的气候变迁。然而，人类对深海的认知极其贫瘠：超过 80% 的海底从未被测绘，80% 以上的海洋生物未被记录。

### 1.1 水下物理介质的四重枷锁

在陆地上成熟运作的无线物联网协议，入水瞬间全盘崩溃：

| 陆地成熟技术 | 水下失效机理 | 物理学根源 |
|:---|:---|:---|
| **Wi-Fi / 5G / 蓝牙** | 传输距离不足数厘米 | 海水富含解离电荷（NaCl 强电解质），电导率高达 $4\text{ S/m}$，高频电磁波产生极强涡流损耗 |
| **GPS 卫星导航** | 无法穿透水面 | 1.5 GHz 卫星射频信号在水下数毫米内衰减殆尽，水下潜航器与浮标无法自主授时与定位 |
| **太阳能电池补能** | 数米水深下几乎全黑 | 阳光中的红外与可见光波段被水分子强烈吸收散射，无法提供持久光伏能量 |
| **传统水声调制解调器** | 节点单价数万美元，功耗数十至数百瓦 | 水下主动换能器必须以巨大机械振幅剧烈压缩水分子发射纵波，单次发包即耗尽小型电池 |

::: definition 传统水声通信 vs 压电声学反向散射（PAB）
- **传统主动水声通信（Acoustic Modem）**：节点内部搭载大功率功率放大器与压电换能器，主动驱动水体发声，功耗在 $10 \sim 100\text{ W}$ 级别，仅适用于核潜艇或大型科考船。
- **压电声学反向散射（Piezo-Acoustic Backscatter, PAB）**：水下微型节点完全不自主发声，仅利用浮标或船载声纳发射的环境声波作为载波，通过翻转片上极低功耗晶体管开关改变声阻抗，以反射形式回传数据。节点功耗骤降至**数百微瓦（$\mu\text{W}$）**，实现百万倍的能耗降维。
:::

## 2. 压电效应与声阻抗调制原理

PAB 的物理核心是压电陶瓷（PZT, Lead Zirconate Titanate）晶体圆柱。

::: definition 压电效应的双向能量转换机制
- **正压电效应（Direct Effect，用于能量收集）**：当外部声波作为机械压力波压缩压电陶瓷时，晶体晶格形变导致电偶极矩发生偏转，在材料两端电极表面感应出可观的电荷差与开路电压；
- **逆压电效应（Converse Effect，用于声波反射调制）**：当在压电陶瓷两端施加外加电场时，晶体自发产生纳米级机械伸缩变形。
:::

```text
水下水听器 / 母船声纳 ── 发射连续声波 (Acoustic Carrier) ──> 水中传播
                                                              │
                                                              ▼
                                                   [ 压电陶瓷传感器节点 ]
                                                   开关闭合 (Closed): 能量吸收储存
                                                   开关断开 (Open):   强机械振荡反射声波
                                                              │
                                                              ▼
母船接收端 <── 反向散射调制声波 (带有传感器数据) ──────────────┘
```

### 2.1 状态切换与 OOK 编码

微控制器通过控制与压电片串联/并联的低导通电阻 MOSFET 开关：
1. **状态 1（开关闭合，Short-circuit）**：外部负载电阻极小，压电陶瓷内部产生的机械能被外部电路回路迅速阻尼消耗，声波被吸收并转化为电能储存进超级电容中，对外声反射系数 $\Gamma \to 0$；
2. **状态 2（开关断开，Open-circuit）**：电荷无法在外部回路释放，压电材料表现为刚性固体，外部声压波被晶体完全反弹反射回水体中，对外声反射系数 $|\Gamma| \to 1$。

通过在吸收与强反射两种声学边界条件之间交替切换，节点在反射波中完成了振幅开关键控（OOK）调制。

## 3. 多节点并发组网：克服谐振瓶颈的可编程频移

无线 RFID 凭借宽带偶极子天线可以轻松在不同载频下工作；然而水下压电晶体受制于其物理几何尺寸，具有极其尖锐的**机械谐振频率（Resonance Frequency, $f_0$）**：

$$Z_\text{piezo}(f) = R_m + j\left(2\pi f L_m - \frac{1}{2\pi f C_m}\right)$$

在谐振点 $f_0$ 之外，压电元件的机械阻抗暴增，反向散射效率雪崩式下跌，传统射频频分多址（FDMA）在水下失效。

::: theorem 可编程复阻抗频移调制
PAB 通过在压电陶瓷后端并联可由数字逻辑控制的开关电容与电感阵列，动态改变后级电路的复阻抗 $Z_\text{circuit}(f)$。根据电声网络耦合理论，外部电路抗阻会反向等效修改晶体的机械谐振极点：

$$f_\text{resonance}' = f_0 \cdot \sqrt{1 + \frac{C_m}{C_0 + C_\text{tune}}}$$

通过为不同传感器烧录不同的调谐电容值 $C_{tune}$，节点 A 将其谐振窗口锁定在 $f_1 = 15.0\text{ kHz}$，节点 B 锁定在 $f_2 = 17.5\text{ kHz}$，成功在极端窄带的水声物理介质中实现了多传感器正交频分复用（FDMA）。
:::

## 4. 无电池水下高精度定位：多频相位估计

在浑浊或黑暗的水下，光学视线完全丢失，机器人与环境监测迫切需要分米级定位。

### 4.1 传统 ToA 测距的失效困境

传统水声定位使用到达时间（ToA）：$d = v_{sound} \times \Delta t$。然而，PAB 节点必须先经历微秒至毫秒级不等的**随机能量收集充电唤醒延迟（Random Wake-up Latency）**，这一电路层面的非确定性延迟与声速 $1500\text{ m/s}$ 相乘，直接引入了数米级的定位随机误差。

### 4.2 基于载波相位的微米级分辨率解法

PAB 创新性地采用**声学连续波载波相位（Carrier Phase）**测距。声波相位测量仅取决于声程所走过的空间旋转角，在物理上天然免疫唤醒时延：

$$\phi = 2\pi \cdot \frac{2d}{\lambda} \pmod{2\pi}$$

::: example 水中声波相位物理尺度
在海水环境中，声速 $v_{sound} \approx 1500\text{ m/s}$。若发射声源载频 $f = 15\text{ kHz}$：

$$\lambda = \frac{v_{sound}}{f} = \frac{1500}{15000} = 0.1\text{ 米} = 10\text{ 厘米}$$

接收端数字正交解调（I/Q Demodulation）能够轻松测量出 $0.05\text{ rad}$（约 $2.8^\circ$）的微小相位抖动：

$$\Delta d = \frac{\Delta\phi \cdot \lambda}{4\pi} = \frac{0.05 \times 0.1}{12.56} \approx 0.4\text{ 毫米}$$

**双频差分破除相位周期模糊**：单频相位的有效测距范围仅有一个波长（10 cm）。PAB 发射两路相近的载频 $f_1$ 与 $f_2$（如 $15\text{ kHz}$ 与 $16\text{ kHz}$），通过合成“虚拟大波长” $\Lambda = \frac{v_{sound}}{|f_1 - f_2|} = 1.5\text{ 米}$，在河道与海港现场测试中达成了 **10 cm** 的高精度定位。
:::

## 6. 极端环境下的零功耗通信范式

::: insight
海洋物联网（Ocean IoT）是移动计算对极端物理信道的最严苛探索：
1. **逆转经典通信设计的先验直觉**：在陆地无线电中，光速极快（$3 \times 10^8\text{ m/s}$）、波长较短，通信带宽充裕但多径复杂；而在水下声学中，声速极慢（$1500\text{ m/s}$），传播时延高达数百毫秒，信道动态变化极其剧烈。PAB 证明了：当介质物理特性发生反转时，照搬地面协议栈只会走向死胡同；唯有将传感器本身的机电特性（如压电逆效应）与声学物理定律深度绑定，才能开辟全新的系统路径。
2. **“寄生”哲学的终极形态**：在深海这片人类难以涉足的蛮荒疆域，任何需要更换电池的节点都是不可扩展的“死点”。PAB 放弃了人类向大自然强行发射能量的傲慢，转而让传感器静默伏于海底，等待母船声纳的掠过并顺应其机械能量完成呼吸式反射。这种让电子系统与自然物理环境和谐共生的零功耗思想，是普适计算走向深空与深海的终极技术范式。
:::

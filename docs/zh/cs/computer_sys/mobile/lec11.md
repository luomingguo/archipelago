# Lec 11 声学感知攻击与硬件非线性（Acoustic Sensing Attacks）

> MIT 6.1820 / MAS.453 · Mobile and Sensor Computing  
> 阅读材料：BackDoor [MobiSys'17] — UIUC / MIT

## TL;DR

- 传统低通滤波器在模数转换（ADC）之后工作，无法阻断模拟前置放大器的非线性失真。
- 双超声波信号经放大器平方项产生可听频段互调差频（$F_1 - F_2$），突破 20 kHz 人耳听觉上限。
- BackDoor 采用调频（FM）调制与双独立扬声器空气混叠，消除发射端非线性引发的可听泄漏。
- 攻击不仅可在智能手机上隐蔽注入语音指令，还可充当无声干扰器压制周围窃听麦克风。

## 1. 传感器安全与模拟物理攻击面

在传统网络与软件安全体系中，防护重心聚焦于防止内存溢出、加密网络报文与校验数字签名。上层操作系统和 AI 语音助手（如 Siri、Google Assistant）始终持有一个底层假设：**麦克风等物理传感器采集到的数字样本，诚实无误地反映了客观物理世界的真实声音**。

然而，微型硬件在模拟域的物理缺陷彻底摧毁了这一信任链条。

```text
物理声波 (空气振动)
   │
   ▼
[ MEMS 机械振膜 (Diaphragm) ] ──> 将空气气压转化为微弱电容变化
   │
   ▼
[ 模拟前置放大器 (Pre-Amplifier) ] ──> 【致命物理漏洞：非线性互调产物发生在此！】
   │
   ▼
[ 低通抗混叠滤波器 (LPF, 截止 20 kHz) ] ──> 试图滤除高频超声波（为时已晚！）
   │
   ▼
[ 模数转换器 (ADC, 采样率 44.1/48 kHz) ]
   │
   ▼
数字音频流 (OS / 语音识别软件接收) ──> 软件层读取到了“幽灵语音”！
```

::: definition 麦克风信号链的核心架构漏洞
为了让人耳听不见超声波噪音并防止高频混叠，所有商用音频设备都配备了截止频率约为 $20\text{ kHz}$ 的低通滤波器（LPF）。
然而，**前置放大器（Pre-Amplifier）必须紧接在极其微弱的振膜之后工作，位于低通滤波器的前级**。如果攻击者向麦克风注入超声激励，放大器自身的非线性特性将在进入滤波器之前直接把高频能量下变频为可听声频！
:::

## 2. 放大器非线性与互调失真（IMD）数学原理

一个理论上的理想线性放大器，其输出电压与输入电压成完美正比：$V_{out} = a_1 V_{in}$。

然而，在任何基于 CMOS / 双极型晶体管的真实半导体前置放大器中，受制于晶体管的伏安特性曲线弯曲，输出电压遵循泰勒级数展开：

$$V_{out} = a_1 V_{in} + a_2 V_{in}^2 + a_3 V_{in}^3 + \cdots$$

其中 $a_1$ 为基波线性增益，$a_2$ 为二次谐波非线性失真系数。

### 2.1 双音超声激励下的差频生成

设攻击者在空气中同时发射两个纯超声波正弦信号（频率均高于人耳听觉上限 $20\text{ kHz}$）：

$$V_{in}(t) = \cos(2\pi F_1 t) + \cos(2\pi F_2 t)$$

将 $V_{in}(t)$ 代入放大器的二次非线性项 $a_2 V_{in}^2$：

$$V_{out}^{(2)} = a_2 \left[\cos(2\pi F_1 t) + \cos(2\pi F_2 t)\right]^2$$

利用三角恒等式展开平方项：

$$V_{out}^{(2)} = a_2 \left[ \underbrace{\cos^2(2\pi F_1 t) + \cos^2(2\pi F_2 t)}_{\text{直流分量与高阶倍频 } 2F_1, 2F_2} + 2 \cos(2\pi F_1 t)\cos(2\pi F_2 t) \right]$$

其中乘积项利用积化和差公式展开为：

$$2\cos(2\pi F_1 t)\cos(2\pi F_2 t) = \underbrace{\cos\big(2\pi (F_1 + F_2) t\big)}_{\text{和频分量 (极高频超声)}} + \underbrace{\cos\big(2\pi (F_1 - F_2) t\big)}_{\text{差频互调分量 (Intermodulation Difference)}}$$

::: example 超声波差频下变频算例
设攻击者选定两束超声波频率分别为：
- $F_1 = 40\text{ kHz}$（远高于人耳 $20\text{ kHz}$ 听觉上限，人耳完全静默无感）；
- $F_2 = 45\text{ kHz}$（同样完全不可听）。

当它们共同进入麦克风放大器时，二次非线性产生差频：

$$F_\text{diff} = F_2 - F_1 = 45 - 40 = 5\text{ kHz}$$

**严重后果**：$5\text{ kHz}$ 恰好落在人类语言最敏感的中心频段（如辅音清晰度主要频段），且**能够畅通无阻地穿过 $20\text{ kHz}$ 低通滤波器**，最终被 ADC 忠实采样为数字音频信号！
:::

## 3. BackDoor 系统设计：从单音到隐蔽语音注入

如果仅仅注入单音调蜂鸣，只能造成简单干扰。如何将人类复杂的语音指令（如“Open the front door”或“Send money to Alice”）完整编码进超声波？

### 3.1 调制方案选型：调频（FM）胜过调幅（AM）

- **调幅（AM, Amplitude Modulation）的陷阱**：若直接将音频基带 $m(t)$ 调幅至超声载波 $F_c$，扬声器自身的非线性会将高次项畸变为 $[m(t)]^2$。平方运算产生严重的谐波交调失真，导致解调出的语音严重含混不清，无法通过 Siri 的语义识别。
- **调频（FM, Frequency Modulation）的破局**：BackDoor 采用角度调制。由于调频信号幅度恒定，它对放大器的幅度非线性具有天然免疫力：

  $$s(t) = \cos\left(2\pi F_c t + 2\pi k_f \int_{-\infty}^{t} m(\tau)\, d\tau\right)$$

### 3.2 双独立扬声器空气混叠（Dual-Speaker Air Mixing）

::: pitfall 单扬声器发射的“自暴露”灾难
如果攻击者将两个超声信号 $F_1$ 与 $F_2$ 混合后输入**同一个扬声器**：扬声器的振膜与功放芯片本身同样存在微弱的非线性。这会导致扬声器在发射瞬间就在空气中产生可听差频声音（发出可闻的杂音或人声），从而被人耳当场抓获，彻底丧失攻击的隐蔽性。
:::

**BackDoor 的解决架构：空间空气混频**：
- **扬声器 1（Speaker 1）**：专一发射载有调频语音信号的超声波 $S_{FM}(t)$（中心频率 $40\text{ kHz}$）；
- **扬声器 2（Speaker 2）**：专一发射纯净的连续波单频载波 $F_2 = 50\text{ kHz}$。

每个扬声器仅发射单频或纯调频信号，自身绝不产生可听差频；**两路电磁/声波仅在传播至受害者手机麦克风振膜附近的“空气”中相遇**，强制利用受害麦克风的放大器芯片充当被动解调器。

## 4. 实验评估与跨设备泛化性

BackDoor 团队采购了市场上主流消费电子设备进行实测，验证了该硬件级物理漏洞的无差别普遍性：

| 目标受害硬件 | 麦克风封装类型 | 测得非线性信号强度 | 语音识别通过率（Siri / Google） |
|:---|:---|:---|:---|
| **Apple iPhone 6 / 6s** | 楼氏电子（Knowles）MEMS | 41.2 dB SNR | > 95%（可在 1.5 米外隐蔽解锁执行指令） |
| **Samsung Galaxy 旗舰机** | 意法半导体（ST）MEMS | 36.8 dB SNR | > 90% |
| **MacBook Air 笔记本** | 阵列式 MEMS 麦克风 | 54.6 dB SNR | 100% |
| **数字单反相机与录音笔** | 驻极体电容麦克风（ECM） | 48.0 dB SNR | 音频轨道录入清晰可懂语音 |
| **数字医疗助听器** | 超微型专业助听器 | 32.5 dB SNR | 佩戴者听到无源凭空出现的杂音干扰 |

### 攻击的另一面：无声声学干扰器（Acoustic Jammer）

BackDoor 技术不仅能作为注入木马，还能被防御者反向用作**绝对静音的防窃听护盾**：
- 在绝密会议室内架设超声双频发射阵列，向空间广播编码为随机白噪声的超声信号；
- 参会人员在现场完全听不到任何刺耳声响（室内针落有声）；
- 但在场所有潜伏窃听手机、微型录音笔的麦克风放大器内部，全部被差频白噪声打满饱和，录制到的音频信噪比恶化至 -20 dB，窃听录音彻底报废。

## 5. 模拟信号链安全与信任假设反思

::: insight
BackDoor 对计算机系统工程与信息安全界带来了范式级的震动：
1. **“数字抽象”的自负与盲区**：现代操作系统的安全边界建立在内核环（Ring 0）、沙箱和内存隔离之上。我们假设驱动程序从硬件寄存器读取的每一个比特都是物理世界的诚实映射。然而，BackDoor 证明了：**无需修改一行代码、无需发送一个畸变网络包，纯粹利用麦克斯韦电磁学与半导体晶体管非线性，就能在底层硬件制造出操作系统绝对无法鉴别的“幽灵信号”**。
2. **软硬件协同防御的尴尬权衡**：要从根本上修复该漏洞，硬件厂商必须在放大器之前引入模拟电感-电容（LC）低通滤波器。然而在微米级 MEMS 芯片封装内，制造高品质因数的微型电感体积极其庞大、成本高昂。这再次折射出物联网系统的核心母题：安全从来不是免费的午餐，它时时刻刻都在与芯片硅片面积、功耗预算和生产良率进行残酷的工程博弈。
:::

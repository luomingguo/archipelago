# Lec 14 无线神经辐射场与空间重建（Wireless NeRFs & Spatial Reconstruction）

> MIT 6.1820 / MAS.453 · Mobile and Sensor Computing  
> 阅读材料：EchoNeRF [arXiv:2505.22441] — MIT CSAIL

## TL;DR

- 场景重建是物联网感知的最高形态，探索仅凭携带手机移动测得的 Wi-Fi 信号强度反演室内建筑布局。
- EchoNeRF 泛化视觉 NeRF 框架，将光线体积渲染替换为射频电磁波直射衰减与墙体镜面反射模型。
- 两阶段训练策略先行解耦直射路径确定几何粗胚，再冻结 LoS 拟合反射残差求解墙体不透明度与法向。
- 将无处不在的室内射频基建转化为无传感器的被动雷达，在拓展空间智能的同时暴露出静默平面图窃取隐私隐患。

## 1. 终极图景：从物理测距到全场景隐式三维重构

在前面的课程中，感知任务经历了从一维标量测量（如温度、RSSI 测距），到二维/三维点坐标推断（如 GPS、Cricket、WiTrack 目标追踪），再到运动学状态估计（IMU 航位推算）的演进。

而物联网感知的终极形态是：**环境场景重构（Scene Reconstruction）**——系统不满足于追踪移动的人，而是期望自主反演并绘制出物理世界环境本身的完整三维建筑几何与材质结构。

::: definition 终极探索问题
能否完全不使用激光雷达与光学摄像头，**仅凭普通人握持一部廉价智能手机在房间内自然走动时、后台记录的离散 Wi-Fi 信号强度（RSSI）**，就能端到端“逆向反演”出整栋房屋的建筑平面图（Floor Plan）？
:::

## 2. 经典视觉神经辐射场（NeRF）范式回顾

在计算机图形学与视觉领域，NeRF（Neural Radiance Fields, Mildenhall et al., ECCV'20）彻底改变了三维场景重建：

```text
已知相机位姿的三维射线 r(t) = o + t*d
   │
   ▼
[ 连续坐标多层感知机 MLP: F_θ ]
   │
   ▼
输出空间场值: 颜色 c = (r, g, b), 空间体密度 σ
   │
   ▼
沿光线数值离散体积积分 (Volume Rendering) ──> 渲染出二维像素预测颜色 C(r)
   │
   ▼ 损失反向传播
与真实相机拍摄的照片像素计算 L2 损失 ──> 反向更新神经网络参数 θ
```

::: theorem 神经隐式表示的可迁移性
NeRF 成功的底层数学本质是：**利用全连接神经网络作为连续物理场的紧凑隐式表达，通过可微的物理正向传播渲染模型，将观测数据与预测数据之间的残差反向传播至场景参数**。
这套范式完全不局限于可见光光子——任何遵循明确微分几何或电磁波波动方程的物理信号（如声波、毫米波、Wi-Fi 射频），都可以套用 NeRF 的可微逆问题求解范式。
:::

## 3. EchoNeRF：以 Wi-Fi RSSI 反演室内墙体

MIT 团队提出的 **EchoNeRF** 将视觉 NeRF 优雅地跨界投射到了室内射频信号域。

### 3.1 跨模态映射关系

| 概念与组件 | 视觉 NeRF（光学世界） | EchoNeRF（无线射频世界） |
|:---|:---|:---|
| **物理探测源** | 相机光圈中心发射的视线光子射线 | Wi-Fi 发射天线（Tx）与接收手机（Rx）空间连线 |
| **观测数据标签** | 二维像素 RGB 真实色彩 | 手机在坐标 $(x_i, y_i)$ 测得的 Wi-Fi 信号强度 RSSI |
| **可学习空间属性** | 空间体积分密度 $\sigma$ 与散射色彩 $(r, g, b)$ | 网格单元不透明度 $\delta \in [0, 1]$ 与表面法线角 $\omega$ |
| **正向物理渲染** | 沿光线视线积分吸收与发光（体积渲染） | 电磁波直射损耗（LoS）与多径墙面镜面反射模型 |
| **最终输出表征** | 任意新视角下的逼真照片渲染 | 建筑物室内二维矢量平面图（哪里是墙，哪里是空旷走廊）|

### 3.2 离散网格与射频可微前向物理模型

EchoNeRF 将待重构的房间离散化为二维空间网格。每个微元单元学习两个物理参数：
1. **不透明度（Opacity, $\delta_i \in [0, 1]$）**：若 $\delta_i \to 0$ 表示该微元为空气；若 $\delta_i \to 1$ 表示该位置存在厚实承重墙；
2. **表面法线朝向（Normal Angle, $\omega_i \in [-\pi, \pi]$）**：确定墙壁反射电磁波时的镜面入射角与出射角。

接收端天线合成的理论接收功率由**直射分量（Line-of-Sight, LoS）**与各阶**镜面反射多径（Specular Reflections）**叠加而成：

$$\widehat{P}_\text{RX} = P_\text{LoS} + \sum_{k} P_{\text{reflection}, k}$$

- **直射路径建模**：电磁波沿连接 Tx 与 Rx 的线段传播，其功率受距离平方衰减，并被沿途所有网格的不透明度连续相乘衰减：

  $$P_\text{LoS} \propto \frac{1}{d_{\text{Tx}-\text{Rx}}^2} \times \prod_{j \in \text{Line}(\text{Tx}, \text{Rx})} (1 - \delta_j)$$

- **镜面反射建模**：根据几何光学反射定律，若墙面法线 $\omega$ 与入射波满足费马极值光程，反射能量被弹射至 Rx，其振幅取决于反射面的介电反射系数与两段光程总衰减。

## 4. 优化瓶颈破解：两阶段递进训练策略

::: pitfall 直接端到端优化的“梯度淹没”灾难
如果在初始化阶段直接对总损失函数 $\mathcal{L} = \|\widehat{P}_\text{RX} - P_\text{measured}\|^2$ 执行梯度下降：
由于直射路径（LoS）的信号功率通常比微弱的反射波大 20–40 dB，直射误差项产生的梯度彻底主导了反向传播过程。神经网络会为了迎合 LoS 的粗糙拟合，在空间中胡乱填充大片模糊的低透明度“迷雾网格”，导致真正微弱的墙体法线与镜面反射项完全无法收敛，墙面边界彻底失效。
:::

### 两阶段分治求解法（Two-Stage Training）

```text
第一阶段: 仅基于直射几何 (LoS Only)
  忽略复杂多径反射，仅利用视线阻断衰减
  快速收敛出房间大致的“空旷空间 vs 墙体粗胚”二值骨架
     │
     ▼ 冻结 (Freeze)
锁定第一阶段学得的几何布局与 LoS 功率基线
     │
     ▼
第二阶段: 聚焦残差反射训练 (Residual Reflection Training)
  将网络优化目标对准残差: Loss = || 真实测量 RSSI - 冻结的 LoS 功率 - 预测反射功率 ||^2
  强迫优化器专注于利用细微的信号扰动学习墙体的精准法向量 ω 与精细边界
```

## 5. 实验评估与隐私警钟

### 5.1 墙体重构性能（Wall IoU）

研究团队利用真实 Zillow 房屋平面图结合 NVIDIA Sionna 电磁射线追踪引擎，在数千个真实室内布局上采集离散样本：

$$\text{Wall IoU} = \frac{|\text{预测墙体像素} \cap \text{真值墙体像素}|}{|\text{预测墙体像素} \cup \text{真值墙体像素}|}$$

| 室内建图对比方案 | 1000 个稀疏采样点 | 2000 个密集采样点 | 核心局限与行为表现 |
|:---|:---|:---|:---|
| **传统场强热力图阈值分割** | IoU = 0.09 | IoU = 0.12 | 仅能得到发射机周围的同心圆伪影 |
| **经典 NeRF2 基线** | IoU = 0.12 | IoU = 0.14 | 无法处理电磁波的镜面漫反射双重性 |
| **EchoNeRF（仅阶段一 LoS）** | IoU = 0.25 | IoU = 0.27 | 勾勒出大致轮廓，但缺失盲区墙体 |
| **EchoNeRF（完整两阶段体系）** | **IoU = 0.32** | **IoU = 0.38** | **成功恢复房间完整拓扑、开门位置与走廊结构** |

### 5.2 泛在感知带来的深层隐私威胁

::: theorem 泛在射频感知的隐私漏洞
在现代移动操作系统（iOS / Android）中，调用摄像头和麦克风必须弹出最高安全级别的运行时权限申请，并伴有屏幕顶部绿点/橙点强提醒；
然而，**Wi-Fi 扫描结果与 RSSI 信号强度在绝大多数系统中仅被视作低危的网络辅助信息**。EchoNeRF 证明了：一款恶意的手电筒或天气 App，仅需在后台静默记录用户日常走动时的 Wi-Fi 信号跳变，无需开启任何摄像头，就能在远程服务器上神不知鬼不觉地精确绘制出受害者家庭的内部房间户型与私密平面图！
:::

## 6. 无线空间智能与泛在感知未来

::: insight
行至本课程的最后一讲，我们见证了移动与传感器计算跨越三十年的壮丽系统跃迁：
1. **从“传感器硬件制造”走向“物理逆问题求解”**：在物联网诞生之初，人们坚信“要感知什么就必须发明对应的芯片”——测温度用热敏电阻，测光照用光敏二极管。然而，从 WiTrack 穿墙雷达到 EchoNeRF 场景重构，现代移动计算给出了全新的答案：**空间中早已充斥着人类通信铺设的千瓦级微波与高频无线电；我们不需要在物理世界铺满新的传感器，整个电磁空间本身就是无处不在的连续传感器**。
2. **通信、感知与人工智能的终极三位一体**：过去，通信（如 5G/Wi-Fi）只关心在两个节点之间可靠投递比特；雷达感知（Sensing）是军工航天的专用领域；人工智能（AI）则局限于服务器机房处理数字图像与文本。而在本课程的终章，这三条平行线完全汇聚——通感一体化（ISAC）使每一次无线电传输都成为探测空间的探针，而神经辐射场等隐式 AI 模型则将微弱嘈杂的物理回波升华为高阶空间智能。物理世界与数字世界的边界，在微型计算与电磁波的交织中彻底融为一体。
:::

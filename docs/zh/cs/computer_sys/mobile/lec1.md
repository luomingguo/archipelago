# Lec 1 课程介绍与核心思想

> MIT 6.1820 / MAS.453 · Mobile and Sensor Computing (IoT Systems)

## TL;DR

- 物联网系统由感知模态、边缘与云端计算、网络连接及能源供给四大互锁维度共同定义。
- 无线连接受制于通信距离、数据吞吐量与电池寿命构成的不可逾越的经典“三角权衡”。
- 能量收集与纳安级休眠占空比设计，是支撑野外微型传感器常年免维护运转的物理基础。
- 物联网技术正从传统标量遥测，演化为融通射频成像、声学感知与空间智能的物理人工智能。

## 1. 课程定位与技术视野

本课程全称为 *Mobile and Sensor Computing*，通称为 *IoT Systems*（物联网系统），聚焦三大递进主题：
- **基础原理（Fundamentals）**：无线感知、室内外定位、低功耗连接协议与环境能量收集等核心技术机制。
- **垂直应用（Applications）**：精准农业、海洋物联网、恶劣气象自动驾驶与无感医疗健康监测。
- **前沿方向（Frontiers）**：*Spatial AI*（空间智能）与 *Physical AI*（物理人工智能），使计算系统具备理解物理空间三维几何与物质特性的能力。

---

## 2. 什么是物联网？

::: definition 物联网（Internet of Things, IoT）
微型传感、嵌入式计算与无线通信技术的深度融合，使物理系统能够：
1. 从物理环境中**采集（Sense）**连续信号并离散化；
2. 在资源受限的设备本地执行实时**边缘预处理（Edge Computing）**；
3. 将提取的特征或原始样本按需上传至**云端（Cloud）**进行全局聚合；
4. 从数据中提炼控制策略并对物理环境**施加反作用（Actuate）**，形成闭环。
:::

## 3. IoT 系统的四个协同设计维度

任何一个实际落地的 IoT 系统，都必须围绕以下四个高度依赖的维度展开端到端协同设计：

```text
                ┌────────────────────────────────────────┐
                │ 1. Sensing Tasks & Modalities (WHAT)   │
                │ 2. Computation Paradigms      (HOW)    │
                │ 3. Connectivity Protocols     (TRANS)  │
                │ 4. Power & Energy Budget      (ENERGY) │
                └────────────────────────────────────────┘
```

### 3.1 感知任务与模态（Sensing Tasks & Modalities）

| 感知模态 | 物理介质 | 代表技术与典型系统 | 核心提取维度 |
|:---|:---|:---|:---|
| 无线电（Radio） | 射频电磁波 | GPS、Wi-Fi CSI、77 GHz 毫米波雷达 | 到达时间、载波相位、多普勒频移、反射轮廓 |
| 声学与超声（Acoustic / Ultrasonic） | 机械纵波 | 压电传感器、Cricket 室内定位 | 飞行时间差（ToF）、声阻抗、共振频率 |
| 惯性感知（Inertial） | 质量块位移与科里奥利力 | MEMS 三轴加速度计、陀螺仪、磁力计 | 线加速度、角速度、地磁姿态角 |
| 光学与机器视觉（Visual） | 光波与光子飞行 | RGB 摄像头、固态 LiDAR、近红外 | 像素色彩、稠密点云、多光谱折射率 |

感知任务横跨五大核心领域：**空间位置**（Location）、**生命体征**（Health）、**人机活动**（Activity）、**生态环境**（Environment）与**移动载体**（Vehicles）。

### 3.2 计算范式（Computation）

- **多层编程模型**：极低功耗 MCU 裸机调度、实时嵌入式操作系统（FreeRTOS/Zephyr）、移动端系统级服务与边缘/云端分布式协同。
- **端侧存储与过滤**：在存储与网络带宽严苛受限前提下的流式滑动窗口与事件触发机制。
- **信号处理与轻量推理**：从时域到频域变换（FFT/小波）、信号滤波（卡尔曼/互补滤波）到 TinyML 模型端侧剪枝部署。
- **物理与模拟安全**：防范利用传感器物理缺陷（如麦克风放大器非线性、MEMS 谐振）引发的不可信信号注入。

### 3.3 连接设计空间（Connectivity）

连接层在本质上受制于三维连续权衡空间：

$$\text{设计空间} = f(\text{通信距离},\ \text{数据速率},\ \text{电池寿命})$$

| 技术协议 | 典型覆盖距离 | 数据速率 | 典型电池寿命 | 典型系统定位 |
|:---|:---|:---|:---|:---|
| Wi-Fi (802.11 ax/be) | 室内数十米 | 100 Mbps ~ Gbps 级 | 需外接电源或数日一充 | 高吞吐家庭媒体与网关回传 |
| 蜂窝网络 (LTE / 5G) | 数公里（视基站而定）| 数十 Mbps ~ 1 Gbps | 需持续供电或大容量电池 | 高速移动车载与公共基建 |
| 蓝牙低功耗 (BLE) | 房间级（10 ~ 30 米）| 1 ~ 2 Mbps | 数月至数年（纽扣电池）| 近场可穿戴与去中心化追踪 |
| LoRaWAN / NB-IoT | 数公里至十几公里 | 数百 bps ~ 50 kbps | 5 ~ 10 年（免更换）| 稀疏农田遥测与智慧水务 |

### 3.4 能源与功耗预算（Power & Energy）

::: definition 能量收集（Energy Harvesting）
指系统直接从周围自然或人造物理环境中捕获能量（如光能、热电温差、振动机械能、空间杂散 RF 辐射），转化为电能并储存在超级电容中，达成“部署即遗忘”（Deploy-and-Forget）的永久性免电池运转状态。
:::

物联网节点的供电层级分为三类：
1. **持续电网供电**：无能耗顾虑，但部署范围被死死锁死在有线走线可达区域。
2. **化学储能电池**：依靠严格的低占空比（Duty Cycling）将射频收发时间压至 0.1% 以下。
3. **环境能量捕获与零功耗反向散射**：节点本身甚至不主动合成射频载波，仅调制既有环境信号（如被动 RFID、水下 PAB）。

## 4. 课程涵盖的代表性经典系统

| 系统名称 | 发表年份与出处 | 核心突破机制 | 解决的本质瓶颈 |
|:---|:---|:---|:---|
| Cricket | 2000 / MobiCom | RF 与超声波异质到达时间差（ToF）| 在保护用户终端隐私前提下达成厘米级室内测距 |
| WiTrack | 2014 / NSDI | 扫频 FMCW 雷达结合差分消除静态背景 | 目标无需携带任何终端即可穿墙追踪人体与呼吸 |
| RF-Capture | 2015 / SIGGRAPH | 射频多径聚类与三维骨架反演 | 在被遮挡条件下重构人体的三维粗糙体态与动作 |
| BackDoor | 2017 / MobiSys | 利用麦克风前置放大器高阶互调非线性 | 将不可听的双超声波差频信号注入数字音频通道 |
| Hawkeye | 2020 / CVPR | 条件对抗生成网络（cGAN）超分辨率雷达点云 | 解决毫米波雷达在雨雾中穿透强但角分辨率不足的缺陷 |
| FarmBeats | 2017 / NSDI | TVWS 穿透树冠通信与气象感知自适应调度 | 消除偏远农田网络缺失与太阳能阴天断电瓶颈 |
| PAB | 2019 / SIGCOMM | 压电晶体声学反向散射与可编程频移 | 突破海水导电性屏蔽，以微瓦功耗实现水下数公里级组网 |

::: example 恶劣天气下的自动驾驶感知挑战
在暴雨、大雾与黑夜场景中，光学摄像机受到光子散射与水雾吸收影响严重失真；激光雷达（LiDAR）脉冲被悬浮微粒遮挡导致点云噪点严重甚至彻底失效。
相反，77 GHz 毫米波雷达电磁波波长约 3.9 mm，能无视微米级雾滴直接穿透障碍物，但受制于物理天线孔径，其角分辨率极低。Hawkeye 系统利用深度神经网络将粗糙点云与环境物理先验对齐，直接恢复出高精度的密集深度图，构成了全天候感知系统的基石。
:::

## 5. 极端场景挑战：为何深耕海洋与极端环境？

- **地球气候核心调节器**：海洋蓄积了全球超过 90% 的多余热量与 93% 的二氧化碳，但超过 95% 的深海区域至今从未建立实时数字感知。
- **物理介质的反常性**：海水的高电导率导致无线电波在数厘米内衰减殆尽，常规 GPS、Wi-Fi、蜂窝网络完全瘫痪；而传统数百瓦的水声通信调制解调器令微型传感网络无法落地。
- **系统范式的极限检验**：如果一套系统能在深海冰冷、高压、断电且无法人工维护的环境下依靠反向散射持续存活数年，该设计思想在陆地物联网中将拥有极强的降维鲁棒性。

## 6. 系统协同与架构思考

::: insight
传统的计算机系统工程往往假定底层硬件与物理环境是相对透明、确定的抽象层（如内存是一致的字节数组、网络遵循标准 TCP 可靠传输协议）。而在移动与传感器计算领域，这种抽象完全被打破：
1. **物理信道是系统的一等公民**：多径效应、多普勒频移、阴影衰落不再是“需要掩盖的硬件错误”，而是直接被算法用来反演室内墙体、生命体征与位移的物理探针。
2. **连接与能量的不可解耦性**：在物联网中，通信协议设计不能脱离微安级电路状态转换；软件架构师必须深入底层，在“唤醒几毫秒广播一个包”和“沉睡一小时收集几微焦耳能量”之间精确权衡。
3. **从标量感知到空间智能（Spatial AI）**：早期的传感器网络（WSN）停留在读取温湿度等低维数据；现代移动计算则全面走向神经辐射场、跨模态物理反演与端侧闭环驱动，使无处不在的微弱电磁波与机械波共同构筑物理世界的动态数字镜像。
:::

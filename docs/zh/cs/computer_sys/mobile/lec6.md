# Lec 6 网状网络与多跳路由（Mesh Networking & Multi-Hop Routing）

> MIT 6.1820 / MAS.453 · Mobile and Sensor Computing  
> 阅读材料：ETX 论文 [MobiCom'03] — MIT CSAIL

## TL;DR

- 传统跳数路由在无线多跳网络中失效，往往偏好易丢包的边缘弱链路导致吞吐暴跌。
- ETX 测量正反向双向探测成功率，以几何分布期望传输次数量化单跳与整条路径开销。
- 路径 ETX 直接累加单跳度量，通过 Dijkstra 算法自适应避开高丢包过渡区链路。
- MIT Roofnet 实测证明 ETX 在非对称与时变无线环境下吞吐量比最小跳数提升 2–4 倍。

## 1. 动机：无线多跳网络的根本矛盾

在低功耗传感器与城域宽带接入场景中，单跳直接通信受制于发射功率与路径损耗（$P_r \propto d^{-\alpha}$，$\alpha \approx 2 \sim 4$）。强行提高发射功率不仅加剧电池耗竭，更会导致大范围射频干扰。

::: definition 无线网状网络（Wireless Mesh Network）
网络中每个节点既是应用数据的生成者，也是数据包转发的中继路由器（Relay）。数据包经过若干中间节点跨越障碍，接力传输至目标网关，形成网状互联拓扑。
:::

### 传统有线路由度量的失效

在有线局域网（如以太网）中，双绞线具有极高信噪比，误码率低于 $10^{-9}$，链路状态近乎离散二值化（完全连通或物理断开）。因此，RIP 等经典路由协议采用**跳数（Hop Count）**作为代价函数：跳数越少，转发延迟越低，链路越优。

但在无线介质中，“最小跳数”往往会导致吞吐量的灾难性崩溃：
- **最大跨度陷阱**：最小跳数算法会贪婪地选择物理距离最远的边缘节点，而这些节点正处于接收灵敏度的临界区（边缘弱信号）。
- **重传雪崩**：弱链路的高丢包率导致 802.11 MAC 层频繁发起退避与高达 7 次重传，整条链路的有效吞吐量趋近于零。

## 2. ETX：期望传输次数度量

为彻底解决跳数贪婪导致的弱链路陷阱，MIT 提出了 **ETX（Expected Transmission Count）** 度量。

::: definition 期望传输次数（Expected Transmission Count, ETX）
在一条物理无线链路上，成功将一个单播数据包送达接收端并收到链路层确认（ACK）所需要的期望传输尝试次数（包含首次发送与后续所有重传）。ETX 的理论下界为 1.0（完美无丢包链路），丢包率越高，ETX 趋近于无穷大。
:::

### 2.1 数学推导与非对称信道建模

设：
- $r_{fwd}$：数据包由节点 A 向节点 B 发送的正向（Forward）交付成功率；
- $r_{rev}$：确认帧（ACK）由节点 B 返回节点 A 的反向（Reverse）交付成功率。

一次单播数据包完成完整传输（发包成功且收到 ACK）的联合概率为：

$$p_\text{success} = r_{fwd} \times r_{rev}$$

假设在链路相干时间内每次传输尝试相互独立，成功所需的尝试次数 $K$ 服从参数为 $p_{success}$ 的几何分布（Geometric Distribution）：

$$P(K = k) = (1 - p_\text{success})^{k-1} \cdot p_\text{success}$$

其数学期望值即为该链路的 ETX：

$$\text{ETX} = \mathbb{E}[K] = \frac{1}{p_\text{success}} = \frac{1}{r_{fwd} \times r_{rev}}$$

::: theorem ETX 对链路质量的放大效应
假设一条看似“可用”的边际链路，$r_{fwd} = 0.5$，$r_{rev} = 0.5$（即双向各有一半概率丢包）：

$$\text{ETX} = \frac{1}{0.5 \times 0.5} = \frac{1}{0.25} = 4.0$$

这意味着平均需要发送 4 次才能交付一个包，占用了 4 倍的空中介质时间。当链路进一步恶化至 $r_{fwd} = r_{rev} = 0.3$ 时，$\text{ETX} \approx 11.1$。ETX 的非线性反比特性对高丢包链路施加了极其严厉的数学惩罚。
:::

### 2.2 双向探测包机制（Dedicated Probe Packets）

节点 A 与 B 如何在不干扰正常业务的前提下实时测量 $r_{fwd}$ 与 $r_{rev}$？

1. **周期性广播探测包**：每个节点每秒以最低基础速率广播一个固定长度（如 134 字节）的探测包。广播包不使用 MAC 层重传机制，真实反映物理信道丢包。
2. **滑动窗口统计**：节点维护过去 $\tau = 10\text{ 秒}$ 的接收滑动窗口，统计应收探测包与实收包的比值，计算出入向交付率。
3. **反向捎带（Piggybacking）**：节点 B 在向外广播自己的探测包时，将“我收到节点 A 探测包的近期成功率”编码在载荷中广播出去。节点 A 收到后，即可在本地同时获知正向率 $r_{fwd}$ 与反向率 $r_{rev}$。

## 3. 路径路由计算与选路对比

### 3.1 路径 ETX 的可加性（Additivity）

整条多跳路由路径 $P$ 的综合开销等于沿途所有单跳 ETX 的简单代数累加：

$$\text{ETX}_\text{path} = \sum_{e_i \in P} \text{ETX}_{e_i}$$

由于各跳开销为正且具有可加性，系统可在网络图上直接运行经典 **Dijkstra 最短路径算法** 或分布式 DSDV/DSR 协议，快速收敛到全局吞吐量最大的最优转发拓扑。

::: example ETX 与最小跳数路由决策冲突分析
考虑从源节点 $S$ 到目的节点 $D$ 的三条备选路径：
- **路径 1（贪婪单跳）**：直接跨越大跨度距离，链路弱，$r_{fwd}=0.4, r_{rev}=0.5 \implies \text{ETX} = \frac{1}{0.2} = 5.0$。
- **路径 2（优质两跳）**：经由中继 $R_1$，两跳均为短距优质视距，$r_{fwd}=0.95, r_{rev}=0.95 \implies \text{每跳 ETX} \approx 1.11 \implies \text{路径 ETX} \approx 2.22$。
- **路径 3（稳健三跳）**：经由中继 $R_2, R_3$，三跳极近，$r_{fwd}=1.0, r_{rev}=1.0 \implies \text{路径 ETX} = 3.0$。

**决策结果**：
- **最小跳数协议（Min-Hop）**：盲目选择**路径 1**（仅 1 跳），实际产生大量重传风暴与信道拥塞；
- **ETX 路由协议**：精确选择**路径 2**（总开销 2.22 最小），相比单跳直连，网络吞吐量提升超过 2.25 倍。
:::

## 4. MIT Roofnet 真实城域部署实证

MIT 计算机科学实验室在马萨诸塞州剑桥市居民房屋屋顶部署了 **Roofnet** 实验平台（38 个 802.11b 无线节点，跨越约 4 平方公里市区）：

```text
         [ 节点分布在剑桥市居民屋顶 (802.11b 网状互联) ]
              /              |             \
          Node 1 --------- Node 2 ------- Node 3
             \              /               /
              \            /               /
                ---- Gateway (接入 MIT 骨干网) ----
```

### 关键实测发现

1. **过渡区（Grey / Transitional Region）广泛存在**：真实无线环境并非存在清晰的“完全连通圆”，在覆盖边缘存在长达数十米至数百米的过渡带，链路丢包率在 10% 到 90% 之间剧烈震荡。
2. **链路非对称性显著**：由于两端射频前端放大器增益公差、局部噪声底噪差异（如微波炉干扰），超过 30% 的链路呈现极强的单向不对称性（$r_{fwd} \gg r_{rev}$）。
3. **系统性能翻倍**：在全部节点对端到端 TCP/UDP 吞吐测试中，ETX 相比最小跳数路由将中位吞吐量提高了 **2 到 4 倍**。

## 5. 后续路由度量的演进脉络

| 度量名称 | 提出年份与背景 | 针对的核心缺陷 | 核心机制与计算模型 |
|:---|:---|:---|:---|
| **ETX** | 2003 / MobiCom | 最小跳数忽略链路丢包与非对称性 | $\text{ETX} = \frac{1}{r_{fwd} \times r_{rev}}$，各跳直接累加 |
| **ETT** | 2004 / Sigcomm | ETX 假定各跳物理速率相同，无法反映多速率（1M ~ 54M）链路 | $\text{ETT} = \text{ETX} \times \frac{S}{B}$，引入数据包大小与链路实际物理带宽 |
| **WCETT** | 2004 / MobiCom | ETT 未考虑同一射频信道相邻节点的自干扰（Self-interference）| 联合加权总时延与网络中最拥挤信道的传输时间峰值 |

## 6. 无线路由度量演进与分布式权衡

::: insight
ETX 的成功不仅在于一个简单的倒数公式，而在于它揭示了分布式网络系统建模的深层哲学：
1. **抽象泄漏与跨层设计（Cross-layer Design）**：传统的 OSI 分层模型试图在网络层完全隐藏数据链路层的丢包重传细节。然而在无线通信中，链路层的动态丢包是无法掩盖的“泄漏抽象”。ETX 大胆打破黑盒，将链路层底层 ACK 统计直接暴露为网络层的拓扑图权重，取得了惊人的吞吐跃升。
2. **可加性与最优子结构的妥协**：Dijkstra 算法的成立依赖于路径权重的单调累加性。ETX 满足可加性，因此计算代价极低；但后续的 WCETT 试图精准建模“同信道空间争用干扰”，这使得路径开销变得不可直接累加，破坏了最优子结构（Optimal Substructure），系统不得不引入启发式贪心逼近。在系统工程中，如何在度量的“物理保真度”与图算法的“多项式可解性”之间寻找平衡，是永恒的艺术。
:::

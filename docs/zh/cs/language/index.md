# 编程语言

这个分类关注「程序如何被理解、执行与优化」，从词法、语法和语义一路进入编译器、虚拟机、垃圾回收与程序分析。

## 课程

- [MIT 6.1100 计算机语言工程](./computer_language/)：以 Decaf 编译器为主线，重点是静态语义、代码生成、数据流分析与优化。
- [MIT 6.1120 动态计算机语言工程](./dynamic_language/)：以 MITScript 运行时为主线，重点是操作语义、闭包、垃圾回收、字节码 VM 与 JIT。

## 建议顺序

想建立完整的编译器工程视角，先读 6.1100；想理解动态语言的执行模型与运行时取舍，先读 6.1120。两门课的解析、IR、数据流与寄存器分配部分可以交叉对照。

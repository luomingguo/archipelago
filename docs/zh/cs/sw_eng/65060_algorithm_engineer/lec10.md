# Lec 10 共享内存图算法：分解与着色（Shared-Memory Graph Algorithms: Decompositions & Coloring）

## TL;DR

- **并行图分解的基石作用**：低直径图分解将复杂图划分为内部直径有界的小连通簇，同时严格限制跨簇切边比例，为并行生成子图（Spanners）、最短路近似与谱图理论提供了通用分治底座。
- **随机移位（Random Shifts）的并行突破**：Blelloch 等人抛弃了传统的逐轮顺序球生长模型，通过赋予每个节点几何/指数分布的随机起始时间，以多源并行竞争生长的形式实现了 $O(m)$ 工作量与 $O(\log^2 n)$ 跨度的最优并行分解。
- **排序启发式与并行图着色**：将贪心图着色的串行因果链抽象为有向无环依赖图（DAG），结合 Smallest-Degree-Last 等排序启发式，兼顾了多核高度并行性与极低的着色数质量。

## 并行图分解：分治计算的几何底座

在串行计算中，图分治通常依赖平衡割（Balanced Cuts）或分离子（Separators）。然而，在海量无标度网络（如互联网拓扑或社交网络）中，由于扩张图（Expander Graphs）特性的存在，并不存在理论上很小的平衡顶点割。

为了在无良好分离子的图上开展分治，理论界引入了**低直径图分解（Low-Diameter Graph Decomposition）**。

::: definition $(\beta, d)$-图分解
给定无向图 $G = (V, E)$ 与参数 $\beta \in (0, 1)$。一个图分解将顶点集 $V$ 划分为若干互不相交的簇 $V_1, V_2, \dots, V_k$。若满足：
1. **簇内强直径有界**：每个簇 $V_i$ 在诱导子图中的连通直径至多为 $d = O(\frac{\log n}{\beta})$。
2. **跨簇割边比例受控**：任意一条边 $e = (u, v)$ 两端顶点被划分到不同簇的概率严格受限于 $\Pr[u, v \text{ 跨簇}] \le O(\beta)$。
则称该划分为一个 $(\beta, d)$-低直径图分解。
:::

### 传统球生长（Ball Carving）的并发困境

在经典的串行分解算法（如 Awerbuch 或 Linial-Saks）中，算法从单个源点发起 BFS 球生长，遇到满足割边比例的边界时将球切下，再从剩余图中选择下一个源点串行重复。这种“单源切球—更新残差—下一轮单源”的模式具有深度的串行因果依赖，并行跨度高达 $O(n)$，在现代多核机器上完全无法扩展。

## 随机移位（Random Shifts）并行算法

Guy Blelloch、Julian Shun 等人在 SPAA 2014 提出了革命性的**基于随机移位的并行分解算法**。

算法彻底颠覆了单源依次切球的逻辑，改由全网**所有顶点同时并发发起球生长**：

```text
时间轴: 0 ──────────────────────────────────────────>
节点 1: [--- 随机延迟 δ1 ---] ==> (开始向外生长球)
节点 2: [-- δ2 --] ==========> (更早开始向外扩张，抢先吞并领地)
节点 3: [----- δ3 -----] ====> (较晚生长，已被邻居吞噬)
```

### 算法核心机制

1. **为每个节点赋予随机偏移时间**：每个节点 $v \in V$ 独立抽取一个服从参数为 $\beta$ 的指数分布或几何分布的随机偏移量 $\delta_v$。
2. **多源带权最短路径竞速**：令节点 $v$ 作为生长中心的物理触发时间为 $-\delta_v$。所有中心同时以单位速度沿边向外广播扩散。
3. **首达原则归属**：全网任意顶点 $u$ 最终归属于**最早到达该顶点的生长中心** $c$：
   $$
   \text{center}(u) = \arg\min_{v \in V} \big(\mathrm{dist}(u, v) - \delta_v\big)
   $$

::: theorem 随机移位分解的最优复杂度
得益于指数分布独特的“无记忆性（Memoryless Property）”，任意边被不同中心切断的概率严格恒定为 $O(\beta)$。Blelloch 等人证明，该多源竞速过程可以通过并行受限的 BFS 森林生长实现，算法总工作量严格为 Work-Efficient 的 $O(m)$，关键路径跨度仅为：
$$
T_\infty = O\left(\frac{\log^2 n}{\beta}\right)
$$
在 40 核多核服务器上，该算法仅需 1~2 秒即可完成十亿级边真实社交网络的完整低直径聚类。
:::

## 并行图着色（Parallel Graph Coloring）

图着色要求为每个顶点分配一个整数颜色，使得任意相邻顶点的颜色互不相同。其在编译器寄存器分配、有限元网格更新调度及并行事务加锁中扮演着核心角色。

### 贪心着色与有向依赖图（DAG）

串行贪心着色按某种顺序 $\pi$ 遍历顶点，每个顶点选取其所有已着色邻居未使用的**最小可用非负整数色（First-Fit）**。

将串行因果依赖进行拓扑展开：对于图中的任意边 $(u, v)$，若在排列中 $\pi(u) < \pi(v)$，我们在两者之间建立一条有向依赖边 $u \to v$。
- 这样，无向图 $G$ 结合排列 $\pi$ 被升维为一个**有向无环图（DAG）**。
- **无入度的源节点**（即其在排列中的优先级高于所有相邻邻居）可以立即并行染上颜色！
- 节点染色完毕后，将其出边从 DAG 中移除，暴露出新的无入度源节点，递归并行推进。

### 排序启发式（Ordering Heuristics）

算法工程的实验表明：**排列 $\pi$ 的选择同时决定了并发跨度 $T_\infty$ 与最终着色数 $\chi$ 的质量**。

Hasenplaugh、Shun、Leiserson 等人（SPAA 2014）系统评测了四大排序策略：
1. **随机排序（Random Order / Luby 式）**：每个节点随机分配优先级。DAG 深度为 $O(\log n)$，并行度极高，但着色数通常比最优解多出 30%~50%，颜色质量低。
2. **最大度数优先（Largest-Degree-First, LDF）**：优先处理度数极大的超级节点。能大幅压制最大颜色数，但在幂律图中高层因果链较长。
3. **最小度数最后（Smallest-Degree-Last, SDL）**：反复剥离当前图中断度数最小的节点并将其放入队列尾部。理论上保证着色数严格受限于该图的**退化度（Degeneracy / Col-number）**加一：
   $$
   \text{Color Count} \le \max_{H \subseteq G} \delta(H) + 1
   $$
4. **关联度动态着色（Incidence-Degree）**：动态优先选择未着色邻居中已被占用颜色最多的节点。

::: pitfall 并行冲突与推测执行的开销
在共享内存多核着色中，若不对 DAG 依赖进行严格拓扑管理，直接允许多个线程并行对相邻节点染色，就必须引入类似推测执行（Speculative Execution）的机制：先无锁读取邻居颜色，染完后再二次检查是否存在冲突；若发生冲突，则迫使某一线程回滚并重新分配颜色。在高冲突的稠密图上，冲突回滚率可高达 40% 以上，严重损耗内存带宽。采用基于 DAG 拓扑前沿调度的确定性算法在实测中表现出更强的一致吞吐。
:::

::: insight 破除全局刚性的智慧：从单点突破到全域多源竞速
随机移位分解和拓扑着色展现了算法工程破解并发死锁的最高境界。单源球生长和传统贪心染色之所以难以并行，是因为人们直觉上认为“必须维护一个全局唯一的中心，等它决定完了才能启动下一步”。而算法工程的解题思路是“去中心化与全域竞速”：为每一个节点赋予由随机性或局部度数决定的局部初始势能，让所有可能的主体同时起跑。微观上各个主体只是在遵循极简的贪心物理规则（如最近中心归属或首可用色），宏观上整个系统却自然涌现出全局最优的拓扑分块。这种自组织涌现的机制，正是现代超大规模并行算法设计的永恒魅力所在。
:::

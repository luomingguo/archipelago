# Lec 3 缓存无关算法设计（Cache-Oblivious Algorithms & Memory Hierarchy）

## TL;DR

- **理想缓存模型（Ideal-Cache Model）**：将两级存储体系形式化为容量为 $M$、缓存行大小为 $B$ 的全相联缓存；Sleator-Tarjan 竞争分析保证实际系统采用的 LRU/FIFO 策略在渐近意义上紧密逼近理论最优替换策略 OPT。
- **缓存无关的哲学革命**：算法代码中不包含任何与硬件特定的参数 $M$ 或 $B$；只需基于分治策略（Divide-and-Conquer）将问题规模递归缩小至常数个子块能够整体装入缓存，算法即可在物理层面上自发终止缓存缺失。
- **跨层级最优性自动传递**：一个在理想两级缓存模型下达到渐近最优 I/O 复杂度的缓存无关算法，在任意包含任意级 Cache、主存乃至外部磁盘的多级分层存储体系上，各层之间均能同时达到理论最优传输边界。

## 外部存储模型与参数敏感算法的局限

在 1980 年代，Aggarwal 与 Vitter 提出了著名的**外存模型（Disk Access Machine, DAM）**。在 DAM 模型中，程序员必须明确获知底层系统的硬件参数：
- 内存/缓存容量：$M$
- 单次块传输大小：$B$

基于 DAM 模型设计的算法被称为**缓存感知算法（Cache-Aware Algorithms）**，例如经典的外存 $B$ 树与分块矩阵乘法（Tiled Matrix Multiplication）。这类算法在内层循环中硬编码诸如 `BLOCK_SIZE = 64` 的常数，手工调节循环展开与步长。

然而，缓存感知算法在现代系统上面临严峻的工程困境：
1. **多级存储的多参数爆炸**：现代 CPU 拥有 L1i、L1d、L2、L3 以及持久内存，每一级缓存的 $M$ 与 $B$ 各不相同。为某一特定级缓存硬编码调优的切块，在另一级缓存上往往是极度低效的。
2. **多核竞争与动态容量漂移**：在多核共享 LLC（末级缓存）的环境下，操作系统后台进程及并发线程会动态挤占缓存空间，物理可用的有效缓存容量 $M$ 时刻在动态剧烈波动。
3. **软件可移植性危机**：针对 Intel Skylake 架构微调的最佳分块尺寸，迁移至 AMD Zen 架构或 ARM Neoverse 芯片时性能往往剧烈劣化。

## 理想缓存模型（The Ideal-Cache Model）

1999 年，Frigo、Leiserson、Prokop 与 Ramachandran 在 FOCS 发表里程碑论文，提出了**缓存无关模型（Cache-Oblivious Model）**。

::: definition 理想缓存模型（Ideal-Cache Model）
计算机由两级存储构成：大小有限但速度极快的缓存（容量为 $M$ 字节），以及容量无限但速度较慢的主存。数据在两级之间的传输以固定大小为 $B$ 字节的块（Cache Line）为原子单位。模型做如下理论约定：
1. **全相联缓存（Fully Associative）**：主存中的任意块均可放置于缓存中的任意空闲槽位。
2. **最优替换策略（Optimal Replacement / OPT）**：当缓存满载时，系统具有全知能力，总是淘汰未来最晚被再次访问的块（即 Bélády 最优离线置换算法）。
3. **高瘦缓存假设（Tall-Cache Assumption）**：缓存容量通常远大于块大小的平方，即 $M = \Omega(B^2)$，这与几乎所有现代商业硬件完全吻合。
:::

::: theorem 实际替换策略与全相联的理论支撑
现实硬件采用有限路组相联与在线的 LRU（最近最少使用）策略。Sleator 与 Tarjan 的经典竞争分析证明：在容量为 $M$ 的两级缓存上运行 LRU 所产生的总缓存缺失次数，不超过在容量为 $M/2$ 的理想缓存上运行最优离线替换策略 OPT 的 2 倍。这意味着**基于理想缓存模型推导出的渐近上界在真实硬件上依然稳定成立**。
:::

## 矩阵转置的缓存无关分治

考虑将一个 $N \times N$ 的稠密矩阵 $A$ 转置到矩阵 $B$ 中。
若采用朴素的双重循环：
```c
for (int i = 0; i < N; i++) {
    for (int j = 0; j < N; j++) {
        B[j][i] = A[i][j];
    }
}
```
当 $N \times N$ 远大于缓存容量 $M$ 且矩阵按行优先存储时，读取 $A[i][j]$ 是连续步长，而写入 $B[j][i]$ 则是跳跃步长 $N$。只要 $N > M/B$，对 $B$ 的每一次内层写入都会触发一次全新的缓存缺失，总 I/O 复杂度高达 $\Theta(N^2)$。

### 缓存无关递归四分法

我们将矩阵沿行和列方向一分为四：
$$
A = \begin{pmatrix} A_{11} & A_{12} \\ A_{21} & A_{22} \end{pmatrix}, \quad
B = \begin{pmatrix} B_{11} & B_{12} \\ B_{21} & B_{22} \end{pmatrix}
$$
递归执行四个子矩阵的转置：
$$
B_{11} \leftarrow A_{11}^T, \quad B_{12} \leftarrow A_{21}^T, \quad B_{21} \leftarrow A_{12}^T, \quad B_{22} \leftarrow A_{22}^T
$$

```text
       ┌───────┬───────┐              ┌───────┬───────┐
       │  A11  │  A12  │              │  B11  │  B12  │
       ├───────┼───────┤   转置映射   ├───────┼───────┤
       │  A21  │  A22  │  ─────────>  │  B21  │  B22  │
       └───────┴───────┘              └───────┴───────┘
          (输入矩阵 A)                   (输出矩阵 B)
```

**I/O 复杂度证明**：
递归持续向下切分，直到子矩阵的规模满足 $\gamma N_0^2 \le M$（其中 $\gamma$ 为常数，保证子矩阵 $A_{\text{sub}}$ 和 $B_{\text{sub}}$ 能完全容纳进缓存中）。
- 在递归基阶段，两个子矩阵一旦装入缓存，其内部的所有元素置换操作不再触发任何额外的 I/O 缺失，只需支付初始加载的块传输代价，即 $O(N_0^2 / B + 1)$。
- 全局共有 $(N / N_0)^2$ 个互不重叠的叶子任务。将叶子代价累加，并考虑边界整除情况，总 I/O 复杂度为：
$$
Q(N) = O\left(1 + \frac{N^2}{B}\right)
$$
这一界限严格匹敌连续线性顺序扫描矩阵的理论下限，比朴素实现的 I/O 缺失减少了 $B$ 倍！

## 矩阵乘法的缓存无关极致优化

对于两个 $N \times N$ 矩阵的乘法 $C = A \times B$，分治算法将矩阵划分为 8 个子乘法任务：
$$
C_{ij} = A_{i1} B_{1j} + A_{i2} B_{2j}
$$

当递归切分至子矩阵规模 $N_0$ 满足 $3 N_0^2 \le M$（即三个子块能同时放入缓存）时，递归基总共需执行 $N_0^3$ 次标量乘法，而期间的 I/O 次数仅为加载三个矩阵块的代价：
$$
O\left(\frac{N_0^2}{B} + 1\right) = O\left(\frac{N_0^2}{B}\right) \quad (\text{由高瘦缓存假设 } N_0 = \Theta(\sqrt{M}) \ge \Omega(B))
$$
由于全过程包含 $(N / N_0)^3$ 次规模为 $N_0$ 的子乘法，代入 $N_0 = \Theta(\sqrt{M})$，总 I/O 复杂度为：
$$
Q(N) = \left(\frac{N}{\sqrt{M}}\right)^3 \cdot O\left(\frac{M}{B}\right) = O\left(1 + \frac{N^2}{B} + \frac{N^3}{B\sqrt{M}}\right)
$$
该结果在渐近意义上严格匹配了 Hong 与 Kung 在 1981 年利用红蓝卵石游戏推导出的矩阵乘法 I/O 理论绝对下确界！

::: insight 缓存无关性：用分治递归拟合硬件分形
缓存感知算法本质上是在特定物理维度上做“单点适配”，而缓存无关算法则是用数学的分治递归去自然拟合计算机体系结构的“分形特征”（Fractal Nature）。无论硬件在物理层面上堆叠了三级、四级还是未来基于 CXL 的十级存储层次，数据结构都在全尺度上保持几何自相似性。当数据规模大于某一层的容量时，算法按分治递推优雅降维；当数据缩小至进入该层容量时，该层自发实现近零缺失的高速流水线。这种不着相于具体硬件参数的深层数学对称性，正是计算机科学最纯粹的美学体现。
:::

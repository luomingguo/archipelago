# 菲茨定律

## 问题情境

在图形用户界面（GUI）和触屏交互开发中，开发者经常忽视细微的几何布局对用户操作效率造成的巨大影响：
- 网页上极小的文本链接或复选框，用户必须小心翼翼地把鼠标光标对准那几个像素，稍有手抖就会点偏；
- 在移动端网页上，按钮尺寸过小且挨得太近，导致粗手指（Fat Finger）频繁误触相邻元素；
- 某些桌面操作系统的菜单栏被放置在每个应用窗口内部，当窗口未最大化时，用户移动鼠标很容易越界甩出菜单范围。

这些交互耗时与定位精度的物理现象，早在半个多世纪前就已被心理物理学公式精确刻画。

## 概念界定

::: definition [菲茨定律（Fitts's Law）]
由心理学家保罗·菲茨（Paul Fitts）于 1954 年提出，菲茨定律是人机工程学中量化**从当前初始位置快速移动物理指示器（如手、手指或鼠标光标）到达指定目标区域所需时间**的经典预测模型。
:::

定律表明：**到达目标所需的时间取决于两点——到目标的距离（Distance, $D$）以及目标在运动方向上的尺寸宽度（Width, $W$）**。距离越远耗时越长，目标越宽耗时越短。

## 解释与依据

### 1. 数学模型与香农公式（Shannon Formulation）

菲茨定律在人机交互领域最通用的现代形式为麦肯齐（Scott MacKenzie）修正的香农表达式：

$$
MT = a + b \cdot ID = a + b \cdot \log_2 \left( \frac{D}{W} + 1 \right)
$$

各变量物理含义如下：
- **$MT$（Movement Time，运动时间）**：完成指向定位动作的平均时间；
- **$a$（截距）与 $b$（斜率）**：由经验拟合决定的设备物理常数（取决于输入设备特性，如鼠标、触控板、触控笔或手指）；
- **$D$（Distance / Amplitude，距离）**：光标或手指起始点到目标中心点的直线距离；
- **$W$（Width / Size，目标宽度）**：目标在运动方向上的投影视在尺寸；
- **$ID$（Index of Difficulty，难度指数）**：以比特（bits）为单位量化任务的物理难度，即 $ID = \log_2(D/W + 1)$。

```text
起始点 [•] =================== 距离 D ===================> [   目标宽度 W   ]
```

对数关系的本质解释了人类运动控制的生物神经机制：动作通常由两个阶段组成——首先是一个高速但粗略的大幅度摆动（Ballistic Movement），随后是眼手反馈闭环控制下的微小连续减速修正（Fine Adjustment）。

### 2. 界面设计的三大推论

1. **目标越大越容易点击，但边际收益递减**：
   由于公式包含 $\log_2$，把一个 8px 的超小按钮扩大到 24px 会带来巨大的定位提速；而把一个 100px 的巨大按钮继续扩大到 200px，所带来的运动时间缩短却微乎其微；
2. **距离越近越快到达**：
   右键上下文菜单（Context Menu）直接在光标当前停留的坐标原地展开（$D \to 0$），其定位难度 $ID \approx 0$，因此是呼出速度最快的交互模式；
3. **屏幕边缘与四角拥有“无限大”的等效宽度（$W = \infty$）**：
   因为屏幕边界会强行卡住光标，用户可以闭着眼睛以最高速度把鼠标直接甩向屏幕最边缘，光标绝不可能甩过头。

## 边界与辨析

### 1. macOS 顶部全局菜单栏 vs Windows 窗口菜单栏

- **macOS 的菲茨定律优势**：
  macOS 将菜单栏固定在屏幕最顶部边缘。在桌面视口下，屏幕物理边缘赋予了菜单“无限大”的垂直厚度（$W = \infty$）。用户只需向上一甩鼠标即可停在菜单栏上，无需精确减速对齐；
- **Windows 独立窗口菜单栏的劣势**：
  在非全屏状态下，Windows 应用窗口的菜单栏悬浮在屏幕中间，既有距离 $D$，又有极严格的上下边界 $W$（鼠标甩过头就会滑出菜单）。用户必须在接近菜单时强制肌肉减速微调，整体耗时明显高于 macOS。

### 2. 鼠标光标环境 vs 触屏手势环境的区别

| 维度 | 鼠标与触控板（Desktop） | 触控屏（Mobile Touchscreen） |
| :--- | :--- | :--- |
| **距离 $D$ 的起始点** | 光标当前停留的屏幕物理像素位置 | 用户手指悬停在空中的物理位置（不可精准预测） |
| **边缘优势的存在性** | **有效**：屏幕物理边框能阻挡并捕获光标 | **部分失效**：手指滑到手机玻璃边缘不仅没有无限大边界，反而容易触发系统返回手势冲突 |
| **最小尺寸约束** | 鼠标指针对准能力高，通常建议 $\ge 24\text{px}$ | 视网膜手指指腹接触面大，Apple HIG 规范要求 $\ge 44 \times 44\text{pt}$，Material Design 要求 $\ge 48 \times 48\text{dp}$ |

::: insight
在 Web CSS 排版中，扩大点击面积并不意味着破坏视觉比例。通过为按钮或链接设置宽松的 `padding`，或者使用伪元素 `::before` 拓展不可见的命中测试区域（Hit Target），可以在保持视觉精致的同时最大化菲茨定律红利。
:::

## 提取与迁移

- **在现代 Web CSS 工程中的应用**：
  ```css
  /* 利用 ::before 将移动端文本链接的点击热区从 16px 隐式扩大至 44px */
  .touch-link {
    position: relative;
  }
  .touch-link::before {
    content: "";
    position: absolute;
    top: -12px;
    bottom: -12px;
    left: -12px;
    right: -12px;
  }
  ```
- **在游戏 UI 与径向菜单（Pie Menu / Radial Menu）中**：
  传统列表菜单从上到下排列，越靠下的项目 $D$ 越大；而圆形饼状菜单将所有功能围绕中心均匀排列，所有候选项的 $D$ 完全相等且极小，熟练玩家可以凭肌肉记忆毫秒级触发。

## TL;DR

- 菲茨定律量化预测了从起点移动到目标区域的物理耗时：$MT = a + b \log_2(D/W + 1)$。
- 界面设计三大推论：扩大目标尺寸能大幅缩减定位耗时；缩短物理距离（如上下文弹出菜单）能加速操作；屏幕边缘与四角因物理阻挡拥有“无限大”的等效命中宽度。
- 触控屏开发中必须遵守最小热区规范（$\ge 48 \times 48\text{px}$），并善用内边距避免误触。

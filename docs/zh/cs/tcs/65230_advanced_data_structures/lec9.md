# Lec 9 惰性漏斗排序与缓存无关正交二维范围搜索（Lazy Funnelsort & Cache-Oblivious Orthogonal 2D Range Search）

> 对应 MIT 6.851 Lecture 9 · 讲师：Erik Demaine · 核心文献：Frigo et al. (FOCS 1999), Brodal & Fagerberg (STOC 2002), Arge et al. (2007)

## TL;DR

- 本讲为存储层级专题的收官之作，完成缓存无关模型与计算几何的深度交叉。
- 详述惰性漏斗排序（Lazy Funnelsort）的 $K$-漏斗缓冲区递归合并器，在未知 $M$ 和 $B$ 下达成理论最优的 $O(\frac{N}{B}\log_{M/B}\frac{N}{B})$ 传输次数。
- 结合几何分治提出分发扫描（Distribution Sweeping），高效解决批量范围检索；进一步给出在线二侧（$O(N)$ 空间）、三侧（$O(N\log N)$ 空间）与四侧（$O(N\frac{\log^2 N}{\log\log N})$ 空间）的高效缓存无关正交范围树。

## 一、惰性漏斗排序（Lazy Funnelsort）

外存模型下的最优排序是 $M/B$ 路归并排序，但该算法依赖于预先配置的分块参数。Brodal 和 Fagerberg（2002）提出的**惰性漏斗排序（Lazy Funnelsort）**是首个简洁优美的缓存无关最优排序算法。

### 1.1 $K$-漏斗（$K$-Funnel）的递归结构

$K$-漏斗是一个专门用来合并 $K$ 个已排序流的递归归并器，能够吐出大小为 $K^3$ 的排好序的数据流：
1. **树形拓扑**：在逻辑上表现为一棵具有 $K$ 个叶子节点的完全二叉树，每个叶子连接一个输入有序流，根节点产生最终的合并有序流；
2. **递归双层剖分**：整棵树由顶层一个 $\sqrt{K}$-漏斗和底层 $\sqrt{K}$ 个互不相交的 $\sqrt{K}$-漏斗共同组成；
3. **几何级缓冲配置**：连接顶层漏斗与各底层漏斗的边上配备了容量为 $K^{3/2}$ 的中转缓冲区（共有 $\sqrt{K}$ 个），所有中转缓冲区总容量恰为 $\sqrt{K} \times K^{3/2} = K^2$；
4. **缓冲容量设计哲学**：为什么必须设为 $K^{3/2}$？因为子漏斗能够产生 $K^{3/2} = (\sqrt{K})^3$ 大小的有序流，恰好能一次性将中转缓冲区填满。这种精巧的参数选择确保了子问题递归过程中的输入输出匹配，彻底消除了频繁的父子上下文切换开销。

```text
              ┌────────────────────────┐
              │  顶层 √K-漏斗 (合并器) │
              └───────────┬────────────┘
                          │ 内部缓冲区 (大小 K^(3/2))
             ┌────────────┴────────────┐
             ▼                         ▼
   ┌───────────────────┐     ┌───────────────────┐
   │ 底层 √K-漏斗 (1)  │ ... │ 底层 √K-漏斗 (√K) │
   └───────────────────┘     └───────────────────┘
```

### 1.2 惰性驱动与 I/O 复杂度

- **惰性填充（Lazy Invocations）**：自顶向下按需驱动。当顶层输出缓冲区需要更多数据时，对左右子缓冲区做二路归并。当某个子缓冲区变空时，暂停当前合并，递归激活其下方的子漏斗装填满该缓冲区。
- **全局排序**：将 $N$ 个元素分为 $N^{1/3}$ 组递归排序，随后送入一个 $N^{1/3}$-漏斗完成大一统合并。
- **复杂度证明**：在高瘦缓存假设 $M = \Omega(B^{1+\varepsilon})$ 下，大小小于等于 $M$ 的子漏斗在内存中完全免费。双指数规模展开使递归总和被最大规模的一层完全支配，达成外存理论下界：
  $$
  \text{Sort}(N) = O\left(\frac{N}{B} \log_{M/B} \frac{N}{B}\right)
  $$

## 二、分发扫描与批量二维范围搜索

分发扫描（Distribution Sweeping）将惰性漏斗排序从纯粹的排序工具升维为几何算法引擎。

### 2.1 问题形式化

给定平面上 $N$ 个离散点和 $N$ 个轴对齐查询矩形，要求批量输出所有落入对应矩形内的点对。目标 I/O 复杂度为 $O(\text{Sort}(N) + \frac{\text{out}}{B})$。

### 2.2 分发扫描执行步骤

1. **投影排序**：用漏斗排序按 $x$ 坐标对所有点和矩形端点排序；
2. **空间竖切与分治**：在 $x$ 中位数处将平面竖切为左半板 $L$ 和右半板 $R$ 递归处理；
3. **自底向上扫描线合并**：
   - 沿 $y$ 坐标向上推进扫描线，仅在当前层级处理**横跨边界的矩形**（左角在 $L$ 且右边界完全覆盖 $R$，或反之）；
   - 维护计数器 $C_L$（左侧跨越活跃矩形数）和 $C_R$（右侧跨越活跃矩形数）；
   - 遇到 $L$ 中的点累加 $C_R$，遇到 $R$ 中的点累加 $C_L$。
4. 将递归树划分为线性大小的子树批次执行，整套流程在无需感知 $M$ 与 $B$ 的情况下达成最优批量 I/O。

## 三、在线正交二维范围搜索体系

对于在线查询，目标是单次查询传输次数达到 $O(\log_B N + \frac{\text{out}}{B})$。根据查询区域的开闭约束边数（Sidedness），空间代价呈现层次递进：

### 3.1 二侧查询 $(\le x_q, \le y_q)$：严格 $O(N)$ 空间构造

这是整个在线体系最具智慧的核心。如果为每个前缀建立静态数组，空间将膨胀为 $O(N^2)$。
Brodal 等人引入**密集（Dense）与稀疏（Sparse）分解**：
- 定义：若当前点集中满足 $x \le x_q$ 的点数不超过查询结果总数的 2 倍，则称该查询是密集的；
- 只有在查询密集时，顺序扫描数组才能保证 $O(\text{out})$ 的扫描量；
- 通过递归地将稀疏点集（长尾非关键点）剥离为独立前缀数组 $P_0, P_1, \dots$，剩余密集主体保留在 $S_i$ 中；
- 势能收费证明：每次剥离的点数至少为原集合的一半，按几何级数收敛，使得所有拼接数组的总空间被严格限制在 $\le 2N$！
- 配合按 $y$ 排序的静态 vEB 二叉树，实现 $O(N)$ 线性空间与 $O(\log_B N + \text{out}/B)$ 最优查询！

### 3.2 三侧查询 $([x_{\min}, x_{\max}], \le y_q)$

- 在主树中按 $x$ 坐标构建完全 vEB 搜索树；
- 每个内部节点 $v$ 维护两个二侧查询结构（分别面向左子树与右子树中全部点）；
- 查询时，定位 $x_{\min}$ 与 $x_{\max}$ 的最低公共祖先（LCA），将三侧问题完美分解为左侧的一个二侧查询与右侧的一个反向二侧查询；
- 每个点仅出现在祖先路径的 $O(\log N)$ 个节点中，总空间为 $O(N \log N)$，查询 I/O 为 $O(\log_B N + \text{out}/B)$。

### 3.3 四侧查询 $([x_{\min}, x_{\max}], [y_{\min}, y_{\max}])$：压缩树高

朴素构造需 $O(N \log^2 N)$ 空间。通过压缩树高，可省去 $\log\log N$ 因子：
- 将高度为 $\frac{1}{2}\log\log N$ 的二叉子树收缩为一个度数为 $\sqrt{\log N}$ 的粗粒度大节点；
- 树的总高度缩减至 $O(\frac{\log N}{\log\log N})$；
- 节点内维护跨分支的三侧结构，总空间成功压缩至 $O(N \frac{\log^2 N}{\log\log N})$，单次查询 I/O 维持在 $O(\log_B N + \text{out}/B)$。

## 四、存储层级全景总结与技术闭环

| 核心问题 | 查询 / 排序传输代价 | 存储空间 | 核心算法与数据结构 |
| :--- | :--- | :--- | :--- |
| **缓存无关排序** | $O(\frac{N}{B}\log_{M/B}\frac{N}{B})$ | $O(N)$ | 惰性漏斗排序（$N^{1/3}$-漏斗归并） |
| **批量二维范围检索** | $O(\text{Sort}(N) + \frac{\text{out}}{B})$ | $O(N)$ | 分发扫描（Distribution Sweeping） |
| **在线二侧范围查询** | $O(\log_B N + \frac{\text{out}}{B})$ | $O(N)$ 最优 | 密集/稀疏几何剥离 + 辅助 vEB 树 |
| **在线三侧范围查询** | $O(\log_B N + \text{out}/B)$ | $O(N \log N)$ | LCA 分解为对偶二侧查询 |
| **在线四侧范围查询** | $O(\log_B N + \text{out}/B)$ | $O(N \frac{\log^2 N}{\log\log N})$ | 粗粒度树高收缩技术 |

## 五、我的理解

::: insight 漏斗与密集分解：以几何收敛战胜存储壁垒
回顾 Lec 7 至 Lec 9 的存储层级旅程，最震撼的方法论是两次“几何级数收敛”的精妙应用：
1. **漏斗排序的缓冲区几何收敛**：通过将中转缓冲区容量设为 $K^{3/2}$，漏斗树在递归向下时以平方根速度急剧微型化，最终使整个递归求和被最大规模的一层死死锚定，抹平了不知道 $M$ 和 $B$ 的鸿沟；
2. **二侧查询的密集剥离几何收敛**：原本可能导致 $O(N^2)$ 空间灾难的冗余子数组，通过每次剥离至少 $1/2$ 的稀疏元素，将空间成本绑定在被丢弃元素的几何衰减序列上，硬生生在连续存储介质中逼出了严格的 $O(N)$ 空间。
这种在不确定性（未知硬件）中寻找“收敛不变量”的数学洞察，是理论计算机科学中无与伦比的美。
:::

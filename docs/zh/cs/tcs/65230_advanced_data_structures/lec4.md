# Lec 4 三维范围搜索与运动数据结构（3D Range Search & Kinetic Data Structures）

> 对应 MIT 6.851 Lecture 4 · 讲师：Erik Demaine · 核心文献：Chazelle & Guibas (1986), Basch, Guibas, Hershberger (SODA 1997 / J. Algorithms 1999)

## TL;DR

- 本讲完成几何数据结构两大前沿：利用分数级联极限将三维正交范围搜索压至 $O(\log n + k)$，以及提出处理连续运动物体的运动数据结构（Kinetic Data Structures, KDS）。
- 三维正交范围搜索通过射线刺穿（Ray-Stabbing）与单侧到双侧区间的分叉映射，在 $O(n \log^3 n)$ 空间下省去两个 $\log$ 因子。
- 运动数据结构建立“证书（Certificate）+ 事件优先队列”范式，定义了响应性、局部性、紧凑性与效率四维评估标准；通过对后代超越次数构造势函数，证明运动堆（Kinetic Heap）在整个运动周期中仅触发 $O(n \log n)$ 次事件。

## 一、三维正交范围搜索与分数级联极限

在第三讲中，分数级联仅在最后一个搜索维度上省去了一个 $\log$ 因子，使 $d$ 维范围搜索达到 $O(\log^{d-1} n + k)$。Chazelle 和 Guibas（1986）展示了如何利用空间换时间，在三维情况下消除两个 $\log$，达成突破性的 $O(\log n + k)$ 查询。

### 1.1 核心分步构造

目标是对轴对齐方盒 $[a_1, b_1] \times [a_2, b_2] \times [a_3, b_3]$ 检索点集。构造分四步逐步消除单侧约束：

1. **第一步：受限二维支配查询 $(-\infty, b_2) \times (-\infty, b_3)$**：
   - 转换为**射线刺穿查询（Ray-Stabbing Query）**：每个点在 $yz$ 平面引出一条向上的垂直射线；查询点 $(b_2, b_3)$ 向左发射水平射线。
   - 利用分数级联思想，将射线构成的面细分，控制每个面的度数为 $O(1)$，使空间几何级数收敛仅增加 $O(n)$。查询仅需对 $b_3$ 做一次二分搜索，然后沿水平线常数步前进，耗时 $O(\text{Search}(b_3) + k)$。
2. **第二步：$[a_1, b_1] \times (-\infty, b_2) \times (-\infty, b_3)$**：
   - 在 $x$ 坐标上建立一维范围树，内部节点维护其子树的第一步结构。
   - 在范围树的层级之间对 $z$ 坐标进行图形式的分数级联，将二分搜索次数压缩为根节点的唯一一次，查询耗时降为 $O(\log n + k)$。
3. **第三步：$[a_1, b_1] \times [a_2, b_2] \times (-\infty, b_3)$**：
   - 在 $y$ 坐标上建树。节点 $v$ 维护分割键 $\text{key} = \max(\text{left}(v))$。
   - **单侧到双侧分叉技术**：在节点 $v$ 处存储右子树的第二步结构，以及左子树的反转第二步结构（支持 $(a_2, \infty)$ 查询）。
   - 查询时沿树下行至分叉点，只需并发查询左右两个第二步结构，即可拼装成双侧闭区间 $[a_2, b_2]$！
4. **第四步：$[a_1, b_1] \times [a_2, b_2] \times [a_3, b_3]$**：
   - 对 $z$ 坐标对称实施第三步的分叉，最终达成 $O(\log n + k)$ 查询时间，空间代价为 $O(n \log^3 n)$。

::: theorem 多维正交范围搜索极限
对于 $d \ge 3$ 维正交范围搜索，可在 $O(n \log^d n)$ 空间内实现 $O(\log^{d-2} n + k)$ 查询时间。然而该方法受限于几何相交复杂度，无法在四维及以上继续通过刺穿省去额外的 $\log$。
:::

## 二、运动数据结构框架（Kinetic Data Structures, KDS）

在计算机动画、物理仿真与机器人规划中，几何对象随时间连续运动（例如车辆、粒子）。传统离散采样的“时间步进（Time-Stepping）”方法若步长太小则浪费算力，步长太大则丢失碰撞事件。

Basch、Guibas 和 Hershberger（1999）创立了 KDS 框架：**用数据结构记录当前拓扑，仅在发生可能改变结构合法性的离散事件时才进行修复**。

### 2.1 证书（Certificates）与事件队列

1. **当前数据结构**：维护当前时刻有效的数据拓扑（如平衡树、凸包、Delaunay 三角剖分），查询立即可达。
2. **证书集合**：一组关于对象几何位置的布尔断言（如点 $A$ 在点 $B$ 左侧），只要所有证书均保持为真，当前数据结构的组合拓扑就严格正确。
3. **失效时间计算**：根据已知的对象运动轨迹方程 $f_i(t)$，联立求解证书失效的最早未来时间 $t_{\text{fail}}$。
4. **全局事件队列**：将所有证书失效时间放入优先队列中。时间推进时，连续取出失效证书并局部修复数据结构与证书，直到当前物理时间。

### 2.2 评估 KDS 的四大品质准则

::: definition KDS 性能评价准则
- **响应性（Responsiveness）**：单次证书失效发生时，局部更新数据结构与维护事件队列的最坏情况耗时。理想目标为 $O(\text{polylog } n)$。
- **局部性（Locality）**：单个几何对象最多同时参与多少个证书。保证当某物体突然改变运动轨迹时，重算受影响证书的开销很小。理想目标为 $O(1)$ 或 $O(\text{polylog } n)$。
- **紧凑性（Compactness）**：系统在任意时刻维护的活动证书总数。理想目标为 $O(n)$。
- **效率（Efficiency）**：系统触发的数据结构内部事件总数与外部几何属性“必须改变的次数”之比。若比值为 $O(1)$ 或 $O(\log n)$，说明几乎没有内部无效震颤。
:::

## 三、运动排序与运动前驱（Kinetic Predecessor）

- **数据组织**：用一棵平衡 BST 维护 $n$ 个运动元素在中序遍历下的全序关系 $x_1(t) \le x_2(t) \le \dots \le x_n(t)$。
- **证书定义**：仅需维护相邻元素的大小顺序：
  $$
  C_i: x_i(t) \le x_{i+1}(t) \quad (1 \le i \le n-1)
  $$
- **性能评估**：
  - **紧凑性**：恰好 $n-1$ 个证书，空间 $O(n)$；
  - **局部性**：每个元素仅与左右邻居形成证书，局部性至多为 2；
  - **响应性**：相邻元素次序颠倒时，在 BST 中交换位置并更新常数个优先队列事件，耗时 $O(\log n)$；
  - **效率**：在有界度数多项式运动模型下，每对元素最多交叉常数次，内部事件总数与外在顺序变更总数均为 $O(n^2)$，效率达到最优的 $O(1)$！

## 四、运动堆与势函数分析（Kinetic Heap）

在运动场景下实时追踪最小值（Find-Min）。如果直接维护有序数组，更新代价过大。da Fonseca 和 de Figueiredo（2003）设计了运动二叉堆。

### 4.1 堆结构与证书

- 采用普通二叉堆拓扑。
- **证书定义**：对于每个非根节点 $x$ 及其父节点 $p(x)$，维护证书：
  $$
  C_x: \text{key}(p(x), t) \le \text{key}(x, t)
  $$
  证书总数为 $n-1$。当某证书失效时，说明子节点键值超过了父节点，执行一次单步上浮（Heap-up）交换。

### 4.2 势函数分析：为何总事件数仅为 $O(n \log n)$？

若父子交换后引发连锁震荡，事件数会失控吗？通过引入势函数证明总事件数有严格上界。

::: theorem 运动堆事件总数定理
对于按线性轨迹运动的 $n$ 个元素，运动堆在整个时间轴上触发的内部交换事件总数至多为 $O(n \log n)$。
:::

**证明思路**：
定义全系统势函数 $\Phi(t) = \sum_{x} \Phi(t, x)$，其中 $\Phi(t, x)$ 表示节点 $x$ 的后代中在未来时刻会超过 $x$ 的元素个数。
1. **势函数上界**：任何时刻，$\Phi(t, x)$ 不超过 $x$ 的总后代数。对所有节点求和，$\Phi(t) \le \sum_x \text{descendants}(x) = O(n \log n)$。
2. **事件单调消耗**：当节点 $y$ 在时刻 $t$ 超过其父节点 $x$ 并交换位置时，代入代数展开：
   $$
   \Phi(t^+, x) + \Phi(t^+, y) \le \Phi(t, x) + \Phi(t, y) - 1
   $$
   其他节点的后代关系保持不变，因此全系统总势能**严格减少至少 1**！
3. 由于 $\Phi(t) \ge 0$，系统在整个物理演化过程中发生的总事件数必然受限于初始总势能 $O(n \log n)$！
4. 外在最小值的必要变更次数至少为 $\Omega(n)$，故运动堆的效率为 $O(n \log n) / \Omega(n) = O(\log n)$。

## 五、高级运动几何结构结果概览

| 几何问题 | 证书数量（紧凑性） | 响应时间 | 效率比率 | 关键技术机制 |
| :--- | :--- | :--- | :--- | :--- |
| **运动排序 / 前驱** | $O(n)$ | $O(\log n)$ | $O(1)$ 最优 | 相邻中序证书链 |
| **运动二叉堆 (Min)** | $O(n)$ | $O(\log n)$ | $O(\log n)$ | 势函数追踪未来逆序对 |
| **二维运动凸包** | $O(n)$ | $O(\log n)$ | $O(n^\varepsilon)$ | 极端支撑线证书 |
| **运动 Delaunay 剖分** | $O(n)$ | $O(\log n)$ | $O(1)$ | 局部外接圆空球证书与对角线翻转 |

## 六、我的理解

::: insight 运动数据结构是“时间连续性”向“拓扑不变性”的离散投射
现实世界的运动是连续的，但在数据结构眼中，**连续的数值变化根本不重要，只有关系表达式的真值翻转（拓扑跃迁）才具有计算意义**。
KDS 的哲学在于：
1. 它用一组代数证书编织了一张“拓扑防护网”；
2. 只要物理运动在安全边界内漫步，CPU 可以完全休眠，达到 $O(0)$ 的惊人常态开销；
3. 当且仅当某一根安全警报线（证书）被踩断时，才精准执行一次针对局部的微创手术。
运动堆利用“后代超越势函数”证明 $O(n \log n)$ 总事件数的技巧，更是将对未来可能性的组合计数压缩为可微减的 Lyapunov 能量函数，是静态势能分析法在时变动力系统中的登峰造极之作。
:::

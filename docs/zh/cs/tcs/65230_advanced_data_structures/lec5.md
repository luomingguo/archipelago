# Lec 5 动态最优性：二叉搜索树的几何视角（Dynamic Optimality: Geometric View of Binary Search Trees）

> 对应 MIT 6.851 Lecture 5 · 讲师：Erik Demaine · 核心文献：Sleator & Tarjan (JACM 1985), Demaine et al. (FOCS 2009 / SICOMP 2011)

## TL;DR

- 探讨计算机科学核心未解之谜：是否存在一个在线二叉搜索树（BST），其在任意访问序列上的代价与离线全知最优 BST（$\text{OPT}$）相比仅相差 $O(1)$ 常数因子。
- 梳理动态最优性的必要解析性质谱系：顺序访问性质、静态最优性（熵界）、工作集性质（Working Set）、动态手指性质（Dynamic Finger）以及统一性质（Unified Bound）。
- 建立 BST 运行的几何等价模型：将搜索序列转化为二维点集，证明合法的 BST 旋转执行等价于点集的树形满足性（Arborally Satisfied Property），将树旋转的动态过程升华为求最小满足闭包的纯组合几何问题。

## 一、二叉搜索树作为计算模型

传统的平衡二叉搜索树（如 AVL 树、红黑树）在最坏情况下达到 $O(\log n)$ 单次查询时间，这在对抗性模型下是渐近最优的。然而在实际工业负载中，访问往往呈现高度局部性或非均匀性（例如重复访问相同键、按序扫描、局部局部集中访问）。

为了研究“能否根据访问序列自适应达到最优”，我们将 BST 抽象为受限的指针机计算模型：
1. **拓扑约束**：数据存储在二叉搜索树的节点中，键值严格满足二叉搜索性质。
2. **单位代价原语**：
   - 沿指针移动：访问左孩子、右孩子或父节点；
   - 结构变动：对某个节点 $x$ 执行单旋转（Rotate）。
3. **查询过程**：`Search(x)` 必须从当前根节点出发，在经过若干步指针移动和旋转后访问到键 $x$。
4. **度量指标**：处理访问序列 $X = (x_1, x_2, \dots, x_m)$ 的总操作步数。离线最优代价记为 $\text{OPT}(X)$。

## 二、解析性质谱系：从静态最优到动态最优

动态最优性要求算法能够自适应匹配任何潜在规律。学者们提出了由弱到强的一系列解析性质作为其检验标尺：

1. **顺序访问性质（Sequential Access Property）**：
   顺序访问集合元素 $\{1, 2, \dots, n\}$ 的总均摊代价应为每次 $O(1)$。
2. **静态最优性 / 熵界（Static Optimality / Entropy Bound）**：
   设元素 $k$ 出现的经验概率为 $p_k$。单次搜索的均摊代价不超过香农熵（Shannon Entropy）：
   $$
   O\left(1 + \sum_{k=1}^n p_k \log \frac{1}{p_k}\right)
   $$
   这代表了任意静态固定拓扑树所能达到的信息论极限。
3. **工作集性质（Working Set Property）**：
   若自元素 $x_i$ 上次被访问以来，一共有 $t_i$ 个不同的互异键被访问过，则本次访问的均摊代价为 $O(\log(t_i + 1))$。这保证了时间局部性（Temporal Locality）。
4. **动态手指性质（Dynamic Finger Property）**：
   若连续两次访问的键值为 $x_{k-1}$ 与 $x_k$，均摊代价为 $O(\log(|x_k - x_{k-1}| + 1))$。这保证了空间局部性（Spatial Locality）。
5. **统一性质（Unified Property, Iacono 2001）**：
   均摊代价为 $O(\log(\min_{j < k}(|x_k - x_j| + t_{j,k} + 2)))$，同时统摄了工作集与动态手指性质。
6. **动态最优性猜想（Dynamic Optimality Conjecture）**：
   算法 $A$ 对任意序列 $X$ 均满足 $\text{Cost}_A(X) \le O(\text{OPT}(X)) + O(n)$。动态最优性自然蕴含上述所有解析性质。

## 三、伸展树（Splay Tree）及其性质

Sleator 和 Tarjan 于 1985 年提出的**伸展树（Splay Tree）**是动态最优性最著名的候选者。

### 3.1 核心操作机制：双旋策略

每次访问节点 $x$ 后，通过自底向上的伸展（Splaying）将 $x$ 旋转至根节点。关键在于根据父节点 $p$ 和祖父节点 $g$ 的相对方向采用双旋：
- **zig-zig 操作**（$x$ 和 $p$ 同向）：**先旋转父节点 $p$，再旋转当前节点 $x$**。
- **zig-zag 操作**（$x$ 和 $p$ 反向）：连续对 $x$ 执行两次旋转。
- **zig 操作**（$p$ 为根）：对 $x$ 做一次单旋。

先旋父节点而非朴素的连续旋子节点（Move-to-Root）是伸展树能够均摊树高的灵魂所在：zig-zig 能够将整条访问路径的深度减半，而朴素单旋只会将其他节点推得更深。

### 3.2 伸展树的理论地位

- 已严格证明满足：顺序访问定理、静态最优性、工作集性质，以及极其复杂的动态手指性质（Cole et al. 2000）。
- **未解之谜**：伸展树是否满足统一性质？是否是动态最优的？

## 四、BST 执行的几何视角与树形满足性

Demaine 等人（2009）提出了颠覆性的几何化工具，将复杂的树旋转操作彻底转换为二维几何点集问题。

### 4.1 几何映射建立

- 构建二维平面：水平 $x$ 轴为键值空间 $\{1, \dots, n\}$，垂直 $y$ 轴为离散时间轴 $\{1, \dots, m\}$。
- 输入访问序列映射为 $m$ 个点：$P_{\text{input}} = \{(x_i, i) \mid 1 \le i \le m\}$。
- 若算法在处理第 $i$ 次访问时，访问或旋转了树中的节点 $y$（触及点），则在平面上对应打下一个点 $(y, i)$。
- 算法的总操作代价与平面上的总点数在常数因子意义下等价。

### 4.2 树形满足性（Arborally Satisfied Property, ASSP）

::: definition 树形满足点集
平面点集 $P$ 称为树形满足的（Arborally Satisfied），当且仅当对于 $P$ 中任意不在同一水平或垂直线上的两点 $a = (x_1, y_1)$ 与 $b = (x_2, y_2)$，由 $a$ 和 $b$ 作为对角线构成的闭轴对齐矩形内部或边界上，**必须存在属于 $P$ 的第三个点** $c \notin \{a, b\}$。
:::

::: theorem 几何等价主定理（Demaine et al. 2009）
包含输入点集 $P_{\text{input}}$ 的点集 $P$ 是树形满足的，**当且仅当**存在一个合法的离线 BST 算法，其在处理输入序列时的触及点集合恰好为 $P$。
:::

**推论**：求解离线最优二叉搜索树 $\text{OPT}(X)$，严格等价于求解包含输入点集 $P_{\text{input}}$ 的**最小树形满足超集（Minimum Arborally Satisfied Superset）**！

```text
     时间 y ▲
            │       a (x1, y1)
            │        ┌──────────────┐
            │        │   点 c (必须存在)
            │        │              │
            │        └──────────────┘
            │                       b (x2, y2)
            └──────────────────────────────────► 键值 x
```

## 五、贪心算法与在线等价转换

几何视角启发了一个极其优雅的在线候选算法——**贪心算法（Greedy Algorithm）**：
1. 沿时间轴逐行向上扫描；
2. 在时刻 $t$，根据已有历史点集，贪心地添加最少数量的点，使得当前行与先前所有行构成的点集满足树形满足条件。

::: theorem 在线几何向在线 BST 的保常数转换
若存在一个在线算法能在平面上维护树形满足点集并在总点数上达到 $O(\text{OPT})$，则利用**分裂树（Split Tree）**结构，可以在时间仅慢 $O(1)$ 常数因子的前提下，将其转换为一个严格合法的在线 BST 算法。
:::

这意味着，如果我们能证明贪心算法的点集扩张倍数是 $O(1)$，那么动态最优性猜想将被彻底证明！

## 七、我的理解

::: insight 几何对偶将因果拓扑坍缩为全局空间约束
动态二叉搜索树的研究在几何视角出现之前陷入了长达二十年的泥潭：人们试图用复杂的局部旋转势能函数去对抗无穷无尽的动态树拓扑变化。
Demaine 等人的几何化工作展示了理论计算机科学最震撼的洞察力：
1. **时间不是一维流动的因果，而是空间的第二维度**。
2. 树上所有复杂的祖先-后代、LCA、旋转与穿越关系，在时空二维图上全部坍缩为一个极其简洁的局部正交约束——**任意空矩形内部必须有支撑点**。
3. 动态搜索树的算法设计，因此从“维护树的高度”升维为“二维点集的无空腔覆盖”。这种对偶性不仅孕育了 Tango 树与贪心算法，更向我们揭示：数据结构的本质就是高维约束在低维物理介质上的投影。
:::

# 理论计算机科学

## TL;DR

- 本目录聚焦计算机科学的数学基础、算法设计与复杂性分析，不只收集课程文件，也强调证明链和方法选择。
- 建议先学「计算机科学的数学」，掌握证明、渐近分析、图论、计数和概率，再进入「算法导论」。
- 当前两门课均以 MIT OpenCourseWare 的视频 transcript 为讲授脉络，并整合官方 lecture notes 中的定义、定理与证明条件。

## 待扩展方向

算法设计与分析、高级算法、高级数据结构和分布式算法尚未建立可校验的课程笔记，因此暂不创建空链接或占位课程页。

## 我的理解

::: insight
理论计算机科学的学习顺序不宜完全按课程边界切开：证明、渐近分析和图论是算法课中反复使用的工具。先建立这些共同语言，再学习具体算法，能把“记住解法”转化为“自己推出解法”。
:::

# Lec 4 着色下界

> 对应 DGA 第 1.2.2 节（有根树/有向路径）与第 1.3.1 节（无根树） · 延伸阅读：Linial (1992)、Laurinharju–Suomela (LS14)

## TL;DR

- Linial 定理证明在长度为 $n$ 的有向路径上进行 3-着色至少需要 $\tfrac12\log^* n - O(1)$ 轮，确立了 $O(\log^* n)$ 上界的紧确性。
- 下界论证通过将局部算法抽象为相邻 ID 窗口上的多元着色映射，利用组合降维或超图 Ramsey 理论诱导指数级颜色膨胀矛盾。
- 在无根树上，节点缺失父指针导致局部信息大幅弱化；借助高围长图在局部与树不可区分的性质，证明 $o(\Delta/\log\Delta)$-着色至少需 $\Omega(\log_\Delta n)$ 轮。

## 1. 本讲要回答的核心问题

Lec 1 给出了有根树 3-着色的 $O(\log^* n)$ 上界。本讲证明它**本质最优**——即便在最受限的有向路径上，也需要约 $\tfrac12\log^* n$ 轮。这是分布式计算里第一个、也是最经典的局部性下界，由 Linial 提出。

随后转向**无根树**：当节点不知道哪个邻居是父亲时，局部信息变弱，我们证明 $o(\log_\Delta n)$ 轮内无法用少于 $\Omega(\Delta/\log\Delta)$ 色着色。

## 2. 有向路径 3-着色的下界

> **定理 1.7.** 任何对长度 $\le n$、ID 取自 $\{1,\dots,n\}$ 的有向路径做 3-着色的确定性算法，至少需 $\tfrac{\log^* n}{2}-2$ 轮。即便 ID 沿路径单调排列，下界仍成立。

**思路.** 反设存在 $t<\tfrac{\log^* n}{2}-2$ 轮的算法 $A$。$t$ 轮内节点 $v$ 至多看到自己前后各 $t$ 跳、共 $k=2t+1$ 个 ID 的向量。于是 $A$ 诱导一个“把 ID 向量映射到颜色”的函数，且相邻向量须异色。把这一对象形式化：

::: definition $k$ 元 $q$-着色（$k$-ary $q$-coloring）
函数 $B$ 称为 $k$ 元 $q$-着色，若对任意 $1\le a_1<a_2<\cdots<a_{k+1}\le n$：
1. **取值界**：$B(a_1,\dots,a_k)\in\{1,\dots,q\}$；
2. **相邻异色**：$B(a_1,\dots,a_k)\ne B(a_2,\dots,a_{k+1})$（相邻“窗口”异色）。
:::

> **观察 1.9.** 若存在 $t<\tfrac{\log^* n}{2}-2$ 轮的 3-着色算法 $A$，则存在 $k$ 元 3-着色 $B$，$k=2t+1<\log^* n-3$。
>
> *构造：* 在一段 ID 恰为 $a_1,\dots,a_k$ 的虚拟路径上模拟 $A$，取节点 $a_{t+1}$ 所得色作 $B(a_1,\dots,a_k)$。若性质 2 被违反，则 $A$ 给某虚拟路径上相邻两点同色，矛盾。

### 2.1 两条降维引理

> **引理 1.10.** 不存在 $q<n$ 的 1 元 $q$-着色。
> （1 元着色要求 $B(a_1)\ne B(a_2)$ 对所有 $a_1<a_2$，鸽笼原理迫使 $q\ge n$。）

> **引理 1.11.** 若存在 $k$ 元 $q$-着色 $B$，则存在 $(k-1)$ 元 $2^q$-着色 $B'$。
>
> **证明.** 令 $B'(a_1,\dots,a_{k-1})=\{\,i\in\{1,\dots,q\}:\exists a_k>a_{k-1},\,B(a_1,\dots,a_{k-1},a_k)=i\,\}$，是 $\{1,\dots,q\}$ 的子集，故 $B'$ 取值于 $2^{\{1,\dots,q\}}$（共 $2^q$ 个值，满足性质 1）。验证性质 2：若 $B'(a_1,\dots,a_{k-1})=B'(a_2,\dots,a_k)$，取 $q^*=B(a_1,\dots,a_k)\in B'(a_1,\dots,a_{k-1})$，则 $q^*\in B'(a_2,\dots,a_k)$，即存在 $a_{k+1}$ 使 $B(a_2,\dots,a_{k+1})=q^*=B(a_1,\dots,a_k)$，与 $B$ 是 $k$ 元着色矛盾。$\square$

### 2.2 合成证明

**定理 1.7 的证明.** 由观察 1.9 得 $k$ 元 3-着色，$k<\log^* n-3$。反复用引理 1.11：
$$3\text{-色}\xrightarrow{\ 2^{(\cdot)}\ }8\text{-色}\to2^8\text{-色}\to\cdots$$
每次指标 $k$ 减 1、颜色数变为 $2^{(\cdot)}$。$k<\log^* n-3$ 次迭代后到 1 元、颜色数 $<n$，与引理 1.10 矛盾。故算法不存在。$\square$

> **直觉：** 颜色数的“塔状指数”增长恰好被 $\log^*$ 抵消——每轮算法只能把“塔”削掉一层，而把任意 ID 着 3 色需要的“塔高”是 $\log^* n$，于是至少 $\sim\tfrac12\log^* n$ 轮。

### 2.3 Ramsey 理论的替代证明

完全 $k$ 阶超图用 3 色染超边时，只要 $n\ge n_0$（其中 $k=O(\log^* n_0)$），必有大小 $k+1$ 的单色团，即存在 $a_1<\cdots<a_{k+1}$ 使 $\{a_1,\dots,a_k\}$ 与 $\{a_2,\dots,a_{k+1}\}$ 同色——直接违反性质 2。于是 Ramsey 定理排除了 $o(\log^* n)$ 轮的 3-着色算法。

### 2.4 推广到随机算法

::: theorem 推论 1.12（随机着色下界）
不存在能在 $<\tfrac{\log^* n}{2}-3$ 轮内、以概率 $1-\tfrac{1}{2n}$ 给长度 $\le n$ 有向路径 3-着色的随机算法。

*证明草图（去随机化）：* 设有这样的随机算法 $R$，在 $\sqrt n\cdot n/n'$ 条长度 $\le n'=\log n$ 的路径上跑它；对每个 ID 排列，失败的随机串占比 $\le 1/2^{n'+1}$。对全部 $\le 2^{n'}$ 种排列做并集界，存在一个随机串对所有排列都不失败——把它固定下来即得一个确定性算法，与定理 1.7 矛盾。
:::

## 3. 无根树着色的下界

有根树的 $O(\log^* n)$ 算法重度依赖“每个节点知道父亲”。若是**无根树**（节点分不清哪个邻居是父亲），局部信息显著变弱：

> **定理 1.13.** 任何用少于 $o(\Delta/\log\Delta)$ 色给最大度 $\Delta$ 的 $n$ 节点树着色的确定性算法，轮复杂度至少 $\Omega(\log_\Delta n)$。

证明用到一个图论存在性结果（概率方法）：

> **事实 1.14（Bollobás 1978）.** 存在无穷多 $n$ 节点 $\Delta$-正则图族 $H^*$，围长 $g(H^*)=\Omega(\log_\Delta n)$ 且色数 $\chi(H^*)=\Omega(\Delta/\log\Delta)$。

**定理 1.13 的证明（不可区分性论证）.** 反设有算法 $A$ 在 $o(\log_\Delta n)$ 轮内用 $o(\Delta/\log\Delta)$ 色给任意树着色。把 $A$ 跑在 $H^*$ 上：因 $g(H^*)=\Omega(\log_\Delta n)$，任一节点 $v$ 的 $o(\log_\Delta n)$ 跳邻域是一棵树 $T_v$，故 $v$ **无法察觉**自己其实不在树上，会照常输出。若 $A$ 给 $H^*$ 中某相邻 $u,v$ 同色，则在 $T_v$ 上跑 $A$ 也会非法——矛盾于 $A$ 在树上正确。因此 $A$ 实际给出了 $H^*$ 的 $o(\Delta/\log\Delta)$-着色，与 $\chi(H^*)=\Omega(\Delta/\log\Delta)$ 矛盾。$\square$

> **直觉：** “高围长 = 局部看像树”。在小半径内 $H^*$ 与树无从区分，于是树上的快算法被迫也给非树图正确着色，但 $H^*$ 的色数硬性下界使这不可能。

## 4. 本讲小结与下界技术对比

| 设定 | 结论 | 下界技术 |
|---|---|---|
| 有向路径 3-着色（确定性） | $\ge\tfrac12\log^* n-O(1)$ 轮 | $k$ 元着色降维 / Ramsey |
| 有向路径 3-着色（随机） | $\ge\tfrac12\log^* n-O(1)$ 轮 | 去随机化 + 并集界 |
| 无根树 $o(\Delta/\log\Delta)$-着色 | $\ge\Omega(\log_\Delta n)$ 轮 | 高围长图不可区分性 |

两类核心论证：**降维 / 不动点**（把 $t$ 轮算法压成对邻域的函数，再做组合学矛盾）与**不可区分性**（高围长图局部像树，骗过快算法）。它们是分布式下界的两大支柱。

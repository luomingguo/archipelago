# Lec 7 网络分解：确定性构造

> 对应 DGA 第 1.5.4 节（多项式对数时间确定性构造） · 延伸阅读：Panconesi–Srinivasan (STOC 1992)、Rozhoň–Ghaffari (STOC 2020)

## TL;DR

- Rozhoň 与 Ghaffari（RG20）在 STOC 2020 取得了里程碑突破，首次在多项式对数时间 $O(\log^8 n)$ 内确定性构造强直径网络分解。
- 核心发动机是聚类引理（Clustering Lemma）：通过 $O(\log n)$ 个阶段逐位对齐节点标号后缀，每阶段消除一半存活节点的蓝-红边界。
- 蓝簇扩张与边界清除机制同时维持了簇分离性、多项式对数低半径与死亡节点受限三条不变量，成为分布式去随机化的通用引擎。

## 1. 本讲要回答的核心问题

Lec 6 给出了**随机** $O(\log n)$ 轮的网络分解。一个长期开放的难题是：**能否确定性地、在 $\mathrm{poly}(\log n)$ 轮内**构造网络分解？

这极其重要——因为网络分解是通用归约器，确定性 $\mathrm{poly}(\log n)$ 分解将立刻给出 $(\Delta+1)$-着色、MIS 等一大批问题的首个确定性 $\mathrm{poly}(\log n)$ 算法（也是分布式去随机化的基石）。

- **旧结果（PS92 / ALGP89）：** 仅达到**亚多项式** $2^{O(\sqrt{\log n})}$ 时间，未到多项式对数。
- **RG20 突破：** 首个确定性 $\mathrm{poly}(\log n)$ 构造。本讲聚焦于此。

## 2. 主结果

> **定理 1.43.** 存在确定性 LOCAL 算法，在 $O(\log^8 n)$ 轮内算出任意 $n$ 节点图的 $(C,D)$ 强直径网络分解，$C=O(\log n)$，$D=O(\log n)$。

为聚焦核心，证明一个看似更弱、但对多数应用（着色、MIS）已足够的版本：

> **定理 1.44.** 存在确定性 LOCAL 算法，在 $O(\log^7 n)$ 轮内算出 $(C,D)$ 弱直径网络分解，$C=O(\log n)$，$D=O(\log^3 n)$。

定理 1.44 由对**聚类引理**迭代 $c=\log n$ 次得到——每次迭代给出网络分解中“一种颜色”的簇。

## 3. 聚类引理（Clustering Lemma）

> **引理 1.45.** 给定 $n$ 节点图 $G$，每节点有唯一 $b=O(\log n)$ 位 ID，及一个“存活”节点集 $S\subseteq V$。存在确定性算法在 $O(\log^6 n)$ 轮内找出子集 $S'\subseteq S$，满足 $|S'|\ge|S|/2$，且 $G[S']$ 被划分为**互不相邻**的簇，每簇在 $G$ 中弱直径 $O(\log^3 n)$。

**从引理到定理 1.44：** 从 $S=V$ 起迭代 $c=\log n$ 次，第 $j$ 次的 $S'$ 即网络分解中颜色 $j$ 的簇，然后令 $S\leftarrow S\setminus S'$。每次至少聚类掉一半存活节点，故 $\log n$ 次后全部聚类，得 $C=O(\log n)$、$D=O(\log^3 n)$。

## 4. 聚类引理的算法

构造分 $b=O(\log n)$ 个 **phase**（对应 ID 的位数）。

- 初始所有 $S$ 节点存活；过程中部分存活节点会“死亡”。
- 用 $S_i'$ 记第 $i$ phase 开始时的存活集，$S'=S_b'$ 为最终存活集。
- 每个存活节点 $v$ 带一个 $b$ 位**标号** $\ell(v)$，初始 $=v$ 的 ID。标号相同的存活点构成一个簇 $S_i'(L)=\{v\in S_i':\ell(v)=L\}$。

### 4.1 三条不变量

对每个 phase $i\in[0,b-1]$ 维持：

::: theorem 不变量 (I) 分离性
对每个 $i$ 位后缀 $Y$，标号以 $Y$ 结尾的存活点集 $S_i'(Y)$ 与其余存活点 $S_i'\setminus S_i'(Y)$ **无边相连**——即 $S_i'(Y)$ 是 $G[S_i']$ 若干连通分量之并。
:::

::: theorem 不变量 (II) 低半径
每个簇 $S_i'(L)$ 弱半径 $\le iR$，其中 $R=O(\log^2 n)$。（簇在存活诱导子图里可以是断开的。）
:::

::: theorem 不变量 (III) 控制死亡量
$$|S_{i+1}'|\ge|S_i'|\,(1-\tfrac{1}{2b}).$$
:::

**三条不变量如何蕴含引理 1.45：**
- (I) ⇒ $b$ phase 后不同簇互不相邻；
- (II) ⇒ 每簇弱半径 $bR=O(\log^3 n)$；
- (III) ⇒ $|S'|=|S_b'|\ge(1-\tfrac1{2b})^b|S|\ge|S|/2$。

### 4.2 一个 phase 的目标

固定第 $i$ phase 与某 $i$ 位后缀 $Y$，看 $S_i'(Y)$。按标号第 $(i+1)$ 低位把节点分两类：
- **蓝色**：标号形如 $(\ast\cdots\ast\,0\,Y)$；
- **红色**：标号形如 $(\ast\cdots\ast\,1\,Y)$。

本 phase 中，让少量红点死亡、让其余部分红点改成蓝标号（变蓝）；蓝点始终存活、保持标号。**目标**：phase 结束时存活点中不存在蓝–红边，于是每个连通分量要么全蓝要么全红，公共后缀长度 $+1$，从而进入下一 phase 的不变量 (I)。同时每个 $S_i'(Y)$ 中至多死 $|S_i'(Y)|/2b$ 个红点，保证 (III)。

### 4.3 一个 phase 的步骤

每 phase 含 $R=10b\log n=O(\log^2 n)$ 步，每步用 $O(\log^3 n)$ 轮实现（蓝簇半径 $\le O(\log^3 n)$，可在簇内汇总信息）。故一 phase 为 $O(\log^5 n)$ 轮，全部 $O(\log n)$ 个 phase 共 $O(\log^6 n)$ 轮（与引理陈述一致）。

每步：每个红点向某个相邻蓝簇**请求加入**（采纳其标号）。对每个蓝簇 $A$：
1. 若请求加入 $A$ 的相邻红点数 $\le|A|/2b$：$A$ **拒绝全部**，这些被拒红点死亡；$A$ 本 phase 就此**停止**，不再参与后续步。
2. 若 $>|A|/2b$：$A$ **接纳全部**，这些红点改成 $A$ 的蓝标号；$A$ 半径至多增长一跳。

> 每个红点独立行动（同红簇的点彼此无关），故红簇可能收缩、断裂甚至消失；而一旦节点变蓝就保持蓝标号，故蓝簇只增不减。

### 4.4 分析（维持不变量）

> **观察 1.46.** 任何蓝簇至多 $4b\log n$ 步后停止。
> *证明：* 每个不停止的步使 $|A|$ 增长 $\ge(1+\tfrac1{2b})$ 倍；$4b\log n$ 步后将超过 $(1+\tfrac1{2b})^{4b\log n}>n$，不可能。$\square$

> **观察 1.47.** 蓝簇 $A$ 一旦停止，便与红点无边，且本 phase 内永不再有。**这蕴含不变量 (I)。**
> *证明：* 停止那步中，每个相邻红点要么请求加入 $A$（被拒后死亡）、要么请求加入别的蓝簇（变蓝或死亡）；无论哪种都不再是存活红点，此后 $A$ 不增不减。$\square$

> **观察 1.48.** 每步蓝簇半径至多 $+1$、红簇半径不增。**这蕴含不变量 (II)。**

::: theorem 观察 1.49（死亡节点上限）
本 phase 中 $S_i'(Y)$ 内死亡的红点总数 $\le|S_i'(Y)|/2b$。**这蕴含不变量 (III)。**

*证明：* 由观察 1.47，每个蓝簇 $A$ 恰停止一次，停止时它有 $|A|$ 个点，至多使 $|A|/2b$ 个红点死亡。对全 phase 求和，死亡红点数 $\le\tfrac{1}{2b}\times(\text{停止的蓝簇总点数})\le|S_i'(Y)|/2b$。
:::

三条观察证明了构造维持 (I)–(III)，从而完成引理 1.45 的证明。

> **直觉：** 把“消除蓝–红边界”逐位完成。每 phase 处理一个比特：蓝簇要么“吃掉足够多红点而长大”，要么“主动停止并清空边界（让边界红点死亡）”。停止条件 $|A|/2b$ 同时控制了两件事——大小指数增长不可能太久（观察 1.46），死亡总量受限（观察 1.49）。比特逐位对齐，$b$ 个 phase 后所有相邻簇后缀一致，自然分离。

## 5. 与旧构造对比

| 构造 | 类型 | 轮数 | 参数 $C,D$ |
|---|---|---|---|
| ALGP89 / PS92 | 确定性 | $2^{O(\sqrt{\log n})}$ ~ $2^{O(\sqrt{\log n\log\log n})}$ | 亚多项式 |
| Lec 6 随机构造 | 随机 | $O(\log n)$ | $O(\log n),O(\log n)$ |
| RG20（本讲） | 确定性 | $O(\log^7 n)$（弱）/ $O(\log^8 n)$（强） | $O(\log n),O(\log^3 n)$ |

旧构造（球生长 + 标尺集）受限于 $2^{O(\sqrt{\log n})}$，差距正是 RG20 用上述“逐位消界”思想填平的。

## 6. 本讲小结与理论突破

RG20 的确定性 $\mathrm{poly}(\log n)$ 网络分解，核心是**聚类引理**：通过 $b=O(\log n)$ 个 phase 逐位对齐标号后缀，每 phase 用“蓝簇增长 / 停止清界”机制消除蓝–红边界，三条不变量分别保证最终的分离性、低直径与高存活率。

它的意义超出网络分解本身：作为分布式去随机化的通用引擎，它把许多此前只有随机算法的局部问题（着色、MIS 等）一举带入确定性 $\mathrm{poly}(\log n)$ 时代。

# 计算机安全

这里按“先建立安全思维，再深入密码协议”的顺序整理 MIT 的两门安全课程。两门课共享密码学基础，但学习目标不同：6.1600 关注完整系统如何失效与防御，6.5610 关注密码原语为何安全、如何组合。

## 建议路线

1. 先读 [6.1600 计算机安全基础](./foundation_of_security/)，建立威胁模型、认证、隔离、软件安全与隐私的整体框架。
2. 再读 [6.5610 应用密码学与安全](./apply_cryptography/)，深入安全定义、归约、格密码、FHE、MPC、证明系统与 ORAM。
3. 已有密码学基础的读者，可以从 6.5610 的主题地图直接跳到所需原语；做系统安全设计时，则应回到 6.1600 核对信任边界与实现假设。

## 两门课的分工

| 课程 | 核心问题 | 适合读者 |
| --- | --- | --- |
| [6.1600 计算机安全基础](./foundation_of_security/) | 如何定义威胁、构造安全通道、划分权限并减小攻击面？ | 第一次系统学习安全，或需要做安全设计与评审 |
| [6.5610 应用密码学与安全](./apply_cryptography/) | 一个密码方案在什么安全游戏和计算假设下成立？ | 已掌握离散数学与基础密码学，希望理解现代隐私计算 |

::: insight
安全不是原语清单。密码学保护的数据边界、软件实现的内存边界、系统架构的权限边界和用户流程的信任边界，必须在同一威胁模型中闭合。
:::

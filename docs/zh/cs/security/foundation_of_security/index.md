# 6.1600 计算机安全基础（Fall 2026）

> 课程主页：[MIT 6.1600 Foundations of Computer Security](https://61600.csail.mit.edu/2026/)

## TL;DR

- 课程从威胁模型出发，依次连接认证、密码协议、安全架构、隔离、软件安全与隐私。
- 本目录已整理前 20 个主题；每讲使用官方 lecture notes 校准内容，并给出摘要与作者判断。
- 课程录像不是本次笔记的事实来源：2026 录像需要 MIT 登录，抽查到的公开旧录像又没有可用字幕或 transcript。

## 怎么学

如果第一次系统学习安全，建议按顺序阅读。前 11 讲建立密码学与安全通信的语言；L12 以后把这些原语放回真实系统，讨论权限、隔离、供应链、侧信道和内存安全。只为解决具体问题时，可以按下面的主题地图跳读，但仍应先看 [L1 的威胁模型](./lec1.md)。

:::

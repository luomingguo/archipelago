# 6.1600 计算机安全基础（Fall 2026）

> 课程主页：[MIT 6.1600 Foundations of Computer Security](https://61600.csail.mit.edu/2026/)

## TL;DR

- 课程从威胁模型出发，依次连接认证、密码协议、安全架构、隔离、软件安全与现代隐私保护。
- 完整覆盖从密码学原语到系统实现在内的 24 个核心主题，深入分析硬件隔离、差分隐私与私密机器学习。
- 每讲基于官方 lecture notes 与前沿文献校准，配齐核心定义、威胁模型推导与深度作者见解。

## 怎么学

如果第一次系统学习安全，建议按顺序阅读。前 11 讲建立密码学与安全通信的语言；L12 以后把这些原语放回真实系统，讨论权限、隔离、供应链、侧信道和内存安全；最后聚焦现代隐私计算与全课程系统性综合。只为解决具体问题时，可以按下面的主题地图跳读，但仍应先看 [L1 的威胁模型](./lec1.md)。
